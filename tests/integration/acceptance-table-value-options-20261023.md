## 原失败与修复

1. 首次类型检查发现新测试参数的字面量推断错误；修正测试注解，断言保持。
2. 首轮完整单元 66 项失败来自四个旧 AST 夹具未注入新增空引用／真实确认函数；补依赖并继续执行原生产函数，不 stub 成功。
3. 首次 13384 读取拒绝元数据内部非枚举 `unsupportedDesign`。仅公开输出投影枚举字段；前后原定义／身份校验保持，恶意非枚举字段和 getter 继续拒绝。
4. MariaDB 将布尔变量转文本为 `ON`。生产查询先原生数值化再转文本，严格身份仍要求 `1`。前批三个 MySQL 成功不冒充最终六实例结果。
5. 首轮窗口用 CDP 回答 Electron 确认框失败，保留失败，不算正常退出。其后只读进程盘点无 Electron，完整定义与原行核验后清理随机库；最终改用上述明确限定的测试适配器。
6. 一次清理在只读身份端口的字符串／数值严格比较处退出，零删除；改为精确十进制比较后重新核全部事实，才执行本例清理。

原失败批次及各精确清理均独立封存，未自动重跑原用例、复用原期限或取消失败门。
