# 数据提交回执的源码与实库界面验收

2026-10-17，Windows x64。产品与正式用例固定为 `903f953eb6ce11cf05949af7d48e738d53632054`，尚未公开发行。

## 已实现

集中提交绑定单次随机预览编号、连接修订、目标及所展示计划。主进程在派发前持久保存意图；utility进程按真实服务器回应记录目标事务事实，提交确认先于取消和后续收尾。结果区分未发送、已确认提交、已确认目标事务回滚及未知，未知写入不自动重放。

提交记录独立存入本地SQLite，最多200项；未结束或未知项不自动淘汰，容量不足在派发前拒绝。记录只含目标、编号、阶段、计数和固定原因，SQL、参数、行值、值摘要及原错误不进入回执。界面提供本次记录与任务中心查看；恢复时缺少确认的运行记录保守归为未知。

任务中心先订阅事件，再读取主进程内存取消状态。未核验、COMMIT可能已发送或任务终结时不提供取消；迟到读取、旧事件及辅助写盘失败不能恢复取消权限。保留目标InnoDB事务边界，触发器和外部副作用不包含在回滚保证内。

## 纯验证与整合

核心、任务中心重开修复及最终TableTab接线分别独立审查。原重开窗口取消反例在父版失败、新版通过；审查补充迟到快照、StrictMode、卸载及最终写盘失败下的ACK/unknown组合。最终接线逐字保留编辑器生命周期、Undo门及其余函数，仍为消费预览一次、清空历史一次、携同一编号派发一次。生命周期测试夹具仅增加原正式API已有的空事件订阅端口，断言未改。

run1050在HEAD `57fa21a7707153fe96bf1bb9f97dff1c5b34a80e`加已审暂存树上执行：5020项单元全部通过，类型和构建退出0。最终903f953提交树 `8c35339de317baa0e86e6f66167bbc3e89385afe`与该暂存树相同；run1053独立核1237个源码SHA/Git对象及108个dist，原执行HEAD未改写。命名窗口作用域及能力隔离也在这棵整合树中，其新专项界面尚未实际执行。
