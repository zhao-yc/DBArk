# W03 搜索定位键读取权限修复验收（2026-10-15）

状态：0.17开发中。此批修复精确记录导航的权限前置条件，不代表精确记录定位或完整W03已经完成。

## 问题与修复

账号可以对同表不同列拥有不同权限：某列因为INSERT而出现在目录中，却没有SELECT。此前零行描述将所选搜索列与所有候选定位键一起查询，不可读主键可能使整个搜索失败，即使另有可读的唯一键或搜索本来只需要只读预览。

现在先独立验证用户明确选择的字段，再按完整非空唯一键逐组验证附加列。已经验证过的列不重复查询；不可读候选整组弃用，继续寻找可读替代键，不把复合键的前导列当作唯一键。只有服务器明确返回1143/1142（列或表SELECT拒绝）才做此降级；所选字段自身无权限仍失败，断线、取消和其它SQL错误继续传播，不冒充无命中或正常只读结果。整个过程使用原搜索账号，没有高权限补查或重新授权。

没有可读可靠键时，命中保留`keyValues:null`和`key-not-selectable`，界面显示“仅只读：无键列读取权限”，并提供完整文字提示。搜索值、预览和键的既有精度、预算、背压及任务清理边界不变。
