# 页内查找夹具缓存隔离及启动记录验收

## 原失败与证据边界

固定候选 `7db7bfb19133c359eaff741e9d4e986d5c2daa43` 的 CI `38990871270`、attempt 1 已结束为失败。三平台源码阶段各有 72 项通过、277 项跳过；两个 macOS 安装阶段同样通过。Windows 安装阶段有 58 项安装应用用例通过、13 项开发组件用例通过、1 项开发组件用例失败、277 项跳过，原阶段退出码为 1，未重试，安装及临时目录清理已确认。

唯一失败发生在“外部结构变化撤销旧预览，可靠键缺失仍可查找”的 `beforeEach`，等待“当前页查找替换”按钮 30 秒后报告元素不存在，用例正文尚未执行。原测试 ZIP、日志、error-context 和 trace 已保留；trace 没有现场 DOM，不能据此确定页面或模块没有启动的原因。Windows 安装包上传被跳过，因此本轮没有可供本机安装的 Windows 包。

## 改动

只调整正式开发组件夹具：每次启动使用独占的临时 Vite 缓存，关闭服务器后核对路径再清理；在首个窗口等待前旁观渲染异常、请求失败及控制台错误，启动失败时附加诊断。原有按钮条件、全部业务断言、45 秒默认期限、个别用例原有期限和零重试保持。

默认共享预构建缓存是静态检查发现的耦合因素。本改动移除该耦合并补齐诊断，不能称已复现或根治原 CI 失败。未修改生产实现、数据库行为、系统剪贴板或依赖。

诊断从 `electron.launch` 返回后开始；HTTP 504 不一定触发 `requestfailed`。附件不能保证捕获启动更早阶段或所有 HTTP 异常，不以空记录证明没有这些异常。
