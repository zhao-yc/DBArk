## 实现及验证

新建表的显式字符集和排序规则来自实际目录配对，目录摘要绑定预览，发送前与 ACK 后重新核对；旧调用和已有表 ALTER 保持原行为。不能通过客户端任意组合绕过目录校验，详见[编码配对设计](../../docs/development/table-create-encoding-20261017.md)。

Root 在上述固定头执行完整纯回归：**6390/6390**、零跳过，类型及构建均退出 0；1462 个跟踪源码文件前后不变，108 个构建文件已冻结。旧 `bf6fb5e` 的 6312 项属于较早检查点，未与本轮相加。审查中发现的正式入口目标漂移及通知失败后误清理均有保留的原红例，追加固定身份、严格关闭及本地永久保留锁修复后才运行实际界面。

## 三个实际界面身份

controller 将当轮当前 UUID 只在内存送入 EXPECTED 字段，正式定义固定 raw 目标及凭据，并用严格相等比较核观察连接；任何 DDL 前要求严格 QUIT 和同一原生流 close。这与旧安装八项只校验 UUID 格式的布尔记录是不同证据链，不互相补证。
