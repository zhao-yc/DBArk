# 表设计器默认值、目标修订与Maria后核：源码整合检查点

本批是后续未发布源码，包内版本仍为0.21.0，公开版保持0.20.0。空字符串默认值、已有表迟到预览保护及Maria字符集补证已整合；本记录区分纯验证、源码构建与尚待执行的真实界面验收，不增加固定R93安装215个身份。

## 最终行为

表设计器增加显式“空字符串默认值”，取消时回到未设置；普通文字、SQL NULL及文字NULL保持区别。已有表窗口按准确连接/数据库/表隔离，预览和提交捕获连接修订、挂载及草稿代次；迟到元数据或预览不能恢复旧SQL，提交等待期间切换目标不能误投，已发送DDL的迟到完成不能关闭新目标窗口或触发新目标回调。

MariaDB 11.4的通用UCA排序规则可能无法从原目录联查获得字符集。仅当目录值准确为NULL、完整SHOW明确提供字符集及排序规则且与实际目录一致时，才使用解析证据补证；再核对引擎、表注释、重复或额外表选项。未知信息仍返回“已收到CREATE成功响应，定义尚未核验”，不会重放或补DROP。MySQL路径没有引入该补证。

## 真实Maria界面与保留现场

旧`run1351`的数据复制两项完整阶段见[Data实证](acceptance-table-copy-data-root-20261017.md)，Maria10.11在DDL前因测试模式白名单遗漏IGNORE_SPACE失败，11.4未执行。修正测试门后的`run1361`，10.11一项完整单次通过、约8080.72毫秒；11.4已成功CREATE，但原字符集后核未完成而失败，整批仍失败。

`run1363`只读保存本例空表的完整SHOW、列、索引及目录差异，支持上述生产修复；并非修复后真实界面复验。11.4单例按保留状态处理：最后六实例观测仅13311有该临时库，相关用户/线程零；原生退出未确认，故恢复检查没有发送DROP或目录删除。正常窗口关闭已请求，原生界面工具访问授权超时，未点击确认或强制终止。
