# O01 外键差异验收记录（2026-10-14）

本批属于 0.10.0 的受控外键设计，O01 整体仍为部分。独立窗口、产品接口、原生探针、源码回归、实际安装和公开下载分别记录，不能互相替代。所有数据库操作使用已核对的 Server-200 / 192.168.31.200 专用实例，没有执行本机 Docker。

## 实现与行为

对象树和表标签提供“外键差异”入口，读取真实子表、已有父表及显式候选父表。支持复合有序映射、跨库、自引用、新增、删除、用户明确异名替换，以及 RESTRICT、NO ACTION、CASCADE、SET NULL。先形成草稿和只读 SQL，再确认一次性执行；不自动补索引、改名、修复数据、拆分失败计划或重放 DDL。

已有完整子表升序 BTREE、父表精确完整 PRIMARY/UNIQUE、类型与字符属性、可空性、模式、物理能力和完整名称目录共同决定能力。首批新名称只允许 64 位内 ASCII 字母、数字、下划线且不能数字开头；未知旧名称或语法保留原片段只读。同一条 ALTER 同名 DROP/ADD 在五基线原生均被拒绝，产品要求明确异名。未改变的字段、索引、CHECK、表尾、外部入向关系以及新旧父表参与执行后核验。

父子表共享原子执行租约，直到原连接和取消控制连接真实关闭才释放。查询标签事务和临时表不被借用。预览/执行重读结构、目录、模式和名称比较；外部客户端 DDL 窗口仍存在，客户端租约不等于数据库全局锁。任务区分未投递、收到成功包、完成核验和结果未知；取消不能承诺回滚。

全局原生头/字段目录与逻辑 RC/KCU 双向闭合，分批读取并受共享预算限制。名称由服务器按已证版本规则比较，不以空目录、数量相等或客户端转小写当成可用。只读查询没有原子快照；权限不足、未知、超限或不可解释内容保持 partial。120 秒快照与一次性预览共用原有总额度，连接修订和退出使旧令牌失效。

## 失败与清理工具修正

run02/run03 各 25 个行为断言通过，但 afterAll 立即检查 COM_QUIT 后服务器目录，短暂线程尚未消失，suite 失败。之后观察线程已归零，再精确清理四个本轮库，原件保留。COM_QUIT 没有服务器 ACK，本地关闭回调不等于服务器目录即时消失。

run04/run05 各 25 行为通过，但新钩子误用只能在 test 内使用的 `expect.poll`，suite 再次失败；不计最终通过。已精确回收这四座随机库并独立核记录 ID 和库为零。最终改为与 Vitest 上下文无关的真实读取轮询，每 50ms 检查、单调时钟 10 秒截止，非零超时仍失败；立即归零、延迟归零、超时和读取错误四个离线断言通过。最终 run09/run10 完整复验通过，没有放宽零残留标准或修改产品掩盖测试工具问题。

原件分别位于忽略目录 `.cache/o10-product-validation/` 的各独立 run、`cleanup-run02-run03-20261014`、`cleanup-run04-run05-20261014` 和 `cleanup-poll-helper-20261014`；不覆盖失败记录，不公开私密环境。

## 最小权限、UI 和安装

最小权限复用用户明确授权的 `cp_*` 用户及 `dbark_colperm_*.subject` 表，只授予 SELECT，或 SELECT/ALTER/CREATE/INSERT。没有扩展 PROCESS、REFERENCES、LOCK TABLES、schema/global/column 权限，也没有创建额外父表。两项验证读到真实 self/主键引用，但名称及入向目录为 partial，新增预览拒绝且未发送 DDL，原定义、行和精确权限保持。五基线、SSH及严格TLS各2/2，共14项通过，28项旧字段/索引用例因本次过滤跳过，不计为本批通过；各项库、用户、该用户线程和已记录ID均0，观察连接真实关闭。原件为run19至run25，权限前后目录均核对，没有扩大授权。

Windows 真实 Electron 每版本七项：双入口/零 DDL 预览/双击一次、跨库父加载与弃稿及有序映射异名替换、父子数据草稿保护、迟到 get/preview 释放、真实锁等待取消及普通会话隔离、未知旧名称只读、自引用新增删除。五版本各 7/7，共 35 次适用执行；没有通过 mock 服务结果替代数据库操作。各轮为 run08、run14、run16、run17、run18，零重试和跳过。
