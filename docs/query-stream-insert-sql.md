# 将本次完整查询导出为 INSERT SQL

在查询工作台打开“新执行并完整导出”，选择“INSERT SQL：一个完整行结果集”。这会在当前查询会话新执行一次 SQL。请先核对源 SQL；取消导出不会撤销已经执行的 SQL，也不会自动重放。

1. 填写准确目标数据库、表和全部目标字段，每行一个字段，按实际结果列位置对应。系统不猜测查询来源，也不读取目标表。
2. 选择编码及保存文件，确认新执行。打开窗口、填写映射和选择文件本身不执行查询。
3. 等待完整结果流式暂存。窗口显示同一内容的真实 INSERT 样例、完整行数、实际文件字节、编码和准确目标；此时原目标文件尚未替换。
4. 在 120 秒内核对样例与全部映射，输入准确的“数据库.表名”并确认发布。确认只发布本次暂存文件，不再连接数据库或执行查询。成功后原工作台结果保持。

首版仅接受整个脚本恰好一个完整行结果集。状态包、第二个结果、字段数不匹配或无法可靠表示的类型会使导出失败，并保留原目标文件。CALL、多结果脚本或先返回状态的脚本不属于此范围；失败时此前 SQL 可能已执行，请核对数据库状态。

NULL、空串、二进制、BIGINT、DECIMAL 和日期时间原字符串分别保留；文本使用 UTF-8 十六进制，BLOB 使用二进制十六进制。支持 UTF-8、UTF-16LE、GB18030，使用文件时选择对应编码。目标结构、字符集和约束能否接受这些值，需要在执行生成文件前自行核对。

结果逐行写入，文件上限 10GiB；字段 8MiB、生成行 16MiB，样例最多 20 行／4MiB。非空结果没有可完整展示的真实样例时拒绝发布。等待确认期间占用原查询会话；取消、过期、会话或文档变化会终止待发布操作。暂存归属无法确认时保留文件并报告清理未确认。

本功能已通过离线文件及相关回归；实际数据库、百万行、原生保存窗口和安装包验收仍在进行。已有结果快照的操作见[已返回结果导出](query-result-insert-sql.md)。
