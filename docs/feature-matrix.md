0.2.0 增量增加全部/任一组合、IN/NOT IN/BETWEEN/NOT LIKE、条件编辑和跳页；精确数值筛选经五基线实测。固定结果只接受成功查询的已返回数据，每标签 5 组/16 MiB，退出释放。Windows 源码综合 12/12 通过，具体安装及发布证据见验证记录；不能由源码实测外推其它平台的实库 UI。

主分支后续开发新增 SQL 文件三编码打开/另存及已返回结果 CSV/JSON 导出。文件读写不执行 SQL，打开新查询保留原事务；结果导出独立于数据库连接，支持旧快照、列名消歧、进度、取消及原文件保护。完整 SQL 结果流式导出仍待实现。新功能不包含在 v0.2.0 下载文件中，测试及后续发布状态见 [P0 文件批次记录](../tests/integration/acceptance-p0-files-20261014.md)。

## 版本验证矩阵

兼容目标是 MySQL 5.7、8.0、8.4 和 MariaDB 10.11、11.4。只有实际执行集成测试并保留版本、环境与结果，才将对应目标标记为通过。Docker 测试统一在 `deve-server.yinzon.com` 对应的 200 开发服务器执行，禁止调用当前电脑的 Docker。

测试覆盖连接、元数据、精度、分页、编辑冲突、长查询取消、事务和标签页隔离、导入导出；SSH/TLS、百万行压力和安装包属于独立验收场景，不能由单元测试通过替代。

实际数据库补丁版本、结果、平台差异和未测组合见 [验证记录](validation.md) 及 [数据库实测记录](../tests/integration/acceptance-20261013.md)。

## 后续里程碑

2026-10-13 用户已扩展目标至 Navicat 全部功能。本表保留首版记录，完整范围及优先级见 [全功能覆盖清单](navicat-coverage.md)。同步、建模和其他驱动现在属于持续目标，按频率推进。

- 第二阶段：结构/数据比较同步、跨连接传输、备份恢复、用户权限及会话监控。
- 第三阶段：任务编排与本地调度、ER 模型正反向工程、可视化查询、数据字典、生成和脱敏。
- 当前接受的实施范围仅包含 Electron 桌面应用；服务器 Web 运行方式尚未实现。
