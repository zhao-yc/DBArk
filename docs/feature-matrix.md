0.2.0 增量增加全部/任一组合、IN/NOT IN/BETWEEN/NOT LIKE、条件编辑和跳页；精确数值筛选经五基线实测。固定结果只接受成功查询的已返回数据，每标签 5 组/16 MiB，退出释放。Windows 源码综合 12/12 通过，具体安装及发布证据见验证记录；不能由源码实测外推其它平台的实库 UI。

0.3.0 已公开 SQL 文件三编码打开/另存及已返回结果 CSV/JSON 导出。文件读写不执行 SQL，打开新查询保留原事务；结果导出独立于数据库连接，支持旧快照、列名消歧、进度、取消及原文件保护。0.5.0 开发版另有明确新执行的完整流式导出，文件不受预览行数限制。新功能不补计入旧下载文件，测试和公开状态见 [P0 文件批次记录](../tests/integration/acceptance-p0-files-20261014.md) 及 [Q05 记录](../tests/integration/acceptance-q05-query-stream-20261014.md)。

同一后续开发批次增加独立 SQL 片段库及 `:name` 九类型值参数查询。片段 Windows 离线 UI 全流程已验；参数及会话协议核心在五数据库基线各 17 项通过。历史和快照 SQL 留存模板，实际结果可包含填写值；关闭变量跟踪或服务器错误后不猜测会话模式，事务不确定明确展示并保留核对操作。schema 2 回退须恢复升级前完整配置目录。完整 UI、安装和发布状态见 [Q06 批次记录](../tests/integration/acceptance-p0-parameters-20261014.md)，不由核心通过推断全平台通过。

## 版本验证矩阵

0.8 已公开独立“字段差异编辑”，保留未修改片段、短独立会话、执行前重核和单次令牌。默认值精度、Maria 整表表达式风险、旧版二进制文字默认、MySQL 8 大对象默认及 UCA1400 目录别名分别取证和验收，实际安装及公开下载已独立核对，见 [字段验收](../tests/integration/acceptance-o01-columns-20261014.md)。

0.9 已公开普通/唯一/主键 BTREE 的新增、原生改名、删除及字段/前缀/方向/注释差异，独立目录依赖检查及执行后核验已接生产链路和双入口。全文、空间、表达式、不可见/忽略、生成及陌生属性旧键只读；完整特殊索引和复杂表属性继续保留。关闭阶段迟到取消已由 [0.9.1](releases/v0.9.1.md) 独立补丁公开修复，固定旧标签不替换，详见 [索引验收](../tests/integration/acceptance-o01-indexes-20261014.md)。

0.10 已公开外键差异窗口及父子执行租约，支持已有完整支持键上的复合映射、跨库、自引用、四种动作和明确异名替换。命名空间不完整时拒绝新增，未知旧语法只读；三平台标签检查、12公开资产、486源码blob及公开Windows最终原77项通过，首轮失败与诊断分别保留。实际阶段结果和边界见 [外键验收](../tests/integration/acceptance-o01-foreign-keys-20261014.md)。首批字段、BTREE 和外键差异仍不代表完整 O01 完成。

兼容目标是 MySQL 5.7、8.0、8.4 和 MariaDB 10.11、11.4。只有实际执行集成测试并保留版本、环境与结果，才将对应目标标记为通过。Docker 测试统一在 `deve-server.yinzon.com` 对应的 200 开发服务器执行，禁止调用当前电脑的 Docker。

测试覆盖连接、元数据、精度、分页、编辑冲突、长查询取消、事务和标签页隔离、导入导出；SSH/TLS、百万行压力和安装包属于独立验收场景，不能由单元测试通过替代。

实际数据库补丁版本、结果、平台差异和未测组合见 [验证记录](validation.md) 及 [数据库实测记录](../tests/integration/acceptance-20261013.md)。

## 后续里程碑

2026-10-13 用户已扩展目标至 Navicat 全部功能。本表保留首版记录，完整范围及优先级见 [全功能覆盖清单](navicat-coverage.md)。同步、建模和其他驱动现在属于持续目标，按频率推进。

- 第二阶段：结构/数据比较同步、跨连接传输、备份恢复、用户权限及会话监控。
- 第三阶段：任务编排与本地调度、ER 模型正反向工程、可视化查询、数据字典、生成和脱敏。
- 当前接受的实施范围仅包含 Electron 桌面应用；服务器 Web 运行方式尚未实现。
