# 全库搜索（0.17开发中）

## 结构名称搜索

点击工作台“全库搜索”，或按 Windows `Ctrl+Shift+F` / macOS `Command+Shift+F`。活动标签的当前连接和库会带入；无库或未知时，需要明确填写范围。

选择连接，数据库范围每行填写一个实际库名，最多32个，空行忽略，其余空格保留。选择表、视图、字段、索引、主外键、过程、函数、触发器或事件，再输入搜索文字并点击“开始搜索”。输入和勾选不会自动访问数据库。“结构名称”模式仅搜索当前账号可见名称；定义与注释使用下面的“定义正文”，表数据使用“搜索数据”。“搜索保存查询”进入独立的本地搜索；临时表尚未纳入全库搜索。

| 方式 | 含义 |
| --- | --- |
| 包含文字 | 名称包含输入原文；`%`、`_`和`!`按文字处理 |
| 完整名称 | 整个名称相等，保留输入原文及尾空格 |
| 前缀 | 名称从输入原文开始 |
| 服务器正则 | 由数据库执行，语法和Unicode规则随版本不同，错误在窗口显示 |

可以区分大小写。普通文字不区分大小写时采用服务器LOWER映射，保留重音差别，不保证完整Unicode折叠；正则采用服务器规则。文字最多4096个UTF-16单元及8KiB UTF-8，名称限1至64个BMP字符。含换行库名的界面选择尚未实现。

每次最多返回50条并释放连接，点击“继续搜索”才读取下一批；继续入口5分钟后失效，期间无数据库后台任务。上限可设1至1000，达到上限会提示仍有未完成范围，需缩小范围或提高上限重新搜索。每批最多处理10个类别范围，无命中时仍可能需要继续；已处理范围包含失败范围，请同时检查失败明细。页间目录可能变化，当前不提供元数据快照。

错误可以停止或记录后继续其它范围。取消和关闭等待任务收尾，原查询及表格草稿不提交、不刷新；取消控制失败会明确说明服务器终态未确认。选中结果点击“打开当前定义”，或双击/按Enter，重新读取当前原始定义并只读查看。已有名称可能失效或指向新对象；修改结构继续从对象树进入设计入口。

搜索文字、命中和错误原文不写入任务概要，窗口关闭后不持久化。验收和未完成范围见[记录](../tests/integration/acceptance-w03-structure-search-20261015.md)，W03保持部分。

## 定义正文搜索

在结构搜索窗口把“搜索内容”切换为“定义正文”，明确选择数据库和表、视图、存储过程、函数、触发器或事件。字段、索引及约束包含在所属表的定义中，不再按子项重复搜索。输入文字并开始后，独立会话逐个读取当前账号可见对象的完整SHOW CREATE定义，涵盖名称、字段、注释及例程正文；不会执行这些定义，也不会读取表或视图中的数据。

包含、前缀和服务器正则作用于整个定义原文，“整个定义相等”要求匹配完整SHOW CREATE文本。普通文字中的百分号和下划线仍按原文处理，大小写及正则遵循当前服务器规则。每对象最多2MiB，不可读、NULL、读取失败或超限定义明确记入对象失败明细，不能把截断内容当作无命中。继续策略只跳过失败对象，继续检查后面的同类对象；停止策略保留已收到结果并标明未完成范围。

每页最多检查10个对象或执行10次目录枚举，命中较少、目录类别较多时可能需要继续一个没有新增命中的页；请以“仍有未扫描范围”和已处理范围判断完成。结果显示命中对象、定义位置及完整字符数；正文不存入续页句柄或任务概要。页间无数据库连接或后台扫描，原连接、五分钟续页期限、总命中和单页预算与名称搜索相同。

双击、Enter或“打开当前定义”会重新读取当前定义并只读查看。对象在页间或打开前可能变化，结果不提供结构快照或可写身份授权。取消、关闭等待真实任务收尾，已有事务、查询结果与表格草稿保留。此模式没有搜索后编辑结构的入口，W03仍为部分。

## 本地保存查询全文搜索

日常浏览可从“历史与查询”切到“保存的查询”。列表按更新时间和标识降序，每批最多检查25条，只显示512单元SQL预览；“读取下一批”替换当前批，不将全部正文加入界面。搜索名称或完整SQL需点击“搜索保存查询”或Enter，空命中批次也可能仍有未检查记录。修改筛选或错误策略后需重新搜索，不能续接旧条件。累计失败数须与当前批失败明细一起核对。

从列表打开同样先核原文摘要，缺失来源须明确选择连接，不借用当前或首个连接。删除也核所见摘要，原文已改变时拒绝删除；成功后刷新首批。关闭或切回历史会等待当前操作并释放续页。执行历史仍是原500条流程，分页及字节预算另行完善。实现及限制见[说明](development/saved-query-pages.md)。

点击“全库搜索”后的“搜索保存查询”；没有数据库连接也能使用。选择查询名称、SQL全文或两者，按全部来源、指定连接或未指定来源筛选，再选择已知指定库、已知无默认库、未知或遗留上下文范围。遗留记录没有已验证的默认库状态，不混入已知库范围。输入文字并点击“开始本地搜索”，不会连接数据库或执行保存的SQL。

本地匹配支持包含、整个字段相等、前缀及JavaScript Unicode正则，大小写规则与服务器搜索不同，不支持用服务器正则语法替代本地规则。普通文字先转义正则符号，百分号和下划线也按原文处理。每个字段显示第一处命中的UTF16行列及最多256单元预览；一条查询在名称和SQL都匹配时仍只算一个查询命中。SQL正文在打开前不全量传给界面。

每页最多检查25条记录，命中上限1至1000，单页最多128KiB；存在未检查记录时按“继续搜索”读取下一页。页间不保留匹配线程，续页5分钟后失效，查询或连接库变化后需要重新搜索。每条匹配有2秒预算，超时会终止线程并明确记为失败，不能冒充无命中；错误策略可选择停止或继续。取消和关闭等待真实线程及当前回复收尾。搜索文字、命中和错误原文不写任务历史，窗口关闭后不恢复条件。

选中命中后确认“打开查询的连接”，点击“打开查询（不执行）”，或双击/Enter。保存的来源连接存在时会带入；来源缺失或未指定时，必须明确选择替代连接，不自动借用当前或首个连接。更换来源后，新查询的默认库为未知，执行前需要确认。打开前校验原文摘要，已修改或删除的记录要求重新搜索；打开始终新建独立标签，保留原草稿、结果和事务。SQL命中会将光标移到对应行列，不自动运行语句。

当前仅覆盖DBArk本机保存查询，每字段第一处位置；多处高亮、执行历史列表的分页改造、搜索条件持久恢复及任意规模性能仍待完成。原本地配置仍采用内存SQLite，搜索避免额外构造或发送全部SQL数组，不能据此声称配置文件的物理磁盘读取已经流式化。单条记录JSON最多128MiB、SQL最多2000万UTF16单元；非常大的记录和线程错误明确显示失败，不静默截断匹配。

## 数据搜索

从上述窗口点击“搜索数据”。选择连接后，依次点击“读取数据库”“读取对象”“读取字段”，明确选中需要访问的表或视图及字段。每个目录页最多100项；可以按名称前缀缩小目录，或点击“下一页”。翻页保留已勾字段，“选中本页字段”只选择本页；切换表后仍保留之前显式选择的范围。点击范围名称可以移除该对象，也可以清空全部范围。

选择包含文字、整个值相等、前缀、服务器正则或 NULL，并设置大小写、错误策略及命中上限。文字按服务器中的完整值匹配，显示最多128字符预览；NULL与空字符串分别处理。二进制字段默认使用HEX文本，匹配的是十六进制表示；“完整表示字符数”也以该表示计数。视图搜索必须明确勾选允许，因为视图处理可能执行函数。输入条件和读取目录均不会隐式搜索表数据。

点击“开始数据搜索”后，窗口逐批确认并读取，每批最多50处或128KiB；一处匹配单元格计一次命中，同一行的不同字段分别计数。单任务最多1000处、32MiB，达到上限明确显示未完成范围。宽表分块搜索并显示已处理块数，不仅检查前16列。错误明细可以展开查看；继续策略下的完成仍可能包含失败范围。取消、关闭和切换模式等待当前目录、命令及搜索连接实际释放后才完成。

结果只读。存在有效精确定位引用时，双击、按Enter或点击“定位命中记录”核验对象并读取当前记录，自动聚焦命中字段；返回后保留搜索结果并恢复该结果行的键盘焦点。窗口显示当前命中字段块的所选字段和定位键，不代表整行全部字段。TIMESTAMP按UTC读取，DATETIME和TIME保留原文；NULL、空串和二进制有明确标识，二进制以HEX显示。每字段最多4096字符并按整条预算调小，截断会明确提示完整长度，单条输出最多1MiB。内容是本次读取的当前值，可能与旧128字符搜索预览不同。

定位引用从签发起有效5分钟，不保留数据库连接；新搜索、窗口关闭、连接更改或到期时释放。读取失败、表重建/定义改变、键删除或会话模式不一致需要重新搜索；返回时等待正在进行的读取实际结束。首批精确身份仅覆盖已验版本族的Linux、大小写设置为0、库/表名为ASCII字母数字下划线、非分区InnoDB，且当前账号可读取原生InnoDB目录。其它情况仍可搜索，但不会签发伪造的精确定位引用。

“打开所属表”仍是独立入口，读取当前表或复用已有同表标签，保留草稿、查询结果和事务；它不自动定位某条记录，也不表示旧对象身份已确认。候选键提示和预览不能作为更新授权，精确定位窗口也不执行修改。详见[导航验收与限制](../tests/integration/acceptance-w03-record-navigation-20261015.md)。

定位候选键只使用当前账号实际可读的完整唯一键。某个键列无SELECT权限时尝试其它可读候选；没有可读键仍可返回命中，明确显示“仅只读：无键列读取权限”，悬浮可查看完整说明。用户明确选择的搜索字段没有SELECT权限时仍报错，不会伪装成无命中或借用其它账号，见[权限专项](../tests/integration/acceptance-w03-search-key-permissions-20261015.md)。

搜索窗口的文字、结果和错误仅保留在内存，目录不写任务历史，搜索任务概要只保存计数；记录定位也不保存键、字段值或服务器错误原文。当前范围最多64个对象、每对象4096列、总计16384列；目录页间可能变化，没有元数据快照。数据搜索早期界面及六实例目录验收见[记录](../tests/integration/acceptance-w03-data-ui-20261015.md)。任意对象和可编辑记录导航、定义内多处定位等仍待完成，W03继续保持部分。
