# O09 索引与主键差异：原生取证及验收边界

状态：2026-10-14，已完成两轮独立原生研究、有限公开结构夹具及本地纯依赖/前端模型验证。**新索引差异产品 API、真实 UI、任务生命周期和发布验收尚未由本记录证明通过。** 第一轮覆盖基本索引语法与目录规范化，第二轮覆盖 InnoDB 外键目录名称映射和复合列序；原始失败、忽略、截短及探针假设不成立均保留。

## 研究隔离与记录规则

每轮先核对已授权专用服务器的实际身份，静默读取既有私有环境；只创建带随机后缀的自主研究库及最小表。没有业务对象、账户/GRANT、Docker、全局配置或关闭约束检查的操作。每个 DDL 单次执行，不在失败后自动换语法重放；DDL 后立即读 SHOW WARNINGS，再读其他目录，保留实际错误与诊断级别。

原始输入、输出和执行器副本在忽略目录 `.cache/o09-index-native-evidence/`，以新增方式保存。公开文件只保留自主结构、必要目录语义、软件版本/会话模式和 SHA，不复制凭据、服务器身份、行值或随机库名。每轮 finally 结束研究连接，再以独立观察连接精确删除本轮库，并查询库目录、库线程及已记录原连接 ID。目录已查零与等待连接结束分别记录，不用其中一项推测另一项。

## run02：全局 InnoDB 外键目录与目标名称

五版各两个新隔离库、6 组父子表，共 **10 库、60 表、30 个二列外键，其中 15 个跨库**。名称覆盖 ASCII 混合大小写、Unicode、空格、@、反引号及组合。约束均一次 ALTER 成功、即时警告为空，`foreign_key_checks` 前后均为 1；没有插入行来冒称已验证 DML 约束行为。

### 第二次界面冻结：整批草稿的可达性

后续静态复核确认 `indexViews.access` 来自单补丁试算，若界面始终把该布尔值当成所有批次的永久禁用条件，会令“先新增替代自增支持键，再删除旧键”的已支持组合无法形成。新增纯函数 `indexDraftPermission`：只有真实快照可写、能力存在、完整普通定义存在且 `unsupportedReasons` 为空，才可形成受控草稿；单项依赖拒绝仅在**其他索引的 add/alter 草稿**存在时允许整批送审。当前索引自身的 alter、其他 drop 不会放开自己；撤销其他增改草稿后，前置校验恢复原单项限制。

列表入口、编辑器属性、保存草稿及生成预览使用同一判断；具体单项拒绝原因仍显示，并增加“集中预览会重新验证整批依赖，形成草稿不代表可以执行”的说明。只有实际引擎生成的全批令牌能够进入执行。未理解、不透明、隐藏和生成索引不解锁；主键转普通键属于显式重建，名称输入不能误用 PRIMARY 原生改名限制。注释 1024 UTF-8 字节是本版保守预算，界面不将它描述为已证明的服务器多字节极限。
