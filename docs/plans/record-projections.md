# D04 只读记录树与类型化整行 JSON

0.12 当前源码已接入，尚未发布。本批延续[记录视图计划](record-views.md)的同页身份、共享草稿和写入边界，只新增只读投影；树编辑、整行回写、跨页连续表单、关联树、模板、批量表单和草稿恢复仍须后续独立实现。D04继续保持部分，不把有查看入口当作完整完成。

普通表单、只读树和整行JSON复用同一面板及`DraftRow[]`，通过原三选守卫切换。未暂存输入不参与投影；明确暂存只进入原网格草稿。树和整行JSON不增加IPC、SQL、会话、文件或写回接口；显式分页和刷新仍走原读取。

## 表达与预算

- 树以元数据字段顺序和独立类型标签展示摘要，保留NULL、字符串、实际JavaScript数值、缺值DEFAULT、待计算生成列及二进制。BLOB只显示有界Base64前缀和真实字节数。
- JSON结构解析使用词法范围和有序成员数组，数字不进入Number，对象不合并成字典。重复名称按原文序号区分，特殊列名和成员名通过结构化路径定位。仅确认JSON类型或用户明确要求时解析普通字符串。
- 单字段最多262144个UTF-16单元及262144个UTF-8替代编码字节，深度64、8192值节点、每容器2048项；活动行缓存最多1MiB源和16384值节点。非法或超限没有部分树。
- 每组最多32字段和480结构条目，共512可见条目，窗口外不建React行。使用原生按钮和有序列表，不使用未实现方向键的ARIA tree。
- 整行JSON按完整元数据顺序包含隐藏字段，使用`DBArk-record-view/version:1`类型化显示，最终转义后UTF-8最多2MiB。先预检再生成，失败不提供部分全文。该格式不是导入或恢复协议。
- 目标、连接修订、加载代次、结构签名、行UUID、data/original引用和插入/删除状态参与失效。加载或结构过期时撤下旧投影，换行或草稿引用变化清除旧节点选择与缓存。

这里只保留客户端实际收到的原文，不能恢复服务器存储JSON前已丢失的空白、成员顺序或重复成员。MariaDB的JSON别名按实际元数据处理，普通LONGTEXT需明确按JSON查看。
