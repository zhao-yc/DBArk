# D04 JSON 树结构操作

0.15已公开，0.14固定标签和资产保持不变。本批提供成员改名、移除、追加及数组元素插入、移动、移除。1801正式单元、五数据库新增界面50次，Windows源码/本机及公开NSIS原完整各126项通过；两轮三平台原生源码及真实安装各22离线通过、104私网跳过，12公开资产及544源码blob核验完成。原始失败与修正保留，范围见[验收记录](../../tests/integration/acceptance-d04-record-structure-input-20261015.md)，其它D04子能力继续独立推进。

每个操作捕获当前行、缓存文档、词法节点、结构路径和独立输入会话。成员按原文序号定位，数组按当前下标定位，不能仅按名称处理重复成员。对象改名替换原始键token；新增键使用带双引号的完整JSON字符串，新值单独校验，数组下标保留文本直至暂存，不允许指数、小数、符号、空白和不安全整数被自动转换。

删除依据已校验的成员或元素跨度处理前后逗号，不能扫描字符串内的标点。数组移动只旋转完整值token，保留分隔符和空白槽位。任何操作保留范围外原文、大整数、小数、指数、负零及重复名称；原生JSON仅承诺保留服务器实际返回的表示，不能恢复服务器已经规范化的格式。

所有片段先执行代码单元和UTF-8预算预检，合并完整字段后再执行原262144长度与字节、64深度、8192节点和2048容器条目限制。任何失败均不生成部分草稿。根值不能结构删除或改名，可使用原节点值编辑替换。

结构缓冲与字段、整行、节点值缓冲互斥，使用同一离开三选、全局未暂存、隐藏标签、退出及刷新保护。打开删除、新增操作即形成待暂存意图；改名和移动比较原始输入。每次改字和暂存均重新核对当前行与输入会话，失效选择不能自动重选或重放。暂存只更新原本页DraftRow数组，原始值和已有草稿仍保留。数据库写入继续使用原SQL预览、一次性确认和并发检测；没有新增IPC、引擎写入口、配置迁移、依赖或持久草稿。

验收覆盖首中末和唯一成员/元素、空容器、重复及转义名称、嵌套标点字符串、精确数字、非法输入与完整合并预算、下标越界、零部分暂存、三选导航关闭、隐藏退出刷新、只读对象、生成列、删除撤销、原生JSON、预览零写和冲突整批回滚。离线模型及SSR候选125项通过，只能作为对应层证据，不能代替真实入口。

对象成员移动、跨页记录编辑、关联树、模板、批量操作及草稿持久恢复仍需后续设计，D04保持部分。
