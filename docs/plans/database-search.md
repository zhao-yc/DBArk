## 行为依据和完整范围

[Navicat 17 Windows 在线手册](https://www.navicat.com/manual/pdf_manual/en/navicat_17/win_manual/navicat_en.pdf)第362至363页说明：按连接、数据库或schema选择目标；搜索数据或结构；提供包含、完整词、前缀、正则和大小写选项；结构按对象类别选择，双击结果进入记录或结构。此在线手册可能随17.x更新，不是本机17.0.8的实际操作或反编译证据。[官方说明](https://www3.navicat.com/en/company/aboutus/blog/668-performing-database-wide-searches-in-navicat)进一步区分数据与结构搜索。现有资源树的已加载对象过滤不能替代全库搜索。

DBArk 首个驱动工作包覆盖 MySQL/MariaDB 的所选数据库，结构包括表、视图、字段、索引、主外键、过程、函数、触发器、事件，以及本地保存查询；数据包括用户明确选择的表/视图和列。后续新驱动继续按清单完成其适用结构，不把当前驱动范围说成所有数据库。

## 用户流程

工作台提供“全库搜索”和平台对应的 Ctrl / Command + Shift + F，初始选择当前连接与库。搜索前展示数据或结构、对象类别/范围、匹配模式、大小写和可调返回上限；数据搜索须明确选中要访问的表/视图。点击开始后建立独立任务，显示已扫描对象、当前目标、命中、略过/失败明细、进度和取消。不得在输入关键字时隐式扫描数据。

结果包含库、对象类别、对象/字段名称和命中位置；数据命中提供匹配列、精确值预览和可定位记录，不能只显示一个无法进入的计数。达到上限须明确提示范围和未完成部分，可缩小范围或继续；不能声称已搜索全库。打开结果重用真实表格/定义编辑入口，保留已有标签、事务及未提交草稿，并通过现有守卫处理离开与刷新。无可靠定位键的记录只读，失效对象要说明，不能跳到同名新对象后悄悄编辑。

## 引擎和数据边界

主进程注入保存的连接配置；渲染进程只传校验后的范围、匹配参数、上限及任务号，不接受任意搜索SQL或认证信息。任务使用独立连接，不借用用户查询事务。结构目录只按当前账号权限读取；NULL或不可访问定义记录为不可搜索，不从高权限连接补查。数据只运行选择范围内的只读查询；任意视图可能执行函数，界面须在选择时说明其与普通表读取的差别。

包含/前缀的通配符按文字转义，SQL值始终参数化，标识符逐段引用。完整词含义、大小写和Unicode规则要以实际驱动结果校验；正则不能用JavaScript结果假装服务器匹配，须识别MySQL5.7、MySQL8和MariaDB的差异并展示不支持/服务器错误。二进制、NULL、JSON、BIGINT/DECIMAL和微秒仍遵守现有精度边界，不能靠有损转数字或JSON解析生成结果。

结果分批发送、有背压和内存预算；对象枚举和记录扫描均有边界，避免一次性加载库中全部对象/数据。搜索上限限制传输，不等于服务器无需扫描；长查询必须能取消，取消后等待驱动及控制连接实际终态，停止后续对象。一个对象失败继续或停止应由用户选项决定，并报告已完成范围。连接中断不重放任何用户操作，不能以自动重连将权限或默认库切换到另一身份。

## 验收要求

纯逻辑用例验证请求边界、模式、通配符/引用、精度和结果预算；Engine 用例走真实驱动核对匹配结果、权限、错误、取消及逐连接释放，不用假目录冒充。六个既定隔离实例覆盖五版本与严格TLS，SSH单独验；测试授权继续遵守既有随机隔离资源范围，需要不同权限时先完成可审查的具体用例再按现有授权判断。

真实 Electron 验证工具栏/快捷键、范围选择、四模式和大小写、结构与数据结果、双击进入、原草稿/事务保持、取消/关闭和失败明细。百万行表验证分批结果与DOM虚拟化，不能以单张小表代替全库行为。源码、Windows/macOS原生安装、私网实库和公开下载分别验收；未验组合明确标记。分阶段实现可以发布已验能力，但 W03 保持部分直到全部适用能力有实际入口和证据。
