# SQL 语义与跨对象补全

状态：0.16 开发中，Q01 仍为部分完成。本批优先改进日常查询输入；当前公开开发预览为 0.15，不能将本批分层验收视作完整安装或跨平台验收。

## 实际入口和数据流

查询标签的 Monaco 接入有界词法扫描、本地 MySQL 语法 Worker、按目标惰性读取的目录缓存。已删除打开查询时预取前 20 张表字段的旧逻辑。只读 SQL 预览不注册该补全提供器。结果和替换区间均绑定编辑器模型、文档版本、连接修订和数据库；内容变动、连接改变、查询执行和卸载会撤销旧请求。

光标前后整条当前语句参与分析，常用来源包括 SELECT、JOIN、UPDATE、DELETE、INSERT 列清单、普通关联子查询、CTE 和派生表。限定名逐段保留引用与名称；CTE 和派生表显式列在本地解析，星号按实际物理来源读取目录。相同层次的重复别名不任取一张表；内层同名别名遮蔽外层，UNION 分支分别核对。WHERE、连接条件和排序字段不能冒充派生输出。

目录 API 只接受数据库、对象类别、表名和前缀，严格拒绝正文 SQL、会话编号和未知字段。主进程注入保存配置，utility process 创建独立可取消的短连接，固定参数查询 information_schema；补全不借用用户事务会话，也不执行编辑器正文。任务编号仅在内存跟踪，目录进度不进入用户任务面板或 SQLite 历史。用户查询、结构修改和文件任务沿用原持久化流程。

## 上限与取消

| 项目 | 当前上限 |
| --- | --- |
| 编辑快照 | 262144 个 UTF-16 单元 |
| 词法 token / 括号深度 | 16384 / 64 |
| 标识符和前缀 | 64 个 BMP 字符，无 NUL 或代理字符 |
| 目录返回 | 256 项，第 257 项只表示仍有更多 |
| 单次候选触发的目录目标 | 8 个 |
| 每编辑器实际并发 / 活动与排队目标 | 2 / 16 |
| 主进程同时活动目录读 | 8 |
| 每编辑器缓存 | 64 项、4 MiB 字符串和记录开销估算、15 秒有效期 |
| 可见建议 | 256 项 |
| Worker 解析期限 | 2 秒，超时终止线程 |

同一精确键合并读取，库名、对象名、类别和前缀均参加键值；普通 Map 保留原型同名和含点号名称。失败不缓存、不换目标重试。最后一名消费者取消后，数据库任务仍占并发槽直到实际结束。读取命令等真实驱动回调、连接终态或取消控制失败后才释放命令登记，迟到成功不得交付旧目录。

未限定表达式字段插入引用后的别名和字段，INSERT 列清单仅插入字段。接受建议使用普通文本编辑，名称中的美元符号、反引号和点号不作片段表达式解释。Ctrl + 空格触发建议，Enter 接受；macOS 沿用 Monaco 的 Control + 空格，撤销使用平台的 Ctrl / Command + Z。

## 解析依据及仍需完成的边界

模式未知时分别扫描 ANSI_QUOTES 与 NO_BACKSLASH_ESCAPES 的四种组合，只在当前语句和编辑范围一致时继续。字符串、注释、执行注释、无法确认的引号和超预算输入停止建议；文本仍可编辑。未闭合引用名仅在文档末尾允许替换，避免吞掉后方 SQL。跨行名称暂不生成 Monaco 替换。

本批尚未把用户会话的协议缓存模式、USE 后的默认库或临时表定义接入补全。带歧义双引号的输入会保守停止；目录仍按查询标签所选库解释未限定物理表。因此 **USE 切库后的默认目录语义必须完善并验收后，才能发布本批预览**。临时对象补全、选择列别名在 ORDER/GROUP/HAVING 的作用域、LATERAL、窗口/例程局部名称、字符串形式的列别名和完整语法错误恢复继续保留缺项。任意复杂 SQL 不能仅凭第三方 AST 的 accessible 标志承诺已支持。

补全压缩、更多快捷工作流及其它驱动属于 Q01 后续子能力。SSH、完整旧流程、安装包、三平台原生及公开文件仍需独立验证。覆盖清单维持“部分”，不以本批 SQL 入口代替全部工作包。

实现参考 [MySQL 标识符](https://dev.mysql.com/doc/refman/8.4/en/identifiers.html)、[限定标识符](https://dev.mysql.com/doc/refman/8.4/en/identifier-qualifiers.html)、[字符串](https://dev.mysql.com/doc/refman/8.4/en/string-literals.html)、[注释](https://dev.mysql.com/doc/refman/8.4/en/comments.html)，语法库采用 [dt-sql-parser](https://github.com/DTStack/dt-sql-parser/blob/main/README.md)。包内实际源码和测试已用于核对其适配边界；第三方许可见[依赖说明](../third-party-sql-completion.md)。本批证据来自 DBArk 自身测试，没有新增 Navicat 实际运行或反编译结论。
