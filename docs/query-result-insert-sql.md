# 将已返回查询结果导出为INSERT SQL

在查询结果或固定快照中打开“导出已返回结果”，也可以先勾选行再打开“导出勾选结果行”。在文件格式中选择“INSERT SQL”。这只生成本地文件，不重新执行原查询，不连接服务器，也不执行生成的INSERT。

1. 明确填写目标数据库、目标表，以及每个可见结果列对应的目标字段。列名可以与查询别名不同；重复别名、空别名需要分别填写唯一目标字段。系统不从查询文本猜测表名。
2. 点击“生成INSERT SQL预览”。预览来自实际文件使用的同一生成器，最多20行、4MiB，并明确显示样例行数与快照总行数。
3. 选择结果保存位置。选择只对本次SQL预览有效，不能将其他导出的文件选择挪作本用途。
4. 核对全部列映射与预览，输入准确的“数据库.表名”，勾选确认后开始导出。任务面板显示写入进度，快速双击只发起一次提交。

文件包含本次打开时固定的全部已返回行，或全部勾选行，按可见列顺序导出。隐藏列、未勾选行和服务器上尚未返回的行不会写入。源结果截断时，窗口继续说明文件只包含已返回部分。

NULL写成`NULL`；空字符串是带UTF-8字符集标记的空十六进制文本，二进制使用`X'...'`。文本、BIGINT/DECIMAL精确字符串、日期小数、JSON和Unicode都保留来源内容，不把`CURRENT_TIMESTAMP`等文字当作SQL表达式。反斜线、引号、换行和零字节按原UTF-8字节编码，文件生成不依赖数据库的反斜线SQL模式。

目标名称逐段引用，反引号双写。当前名称支持1至64个基本多语言平面字符，不支持控制符、反斜线、尾部空白和无效Unicode。空名、重复目标名、未知源字段或不完整映射会被拒绝。无法无损编码的孤立代理项、负零和非规范二进制来源不会被静默转换。

格式、编码或映射变化会撤销旧预览和文件选择；预览两分钟后到期。修改后请重新预览、选文件并确认。取消或写入失败会保留原目标文件并清理本次临时文件；原子替换已经开始后，迟到取消不能撤销成功保存。SQL提交失败后不会自动重放，需要重新准备。

保留原快照限制：100000行、1024列、2000000单元格、单字段256KiB、单行1MiB、输入总预算32MiB。SQL文件另有512MiB编码后字节上限；超过时保留原目标，不保存半个文件。支持UTF-8、UTF-16LE、GB18030；读取或执行文件时应选择同一编码。

此功能不读取目标表结构。生成文件保留快照值，不代表目标服务器的字段类型转换、字符集、约束、自增或其他会话设置一定接受这些值。请在另行执行前核对目标结构。完整查询流式SQL导出与原生界面验收不属于本片交付范围。
