# DBArk 0.16.0：SQL 语义与会话补全

本版本交付常用 SQL 语义与会话补全，按已验能力发布开发预览；Q01 和完整 Navicat 目标继续保持部分。

查询编辑器增加本地语义 Worker 和按目标读取的目录，替换仅预取前20张表的补全。支持常用别名、JOIN、CTE、派生投影、INSERT列清单，以及普通 ORDER BY/GROUP BY/HAVING 的 SELECT 输出别名；字符串别名按一个名称引用，UNION全局排序采用首分支输出。目录、解析时间和结果量有界，失败或模式不确定时明确提示，不执行用户SQL来猜补全。

补全和查询上下文采用本标签真实会话的默认库、SQL模式和临时对象；USE、无默认库、未知状态在历史、保存查询、布局恢复及显式重连中分开处理，配置升级到schema5。临时对象工具栏可读取真实结构，区分永久视图、同名临时遮蔽和隐藏字段的部分状态；结构读取不覆盖正文、结果或事务，读取会影响诊断信息，界面会说明。连接中断不自动重放写入。
