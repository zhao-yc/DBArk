# DBArk 0.1.0 开发预览

首个 MySQL/MariaDB 桌面版本，采用 Electron、React 和 TypeScript，源码以 MIT 许可证开源。支持 Windows x64、macOS arm64 和 macOS x64。

## 已提供

- 连接分组、搜索和颜色、SSH/TLS、对象树、多标签、明暗主题、布局恢复。
- 本地 Monaco SQL 编辑器、格式化、元数据补全、选中/脚本执行、多结果、取消、事务、历史、保存查询与执行计划。
- 服务端分页、虚拟表格、文本/JSON/二进制/NULL 编辑、复制粘贴、增删改预览与集中提交。
- 数据库/表设计、字段及索引/主外键、数据库对象 SQL 定义编辑；结构变更先展示 SQL。
- CSV、JSON、SQL 导入导出、字段映射、编码、独立流式任务、进度、取消及失败明细。
- SQLite 本地保存，系统加密可用时安全保存凭据；精确数值和时间保持原始表示，可靠键定位及完整旧值冲突检测。

已有标签、会话或任务时，修改连接目标/认证参数会被拒绝；名称、分组和颜色可正常修改。保存查询并关闭相关标签后再修改，避免旧会话或表格草稿被用于错误服务器。断线后不自动重放写操作。

## 验证

121 项单元测试通过。真实数据库覆盖 MySQL 5.7.44、8.0.46、8.4.11 和 MariaDB 10.11.19、11.4.13；另测 SSH 密钥、严格 TLS、权限不足、断线、事务隔离、乐观锁及三格式恢复。百万行 CSV 完整导出 188,888,905 字节，耗时 45.923 秒，进程采样 RSS 增长约 61.64 MiB。

Windows 本机 NSIS 真实安装后 9 项全部通过，实库 UI 验收包括连接、查询、取消、事务、集中编辑、导入导出及连接配置修改保护。发布工作流分别在三个原生平台构建，执行源码回归，并从 NSIS/DMG 安装产物运行桌面回归，全部通过后才发布。

## 下载和限制

Windows 下载 `win-x64-unsigned.exe`；Apple Silicon 下载 `mac-arm64-unsigned.dmg`，Intel Mac 下载 `mac-x64-unsigned.dmg`。macOS 同时提供 ZIP。`source.zip` 是本版本提交的源码；`SHA256SUMS.txt` 用于验证所有附件。

Windows 未发行签名；macOS 仅 ad-hoc 签名，没有 Developer ID 与公证。开发预览可能出现系统信誉或首次打开提示，首版手动升级。macOS 原生构建机已验证应用，但实体 Mac 的 Gatekeeper 首次安装交互、macOS 到内网数据库的真实 UI 流程尚未实测。

任意 SQL 结果只读；无可靠唯一键、视图、非事务表只读。复杂已有表结构通过 SQL 定义编辑；DDL 通常隐式提交。导入分批提交，取消和后续失败不会撤销已完成的批次。结果预览有容量限制，完整导出走独立流式任务。

REA/Ghidra 已验证随附数据库驱动的关键导出函数；Navicat 主程序分析超时，完整 UI 调用链尚未确认。公开内容不包含第三方程序、原始反编译产物、凭据或测试数据。服务器网页、同步、备份、自动化和建模留待后续里程碑。
