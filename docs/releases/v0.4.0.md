# DBArk 0.4.0 开发预览

新增日常表格的外键值选择与关联浏览，当前驱动为 MySQL/MariaDB。Navicat 全功能目标仍在持续推进，无可靠非空唯一键父表、完整 SQL 结果流式导出及其它工作包继续保留。

## 新增与修复

- 选中外键单元格后选择父记录或浏览现有关联，支持跨库、复合键、多外键选择、筛选排序和服务器分页。关联条件独立于普通筛选，NULL 或未填写元组不发送无条件父页读取。
- 选择只一次更新整组源行草稿，其它字段及已开父表草稿保留。确认前复核约束、元数据、源行和父记录；变化时拒绝旧选择，普通 SQL 预览与集中提交才实际写入。
- 整组可空外键可确认清空为 NULL。父表 SELECT 权限不足不阻止合法清空，仍重新核对源定义；读取权限错误不降级返回替代候选。
- 独立读取任务覆盖建连、元数据及页读取取消。等待本次服务端连接和本地隧道收尾，不影响查询标签的事务、临时表和诊断；取消控制失败明确显示无法确认服务器任务。
- 表页及整表导出含 FLOAT/DOUBLE 时使用二进制结果协议，保留相邻浮点键；BIGINT/DECIMAL 继续保留精确字符串。
- 修复 MariaDB 10.11 低权限账号的外键元数据缺失；复用服务器真实 SHOW CREATE 的词法解析补足动作规则，不从空查询结果猜测没有约束。
- BIT 写入、键定位与完整旧值比较按无符号位值转换并验证实际位宽，修复 BIT(64) 提交失败及 MySQL 5.7 重复位键比较条件误判。非键旧值和文本字节冲突检测保留。
- 修复存储过程退出后的 SQL 模式与 NBE 状态矛盾。完整报告矛盾、不透明 CALL/EXECUTE 或错误后维持词法不确定，后续普通 EOF 不再重新猜测字符串边界；仅收到完整且状态一致的模式报告或新会话恢复。字面量 `:name` 不会因过时状态被静默绑定，无歧义 SQL 及明确事务控制继续可用，没有新增隐藏状态 SQL。
- 修复新增行包含合法原型同名列时的界面崩溃，单元格只读取自有属性。未填写 DEFAULT、实际 NULL 和空文本分别保留，内部复制可恢复新增字段缺省；已有行粘贴 DEFAULT 整组拒绝，外部 TSV 输出空文本，不创造实际“默认值”字符串。

## 已完成及进行中的验收

最后冻结源码 327 项单元测试、类型检查及构建通过。五个实际版本 MySQL 5.7.44、8.0.46、8.4.11、MariaDB 10.11.19、11.4.13 各 57 项核心、外键与参数测试通过，共 285 项；各 3 项未启用的 SSH/TLS 专属用例明确跳过，共 15 项。其中外键 23 项、参数 21 项各库全部通过，覆盖 BIT 多位宽增改删、浮点键提交和文件往返、低权限、真实锁等待取消、直接/预处理 CALL 与 tracker 开关、后续三次 EOF 不误绑定字面参数及事务保留。

此前 BIT/外键冻结版独立 SSH 私钥隧道 37 项通过、2 个 TLS 专属项跳过；严格 TLS 38 项通过、1 个 SSH 专属项跳过。最终模式修复后，SSH 和严格 TLS 另分别重跑参数完整套件 21/21 通过，两个轮次分别记录，不冒充同一轮。实际错误 SSH 指纹、CA 及 SAN 身份拒绝，复用已有密钥和证书，没有新增长期秘密。

Windows 源码完整首轮 28 项通过、1 项测试加载等待失败（194.102 秒），无跳过；原先独立外键首轮 2 过、3 失败及实际 BIT 提交修复记录保留。测试补充真实刷新等待，不重试写 SQL。前两份本机 NSIS 各 28 过、1 失败（222.759/204.595 秒），分别暴露同坐标点击选择失效及新增原型同名列崩溃；都实际修复，测试不绕开失败路径。原完整二进制、文本、NULL、DEFAULT 与只读关联源码定向复验 1/1 通过（15.017 秒）。

第三份本机 Windows NSIS 真实安装后 **29/29 通过（196.284 秒）**，无跳过、重试或不稳定项。包含 12 项离线和 17 项 MySQL 8.4 实库、五个新增外键流程及百万行分页，系统加密分支实际执行。文件 137447974 字节，SHA256 `c3766838638eae214fab02abebe1760982c18aa00389e711fd5941dc02cc65c9`，测试安装真实卸载、临时目录及注册残留为零。六个专用实例的本批随机库、临时用户、本机项目进程和本轮临时目录亦核对为零，13 个旧目录保留；六个容器、卷和网络继续用于后续验收，没有销毁。此为本机产物，原生 CI、标签发布、公开下载及公开安装结果分别追加，不能互相替代。

详情和原始失败诊断见 [D05 实测记录](https://github.com/zhao-yc/DBArk/blob/main/tests/integration/acceptance-p0-references-20261014.md)。这些新功能不属于已发布 0.3.0 标签或下载文件。

## 升级及范围

本版沿用 0.3.0 的 schema 2。升级或回退前退出应用并备份完整用户目录，恢复到 0.2.0 须使用 schema 1 的升级前完整备份，不能重置新版配置库。

当前只支持手动更新。Windows 未发行签名，macOS 仅 ad-hoc 签名、未公证；实体 Mac Gatekeeper 及 macOS 内网实库 UI 尚未验收。无可靠非空唯一键的父表明确拒绝分页，非标准非唯一被引用键和复杂历史约束仍未完成支持。任意用户 SQL 结果的 FLOAT 文本协议问题与完整流式导出需要单独处理，不能由表页和整表导出修复外推。其它数据库、同步、备份、模型、BI、协作继续见 [完整清单](https://github.com/zhao-yc/DBArk/blob/main/docs/navicat-coverage.md)。
