# DBArk 0.18.0 开发预览：连接凭据、表属性与编辑保护

[本版已公开](https://github.com/zhao-yc/DBArk/releases/tag/v0.18.0)，标签固定`5cd18ca986d8e3e7e3f81dc47ba6316cf4e995c7`；独立下载、源码及安装结果见[公开验收](../../tests/integration/acceptance-v018-public-20261016.md)。

本版继续采用 MIT 许可证，支持 MySQL / MariaDB 的 Windows 和 macOS 桌面工作流。产品基线为 `80b65746242190b9ca3ea22fdb2677c0a8046d0d`；其后输入辅助、测试、CI 和验收说明更新没有改变产品、依赖或正式安装脚本。0.x 为开发预览，仍采用手动更新。

## 本批改进

- **TLS 客户端私钥口令**：连接表单可为加密客户端私钥设置独立口令。秘密与普通配置分开，支持保留、明确清除及不记住；系统加密不可用时仅保留会话值。严格 CA、服务器身份及客户端证书校验保持，口令不写入查询历史。
- **表备注与默认编码**：对象树和表页提供专用面板，先查看单项 SQL，再明确确认执行。表默认字符集/排序规则使用服务器实际候选；此入口只改默认值，现有字段编码转换仍需另行处理。
- **受控表重命名**：同库新名称先预览，绑定原物理表与完整定义，执行前重新核对，并提示隐式提交、外部结构并发及引用/授权影响。未知结果会使旧、新对象链接失效，不自动重放。
- **受控下一自增值**：对已有整数自增列明确上调，保留十进制大数精度；展示完整 SQL 和风险确认，执行后核对目录、结构及实际计数。上述重命名/自增专用写入首批仅开放 MySQL 8.0.30 及以上的 8.0 分支和 8.4，其他版本保留只读及明确原因。
- **页内替换与原行保护**：补齐替换当前一处后的前进、焦点及选择意图；组合输入或切走再切回不会恢复旧操作。捕获组展开由用户明确开启，默认关闭，展开前检查完整预算。修复 MySQL 5.7 超大主键重复谓词导致的误冲突，保留原值并发检查与事务回滚。
- **搜索命中导航**：本机保存查询正文增加最多 200 处高亮及前后定位，支持 Unicode 和零宽位置；不能无损映射的行尾明确降级。打开和导航保留原草稿，不执行 SQL。
- **连接树异步保护**：修复折叠、刷新、修改连接和断开后的迟到回包、旧收尾覆盖新忙态及重复加载，保留最新有效导航意图。

操作与边界分别见[表属性验收](../../tests/integration/acceptance-o01-table-properties-20261016.md)、[重命名](../../tests/integration/acceptance-o01-rename-root-20261016.md)、[自增及本地导航](../../tests/integration/acceptance-o01-auto-w03-root-20261016.md)、[替换捕获](../../tests/integration/acceptance-d06-capture-and-late-20261016.md)、[原行并发保护](../../tests/integration/acceptance-d06-current-and-key-guards-20261016.md)及[连接树](../../tests/integration/acceptance-sidebar-async-20261016.md)。

## 安装与后续范围

发行附件为 Windows x64 NSIS、macOS arm64/x64 的 DMG/ZIP、源码及 SHA256 清单。Windows 未签名，macOS 仅有 ad-hoc 签名，没有发行证书及公证。安装、连接、SQL、数据草稿和文件任务操作见[中文使用指南](../user-guide.md)。12份公开附件及1075个源码blob已独立核对，公开Windows六项常用批及两端口各四项SSH正式场景通过；实际EXE/ASAR与原候选相同，未重跑全部281身份，详见上述公开验收。

密码SSH和加密私钥口令现已通过隔离OpenSSH两端口核心及公开Windows正式表单/原生加密/真实重启，完整清理与原失败见[实证](../../tests/integration/acceptance-c02-isolated-openssh-20261016.md)。Mac 私网矩阵、实体输入法、更多字段转换与认证组合仍继续验收；既有未加密私钥 SSH 和 mTLS 的实际范围以[SSH](../../tests/integration/acceptance-c02-ssh-ui-20261016.md)及[TLS](../../tests/integration/acceptance-c02-mtls-ui-20261016.md)记录为准。任意 SQL 结果保持只读；连接中断不自动重放写操作，取消或导出失败不撤销已提交的数据库操作。

当前语句按钮、完整记录补取、表单跨页及命名窗口继承属于下一批 0.19 候选，继续单独集成验收。全部 Navicat 工作包及子能力仍按[功能清单](../navicat-coverage.md)推进，不以本版或已完成测试计划表示全功能目标完成。
