# 0.28.0 两平台开发预览发行文案（待批准）

这是方案 A 的审阅稿，尚未获准、尚未公开，不表示原三平台范围已经缩减。最终取舍见[最后阻断表](v0.28.0-final-decision-20261020.md)。

## 本次预览内容

- SQL 格式化支持关键字大小写偏好；Windows 源码及原安装包的专项通过，Mac 已知问题见下文。
- 文件查询的首次模型、撤销重做、缩进与分栏，在 Windows x64 和 macOS arm64 的准确源码及安装包完成限定专项验收。
- 已返回结果支持映射后导出 INSERT SQL；完整查询结果增加单结果集流式 INSERT 导出，显示样例、行数和文件大小后确认发布。
- CSV 导出支持逗号、分号和 Tab。完整 CSV/ZIP 有准确 Windows Engine/MySQL 8.4.11 切片证据，不外推为全部平台、安装包或百万行实测。

功能覆盖和未完成项按[功能交付复核](v0.28.0-feature-delivery-audit-20261020.md)及[80 工作包清单](v0.28.0-feature-status.md)逐项说明；本版不代表完整覆盖 Navicat。

## 下载范围提案

最小方案只提升既有 Windows x64 EXE、macOS arm64 DMG 的原字节，另附准确提交的源码 ZIP 和 SHA256 清单。Intel 安装包、Mac 应用 ZIP 不属于本次最小方案；Windows blockmap 为可选辅助文件，不作为安装证明。具体原文件身份见[候选索引](v0.28.0-release-review-assets.json)。

Windows 未签名；Mac 仅临时签名，未做发行公证。使用手动更新，安装前备份完整用户配置目录。配置仍为 schema9，不能通过手改版本号降级。

## 必须公开保留的问题与限制

1. **Mac arm64 关键字格式化存在真实失败**：独立重启后再次格式化仍出现 mixed case，根因未定；lower 和该专项安装阶段未执行。不能承诺 Mac 完整关键字偏好流程可靠，原失败及未知退出记录保留。
2. **安装版系统快捷键保存未闭合**：Windows 安装版 Ctrl+S 因输入工具窗口绑定失败，未实际发键，也未取得完整保存与正常退出证明；Mac 系统 Cmd+S 未验。文件模型专项或页面/菜单保存不能替代这两项系统输入证据。
3. **Intel 暂不包含在此提案中**：当前原生显示环境不足，未形成 0.28 x64 源码与实际安装闭环，不能用旧版、arm64 或 Rosetta 代替。
4. 源码、安装、真实数据库及平台各有明确范围；离线回归中的条件跳过不计通过。命名表筛选/排序方案已有代码但未完整交付，查询结果新筛选/排序等封存功能不纳入本版。

本稿只有在用户明确接受上述例外、最终源码提交及原资产提升路线获准后，才可作为公开预览文案。当前不创建 tag、Release 或 main 合并，不自动触发三平台重构建。
