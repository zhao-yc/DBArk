# DBArk 0.19.0候选：当前语句、记录复制与连续浏览

本版正在验收，尚未公开；当前下载版本仍为[0.18.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.18.0)。本文件描述下一桌面候选，MIT许可证、MySQL/MariaDB、手动更新及现有本地数据边界保持。

## 常用操作

- **执行当前语句**：工具栏及Ctrl/Cmd+Shift+Enter执行光标所在的完整语句，保留原文片段和对应历史。执行选区、全部脚本、多结果、事务及取消入口保持。字符串、注释和DELIMITER沿原扫描器处理；模式不可靠、模型或光标意图变化时拒绝旧操作，不自动重试。
- **复制为新增草稿**：完整普通行可在本页生成一条新增草稿，省略生成列和自增列，保留精确值、NULL及二进制。含INVISIBLE缺列时由引擎签发来源并只读补取，核原键、已加载值、物理身份与完整目录；超限或无法证明完整则拒绝。新草稿仍需预览并明确提交，补取本身不写数据库。
- **记录表单跨页**：到当前页首尾时继续前后页，沿用筛选排序及页大小，实际加载后选择边界记录。当前页任何草稿或输入缓冲都会阻止跨页；失败或外部导航不会恢复过期选择。分页不承诺动态数据的快照一致性。
- **定义命中定位**：从定义搜索打开原文，显示有界命中及前后导航；绑定原文、对象与连接修订，无法精确定位的输入明确降级。定位和打开保留查询草稿，不执行定义SQL。
- **命名窗口继承补全**：补齐受支持普通窗口继承的字段作用域；重复、未知、循环或分支不完整时停止建议。使用实际元数据与原Worker/Monaco输入路径，完整SQL语义仍持续扩展。
- **旧引擎下一自增值**：补充MySQL5.7.44、MariaDB10.11.19及11.4.13的受控上调。保持直接权限、模式、物理身份、前后目录及单ALTER保护；5.7增加重启失效确认，Maria明确持久化与事务回滚区别。这里只报告当前观测，不保证下一次插入或重启后的精确值。

完整源值补取仍受已支持的Linux、区分大小写目录、ASCII库表名、非分区InnoDB及物理目录权限范围约束；普通查看可在降级时继续。租约五分钟、每行原始值256KiB，超限拒绝，不返回裁短内容冒充完整值。读取、取消、连接变化及ABA守卫保持，连接中断不重放写操作。
