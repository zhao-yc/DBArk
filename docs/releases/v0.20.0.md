# DBArk 0.20.0 开发预览：编辑与提交工作流

本版面向 MySQL/MariaDB 日常开发，采用 MIT、本地数据存储和手动更新。提供 Windows x64、macOS arm64/x64 构建；Windows 无发行签名，macOS 使用临时签名且未公证。公开附件和下载后验收以 [GitHub 发行页](https://github.com/zhao-yc/DBArk/releases/tag/v0.20.0)及后续实证为准，构建或上传完成不等于公开安装验收完成。

## 本版改进

- 查询关闭可选择取消、直接关闭或保存后关闭，保留来源绑定、CAS 和迟到草稿保护。
- 当前页草稿按操作撤销、重做，最多 100 步、8 MiB；输入框仍使用文本撤销，集中提交后不会靠重做重放写入。
- 有界文本与 typed 数据可粘贴为新增草稿，明确映射、预览和暂存，保留精确数值、NULL、二进制及 JSON 原文。
- 集中提交绑定一次预览并记录本地回执，区分服务器确认提交、确认目标事务回滚、未发送和未知；任务中心按可信阶段决定取消入口。
- 连接概要可显式替换本机目标，支持可选数据类型颜色；SQL 补全增加当前查询块命名窗口及有界 CALL 过程名候选。
- SQL 编辑器先完成正文监听和受控值同步，再开放输入；布局恢复保留撤销栈，旧模型和卸载后的事件不能写入新草稿。

未知写入不自动重放，回执没有重做执行入口。事务保证限定目标 InnoDB 事务，触发器及外部副作用另行核对。

## 已验证范围

产品固定 686；5124 项 Windows 完整单元、类型检查和构建通过。本机同一未签名候选累计接纳 335 个唯一验收身份：安装产品 298、开发 Electron 组件 34、安装宿主源码组件 3。全部单次通过、0 跳过/重试，卸载和六个隔离实例的相关库、用户、线程清零，见[完整分层检查点](../../tests/integration/acceptance-v020-editor-full-20261017.md)。

百万行专项由本次安装产品实际导出 1000001 行，独立 Python 逐块、逐行及 ZIP CRC 复验通过。测试限定各例实际分配的数据库组合，不外推完整厂商或驱动兼容性。

三平台普通 CI 各源码阶段、安装阶段为 72 通过、267 条件跳过；安装阶段实际包含 58 项产品路径、12 项开发组件和 2 项安装宿主源码组件。另 13 项原生剪贴板开发组件在三平台各自单次通过；Linux 作业为 5114 单元通过、10 条件跳过，类型和构建通过。各层不能混称安装产品，平台重复不计作新增功能，见[原生分层记录](../../tests/integration/acceptance-v020-native-layers-20261017.md)。

## 限制与后续

四项当前候选的本机原生复制组合仍未执行；临时 CI runner 的剪贴板结果不能替代它们或非空富格式恢复。macOS 私网数据库、真实 ACK 丢失、ROLLBACK 回应失败和最终回执写盘失败等组合仍待实际验收。原 Windows 正文同步失败及所有旧候选记录保持，不以本次通过推断唯一故障原因。

后续分支正在开发的 ON UPDATE、选区/快捷格式化、单表清空/删除及新建库编码选择不包含在本版，不能以其源码测试计作本安装包能力。Navicat 全功能目标仍在进行，详见[覆盖清单](../navicat-coverage.md)。

REA/Ghidra 已验证最小自有样例链路；Navicat 17.0.8 关键行为仍按[取证方案](../reverse-engineering.md)核实。第三方程序、原始反编译产物、凭据和测试数据不进入仓库。
