# DBArk 0.20.0开发预览：编辑与提交工作流

本版正在准备，尚未公开发行；本机Windows候选已构建，正式安装验收待执行。当前公开版本仍为[0.19.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.19.0)。本页只列已进入开发分支的能力及其真实证据，发行前继续补安装及平台验证。

## 本批能力

- 查询关闭时选择取消、直接关闭或保存后关闭；来源更新与另存沿用CAS及迟到草稿保护。
- 当前页草稿按操作撤销、重做，有100步/8MiB预算；编辑输入期间保留文本自身撤销，集中提交消耗后不靠重做重放。
- 有界文本/typed数据粘贴为新增草稿，明确映射、预览和暂存，支持精确数值、NULL、二进制及JSON原文。
- 集中提交绑定单次预览，提供本地持久回执，区分服务器确认提交、确认目标事务回滚、未发送及未知；任务中心按可信阶段决定取消入口。
- 连接概要显式替换本机目标，可选数据类型颜色；窗口名称补全限定当前查询块并按服务器能力提供新增建议。

本版继续使用MIT、MySQL/MariaDB、本地数据与手动更新。未知写入不自动重放，回执没有重做执行入口；事务保证限定目标InnoDB事务，触发器及外部副作用另行处理。
