# DBArk 0.6.0 开发预览

新增表格页内查找替换与表列布局，优先完善日常浏览编辑。当前为发布前验收说明；源码、实际安装、原生平台和公开文件结果逐项追加，全 Navicat 功能目标继续推进。

## 新增与修复

- 对当前已加载页可见列查找完整原值，支持字面文字、大小写、整格、列范围及上下处；SQL NULL、DEFAULT 与文字分开，数字精确字符串不转换，二进制不借预览匹配。按行 ID、列名跳转虚拟行和远列，不自动查询其它页。
- 普通文本替换先预览，再核对页面代次、列及可靠键、完整原值和现有草稿，一次形成本地草稿。仅可写 InnoDB 表的非生成 CHAR/VARCHAR/TEXT 字符串参与，集中提交继续使用完整旧值冲突检查并在冲突时整批回滚。
- 查找与替换计划有明确字符、UTF-8 和命中预算，在大字段及二进制旁列复制前计量，超限拒绝。Unicode 匹配使用原串位置，替换值中的 `$&` 等字符保持字面；不将展示前 50 格当作全部计划。
- 列显隐、前后移动、网格拖动与 64～2000px 宽度共用一个模型；复制粘贴、查找和活动外键定位同步采用可见顺序，隐藏主键不删除提交定位。布局即时生效、手动保存，未保存与失败明确标明；新列追加、旧列移除，大小写歧义不猜，至少一列可见。
- schema 3 独立表偏好与主进程 IPC 不建数据库连接，不混入工作区快照，不存搜索值、行或凭据。500 表、4096 列、单条 512 KiB/总 8 MiB 有界；目标更换、连接删除与清理同事务，认证轮换及外观变更保留。
- 修复 Ctrl/Cmd+F/H 打开后仍停留网格焦点的误编辑风险；重复快捷键同样聚焦搜索/替换，NULL/DEFAULT 回类型控件，编辑器和模态内不捕获后台快捷键。
- 修复旧公共 Zod record 丢弃合法 `__proto__` 行字段及导入映射。逐自有数据字段使用原严格值校验并安全重建，拒绝继承、访问器、非普通对象和非法值；完整旧值及修改批次数限制继续保留。

## 升级与范围

配置升级至 schema3，0.3～0.5 不能读取，升级前退出并备份整个用户目录；回退使用升级前完整备份，保留新目录，不能删除新库或降低 `user_version`。已有连接、凭据、查询、片段、历史、任务和工作区设置不改格式；未保存的列布局不会自动持久化。

当前页工具不替代全库搜索。单处替换、用户正则、二进制搜索、其它类型和驱动继续保留；已实现 MySQL/MariaDB，高级对象设计、同步、备份、模型及其它功能按完整清单推进。Windows 未发行签名，macOS 仅 ad-hoc、未公证，实体 Mac Gatekeeper 和本批 macOS 内网实库 UI 未验。
