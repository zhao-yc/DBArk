# 0.25.0 开发中

本版新增表页“批量填充字段”：勾选当前页的完整已有记录，选择普通可编辑列，以文本、JSON、二进制或SQL NULL形成一批本地草稿。主键、可靠定位键、自增及生成列不开放。只暂存一次，可一步撤销/重做；数据库写入继续经过原表页的修改预览和集中提交。

不完整记录、过期来源、选择/页面/连接/元数据或草稿变化都会拒绝本次方案。操作不自动翻页、补取、执行SQL或读取剪贴板；任何输入或预算错误均不部分暂存。BIGINT/DECIMAL保持文本，JSON沿原有无损校验，二进制逐行独立保存。

首轮Root相关回归15文件为392通过、38失败；失败集中在旧VM订阅端口、提取函数依赖及旧接线文本断言。补齐后，Root五个受影响文件190项通过，同头类型和源码构建成功。原失败保留，各批有重叠，完整CI另验，见[整合记录](../../tests/integration/acceptance-table-batch-fill-20261018.md)。本版未公开，原生界面、实际数据库提交、新安装及macOS组合继续验收；公开版本仍为0.21。
