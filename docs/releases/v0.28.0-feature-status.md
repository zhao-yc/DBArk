# 0.28收口：80个工作包的逐子功能状态

核对冻结产品`bf08645`，公开版本仍为[0.21.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.21.0)。本表包含原清单全部80个唯一工作包编号，包括AI01至AI04。A表示该行明确范围已公开可用；B表示已有代码或部分证据但尚未完整交付或未公开；C表示冻结产品尚未实现该行用户能力。A不意味着全驱动、全版本、全平台或整工作包完成。

本表基于冻结源码入口、[原覆盖清单](../navicat-coverage.md)、[0.21说明](v0.21.0.md)、[0.21公开资产实证](../../tests/integration/acceptance-v021-published-20261018.md)及各行原准确来源核对；本轮没有重跑历史实库验收。0.28新证据以[本版矩阵](../../tests/integration/acceptance-v028-release-matrix-20261019.md)为准，版本尚未公开。统计只校验清单完整性，测试数、子功能数和工作包数均不换算功能完成百分比。机器可读原件为[JSON清单](v0.28.0-feature-status.json)。

备份未完成真实备份/恢复闭环；Excel整体仍部分；内部SQLite不是用户驱动；Web后续。0.29排序、含列名复制、命名筛选、片段JSON、文件重载和新增备份另线封存，本轮不开发或纳入交付。
