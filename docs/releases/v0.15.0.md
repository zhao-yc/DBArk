# DBArk 0.15.0：JSON 成员与数组结构操作

开发中，当前公开下载仍为[0.14.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.14.0)。记录树新增成员改名、移除、追加，以及数组元素插入、移动和移除。操作按原词法跨度保留精确数字、重复名称和范围外空白；输入及合并后的完整字段均按原预算校验。

结构、节点值、字段和整行缓冲互斥，共享未暂存及三选守卫。结构暂存只更新原页草稿，真实写入继续走原SQL预览和一次性确认，冲突整批回滚。只读对象、生成列、无键及非事务表保持原能力门；没有新增IPC、引擎写入口、依赖或配置迁移。

1801正式单元及类型检查通过，新增10项在MySQL 5.7/8.0/8.4、MariaDB 10.11/11.4五基线共50次完整通过，零跳过、重试及flaky；154源码和100构建输出一致，六实例、本机进程及本批新目录核零，13历史目录保留。模型深度夹具及SSR属性断言的原始失败和完整复验分别保留。

Windows源码完整126项正在执行，实际安装、三平台原生及独立公开文件仍未验。Windows未发行签名，macOS私网、实体输入法及人工辅助技术仍未验；其它D04子能力继续独立推进。范围和证据见[结构验收](https://github.com/zhao-yc/DBArk/blob/main/tests/integration/acceptance-d04-record-structure-input-20261015.md)与[计划](https://github.com/zhao-yc/DBArk/blob/main/docs/plans/record-structure-input.md)。
