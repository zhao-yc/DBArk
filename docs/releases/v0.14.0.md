# DBArk 0.14.0：JSON 树节点值编辑

开发中，尚未发布。记录树增加“编辑此节点值”，可以替换选中标量、对象或数组。成员按原文序号、数组按下标定位，重复名称及原型同名键分别保留；只替换目标token，保留其它精确数字、指数、负零和空白。根值外的空白也保留，JSON null和SQL NULL独立。

节点、普通字段及整行输入共享一个互斥缓冲，非法原文同样受离开三选、关闭、隐藏标签、退出和刷新保护。每次打开捕获行、文档、路径和独立输入会话，拒绝旧节点及迟到事件；视图、无可靠键、非事务表、生成列和待删除行保持原能力门。暂存只进原页草稿，实际写入仍需SQL预览和一次性确认。单字段原解析预算、schema4、依赖锁、IPC和引擎写路径不变。

正式1697单元、类型和实际构建通过。新增8项在MySQL 5.7/8.0/8.4、MariaDB 10.11/11.4五基线共40次通过；Windows原116项完整回归正在执行，实际安装、原生CI和公开下载各自另验。首轮根空白断言失败和真实布局修正保留。MariaDB 10.11一次分页加载超过原5秒，完整原8项复验通过，未改等待和断言，具体延迟原因未确认。

本批仅提供节点值替换；成员新增、删除、改名、数组插入移动、跨页、关联树、模板、批量及草稿恢复仍待完成，D04保持部分。Windows发行签名和macOS公证未接入，macOS私网实库、实体输入法及人工辅助技术未验。当前可下载版本仍为[0.13.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.13.0)。范围和证据见[节点编辑验收](https://github.com/zhao-yc/DBArk/blob/main/tests/integration/acceptance-d04-record-node-input-20261014.md)与[计划](https://github.com/zhao-yc/DBArk/blob/main/docs/plans/record-node-input.md)。
