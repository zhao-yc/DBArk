# DBArk 0.14.0：JSON 树节点值编辑

记录树增加“编辑此节点值”，支持标量、对象和数组的完整值替换。成员按原文序号、数组按下标定位，重复名称及原型同名键分别保留；只替换目标token，保留其它精确数字、指数、负零和空白，包含根值外的空白。JSON null与SQL NULL独立。

节点、字段及整行输入复用互斥缓冲、未暂存和离开三选守卫。每次打开捕获行、缓存文档、结构路径及独立输入会话，拒绝旧节点和迟到事件。视图、无键、非事务表、生成列及待删除保持原能力门；暂存只进入原页草稿，实际写入仍需原SQL预览及一次性确认。单字段解析预算、schema4、依赖锁、IPC及引擎写路径不变。
