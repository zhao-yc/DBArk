# DBArk 0.14.0：JSON 树节点值编辑

记录树增加“编辑此节点值”，支持选中标量、对象和数组的完整值替换。成员按原文序号、数组按下标定位，重复名称及原型同名键分别保留；只替换目标token，保留其它精确数字、指数、负零和空白，包括根值外的空白。JSON null与SQL NULL独立。

节点、字段及整行输入共享互斥缓冲、未暂存和离开三选守卫；关闭、隐藏标签、退出和刷新继续保护非法原文。每次打开捕获行、缓存文档、结构路径及独立输入会话，拒绝旧节点和迟到事件。视图、无可靠键、非事务表、生成列及待删除保持原能力门；暂存只进入同一页草稿，实际写入仍需原SQL预览及一次性确认。单字段原解析预算、schema4、依赖锁、IPC及引擎写路径不变。

1697正式单元、类型及构建通过。新增8项在MySQL 5.7/8.0/8.4、MariaDB 10.11/11.4五基线共40次通过。Windows源码原116/116（625.764秒）及本机真实NSIS原116/116（777.460秒）分别完整通过，零跳过、重试及flaky；实际系统加密和历史迁移分支通过。首轮根空白断言失败、真实布局修正及MariaDB一次分页加载超过原5秒分别保留；原8项及完整回归复验通过，未更改原等待和断言，具体分页延迟原因未确认。

[主分支CI](https://github.com/zhao-yc/DBArk/actions/runs/38579995835)固定`4c22b47eb677196ba79383352011bbde4710319d`通过类型、单元及Windows x64/macOS arm64/x64原生构建。每个平台源码和真实NSIS/DMG各22离线通过、94私网跳过，真实加密、迁移、卸载或DMG分离及临时目录清理通过；不能外推macOS私网实库。
