# DBArk 0.27.0 开发候选

本版尚未公开发行。当前公开预览仍为 [0.21.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.21.0)，以下新增能力不计入旧版本。

## CSV 导入分隔符

导入窗口可选逗号（默认）、分号或 Tab。参数变化立即使旧预览和字段映射失效，预览与实际流式导入使用同一配置。保留引号内分隔符／换行、尾空列、精确数值、NULL／空串、二进制及原分批提交、取消和当前批回滚语义。继续要求首行为表头；CSV 导出分隔符不在本片范围。

## 新建表自动更新时间

新表字段区可明确设置受控 DATETIME／TIMESTAMP 的 `ON UPDATE CURRENT_TIMESTAMP(p)`，核对默认值、NULL、精度及版本后再预览和单次创建。兼容合法前缀索引与非键时间列组合，创建后核对 SHOW 和实际目录；未知或不一致属性不能报完整核验成功。后核失败仍保留已创建事实，不自动重放或 DROP。
