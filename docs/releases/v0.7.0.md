## 后续发现的结构导出限制

0.8 开发取证发现，0.7 及更早版本的含结构 SQL 导出不能保证重建部分 MariaDB 默认表达式，以及 MySQL 5.7/MariaDB 的二进制文字默认值；服务器可能返回成功但后续默认字节已经改变。普通结构和纯数据的已验范围不因此扩大。受影响表应单独导出数据，并独立核对建表默认值；0.8 正在加入明确拒绝保护，未用新源码替换本版本的标签或安装文件。实际反例与范围见 [O01 取证](../plans/table-column-patches-acceptance.md)。
