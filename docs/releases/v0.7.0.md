# DBArk 0.7.0 开发预览

本批开发连接概要复制及导入导出，继续优先完成日常连接配置流程。源码已完成定向 Windows 验收；完整回归、安装包、原生平台和公开文件结果在完成后追加，不预填。

## 开发范围

- 复制白名单概要到新连接表单，保存产生新 ID；不继承密码、秘密标记、可生效私钥/证书路径或表列偏好，不自动测试或连接。
- 导出所选连接到无秘密的自主 JSON 格式；导入先显示目标与重复候选，最终确认只新增全新 ID 或跳过。预览绑定不可变文件快照，十分钟有效、本地配置变化失效、一次尝试消费，批次失败整批回退。
- 专用文件授权、原子替换及目标占用；未知字段、秘密、认证绝对路径、重复来源 ID、非法版本/编码、500 条或 2 MiB 超限拒绝。
- 缺认证文件可明确暂存，须本机选择器重新授权并保存后才允许真实建连；保留验证及指纹设置。禁用组件的待补标记保留，重新开启仍阻止误连。
- schema4 提高格式门槛，避免旧版本忽略待补标记后改变认证行为；不增加新表，迁移保持旧表及凭据。
