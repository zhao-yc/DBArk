# DBArk 0.9.0：索引与主键差异

本批新增既有表的普通、唯一、主键 BTREE 差异编辑。对象树和表页均有“索引与主键差异”入口，可以新增、改名、删除、调整有序字段、前缀、方向及注释，形成草稿后集中预览并执行一次 ALTER。单纯改名优先使用服务器原生 RENAME INDEX，不在失败后改用删除重建。

当前处于源码与安装验收阶段；尚不能将本文件或本机构建视为已公开版本。最终原生平台、安装和公开文件结果将在实际完成后补充。

## 数据与依赖保护

- 读取、预览、执行使用独立短会话，主动开启本会话外键和唯一性检查，保留查询标签的事务、临时表和设置。
- 预览绑定原定义、真实目录、服务器身份、连接修订及外部外键证据。执行前再次核对，一次性令牌在尝试时消费；仍存在外部 DDL 并发窗口，需要维护窗口。
- VARCHAR/TEXT 前缀按字符，VARBINARY/BLOB 按字节，TEXT/BLOB 必须显式填前缀。不接受超长键的自动截短；MySQL 5.7 的 DESC 在预览拒绝。
- 主键只接受已经 NOT NULL 的普通完整字段；唯一性由服务器按真实排序规则检查，不从已加载页猜测没有重复数据。删除/重建唯一约束及主键分别增加中文确认。
- 外键、自增、分区、隐藏/生成索引和可能自动删除的外键支持键均有独立保护。入向目录无权读取时保留“不完整”，不把空列表解释为没有依赖。
- MariaDB 风险默认表达式继续整表阻止；旧二进制文字默认的原字节未证明时，旁索引可按能力变更，结果不能报告完整定义核验。
- 成功后独立核验全部最终索引、未改列、外键/CHECK 和表选项。完成、未核验、未知及取消分开显示；不自动重放。已核验目标页重新读取真实可靠键，未知状态保留数据草稿并标记过期。

## 首批范围

可写能力限已实证的 MySQL 5.7.44 / 8.0.46 / 8.4.11、MariaDB 10.11.19 / 11.4.13，InnoDB、DYNAMIC、16 KiB 页；MySQL 5.7 还要求实际大前缀已开启。其它版本、引擎、行格式及页大小保持只读，不能按大版本外推。

全文、空间、表达式、不可见/忽略、生成索引及陌生属性保留原片段只读；普通键可在能证明互不破坏时增改。复杂父外键绑定、自动支持键来源和隐式聚簇/分区选择尚未证明的变更保持受限。索引草稿与字段编辑合计使用 32 快照、32 预览、16 MiB 缓存和 120 秒期限，主进程令牌也合计计量；配置格式仍为 schema4。

O01 表设计工作包仍为“部分”，外键差异、复杂表属性及全部特殊索引没有因本批 BTREE 能力而完成。
