# DBArk 0.13.0：整行 JSON 编辑

记录表单增加“整行编辑”，以带字段模式的JSON集中修改当前行，与普通字段输入互斥，共用原网格草稿、未暂存守卫和一次性SQL预览提交。精确文字、JSON原文、HEX、SQL NULL及新增DEFAULT分别保留；生成列和超限值使用锁定占位。所有条目和身份校验后一次合并，失败保留原文及原草稿，缩进和转义均计入2MiB预算。

1622正式单元及类型检查通过；修正版新增九项在MySQL 5.7/8.0/8.4、MariaDB 10.11/11.4五基线Windows直连共45次通过。Windows源码原108/108（581.982秒）、本机NSIS原108/108（626.548秒）及公开下载NSIS原108/108（634.599秒）分别通过，均零跳过、重试及flaky；真实系统加密、历史迁移、精确提交和并发冲突整批回滚分别验证。

首轮源码完整回归107通过1失败，发现删除普通记录时原已展开的只读文本框被清除；收窄整行身份失效范围后，原失败用例及完整108项复验通过。夹具和只读展示切回的原始失败、修正及复验均保留，未调整等待和断言，也未用单例复验替代完整通过。
