# DBArk 0.13.0：整行 JSON 编辑（开发中）

记录表单增加“整行编辑”，以带字段输入模式的JSON集中修改当前行；和普通字段输入互斥，共用原网格草稿、未暂存守卫和一次性SQL预览提交。精确文字、JSON原文、HEX、SQL NULL及新增DEFAULT分别保留，生成列和超限大值使用锁定占位。先完整校验再合并，失败保留原文和原页面草稿。输入格式按字段缩进，空白及转义都计入原2MiB预算。

1622正式单元及类型检查通过；144运行文件和100构建输出留摘要。新增九项在五个MySQL/MariaDB基线Windows直连共45次通过，零跳过、重试及flaky；真实预览提交、并发冲突整批回滚、字段/整行三选、隐藏标签、取消原生退出和刷新确认分别验证。六实例相关资源、项目进程及本批新目录核零，13历史目录保留。首轮大值夹具失败和只读模式切回丢失展开输入的实际回归失败、修正及复验保留。

源码完整108项进行中，本机安装、三平台原生、标签和公开下载仍须独立验收；当前公开版本为0.12.0。schema4、依赖锁、IPC和引擎写路径不变。0.12只读整行JSON没有写回入口；新功能使用独立本行输入格式。树节点编辑、跨页、关联树、模板、批量及草稿恢复继续推进，D04保持部分。macOS私网、实体输入法及人工辅助技术未验，发行签名和公证尚未接入。范围及原始证据见[整行编辑验收](https://github.com/zhao-yc/DBArk/blob/main/tests/integration/acceptance-d04-record-input-20261014.md)。
