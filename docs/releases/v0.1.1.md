# DBArk 0.1.1 开发预览

修复连接参数修改后的工作区上下文，继续提供 Windows x64、macOS arm64/x64 安装包和 MIT 开源源码。

## 修复

- 保存连接目标或认证参数成功后，仅重置该连接的对象树缓存和旧数据库选择；其它连接、查询标签、任务和事务保留。失败、取消或只修改名称等信息时不清缓存。
- 新查询使用当前选择的连接和数据库；选择中没有数据库时，不再从另一连接的活动标签带入库名。
- 安装测试为首次冷启动提供 15 秒就绪等待，仍核对真实界面、页面错误、系统沙箱和全部功能断言。
- 界面和验收使用版本元数据，避免后续发布保留旧版本号。

## 验证与下载

129 项单元测试通过。Windows 本机新 NSIS 真实安装后的 9 项全部通过（35.8 秒），包括连接上下文失效、其它连接保持、新默认库实际查询，以及快捷键 INSERT 单次写入。三个原生平台的安装验收须全部通过后才发布。本版本沿用 0.1.0 的五数据库版本、SSH/TLS、断线不重放、事务/精度及百万行引擎验收；这些修复没有改变数据库协议或精度处理。

Windows 下载 `win-x64-unsigned.exe`；Apple Silicon 使用 `mac-arm64-unsigned.dmg`，Intel Mac 使用 `mac-x64-unsigned.dmg`。macOS 同时提供 ZIP。附件包括源码 ZIP 和 `SHA256SUMS.txt`。

Windows 未发行签名；macOS 仅 ad-hoc 签名、未公证。首版手动安装升级。实体 Mac 首次 Gatekeeper 交互和 macOS 到内网数据库的实库 UI 仍未验证。Navicat 主程序分析超时的证据限制，以及复杂表结构、结果容量、分批导入和只读边界继续适用。

详情见 [使用指南](https://github.com/zhao-yc/DBArk/blob/v0.1.1/docs/user-guide.md)、[验证记录](https://github.com/zhao-yc/DBArk/blob/v0.1.1/docs/validation.md) 和 [功能对照](https://github.com/zhao-yc/DBArk/blob/v0.1.1/docs/feature-matrix.md)。服务器网页、同步、备份、自动化和建模保留后续里程碑。
