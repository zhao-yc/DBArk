# DBArk 0.9.1：独立任务关闭阶段取消修复

本补丁处理独立结构或关联操作已经失败、正在关闭原连接时的迟到取消。动作阶段不论成功或失败，在进入清理的首个异步等待前同步标记已经结束；此后取消只等待该任务实际完成，不再创建新的 KILL 控制连接。动作期间已经登记的取消仍等待控制连接和原连接真实收尾，之后才释放任务编号、配置使用及原有表执行互斥。

变更只涉及上述生命周期门和四项独立回归，不包含后续外键差异、父子多目标锁或新界面。没有放宽取消身份/代次校验，没有修改连接时限、权限或重放策略，配置仍为 schema4。

## 已知证据与待验阶段

公开0.9归档自身的 Engine 已用纯内存驱动独立复现，四项中两项失败、两项操作期间取消的对照通过。工作区相同反例修复后相关90项回归通过；这些工作区结果包含后续准备代码，不能代替本补丁冻结源码及安装文件的验收。没有把纯内存反例声称为实际服务器复现，没有证明误杀新查询或写操作重放。

本补丁将从单独提交的源码归档构建，保留未发布外键工作区。类型/单元、Windows原有完整70项、真实安装、三平台原生及公开文件按实际后续结果记录；当前尚未发布。固定0.9标签和附件不替换。

0.9的BTREE范围、其它未完成Navicat工作包、macOS私网实库和发行签名/公证限制继续适用，详见[0.9说明](v0.9.0.md)。
