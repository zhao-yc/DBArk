# DBArk 0.21.0 开发预览（候选）

本候选继续完善 MySQL/MariaDB 日常开发中的对象操作、查询编辑与表数据导出。当前尚未公开发布，原生构建和新安装包验收继续；公开版本仍为 0.20.0。

- 时间字段可按支持范围设置或移除自动更新时间，新增字段时也能明确选择默认值、精度和自动更新行为。
- SQL 支持选区或全文格式化、按钮及 Alt/Option+Shift+F，保留选区外原文以及一次撤销、重做。
- 新建数据库可选择字符集和排序规则；执行历史支持时间范围筛选，并报告无法识别的旧时间。
- CSV 表导出可勾选字段、调整顺序并保持精确数值；修正 CSV、JSON、SQL 表导出取消与文件提交之间的状态判断，以及取消后仍可能发送数据读取的边界。
- 单表删除、清空和同库复制空表结构提供专用预览、准确名称及风险确认。复制支持已核范围内的自增列，明确展示源计数和新表预期值，创建后核验准确计数；不会复制行数据。

DDL 可能隐式提交。复制不包含外键、触发器、授权或其它依赖；当前限定已核 MySQL 8.4.11/Linux、默认自增策略、ASCII 非分区普通 InnoDB 表。生成/隐藏列、CHECK、复杂/特殊索引、已知依赖及其它复制版本仍未完成。未知写入不自动重放，创建后核验失败不会自动删除或重建目标。

公开 0.20 的表导出取消问题仍保留在其版本说明中；本候选修复不表示旧安装包已经改变。新建表的一次性创建流程、完整数据库兼容性与 Navicat 其它工作包继续开发。
