# DBArk 0.21.0 开发预览

本版继续完善 MySQL/MariaDB 日常开发中的查询、结果浏览、表设计和对象操作。产品源码沿用已完成三平台检查的 `c256c06`；发行整理只修改文档。Navicat 全功能目标仍在推进。

## 常用工作流

- SQL 选区或全文格式化支持按钮与 Alt/Option+Shift+F，保留选区外正文及一次撤销、重做。字号和自动换行可持久化，执行历史增加时间范围筛选。
- 当前查询可复制为独立新查询；“关闭其他查询”逐项处理保存、取消和冲突，保留当前标签，遇到取消或保存失败停止。
- 增加受 MySQL 版本及语法范围约束的 INSERT 新行别名字段补全，避免把 SELECT、CAST 的 AS 误认成新行别名。
- 查询结果支持列搜索、隐藏与顺序调整、本地查找与匹配导航；可将勾选行导出 CSV/JSON。只读整行详情包含已返回的隐藏字段，保持重名列、NULL、空串、精确数字与二进制的区别。
- 表数据可复制为有界 INSERT SQL；CSV 表导出可选择字段并调整顺序，完整导出继续走流式任务。

## 表设计与对象操作

- 时间字段支持范围内的自动更新时间设置和移除；新增字段可明确默认值、精度与自动更新行为。
- 新建数据库和表可选择实际字符集、排序规则配对。新建表增加准确名称确认、SQL 预览与一次性执行；可调整字段顺序，并核对字段、索引、外键之间的关联。
- 普通 BTREE 前缀索引补齐字符/字节单位和复合键预算，具体版本、引擎及页大小限制保留。
- 删除、清空、同库复制空表，以及同库复制结构与数据均提供专用预览和风险确认。复制支持的自增列及有限生成列分别按已证明范围开放。
- 结构比较增加分类、状态、名称筛选和定义展开；服务器监控支持只读概要、有限会话、串行刷新及本地筛选排序。

## 修复

- 修正表导出取消与文件提交之间的状态判断，以及取消后仍可能发送读取的问题。进入不可撤回提交阶段后等待实际结果，不假报取消。
- 修正批量关闭推进时序、旧请求干扰、查询复制覆盖迟到草稿，以及结果来源变化后旧勾选或查找状态复活的问题。
- 修正表设计目标改变后迟到预览重新接纳，以及编辑器偏好旧保存回调、损坏换行设置影响工作区恢复的问题。

## 验证与限制

固定 `c256c06` 的 Linux 检查为 **8353 项通过、10 条件跳过，类型及构建通过**。Windows x64、macOS arm64/x64 各源码和真实安装阶段均 **76 通过、291 条件跳过、0 重试**。阶段计数包含组件层次，不代表 76 个安装产品路径。准确运行、原日志、专项实库来源和下载摘要见[发行检查点](../../tests/integration/acceptance-v021-c256-checkpoint-20261018.md)。标签发行仍须由工作流重新通过源码与三平台门；公开文件以附件及 `SHA256SUMS.txt` 为准。

专项实库证据各有固定版本和产品来源，当前构建尚未覆盖完整实库安装矩阵，macOS 私网实库仍待验。新建表的 MariaDB 11.4.13 后核曾失败，本版不把它计作已验证组合；新表前缀等也仅开放已证明范围。

DDL 可能隐式提交；未知写入不自动重放。复制不是任意表的通用克隆：外键、触发器、CHECK、隐藏列及复杂依赖仍有限制；带数据复制的建表与数据提交不原子。监控为有限非原子快照，不能结束会话；结构比较不自动同步。完整数据库备份/恢复和后续单列排序规则编辑尚未交付。

Windows 未发行签名；macOS 使用临时签名、未公证。采用手动更新。旧 0.20.0 安装字节不因本版源码修复而改变。
