本版尚未公开发行，当前公开预览仍为[0.21.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.21.0)。产品冻结为`bf08645a28fceb5d1d40ba16f013bb78e7a7c0a2`；验收脚本与文档头单独记录，后续0.29代码不纳入本版。

## 本版行为

- SQL格式化新增关键字大小写偏好：默认保持，显式大写/小写只转换可确认的关键字；字符串、注释和标识符保持。等待解析模块期间编辑或切换上下文会撤销旧操作。
- 已返回/勾选结果可导出INSERT SQL：明确库、表及全部目标字段，预览后选择文件；导出本身不执行SQL。
- “新执行并完整导出”增加INSERT SQL：在当前会话新执行一次，流式暂存后显示真实样例、行数与字节，核对准确目标后才发布同一文件。仅接受一个完整行结果集；取消不撤销已经执行的SQL。
- 表CSV、结果CSV及新执行完整CSV/多CSV ZIP增加分号和Tab分隔符，逗号默认行为保持；迟到文件选择不会覆盖新配置。
- 完善SQL文件首次模型、LF/CRLF、格式化单次Undo/Redo及来源保存；编辑器缩进与分栏按真实窗口验证，配置格式仍为schema9。
