# DBArk 0.28.0 开发候选

本版尚未公开发行，当前公开预览仍为 [0.21.0](https://github.com/zhao-yc/DBArk/releases/tag/v0.21.0)。

- SQL 格式化新增关键字大小写偏好，默认保持；显式大写只修改可确认的关键字，解析器按需加载，等待期间编辑或切换上下文会撤销旧操作。
- 已返回／勾选结果可导出 INSERT SQL，明确库表字段映射，先预览、选文件并确认目标；沿原子文件任务写出，不执行 SQL。
- 保留 0.27 的 CSV 分隔符和新建表自动更新时间，SQLite 格式仍为 schema9。

组合源码的 261 项相关测试与类型检查通过，本地正式构建产生 109 个编译产物，关键字角色解析器位于单独动态块。旧当前语句测试夹具漏引用造成的首次 1 项失败已经修正，原 19 项断言通过；修后 `4236db0` 的[完整 CI](https://github.com/zhao-yc/DBArk/actions/runs/39105522660)为 517 文件／9551 通过／10 条件跳过，类型和构建成功，桌面及发行步骤跳过。

三平台原生／安装及实库验收继续；本版尚无安装包，也不继承旧候选的安装结论。完整查询流式 SQL 导出仍未开放，不能将已返回快照当成所有查询行。详细证据、原失败和独立对照见[主线整合记录](../development/sql-workspace-root-20261018.md)。
