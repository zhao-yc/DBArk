# DBArk 0.3.0 开发预览

扩展日常 SQL 文件、结果保存、片段复用和类型参数工作流。当前驱动仍为 MySQL/MariaDB，Navicat 全功能持续目标按高频优先推进；此版本不代表完整覆盖。

## 新增与修复

- SQL 文件按 UTF-8、UTF-16LE 或 GB18030 打开为独立标签；另存保护原文件、查询正文和事务，支持各平台快捷键。
- 成功结果和固定快照可导出 CSV/JSON 已返回行。保留精确值、NULL、二进制、重复列和空名，显示截断范围，独立任务提供进度与取消；断开连接后仍可导出旧快照，不重执行原 SQL。
- SQL 片段支持分组、全文搜索、新建、编辑、复制、删除和内置模板。插入是普通文本编辑，保留撤销栈，不建立会话或执行查询。
- `:name` 值参数支持文本、整数、小数、布尔、日期、日期时间、时长、Hex 二进制和 NULL。选区优先，重复名共用值，精度和整组预算在发送前校验；历史及快照 SQL 保留模板，填写值不进入工作区或配置库。
- 从 mysql2 协议包读取会话模式及事务，去除会影响 `ROW_COUNT()`、`FOUND_ROWS()` 和警告的附加状态 SQL。关闭跟踪或发生错误后仅允许候选模式间边界一致的 SQL，歧义明确停止。
- 服务器错误后事务标为“需核对”，保留提交、回滚和退出保护。后续成功协议状态恢复确定提示，失败脚本不自动撤销已提交前缀或重放写操作。

## 已完成源码验收

273 项单元测试、类型检查及构建通过。参数及协议核心在 MySQL 5.7.44、8.0.46、8.4.11 和 MariaDB 10.11.19、11.4.13 各 17 项通过，共 85 项；既有连接、精度、编辑、筛选、结构与边界回归另有 152 项通过，23 项明确跳过 TLS/SSH、容量或不适用方言场景，独立验证不得由跳过替代。

独立 SSH 私钥隧道再验收 31 项通过、2 个 TLS 专属项跳过；严格 TLS 再验收 32 项通过、1 个 SSH 专属项跳过。两种传输分别包含完整 17 项参数测试；错误 CA、SAN 身份和 SSH 指纹实际拒绝。TLS 强制加密，实测 TLSv1.3；密码 SSH 和双向 TLS 仍未验收。

Windows 完整源码桌面首轮 21 项通过、2 项新增参数测试失败、百万行旧用例明确跳过（166.792 秒）。保留字别名和 Monaco 模拟输入补引号得到真实证据后修正测试，新增参数 4/4 定向复验通过（25.6 秒），运行时代码未为测试改变。逐字输入断言、真实剪贴板粘贴、全部原功能断言、独立观察连接及 SQLite 参数隐私检查保留，不声称单轮全绿。片段、文件、已返回结果及既有实库 UI 均有实际运行记录。

## 升级与范围

升级前退出应用并备份整个用户配置目录。片段迁移将 SQLite schema 从 1 升至 2；旧 0.2.0 不能读取新版配置。回退须恢复升级前的完整目录，另行保留新版目录，不能删除新库或改版本号绕过保护。

当前仅支持手动更新。Windows 未发行签名，macOS 仅 ad-hoc 签名、未公证；实体 Mac Gatekeeper 首次交互及 macOS 内网实库 UI 尚未验证。任意 SQL 完整流式结果导出仍待实现，当前导出只包含已返回行；SQL 结果只读，DDL 通常隐式提交。其它数据库驱动、同步、备份、模型、BI 和协作继续保留在 [完整清单](https://github.com/zhao-yc/DBArk/blob/main/docs/navicat-coverage.md)。
