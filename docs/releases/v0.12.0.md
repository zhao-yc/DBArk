# DBArk 0.12.0：只读记录树与整行 JSON

记录表单增加“只读树”和“整行JSON”展示方式，沿用当前页共享草稿和未暂存输入守卫。切换和展开不自动查询或提交；显式翻页及刷新仍走原读取。完整类型化JSON包含隐藏字段，用于查看和复制。

JSON词法树保留客户端原文中的大数字、负零、大指数及重复成员；路径由精确列名、成员序号和数组下标组成。每组32字段、480结构条目，最多512可见条目；非法、超深和超预算不返回部分树。整行全文在序列化前按转义后UTF-8核对2MiB预算，拒绝显示不截断本页草稿。原生JSON按服务器返还原文核验，Maria别名保持实际元数据类型。

1561单元和正式类型检查通过；新增9项在MySQL 5.7/8.0/8.4、MariaDB 10.11/11.4五基线Windows直连共45次通过。Windows源码完整99/99（576.885秒）、本机NSIS完整99/99（546.527秒）和公开下载NSIS原99/99（562.557秒）分别通过，均零跳过、重试和flaky，实际执行系统加密和schema2到4迁移。本机包137613191字节，SHA256为`ebf625c8a12e0380fdfc5ef29b9c4aa49707f8236e886c9792a069c631538523`，与公开CI产物独立验收。

[主分支CI](https://github.com/zhao-yc/DBArk/actions/runs/38554132517)及[固定标签CI](https://github.com/zhao-yc/DBArk/actions/runs/38556105769)均通过类型、单元和三架构原生构建。Windows x64、macOS arm64/x64每轮源码及真实NSIS/DMG各22离线通过、77私网跳过，真实加密、历史迁移、卸载或DMG分离及临时目录清理通过。macOS私网实库、实体输入法及人工辅助技术仍未验。

12个公开资产的大小、GitHub摘要和SHA256清单全部一致；源码归档512个普通文件与固定标签`b3afb2a749f45d5ff2d5735d24c6211286c21725`逐Git blob一致。公开Windows安装包为137613192字节，SHA256为`ad517923450981903fed1dbba343f0d09e275ffb40061382e98da45193cf8bc7`。安装使用归档自身原99项及配置，源码前后不改；真实卸载及独立六实例相关资源、项目进程、新目录和注册名称/固定GUID均核零，13个历史目录保留。标签及公开资产不替换。

schema4和依赖锁不变。只读JSON没有导入、恢复或写回入口；D04仍为部分，树编辑、整行JSON回写、跨页连续表单、关联树、模板、批量表单及草稿恢复继续推进。Windows未发行签名，macOS仅ad-hoc且未公证。完整适用范围、预检原件和证据见[投影验收](https://github.com/zhao-yc/DBArk/blob/main/tests/integration/acceptance-d04-record-projections-20261014.md)与[实现计划](https://github.com/zhao-yc/DBArk/blob/main/docs/plans/record-projections.md)。
