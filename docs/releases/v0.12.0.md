# DBArk 0.12.0：只读记录树与整行 JSON

记录表单增加“只读树”和“整行JSON”展示方式，沿用当前页共享草稿和未暂存输入守卫。没有新增数据库写路径，切换和展开不自动查询或提交；显式翻页和刷新仍走原读取。整行JSON带明确类型标签并包含隐藏字段，属于只读显示格式，没有导入、恢复或写回入口。

JSON结构使用有序词法树保留客户端原文中的大数字、负零、大指数和重复成员，路径使用列名、成员序号及数组下标。每组32字段和480结构条目，最多512可见条目；非法、超深或超预算不提供部分树。完整整行JSON先按转义后UTF-8预检2MiB，再生成可原生选择复制的只读文本；拒绝显示不改变完整本页草稿。
