# DBArk 0.10.0：外键差异设计

新增独立“外键差异”窗口，可从对象树或表标签进入。支持已有表的外键新增、删除、明确异名替换，复合有序字段、跨库父表、自引用及四种引用动作。先暂存草稿、生成只读 SQL、逐项确认，再单次执行。

父子表必须已有可靠完整支持索引，类型与字符属性相容；需要新索引、改字段或处理孤儿数据时须先独立操作。候选父表由用户显式加载，重读前确认舍弃编辑。首批不支持同名 DROP/ADD，不自动改名、补键、修复数据或失败后重放。未知旧语法和名称保留原片段只读，完整范围见[中文指南](../user-guide.md)。

全局原生目录与逻辑目录交叉闭合，服务器执行名称比较；权限、预算或能力不完整时不猜测可用。预览及执行前重核父子表、支持键、模式及命名空间，执行后核未改定义和新旧父表。共享父子执行租约、草稿保护、一次性令牌和实际关闭终态，保留普通查询事务。DDL 可能隐式提交，取消或断线须独立核对实际结果。

受控版本为 MySQL 5.7.44、8.0.46、8.4.11，MariaDB 10.11.19、11.4.13，以及已证明的 InnoDB/DYNAMIC/16 KiB 等物理条件。其它版本与未知能力只读。O01 仍为部分，特殊索引、复杂表属性、其它驱动和后续工作包继续保留。

当前 1408 项单元、类型与构建通过；五数据库基线、SSH 及严格 TLS 的产品 API 各 25 项通过，共 175 项，五版新增 Windows 真实界面各 7 项通过。完整源码、安装及公开文件按阶段继续验收，不由已有结果外推。阶段结果、早期清理钩子失败与修正见[外键验收记录](../../tests/integration/acceptance-o01-foreign-keys-20261014.md)。

配置仍为 schema4。Windows 未发行签名，macOS 只采用 ad-hoc 签名且未公证；macOS 内网实库继续未验。下载文件将在固定版本标签通过三平台检查后公开，公开文件另行独立校验。
