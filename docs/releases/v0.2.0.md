# DBArk 0.2.0 开发预览

完善日常查数与结果对照，修复表设计、模态窗口和加载失败的正确性边界。持续开发范围已扩展至 Navicat 全功能，当前依然只发布 MySQL/MariaDB；其它驱动及高级工作包见完整覆盖清单，不能据此版本号视为全功能完成。

## 新增与修复

- 表格支持满足全部或任一条件、IN/NOT IN/BETWEEN/NOT LIKE、编辑已有条件和直接跳页。空字符串、NULL、集合中的逗号/空格明确区分。
- 数值筛选采用精确十进制比较，避免字符串隐式转浮点后误命中相邻 BIGINT 或 DECIMAL。非唯一排序追加可靠键作为并列顺序。
- 查询成功完成后可固定结果快照，重执行仍能查看旧数据及原 SQL；每标签最多 5 组、合计 16 MiB，关闭后释放。失败/取消的流式片段不能固定。
- 查看只读快照 SQL 等模态窗口时，执行快捷键不会穿透到后台查询。
- 翻页或筛选失败会清除旧结果并禁用编辑，避免把旧页显示成新条件下的数据；原有草稿放弃确认继续生效。
- 表设计保留未变化的索引和外键。同名外键修改分两条 ALTER 预览，明确部分提交和恢复边界，不关闭外键校验或悄悄改名。
- 导入等待当前目标元数据后生成预览与映射，绑定文件、格式和编码，旧响应不能覆盖人工选择；未就绪禁止导入，不重试写操作。
- 桌面测试生命周期改为每例自动夹具，多个测试文件都真实启动并释放自己的 Electron 实例。

## 验证

191 项单元测试和 TypeScript 检查通过。五个数据库基线的新筛选、精确编辑及结构差异 72 项通过，另 MySQL 8.4 核心及边界 16 项，本轮引擎合计 88 项。Windows 源码桌面 12/12 通过（88.171 秒），本机 NSIS 真实安装后 12/12 通过（88.405 秒），含 7 项离线和 5 项实库；百万行 UI 三阶段仅渲染 22 行，跳第 1000 页核对末行编号 1000000。真实卸载后项目进程、安装注册及随机库为零。三个原生平台的 CI 与随包验收全部通过后才发布；公开文件仍需独立下载校验。

## 下载与边界

Windows 使用 `win-x64-unsigned.exe`；Apple Silicon 使用 `mac-arm64-unsigned.dmg`，Intel Mac 使用 `mac-x64-unsigned.dmg`，另提供 ZIP、源码及 `SHA256SUMS.txt`。

Windows 未发行签名；macOS 仅 ad-hoc 签名、未公证。手动升级。实体 Mac 首次 Gatekeeper 交互与 macOS 到内网数据库的实库 UI 未验证。复杂结构仍使用 SQL 定义，数据库 DDL 通常隐式提交；同名外键修改若第二步失败或取消，必须恢复旧约束并核对相关写入。
