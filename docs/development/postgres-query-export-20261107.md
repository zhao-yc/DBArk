# PostgreSQL 完整查询导出

完整查询也可[流式导出 Excel](full-query-xlsx-20261107.md)。

在 PostgreSQL 查询页输入一条 `SELECT` 或 `WITH … SELECT`，点击「执行并导出完整结果」。有单一非空选区时使用选区，空光标时使用完整正文。核对 SQL、数据库、格式和编码，选择保存位置后点击「执行查询并保存」。窗口展示 SQL 的前 4000 个 UTF-16 单元，查询输入上限为 4 Mi 个 UTF-16 单元。

导出在目标数据库的独立只读会话重新执行查询，读取已提交数据。临时表、会话设置和原事务里的未提交数据仍属于原查询会话。需要会话内结果时，可继续使用「导出已返回结果」。有连续位置参数时，可先在「设置导出参数」中采用本次类型和值，再选择保存文件。

CSV 支持逗号、分号和制表符分隔。CSV 与 JSON 均支持 UTF-8、UTF-16LE 和 GB18030。重名列按位置追加后缀，大整数和精确小数保持文本，JSON 的二进制值带有 `type` 和 Base64。CSV 使用 `\N` 表示 NULL，二进制值使用 `base64:` 前缀。JSON 沿用完整查询结果容器，数据位于 `results[0].rows`。

实现沿用原子文件、文件路径互斥及查询流式文件编码器。游标每批读取 64 行，每批最多 64 MiB，字段和行另受编码器的 8 MiB、16 MiB 上限约束，文件上限为 10 GiB。游标和独立会话正常结束后发布文件。取消会请求取消准确的导出后端，并等待原操作收尾。[PostgreSQL 游标](https://www.postgresql.org/docs/18/sql-declare.html) [分批读取](https://www.postgresql.org/docs/18/sql-fetch.html)
