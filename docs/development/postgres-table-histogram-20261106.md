# PostgreSQL 数值直方图

在 PostgreSQL 表或视图的「字段概况」中选择数值字段和 5、10 或 20 个目标区间，点击「读取数值分布」。选字段和区间只修改窗口输入。常规「开始统计」仍可查看原字段概况。

分布覆盖当前已应用筛选的全部已提交记录。服务端在独立只读事务的一条查询中取得极值及区间计数。未应用的条件和未提交的草稿留在原页。区间左闭右开，最后一个区间包含最大值。有限值全相同时显示一个区间。NULL、NaN 和正负无穷值单独计数，不参与区间百分比。[PostgreSQL 区间函数文档](https://www.postgresql.org/docs/18/functions-math.html)

smallint、integer、bigint 和 numeric 使用精确十进制边界。real 和 double precision 使用服务器可往返的浮点文本计算近似区间。服务器配置舍入浮点文本时会提示无法区分区间，保留当前连接配置。单个极值的十进制文本上限为 4,096 字符，超限时报错，避免截断精确边界。没有有限值时显示空区间。

## 验证记录

- macOS arm64，Node.js 24.17.0。运行时检查、严格类型检查、构建和 35 项定向单测通过，包含既有 MySQL 数值分布用例。
- Server-200 隔离 PostgreSQL 18 的 5 项实库回归通过。覆盖高精度边界上的值、单值、空范围、NULL 和非有限值、超大及次正规浮点、舍入输出设置、超长边界预算，以及易变视图每个源值只计算一次。
- macOS Electron 专项通过 27 项检查。第二页读取五个精确区间及全部两条匹配记录，关闭后原页和待提交草稿仍在。独立读回确认数据保持，窗口正常退出，测试容器在核对原行及零连接后清理。
- macOS 全量单测运行 1,342 个文件，27,524 项通过，10 项 Windows 条件测试跳过。全量运行期间扩大了区间中间边界的校验预算，受影响的定向测试在最终源码上另行复验通过。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
