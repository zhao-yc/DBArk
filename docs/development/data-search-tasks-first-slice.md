# 数据搜索任务首阶段

本阶段将已有数据搜索计划接入独立引擎任务、公开参数校验、预加载白名单和主进程分派。随后已增加正式搜索界面、分页范围目录和“打开所属表”入口，见[界面验收](../../tests/integration/acceptance-w03-data-ui-20261015.md)。精确记录定位仍未完成，因此不是完整 W03，也没有发布新版本。

## 任务协议与边界

- `search.dataStart` 返回首批或实际收尾后的终态。`search.dataNext` 确认上一批序号并拉取下一批；重复确认重用同一回复，不推进额外读取。跨连接、未来序号和失效确认被拒绝。
- `search.dataRelease` 先核归属，再取消并等待真实收尾；不存在的数据搜索句柄不会取消同号普通 SQL 任务。连接关闭和引擎退出共用独立任务取消边界。
- 每处匹配单元格计为一处命中，同一行多个字段分别显示；每批最多 50 处、128 KiB，只有一个在途批次。等待确认期间不继续消费服务器行，60 秒未确认则失败并收尾，不再发需要确认的错误批。
- 最多同时运行 4 个搜索、保留 32 个短期句柄；终态句柄保留 5 分钟。单任务最多 1,000 处、累计结果预算 32 MiB。达到上限是带截断标记的完成，不能据此宣称全部范围已搜索。
- 宽表分成每块最多 16 个字段，保留原字段位置，不丢弃第 17 列以后选择。错误按停止或继续策略逐块回传，未发送的命中不冒充完整结果。
- 服务器对完整字段匹配，仅返回 128 字符预览及独立候选键；预览不能代替原值或更新条件。无可靠键、浮点键或超大键保持只读。视图必须明确允许，其处理可能执行函数。
- 搜索值和命中只经有确认的回复传输；任务事件仅含计数，磁盘概要不保存搜索值、命中或服务器错误原文。

实际查询使用带参数的二进制协议，不因准备失败切换文本并重放。消费者失败或命中上限使用代次保护的 `KILL QUERY`；用户取消结束独立连接。原命令终包、控制连接和独立连接均在收尾边界内等待。控制建连失败则明确失败并提示服务器状态未确认，不能声称已确认服务器结束。

共用流式协议同时修正行 EOF 警告处理：当前固定驱动在 EOF 也携带 SQL，警告数在该真实边界保留，不能按 SQL 字段是否存在推断 EOF。

## 验证

2026-10-15，当前任务分支全量单元 2,134 项通过，严格 TypeScript 检查和生产构建通过。

数据搜索真实引擎矩阵为六实例各 15 项，共 90 项，零失败、零跳过：MySQL 5.7.44、8.0.46、8.4.11，MariaDB 10.11.19、11.4.13，以及 MySQL 8.4.11 严格 TLS。覆盖 50/50/25 分批、重复及非法确认、大字段尾部命中、65 列完整分块、精确键、上限、错误策略、ACK 取消和超时、长查询取消、控制建连失败注入、跨任务释放以及真实文本/二进制 EOF 警告。

既有完整 SQL 导出 19 项在 MySQL 8.4 隔离实例通过，包含事务、模式、精度、取消、断线、100001 行以及百万行 CSV/JSON 逐行验证。该结果不能代替新版本的其它平台或实际安装验收。

一次控制失败注入揭示本地连接销毁先于消费者识别断线的竞态，修正后完整矩阵通过；失败轮留下的唯一随机夹具已核对对象、行和列特征后精确删除。最终独立检查六实例，本批隔离库、临时用户和相关线程均为零。原失败记录保留，不以之后的通过覆盖原结果。

后续仍需稳定对象身份和精确命中记录导航、数据搜索的列权限降级、完整桌面回归，以及本批 macOS 私网界面与安装验收。界面阶段已真实验证已有表格草稿与查询事务保持；不能以已公开命令或打开所属表代替完整工作流。
