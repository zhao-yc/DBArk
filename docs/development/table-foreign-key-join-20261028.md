# 按外键生成 JOIN 查询（开发中）

## 使用范围

表页面新增“按外键生成 JOIN 查询”：选择一条服务器返回的真实外键、LEFT／INNER连接方式及双方输出字段，预览后打开同连接的独立查询草稿。预览只读结构，不查询行数据或执行SQL，也不提交原表页草稿。新查询以子表所在库作为明确默认库，语句中的两侧表名均完整限定。

本切片支持一条出向外键、复合字段、跨库及自关联；完整可视化查询构建器、任意多表关系、聚合和视图设计仍属后续工作，不因此将O04记为完成。表页的筛选、排序、当前分页和本地草稿不作为新查询条件，用户应在独立查询中补充并审阅。

## 数据与异步边界

- ON按外键全部字段的目录顺序使用普通等号，允许合法的可空UNIQUE被引用键，不借用写入定位键条件。LEFT保留未匹配子行，INNER只保留完整匹配；结果受配置的LIMIT约束。
- 两侧使用c/p角色及按原列序号生成的唯一输出别名，同名字段和自关联不会覆盖结果列；显式选列保持顺序。宽表可精简输出，元数据、字段数和SQL文本有上限。
- 父表必须经真实元数据读取，读取失败不猜测结构。打开前重新核对两表的相关列和外键快照，变化则重新打开；这不是跨表DDL锁或物理对象身份承诺。
- 重复预览保留同一关系的字段选择、顺序和空侧选择；相关父结构变更后原意图失效，须重新打开。
- 元数据使用既有任务编号及取消接口。关闭、切页、连接变化或旧回包不生成新查询；取消响应和原请求实际结束前持续保留本例占用，不能仅凭取消ACK释放。

## 验证安排

纯逻辑验证复合映射、别名、标识符引用、NULL等号、选列顺序、预算和拒绝路径；组件验证实际来源失效、取消及单次打开。真实验收使用200专用实例的全新隔离库，不建立用户或授予权限，不使用遗留草稿库。

预置数据将分别检验“同第一字段但第二字段不同”“同第二字段但第一字段不同”及可空父键，避免缺少一项ON条件或误用NULL安全等号仍能通过。实库结果、UI入口、任务收尾和清理必须另有原始证据，未执行前不能以测试代码存在视为通过。当前未发布。

最终候选类型、55项JOIN专项及构建通过；此前九文件156项相关回归与后续两项重复预览反例分轮记录，不简单相加。Windows源码在MySQL8.4完成正式复合例：LEFT精确单次执行、原BIGINT／DECIMAL／NULL结果、原草稿保持、INNER及自关联仅预览打开、8个独立元数据任务和正常退出，准确测试库已独立清理。原类型、预置控制器关闭、playwright命令包装层环境和清理预检告警失败均保留；仅绕过注入NODE_PATH的shim，继续使用原Playwright CLI，不放宽断言。其它平台／版本和新安装另有边界，见[验收记录](../../tests/integration/acceptance-table-foreign-key-join-20261028.md)。
