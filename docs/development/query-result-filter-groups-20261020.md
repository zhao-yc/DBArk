# 已返回结果的分组条件

## 入口与语义

在“筛选已返回结果”点击“添加条件组”，每组可独立选择全部满足（AND）或任一满足（OR），并可添加子组。例如：（状态等于A或B）同时满足金额大于0。分组自带一条可见条件，可移除整组；清空根条件仍表示保留原全部返回行，空子组明确拒绝应用，避免将未填分组误当恒真条件。

原比较器、NULL、区间及多值规则保持；普通否定不纳入NULL，需显式NULL条件。只过滤已返回快照，不重发SQL，不扩展已截断结果。应用后排序、勾选、查找和详情按原规则重置，复制和导出共享最终原行映射。

## 实现边界

总计最多32个叶条件、16组（含根）、8层。整树先校验，再验证全部原值并完整计入原200万次比较及字符预算；OR已满足和空源不能跳过坏值。子数组按自有数据属性、有界固定长度读取，不调用迭代器或getter；拒绝循环、空子组和混合节点。保存独立冻结的树、叶及成员数组，不冻结原结果。

面板使用稳定节点ID、整棵草稿身份及原结果租约。删除组、输入、操作切换和取消都不改变已生效树，旧输入／删除／应用回调不能写入新草稿。输入法组合期间禁用组结构修改和应用。
