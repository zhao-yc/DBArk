# PostgreSQL 查看引用记录

在表页网格选中一行，或在记录表单定位一条记录，点击「查看引用记录」。窗口按当前行在数据库中的原值定位父记录。存在多个外键时可在约束下拉框切换。字段原值可展开为只读文本，BYTEA 以十六进制显示。浏览后可回到原表继续编辑草稿。[Navicat 数据编辑器的外键导航](https://www.navicat.com/en/products/data-editor-for-rdbms?product=navicat-for-oracle#foreign-key-navigation)

读取使用数据库的复合键顺序、比较操作符及父键排序规则。目标字段受列权限和行级策略约束。窗口最多显示外键字段和 16 个可读说明字段。原行已被替换时，刷新表页后再查看；空外键或父记录不可见时显示空结果。[PostgreSQL 外键目录](https://www.postgresql.org/docs/current/catalog-pg-constraint.html)

仅有读取权限的账号可以从拥有表级 SELECT 权限的普通表或分区表查看父记录。打开独立父表页、查看子记录和时间范围外键仍待接入。
