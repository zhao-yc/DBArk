# PostgreSQL 计划快照与比较

在查询标签生成估算或实测计划后，点击「保存计划快照」保存为 `.dbark-plan.json`。从主工具入口「打开计划快照」选取文件，即可离线查看树形计划、原始输出和指标。

- 估算与实测各自沿用现有版本 1 快照。旧 MySQL／MariaDB 快照继续按原规则打开。PostgreSQL 快照保留原始计划和实际协议结果，恢复时重新计算展示树。
- 打开一个 PostgreSQL JSON 快照作为基准，点击「打开对比快照」选择同类文件。界面按 JSON 节点路径显示新增、移除及变化字段，并列原值和新值。可展开未变化的路径。节点换位会在各自路径显示变化。
- 比较保留服务器十进制文本。字段对象的键顺序变化不计入差异。估算与实测分开比较，截断、空树或超过预算的文件可回到原视图查看。
- 保存、打开和比较无需重新执行 SQL。快照排除原查询语句字段、连接、会话及活动事务，计划中的过滤条件仍可能包含业务值。

## 验证

- Mac 类型检查、源码构建和 146 项定向单元通过。覆盖旧快照兼容、PostgreSQL 估算／实测往返、截断和异类拒绝、原始精度与实测时间比较。
- Mac 完整单元回归覆盖 1,319 个测试文件，27,405 项通过，10 项 Windows 系统 tar 检查按平台跳过。
- Server-200 的 PostgreSQL 18 独占实库回归 5 项通过。成功容器复核原行、零连接后清理。
- Mac 原生窗口保存两个估算快照和一个实测快照，关闭查询标签后从主工具入口打开、比较估算计划并离线恢复实测计划。异类比较被拒绝且原比较保留，任务和执行历史保持。只替换文件选择路径，主进程使用正式读写入口。单 worker、120 秒、零重试、trace 关闭，窗口和临时配置已清理。
- WIN11-TEST 会话不可达，本轮未派发，按约定在 Mac 验证。Windows 原生窗口和安装包尚待验收。
