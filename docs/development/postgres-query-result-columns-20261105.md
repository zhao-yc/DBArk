# PostgreSQL 查询结果列管理

查询返回结果后，点「管理结果列」，按列名、类型或原列序号查找列。可隐藏或移动列，冻结从左侧到指定列的可见列，也可设置列宽和数据行高。应用后，网格、复制和文件导出使用同一组可见列与顺序。重名列通过原列序号区分，导出为可见的重名列分配独立名称。

- 更改布局时，当前筛选和排序会重新应用于可见列。若拟隐藏的列仍有筛选条件或排序规则，窗口会提示先移除该规则，并保留原显示和草稿。
- 可逐列、批量或按已返回值调整列宽，也可在网格拖动列边界。列布局只属于当前查询结果集。切换结果集、执行新查询或连接配置变化时重置布局。
- 导出已返回行或勾选行时，使用当前筛选和排序后的行及可见列投影。显示整理与导出均从返回结果读取。
