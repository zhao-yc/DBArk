# 筛选与完整多列排序联动

## 行为

查询结果应用、重应用或清除筛选时，保留已有排序的完整优先级、方向、NULL 位置和文本大小写选项。先筛选再排序，全部停用或空条件显示按原排序排列的全部已返回行；空匹配仍保留规则，方便随后改条件。

“恢复原返回顺序”仍是明确清除排序的入口。筛选成功后撤销旧勾选、查找、复制和详情操作许可，原值及精度保持。每次筛选变更只记一整步，可同时撤销／重做筛选与排序视图，原样应用不丢重做分支。暂存整理槽保持。

清除或放宽筛选可能重新纳入不适合原排序的值，或超过比较／Unicode 映射预算。此时整次拒绝，保留原筛选、排序、历史与草稿；清除失败也保留原选择。可先检查规则或明确清除排序，再改变筛选。没有静默丢弃条件、排序键或回退全集。

## 实现

`FilterLease` 同时捕获准确 filter／sort binding 和 view，开面板期间排序键漂移会永久撤销旧应用，即使值随后恢复。过滤与排序控制器仍保持各自原准入；某列不可排序不影响原可用的 NULL 筛选。

`replaceResultFilter` 在独立控制器中完整试算新表达式和旧排序；全部成功后再次核活，先记录新 filter owner，再一次替换两个控制器。原控制器在失败前不变。租约、工作区、连接代次、列管理和模态门保持，未改变结果传输、服务端 SQL 或 IPC。
