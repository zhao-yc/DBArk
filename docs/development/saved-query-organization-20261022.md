# 保存查询层级分组

## 完整使用流程

从“历史与查询 → 保存的查询”进入。支持全部、未分组、父子组树、包含子组开关，以及组范围内原有名称／完整SQL搜索。创建、改名、移动分组，或勾选查询批量移动，都先展示明确预览，再确认一次。解散分组会解散整棵子树并将成员退回未分组，不删除任何查询。

当前页全选／取消保留其它页的选择，显示当前页外的选择数量。最多选择100条，只保存编号、摘要和名称，不累计SQL正文；超限整批拒绝。分组最多256个、8层、名称80个UTF16单元；不接受首尾空格、控制符、非法Unicode和路径分隔符，同父下精确同名拒绝。分组使用独立编号，不以名称、显示路径或数组下标定位。

## 正确性和存储

组织为可选schema9元数据：独立组织文档和成员映射表，不写入原查询JSON，不改变查询名称、SQL、连接、默认库、更新时间或来源摘要。已打开查询在移组后仍能沿原绑定保存。读取快照只返回树和计数，不把全部成员或查询正文传给界面。

所有变更使用启动世代、查询修订及持久组织修订生成的全局CAS。整批摘要先核对，再在一次SQLite事务内写入；写盘失败恢复原内存和磁盘状态。查询被删除时同事务清理成员，防止同ID重建复活分组。旧客户端删除查询留下的孤儿只在完整校验组织之后精确清理；坏树、未知版本、损坏引用或超过1MiB的组织文档在迁移写盘前拒绝。

按组范围在SQLite复合键位置分页内过滤，沿用25条／128KiB、真实匹配线程、取消及一次性续页句柄。组织变化使旧续页失效；界面需手动核对后重新预览，不能重放失败写入。关闭等待原请求和句柄释放，迟到响应及旧预览不能打开或移动另一个目标。整理不委派数据库引擎、不创建SQL任务或执行历史；打开仍只新建原文标签。
