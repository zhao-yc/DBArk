# SQLite 查询结果不同值勾选

## 使用

在结果筛选面板中，选择字段后点击“从结果选择值”。候选来自原查询已返回的全部行，不受当前本地筛选缩窄；不重发 SQL。显示各不同值、原存储类型及行数，支持原文／类型名称搜索、分页、逐项勾选、勾选全部搜索匹配值、清空和包含／排除。查询已截断时提示候选范围并不代表数据库全表。

点击“写入条件草稿”仅替换所属条件；审阅后仍需点击“应用筛选”才改变视图。取消保留原草稿，筛选后的原多列排序及整理历史继续保留。候选打开期间原条件与外层提交被阻挡，不读取系统剪贴板。

## 类型与正确性

INTEGER、REAL、TEXT、BLOB 分别计数和勾选，同显示的 `2` 不合并。INTEGER 保留 int64，REAL 使用实际浮点等值且正负零合并，保留首次出现原文；TEXT 不解析日期、JSON 或数字，不折叠大小写。BLOB 显示完整十六进制，空字节与空文本、NULL 分离；NULL 使用独立候选。

包含模式把各类型 IN 条件与 NULL 判断组成 OR。排除模式生成各类型补集的 AND，未勾选 NULL 时另外保留 NULL；因此结果与包含模式逐行互为补集，不遗漏未选中的其它存储类型。生成的树沿原结构预算，不平铺父分组；原停用条件替换后仍整体停用。

复用原逐格类型捕获：仅扫描目标列，验证完整原行列与代码身份，不读取 SQL 或其它列的值／访问器。结果、元数据、类型代码、原值或 BLOB 内容变化后永久撤销旧编号；未知类型不从显示值猜测。旧结果仅全 NULL 列可生成候选。

沿用 100000 行、1024 列、2000 种完整候选、128 种勾选、单值 4096 字符和整体 8 Mi 原文预算。BLOB 解码前核完整 HEX 长度，超限整份拒绝，不返回前 N 个候选或部分勾选。长值只省略显示，完整详情及搜索保留原文。不改 IPC、数据库引擎、写操作或凭据协议。
