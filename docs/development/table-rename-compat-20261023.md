# 普通表重命名的旧版本兼容

本批补齐MySQL5.7.44、MariaDB10.11.19及11.4.13的同库普通表重命名，并保留已支持现代MySQL的入口。仍为单条原生RENAME、预览后三项确认；不把改名变成COPY、重建表、自动迁移授权或改写其它对象。其它旧版本仍只读，暂不发布。

## 已核实的原生行为

三个旧实例均经实际服务器身份、Linux及名称映射核对。独立随机库中，含自增、STORED生成列、前缀索引、明确字符集及注释的表，改名并恢复均零警告；原生TABLE_ID稳定，SHOW定义仅首部表名变化，原整数、DECIMAL、二进制、NULL、Unicode及微秒时间保持。原生RENAME仍允许引用视图失效，不会替客户端完成依赖重构。三个测试库均已精确删除，原流关闭。

实际旧实例只有INNODB_SYS_FOREIGN及VIEWS，没有VIEW_TABLE_USAGE；MySQL5.7自带100个sys视图，MariaDB分别有101／102个系统视图。旧版本不能沿用不存在的目录，也不能以存在任意视图或出现同名词就全表只读。现代MySQL继续使用其原生视图关系目录。

## 依赖读取与准入

保留真实全局目录可见性、源ALTER／DROP及目标CREATE／INSERT证明；权限不足不会自动授权。旧实例需要完整、有界的全局视图清单、真实规范定义交叉读取及关系引用解析，区分限定表名、无关同名列／别名／字面量，覆盖JOIN、派生查询及实际支持的CTE作用域。无法证明的语法、缺失／变化／超预算目录明确只读，不能把前N项当作全量或用EXPLAIN消除依赖。

Root独立创建带单引号／反斜杠文字和同名别名的视图，每实例四种创建模式与四种读取模式交叉核验，并回读真实文字值。VIEWS定义统一为规范反引号及反斜杠转义，不随读会话的NO_BACKSLASH_ESCAPES／ANSI_QUOTES变化；不能直接用当前表定义会话模式解释视图规范正文。该结论仅限实际核实的三个版本。所有临时库精确清理，会话恢复并关闭。100／101／102个公有系统视图的四模式私有采样仅作解析补证，不将服务器原定义或行数据入库。

## 令牌与界面意图

本轮新增反例在旧产品上确认十处失败，另四十项正对照通过：原结构连接关闭等待期间配置释放后仍可迟到发布快照；原RENAME错误后同快照其它预览仍可发送；旧界面确认／执行回调可能借后继令牌、ACK恢复或丢稿确认重入继续操作。修复必须在发布和投递边界核原owner，并在发送时同步撤销同快照全部派生令牌；不能用成功后刷新或重试掩盖。

界面保留原两端所有标签的草稿／任务保护、原预览及确认代次，父守卫返回后重新核验。关闭和重新读取须使用最新草稿并撤销旧同意。已发送后的取消或断线结果未知仍不重放；已收到成功ACK但后核失败须保留completed事实。
