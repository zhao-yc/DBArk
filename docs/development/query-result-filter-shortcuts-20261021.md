# 已返回结果筛选的面板快捷键

## 操作与实现

在“筛选已返回结果”的条件面板内，Ctrl+Enter／macOS ⌘+Enter显式应用当前草稿；Esc取消本次草稿，保留已应用条件。面板显示中文提示，应用按钮声明ARIA快捷键。普通Enter保持原输入及按钮行为，多值输入仍可换行。不会重发SQL或访问系统剪贴板。

按钮与快捷键共用原草稿租约及表达式输出，旧面板、连接修订或来源变化不得恢复失效动作。快捷键不接受Alt／Shift组合及长按重复，输入法组合引用、原生isComposing和兼容keyCode229均阻止应用或取消。识别到的有效命令先阻止默认及冒泡，避免同一次按键进入外层查询命令。
