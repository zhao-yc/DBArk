# 固定查询结果的只读对比（2026-10-22）

## 用户入口及语义

在同一查询标签内分别固定两份结果，点击“固定结果对比”，选择左右来源及 1～8 个匹配键，再明确开始。来源为固定时完整克隆的已返回数据，独立于当前筛选、列隐藏及后来 SQL；至少一侧截断时明确提示范围，不能称作数据库全表差异。

完整列的 key、名称、类型和顺序必须一致，不猜主键或按行位置匹配。匹配键允许明确文本、整数、精确小数和日期时间，复合键用无分隔符碰撞的类型元组；NULL、重复键、非法值、浮点／字节／未知类型整份拒绝。键沿用已有精确比较语义：数字不经 Number、时间不经 Date，文本不声称数据库排序规则。键表示等价时匹配同条记录；非键按原返回表示比较，所以字符串 `1.0` 与 `1.00` 不自动当作相同，字节只比较明确包装中的 base64 原文。

结果提供新增、移除、修改和未变化的完整计数。左侧记录保持原顺序，再追加右侧新增记录；列表可按类别筛选，每页 50 条。点击“查看差异”检查所有字段左右原值；NULL、空字符串、文字 NULL、二进制和缺少整行分别显示，同名列用唯一 key 区分。停止不会关闭窗口，可手动重新开始；切换来源要求重新选择匹配键，不自动重跑。

## 来源及预算

捕获只读自有数据描述符，不执行输入 getter。保留准确数组、列、行、全部原值和字节字段身份；观测漂移永久撤销，重新赋回旧值不能复活。最终完整复核后才发布任何计数或差异；伪造的 capture／明细行、取消后的明细及迟到回调均拒绝。标签／连接／忙态／结果切换和其它模态撤销窗口；父级同步占住操作门，不能借同一 tick 的旧网格回调导出或开其它审核窗口。

每侧至多 100000 行、1024 列，合计 2000000 格／16 Mi 原文，单字符串或 base64 至多 4096 字符。超过时完整拒绝，不截取部分列或记录。每批最多 512 行，以 32 Ki 原文作为让出目标，单行原子处理；扫描中可停止，取消清定时器、键映射、部分结果及扫描器强引用。不新增 IPC、文件、数据库或剪贴板写入。
