# 连接批量整理（2026-10-22）

## 操作入口

工具栏“整理连接”提供搜索、每页 50 条的多选列表与预览。勾选本页只选择当前可见记录，搜索隐藏的既有选择保留；清空勾选会清除全部选择。分组和颜色分别明确启用，未启用的字段保持原值；先预览完整所选批次，再确认整理。

一次最多 1000 个不重复连接，超限整批拒绝，不隐式截取。分组名称保留原文和前后空格，空串明确表示空分组；颜色为 #RRGGBB 或明确重置默认。列表和预览均区分空分组与字面名称“未分组”。选择、搜索、草稿或刷新改变后旧预览失效；失败不自动重放写操作，必须刷新再预览。

## 持久化与会话

新 IPC 仅接受全局连接修订、ID 数组及 group／color 两项补丁，不接受目标、完整 profile、密码或认证文件。Main 同步检查整批目标没有正在保存的连接配置，再进入存储 CAS；不委派引擎、不取消任务、不重连或发送 SQL。

完整 INSERT SQL 导出的能力绑定全局连接修订，因此 Main 在其账本仍存在时拒绝整理任何连接，直到原请求 finally 收尾；引擎已报告完成或取消也不能提前放行。只检查账本，不主动停止导出，不放宽旧能力校验；普通查询及没有该账本的 CSV／JSON 导出不受此保护限制。11 项真实 Main 分派测试覆盖该边界。

SQLite 一次事务只更新各原 JSON 的分组和颜色，全部 ID 先存在才开始修改；不调用 resolveConnection、单项 saveConnection 或秘密解密。四槽密文字节和会话秘密保持，成功后全局修订只推进一次。第二行触发器失败或真实写盘失败时，内存、磁盘与修订完整回滚；配置变化及 ABA 都使旧批次拒绝。

成功回调只更新公开连接数组，不改变连接版本、查询标签、忙态、事务和数据草稿。侧栏分组标题及连接节点处于同一兄弟层，保持原连接 key；换组仅移动原节点，展开树、已连接事实和在途加载仍由原 owner 处理。主动刷新与真实连接版本变化继续撤销旧 owner。
