# PostgreSQL 表页高级筛选

在表或视图的记录标签点击「高级筛选」，选择列和操作符，添加一条或多条条件，再点击「应用高级筛选」。编辑区可启停或删除条件，选择全部满足或任一满足，也可将条件编排成嵌套分组。增减条件时恢复平铺，可重新编排。应用时回首页，翻页和全量导出沿用已应用的条件。点击「清除筛选」可恢复完整范围。

等值、不等值、大小、区间和集合比较由 PostgreSQL 按列类型解析。大整数和高精度小数按输入原文传递。`LIKE` 与 `NOT LIKE` 匹配列的文本输出，支持 PostgreSQL 通配符。`IS NULL` 和 `IS NOT NULL` 不输入值，空字符串可使用等值或集合筛选。普通表有待提交记录草稿时，先处理草稿再应用新条件。[PostgreSQL 操作符解析](https://www.postgresql.org/docs/18/typeconv-oper.html) · [PostgreSQL 集合比较](https://www.postgresql.org/docs/18/functions-comparisons.html)

浏览和游标导出使用协议参数，原生 COPY 使用与会话转义设置无关的显式字面量。列和操作符从已核对目录及有限规则生成，SQL 参数仍使用同一棵条件树。非法类型输入会由 PostgreSQL 返回错误，原已应用条件继续保留。

## 验证

- macOS 上 Node.js 24.17.0 运行时检查、类型检查和源码构建通过。
- macOS 完整单元回归共 1,326 个文件，27,455 项通过，10 项 Windows 系统 tar 用例跳过。
- Server-200 独占 PostgreSQL 18 实库回归 5 项通过。覆盖多层条件分组、停用条件、精确数值、跨页保留范围、非法列及运算符、JSON 和原生 COPY 的结果一致性。独立文件验证 NULL、空字符串和包含分号的文字。
- macOS 原生窗口回归通过，共 63 项观察。覆盖条件先编辑后显式应用、按条件翻页、清除后恢复，以及应用后条件标签可见。首轮功能测试通过后，从截图发现两层滚动裁切标签。改为单层滚动后复跑并核对截图。
- Windows 测试虚拟机不可达，本轮切换到 macOS。Windows、两平台安装包和较早 PostgreSQL 版本待验证。
