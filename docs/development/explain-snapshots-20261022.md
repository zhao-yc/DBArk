# 执行计划文件快照（2026-10-22）

## 使用行为

查询结果的“保存计划快照”保存当前已返回的 JSON 或文本 EXPLAIN。主工具栏“打开计划快照”在没有连接时也可使用；进入独立窗口后主动选择文件，可查看树、节点详情、查找、原文和结果表，并另存快照。读取文件不会建立会话、执行 SQL 或写入查询历史；离线窗口没有“获取文本计划”执行入口。

取消选择或打开坏文件保留之前的计划和阅读位置。保存不替换当前计划对象，选择、折叠和查找状态保持。原始文件操作未结束时阻止重复打开、保存和关闭，不能把观察超时当作原操作结束。

## 文件格式与保真

UTF-8 JSON，标识 `dbark.explain-snapshot`、版本 `1`，最多 1 MiB。保存服务器方言、版本、计划格式、原始计划、警告、截断标志以及单个结果的列和行；不保存连接、会话、SQL 语句、耗时或派生树。原计划文本自身仍可能包含表名、条件或常量，分享文件前应检查内容。

BIGINT、DECIMAL、日期时间等驱动字符串保持原样；有限 Number 使用明确标签，负零单独保留；NULL、布尔值和 BLOB 标签往返。文件不接受额外字段、未知版本、非法类型、坏 UTF-8、孤立代理项或超预算内容。最多 64 列、1000 行、64 条警告；无法完整捕获时明确失败，不静默删除行。

导入重新解析原文生成展示树，不信任外部提供的节点或路径；合并并保留当前解析器诊断。索引序号仍仅表示 JSON 数组位置，估算成本不表示真实耗时。

离线另存使用最初验证的原快照文档，新增诊断只参与展示，防止接近上限的合法文件因多出诊断而无法另存；原文、结果、原警告与截断状态不变。

## 进程与文件边界

只开放 `explainFiles.open` 与 `explainFiles.save` 两项有类型且严格校验的 IPC。路径来自主进程原生选择器；渲染进程不能传入路径。操作绑定真实窗口、frame 和文档代际，逐次等待后核对归属，最终 IPC 发布前再次核对。

单句柄有界读取并核对文件身份；保存经现有路径占用、同目录独占临时文件、同步和重命名。清理和原操作全部结算后才释放锁，退出等待集合覆盖文件操作。重命名提交后出现失效或未知结果时明确提示先核对文件，不自动重试。外部程序仍可能在最终检查后并发改动文件，此功能不提供跨程序的持久锁。
