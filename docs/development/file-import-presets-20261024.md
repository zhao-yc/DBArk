# 保存并复用文件导入配置

## 功能入口

表数据页选择“导入”，CSV 或 JSON 格式下可在“导入配置”区域保存并复用参数。显式读取已存配置后，选择配置并点击“应用配置”；应用只恢复选项、重新预览和核对映射，不会自动导入。

当前文件预览就绪且至少映射一个目标字段后，可输入名称“保存为新配置”，或明确“更新所选配置”；“删除配置”仅删除所选本地模板。配置可用于不同连接的目标表，但每次应用都重新读取当前目标元数据。

## 配置与核验规则

- 只保存格式、编码、CSV分隔符／首行字段名选项、完整源列和字段映射。不保存文件路径、文件令牌、数据内容、SQL、数据库或连接身份、凭据。
- CSV无标题按完整位置序列匹配；有标题CSV和JSON按完整具名字段集合匹配，可接受同名列重新排列，并按当前预览顺序恢复映射。字段新增、缺失、重复，或目标字段不存在／为生成列时整份拒绝，不退回自动同名映射。
- 应用配置强制重新读取目标元数据和当前文件预览，最多20条。更换文件、目标、连接修订或手动修改格式选项会撤销当前套用状态；换文件后需要再次明确应用。取消文件选择保留原文件、映射、预览和已应用提示。
- 配置本地修订冲突或迟到回执要求显式刷新，不自动重试覆盖。相同选项重复应用也会换代，旧回调及ABA不能复活。
- 名称最多80字符，允许内部空格，禁止空名称、首尾空白和控制字符。最多100项，单配置256KiB、完整文档4MiB；拒绝额外字段、访问器、符号、稀疏数组、继承配置及损坏Unicode。

## 存储与进程边界

本地SQLite新增可选 `import_presets` 单行文档，保留schema9兼容模式；旧客户端可以忽略，不改变连接、查询或历史合同。未知文档版本、损坏JSON及超预算原文在任何迁移写盘前拒绝。新建、更新、删除使用同一原子写盘事务和持久递增修订，删空仍保留修订墓碑；每次打开存储创建新代次，旧会话请求失效。

`files.importPresets.list/save/delete` 属于受限preload白名单，由Main校验原窗口、框架和文档归属，持久化前及原子替换前复核；不委派数据库引擎、不解密连接密码。配置不是数据库写入授权，执行仍需再次点击导入，沿用已有类型校验及每500行提交一批的规则。
