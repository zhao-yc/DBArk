# SQLite 复制当前记录为新增草稿

## 使用

在可写 SQLite 表页选择一行，从“更多 → 数据编辑 → 复制 SQLite 当前行为新增记录”打开独立新增输入。带入该行**已保存到本地草稿**的完整动态类型和值，包含整数、文本、空串、NULL 与二进制；生成列始终省略。原主键／唯一字段保留，须明确修改或取消勾选使用数据库默认值，不猜测自增列或自动替换键。

取消输入不新增记录，也不清除已有修改；“暂存 SQLite 复制记录”只新增一条本地草稿，可整步撤销／重做。实际写入仍需 SQL 预览及集中提交。复制源可以是已有行、已保存修改或本地新增行；待删除行、只读连接和视图不提供此入口。未保存的单元格输入不能作为复制源。

原非有限 REAL 或超长 TEXT 可以完整带入供修改，新增保存仍按原有限数值、单值与整批输入预算验证；不会暗中转换、截断或跳过字段。打开、取消和暂存均不读写用户数据库，不操作剪贴板或新增查询会话。

## 来源与原子性

`sqliteTableDuplicate.ts` 为准确原页、行数组、原行及值数组、完整 typed 内容、元数据和快照签发内存来源；独立虚拟输入不是 `editor.add`，生成列与 DEFAULT 槽分开处理。公开输入冻结，克隆对象不继承来源。

父输入票据同步观察 workspace，活动、任务、连接或结构变化留下失效标记。保存前还须核唯一准确 `data-sqlite-duplicate-input` 窗口；旧回调和窗口不能新增到后继目标。确认复用真实 `appendRows`，完整预算及类型校验成功才一次发布并形成一个撤销步骤；失败保留原输入和全部旧草稿。取消只撤销自身输入占用，不清后来窗口。
