# PostgreSQL JSON 节点与结构编辑

在 PostgreSQL 可写记录的字段表单或记录弹窗中，点击「编辑 JSON 记录树」，选择 JSON、JSONB 或常用字符类型字段，再点「解析当前字段」。已有文本赋值时使用当前输入，否则使用已加载的原值。新增记录可先在表单为字段填入 `{}` 或 `[]`。

可替换节点值、重命名或追加对象成员、移除成员或元素、插入和移动数组元素，以及移动对象成员。对象成员按出现序号定位，数组下标从 0 开始。修改按原文位置应用，未修改的数字文本、重复成员和空白保留。JSONB 最终显示服务器保存的规范化结果。

每次修改都先核对当前字段和原文，并校验完整候选。生成列只读，字段写入沿用 65,536 个 UTF-16 单元预算。NULL、DEFAULT 及 BYTEA 使用原字段表单。点击「应用节点或结构修改」只改变字段输入，带回表单后仍须暂存、预览并明确确认提交。

## 验证记录

- macOS arm64、Node.js 24.17.0。运行时检查、严格类型检查、构建和 187 项定向测试通过。全量单测运行 1,344 个文件，27,531 项通过，10 项 Windows 条件测试跳过。最终词法代码整理后复跑了定向和原生验收。
- PostgreSQL 18 隔离实库通过 32 项 Electron 检查。从未暂存的字段输入中定位第二个同名键，拒绝非法替换，保留精确数值并追加数组。新增弹窗也能在整行编辑和树之间带回字段输入。独立客户端确认暂存前后原库保持，提交后读回精确文本和默认值。独占容器核对零连接后清理。
- SQLite 离线原生记录树通过 1 项完整回归，核对节点与对象数组操作、精确原文、取消及明确提交。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
