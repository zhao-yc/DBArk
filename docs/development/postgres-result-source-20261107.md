# PostgreSQL 结果来源

执行查询后，在「当前语句回执」中点击「查看结果 SQL」。弹窗只读展示该结果随附的实际 SQL，包括随语句发送的注释。位置参数仍以 `$1` 等占位符显示。脚本有多个结果时，先选中要核对的结果。SELECT 和无结果列的命令都支持查看。

点「定位原语句」会回到执行时的编辑器并选中该语句正文。脚本包含多处相同 SQL 时按原范围定位。执行选区时，范围映射到原选区在完整草稿中的位置。编辑器内容或来源变化后，旧定位会停用，旧结果随附的 SQL 仍可打开。

这两个操作只读取本次执行结果和本地编辑器。查看、切换结果和定位均不会产生新的 SQL 执行或历史记录。固定结果继续使用「快照 SQL」，执行计划继续在计划页核对来源。
