# PostgreSQL 语句折叠

打开 PostgreSQL 查询，在「查看 → 编辑器」启用「按 SQL 语句折叠」。使用编辑器左侧箭头收起或展开多行语句。正文首行保留可见。语句末行若同时含有后续 SQL 或注释，也保留该行。

折叠沿用语句导航和执行当前语句的分段器，识别嵌套块注释及 dollar-quote 正文。已有查询会话时使用最近一次会话状态返回的字符串模式。该模式未知时，只有两种模式都得到一致边界才生成语句折叠。超过本地预算或边界无法确认时，编辑器可继续使用普通缩进折叠。

折叠只改变编辑器显示。它不新建数据库会话、不执行 SQL、不修改草稿，并沿用工作区的折叠偏好。
