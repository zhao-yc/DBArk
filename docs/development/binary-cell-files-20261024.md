# 二进制单元格文件载入与原字节另存

## 使用入口

表数据的记录表单／单元格编辑器中，将二进制字段切换到“二进制 Hex”，选择“从文件载入字节”。载入只替换当前字段缓冲；仍须暂存、查看修改 SQL 并明确提交，取消文件选择保留原缓冲。NULL 须先切换模式，空文件载入为零字节二进制，不能混同 NULL。

“原字节另存为”保存当前完整 Hex 缓冲或只读查看器中的完整原值，不是当前显示分页、文本编码结果或图片重编码。任意 SQL 结果双击二进制单元格后可以另存，仍不提供载入或写表能力。不完整 Hex、NULL、DEFAULT、非法或超限字节不能另存。

## 边界与实现

- 载入上限 131071 字节，另存上限 2 MiB；超限整份拒绝，不截断。保留 BOM、NUL、FF、引号、反斜杠及换行原字节，不探测文本编码。
- 专用类型化 IPC 只接收空载入参数或完整规范 Base64／建议文件名。实际路径由 Main 原生选择器取得，只回传文件名及长度，不生成可复用文件 token，不读连接秘密，不建任务或查询历史。
- Main 限制同一时间一次文件操作，跟踪选择器及实际 IO 直到结束；退出等待文件收尾。载入比较原路径、打开句柄、真实路径和文件版本，关闭原句柄后才发布。
- 另存复用全局导出目标占用与同目录原子文件服务，独占创建、同步关闭、核验后替换；失败清理自有临时文件，保持原目标。最终检查到系统替换间的外部并发竞态不宣称完全消除；系统替换成功后的迟到撤权不抹掉已保存事实，也不自动重试。
- 界面绑定原字段缓冲、记录／结果、连接及执行代次，切换、重新执行、卸载或 A→B→A 后旧回执不能覆盖新输入。只读结果使用独立原值租约，打开自身模态不会恢复其它结果选择能力。
