## 修复内容

- 历史与保存查询沿“查询”分类的真实新入口进入；编辑器字体、自动换行及专注模式使用当前菜单项。动作关闭菜单后重新打开，再核对状态。
- 查询连接名称使用当前 `.query-context-target`；历史读取错误展开准确的失败明细，不能混同“使用说明”。
- “关闭其他查询”消费准确测试 App 的原生“窗口”菜单项，保留原 owner、启用状态、取消、保存冲突及后继标签断言。

未保留隐藏旧按钮、旧名称映射或直接调用渲染业务处理器。业务断言、超时、重试、跳过条件、危险操作和资源保护不降低。
