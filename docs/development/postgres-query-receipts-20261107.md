# PostgreSQL 查询回执

执行 PostgreSQL 查询后，在当前结果上方查看语句序号、服务器回执和本条耗时。多语句脚本可在结果选择器中逐条查看。序号以本次提交的脚本、选区或单条语句为范围。开启「遇错继续」后，成功结果的序号会跳过失败语句，可与错误摘要和服务端消息按同一序号核对。

回执中的命令和可用计数来自 PostgreSQL 驱动。零行计数会明确显示，缺失计数时省略。带 `RETURNING` 的写入也会显示服务端计数。行结果另显示实际接收的行数，达到客户端上限时可能少于服务端计数，结果区会显示截断提示。应用本地筛选后可核对剩余行数。

命令回执说明单条语句的服务器响应。是否提交要结合事务状态和后续回执判断。实库用例中，事务内的 INSERT 收到计数 1，后续语句使事务失败，随后执行的 COMMIT 收到 ROLLBACK，事务中的写入最终未提交。

每条耗时和本次总耗时是客户端测量的时间，包含服务端响应及传输。切换结果只读取内存中的回执。此视图用于本次普通 SQL 执行，固定结果和执行计划各有自己的界面。
