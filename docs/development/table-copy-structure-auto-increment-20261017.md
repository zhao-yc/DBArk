# 复制空表结构的自增追加

本追加在不可改写的 `433667d48aa8bfb1520d83faafc2e9c4ed01eb88` 及独立P2修复 `3916b0607a360dba01f07584cff8122b93db618a` 之后实现，不将原首片排除自增视为完成。本自增追加当时的生成/隐藏列边界保持为历史记录；后续仅准确MySQL8.4.11普通生成列的支持见[生成列追加](table-copy-generated-20261017.md)，8.0生成列及隐藏列仍只读；其它版本、平台、非默认自增策略不外推。

## 官方依据与实测边界

[MySQL 8.4 CREATE TABLE LIKE](https://dev.mysql.com/doc/refman/8.4/en/create-table-like.html)说明保留列属性和索引，但该页未明确给出新表下一自增计数，不能单凭该页推断继承源值或重置规则。[InnoDB自增处理](https://dev.mysql.com/doc/refman/8.4/en/innodb-auto-increment-handling.html)将计数描述为持久化运行状态，也不能代替本次CREATE LIKE观测。

Root在独占隔离的MySQL8.4.11/Linux、lower_case_table_names=0、会话自增步长/偏移均1环境完成直接SQL语义探测：涵盖有数据来源、空来源、高于2^53的源计数及默认计数形态；新表空、原生编号不同，准确目录下一值均为字符串1，列级AUTO_INCREMENT及其它完整列属性保留，源定义/身份/计数/数据保持。没有第二DDL修计数或复制数据。已确认唯一隔离资源清理与观察连接结束。

该证据只支持上述版本、平台和默认策略内的规则，是直接SQLprobe，不是本产品UI/发布包或Navicat验收，也未证明外部并发、断线或非默认步长。公开文档不含实际服务器UUID、隔离库名、行值或原SQL；固定原始报告及SHA256仅在本任务ignored交付绑定中记录。

## 协议、计数与定义

- get/preview的服务端只读计划新增唯一自增整数列身份/类型/上限、准确源值、预期新值1。计数始终是规范正十进制字符串，不经Number，不接受空白、前导零、指数、负值或类型上限外值。客户端不能注入源值、预期值、规则或额外SQL。
- 仅支持完整DDL与列目录共同证明的唯一、普通、非空整数自增列。复用已有整数上限及运行策略读取，不调用要求ALTER的自增修改任务；仍只需原复制能力的直接CREATE、读取和目录可见性，不申请GRANT，不改源计数，不查业务MAX。
- 自增来源先关闭并读回会话information_schema_stats_expiry，再完整重读来源与精确目录，核对TABLE_ID/服务器身份、原始模式、列名、DATA_TYPE/COLUMN_TYPE/EXTRA。首次规范化前的模式保留，不能用第二次读取掩盖隐藏定义属性的原模式。
- 会话和全局步长/偏移须为1，现有策略读取还保守拒绝只读/恢复及未知状态。统计缓存、权限、角色、部分撤销、策略、列目录或准确计数未知均只读。SHOW CREATE省略表尾计数时仍须真实目录观测为1；不凭省略或空表补1。
- 快照和预览继续绑定原物理ID、UUID、profile修订、原模式、能力、完整源DDL及准确源计数。预览后或后核时源结构/计数变化均保守拒绝或判未完整核验，不能把来源计数变化当作可忽略的数据变化。
- 仅在源与新目标的结构比较投影中，分离经完整词法解析确认的唯一顶层AUTO_INCREMENT数值选项及一个相邻普通空格。CREATE头部表名沿既有规则处理；列级AUTO_INCREMENT、类型、默认值、文字量、注释、索引、字符属性及其它表尾原文/布局均保留。重复、未知、分区、可执行片段和不规范范围拒绝。没有全局正则替换或泛化规范DDL；比较投影绝不发往数据库。
- UI逐字展示准确源值与预期新值，自增计划增加专属风险确认，要求暂停来源/目标写入。不理解该确认项的旧界面不能执行。预览回包计数计划不符则释放，不变成可执行授权。
- 仍只发送一条同库CREATE LIKE：全部预览同步消费、准确名称确认、源/目标共享锁、同名原子拒绝及未知不重放保持；没有ALTER“修正”、DROP重建或自动重试。
- 创建后独立返回structureVerified和计数matched/different/unverified。必须准确观测新值为1且完整结构/身份/源/空表均核验，definitionVerified才为true。不同或未知计数保留DDL完成事实和实际观测，不凭OK包或空表推断成功，不补发DDL；未完整核验时源页及准确新页都陈旧、草稿保留。
