# SQLite 查询标签语句超时

在 SQLite 查询页打开「会话与执行选项」，填写「每条语句超时（毫秒）」。空值或 0 表示不限时，可设置 1 到 3,600,000 毫秒。设置只在当前标签生效，关闭后恢复默认。普通脚本、选区、当前语句、类型参数和执行计划均沿用这个设置。

每条语句在原连接分别计时。达到预算时，SQLite 原生进度回调会在下一次可中断的检查点停止语句。超时会停止后续 SQL，即使启用了「遇错继续」。完整的前序结果仍可查看，超时提示可定位到已确认的原语句范围。客户端保留原连接，显示 SQLite 实际确认的事务状态。引擎中断写入时可能回滚事务，不能把前序完成数当作提交记录。[SQLite 原生进度回调](https://www.sqlite.org/c3ref/progress_handler.html)

连接原有的锁等待超时仍独立生效。语句超时依赖 SQLite 回调检查点，阻塞的锁或 I/O 可能推迟中断。整库任务、完整文件导出和语法检查沿用各自的任务控制。
