# PostgreSQL 表页 SQL 模板

在 PostgreSQL 表页点击「生成查询SQL」，选择 SELECT、INSERT、UPDATE 或 DELETE。用搜索定位字段，勾选并调整输出顺序。核对预览后点击「打开新查询」，生成一份绑定原连接和数据库的独立草稿。表格已有的待提交值继续留在原草稿中。

- SELECT 可用于表和可浏览的视图，沿用查询结果上限。
- INSERT 省略生成列、标识列和序列默认列。清空选列可生成 `DEFAULT VALUES`。
- UPDATE 和 DELETE 需要普通表、操作权限及完整的非空主键。UPDATE 的写入字段排除主键和自动生成列。普通表的 SELECT、UPDATE 和 DELETE 使用 `ONLY`，把继承子表留在范围之外。

写入模板按选列顺序生成 PostgreSQL 位置参数。打开后使用「参数执行」为 `$1`、`$2` 等填写对应类型和值。数据库会校验执行时的权限、类型和约束。

## 验证记录

- macOS arm64，Node.js 24.17.0。运行时检查、严格类型检查、构建和 59 项定向单元通过。定向测试覆盖特殊标识符、完整复合主键、选列顺序、缺键及权限、参数预算和原有模板窗口。
- 完整单元回归覆盖 1,341 个文件，27,520 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 的 5 项实库回归通过。使用真实列目录生成四类语句，位置参数沿正式查询链路绑定。父表和继承子表含相同的复合键，SELECT 只读取父表，UPDATE 和 DELETE 只作用于目标父表。大整数键和含引号的参数文本准确读回。
- macOS Electron 专项通过 24 项检查，包含四类预览、按选择生成 SQL、打开独立查询及保留原表待提交值。独立查库确认预览和打开均未写入。窗口正常退出，隔离库在核对零连接后清理。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
