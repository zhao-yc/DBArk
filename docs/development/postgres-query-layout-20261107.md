# PostgreSQL 查询布局

在 PostgreSQL 查询页的「查询结果布局」选择结果在下方、在右侧，或临时仅显示结果。上下布局可上下拖动分隔条，左右布局可左右拖动。聚焦分隔条后，用相应方向键调整 10 像素，按住 Shift 调整 50 像素；Home 恢复默认值，拖动时按 Esc 取消。

位置、高度和宽度分别按查询标签保存。工作区不足 800 像素宽时，右侧布局临时回到下方，拉宽后自动恢复；窗口压缩只影响显示。仅显示结果只隐藏原编辑器，重新打开查询仍采用已保存的上下或左右布局。从仅显示结果调用查找等编辑命令时会恢复编辑区。

切换布局不重建查询模型或重新执行 SQL，已有结果、勾选和活动事务保持。布局拖动使用现有的标签租约，切走标签、关闭或查询进入忙态时，失效的拖动不会写入偏好。布局保存仅合并本次尺寸或位置字段。
