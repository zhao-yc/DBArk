# PostgreSQL 连接与查询工作区

本批推进 Navicat 对标矩阵 R01。PostgreSQL 接入原有 Electron、React 和 TypeScript 工作台，通过独立驱动和每标签物理会话执行 SQL。

## 使用方法

1. 新建连接，选择 **PostgreSQL**。填写主机、端口、用户、密码与默认数据库，测试连接后保存。默认端口为 `5432`，留空数据库时使用 `postgres`。也可用 `postgresql://` 或 `postgres://` 解析连接目标，传输设置通过表单填写。
2. 展开连接和数据库查看表、分区表、视图、物化视图与外表。点击关系打开带 schema 的 SELECT 草稿，点击执行后读取结果。也可从目标数据库新建独立查询。
3. 使用「执行选区或全部」或「执行当前语句」。脚本按顺序执行，首条错误会停止后续语句，保留之前的结果。脚本含多个结果时可切换查看。
4. 单条参数 SQL 使用连续编号 `$1`、`$2`，在「执行位置参数」填写对应的 `p1`、`p2`。参数值通过协议绑定。需要数据库类型推断时可用 `SELECT $1::numeric` 这样的显式转换。
5. 可用状态栏开始、提交或回滚事务。事务失败时先回滚。点击停止会取消原查询并等待原会话终态。断线且状态未知时，先核对数据库，再明确重新连接。执行历史记录模板，不记录参数表单值。
6. 通过「保存查询」保存到本地查询目录，或使用 SQL 文件入口管理草稿。关闭有正文的标签可选择保存后关闭。

## 行为与范围

- 会话状态取自服务器 ReadyForQuery，分别显示空闲、事务进行中、失败及未知。服务器将失败事务中的原始 `COMMIT` 实际回滚时，结果显示 `ROLLBACK`。取消控制连接核对原 backend 的 PID 与启动时间。
- BIGINT、NUMERIC、日期、微秒时间及 JSON 保留数据库返回的文本，BYTEA 以二进制单元格表示。显示受行数和 16 MiB 结果预算限制，已提交的 SQL 仍等待服务器终态。SQL 脚本最多 1000 条，长度上限为 4 Mi 个 UTF-16 单元。
- 交换文件包含公开连接字段和需要重选的文件名提示。凭据沿现有系统保护策略保存，已保存连接禁止在 PostgreSQL、MySQL／MariaDB、SQLite 三组驱动间切换。
- 继续推进 PostgreSQL schema、序列、函数、类型、约束、分页记录编辑、补全、COPY、完整导入导出和备份还原。本轮源码窗口在 macOS 验收，Windows、安装包、客户端证书及 SSH 与 TLS 联用待实测。

## 实证

- 最终严格类型检查通过，产品构建 15.63 秒。完整单元回归共 1315 个文件，27386 项通过，0 项失败，10 项既有平台条件跳过。
- Server-200 官方 PostgreSQL 18 独占容器，随机普通登录角色及同名专用数据库，端口仅绑定回环，经 SSH 回环转发。本机未运行 Docker。完整实库测试覆盖真实目录、同名结果列、精度、位置参数、嵌套注释和 dollar-quote、脚本模式变更、显示截断、COPY 边界、失败事务、取消、强制断开后未知状态和断开期间拒绝后继查询。
- Mac 实际 Electron 源码窗口 1 项通过。覆盖新建及测试连接、目录生成草稿、真实 SELECT、多结果、选区参数、事务失败后回滚、取消后继续查询、历史、保存后关闭和正常退出。单 worker，120 秒，零重试，trace 关闭。原进程退出、临时配置清理和工作区文件无明文测试密码均已核对。
- Mac 回环传输端点独立验证 SSH 和 TLS。错误 SSH 主机指纹在转发前被拒绝，正确指纹可读取原库身份和 BIGINT，结束后 SSH 活动连接数为零。TLS 拒绝不可信 CA，导入本例 CA 后通过 TLS 1.3 查询，回环端点无明文降级及残留连接。两个端点各转发到独占 PostgreSQL 18。
- 通过用例均独立复核目标行仍为「原值」，专用数据库活动连接数为零。核对 Server-200 和准确容器所有者后删除本轮通过用例的专用资源。
- 原生前两次失败分别为类型选择器定位、保存弹窗把编辑器设为只读。后者修复为对话框接管输入，原正文桥保持可捕获。原结果与两套隔离容器及临时配置按现场保留。
- 前置完整回归发现 4 个 MySQL 退出用例中，等待 PostgreSQL 收尾延迟了原建连取消。改为两个驱动在首个等待前同时开始收尾，183 项定向用例通过。原失败日志独立保留。
- Windows 独立测试会话主机不可达，本轮未派发 Windows 任务。依据仓库约定在 Mac 验收。
