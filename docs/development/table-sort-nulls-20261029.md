# 表浏览多列排序的NULL位置

## 使用

打开表数据的“多列排序”，为每条规则选择字段、升降序及NULL位置。可选择“数据库默认”“NULL置前”或“NULL置后”，每列独立设置，最多20个排序字段。修改草稿不查询；明确应用后保留原筛选并从第一页重新读取。

NULL位置与方向独立。例如降序＋NULL置前，先列NULL，再按数据库比较规则降序排列其余值。空文本仍是实际值，不与NULL合并。未显式设置时沿用旧规则和原SQL输出。

调整优先级或点击列头改变同列方向时，保留该列NULL位置；移除后重新加入的字段使用数据库默认。取消排序编辑保留原页及未提交数据草稿。普通表布局偏好不保存排序；需要复用时保存并应用命名方案。

## 一致性边界

- 表页、从当前筛选生成SELECT，以及完整CSV／JSON／INSERT SQL／XLSX导出共用排序编译；未投影的字段仍参与原排序。
- 显式NULL位置先按`列 IS NULL`分桶，再按原方向比较列值。可靠行键继续补充并列顺序，不重复添加，不占显式20条规则预算。
- 排序字段只按元数据白名单引用，方向和NULL位置均为有限枚举。IPC和本地方案不接受SQL扩展、自有getter、符号或稀疏规则；精确数值、文本、二进制原值不做转换。
- 筛选更新／删除的范围预览同样显示NULL位置，并沿原预览确认及事务边界执行。本能力不自动提交数据修改。
- 已有命名方案缺省不补NULL字段，不更改文档版本；新增设置整份保存到本地SQLite，按原修订及来源校验应用。
