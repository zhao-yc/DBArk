# 父记录查看子记录

## 实际入口与范围

表数据页选中一条已存在的父记录，点击“查看子记录”。独立只读窗口列出当前账号可见的真实入向外键，选择关系后按父记录打开时的字段值读取子表。原表的筛选、排序和未提交草稿保留；子窗口不提供修改或提交。

关系目录每页最多50项，支持上一页／下一页。目录为空只代表本账号本次没有可见关系；跨页为实时目录，不承诺全局权限清单或一致快照。子记录独立分页、筛选、组合条件和多列排序；无可靠非空唯一键的子表仍可只读查看，明确提示翻页可能重复或遗漏。

## 契约与正确性

`table.incomingReferences`接收父表身份与可选游标，返回父表结构摘要、真实child→parent映射和后续游标。候选来自有界KEY_COLUMN_USAGE二进制keyset读取，再交叉核对完整有序列及REFERENTIAL_CONSTRAINTS动作。每页最多64列／关系、4096目录行和8MiB预算。

`table.childReferencePage`仅接收关系身份／摘要、必需的完整父元组和标准分页条件。实际读取重新取得父／子结构及真实外键，双目录映射与子表元数据一致才生成SQL；结构摘要包含SHOW定义，读后再核结构。没有客户端SQL或用户事务会话输入，不构造反向外键，不自动重放。

关联谓词始终位于普通OR筛选组之外。BIGINT、DECIMAL、日期、BIT及二进制保留原值，文本遵循真实字段字符集／排序规则；缺字段拒绝、NULL元组不放宽范围。原正向“查看父记录”的可靠键门保持。

## 生命周期与边界

父行、原页、草稿、连接修订、表结构、选中记录或活动标签变化永久撤销原意图；迟到结果不发布，A→B→A不复活。取消ACK不代表原读取结束，锁覆盖原Promise及严格物理连接关闭。Main只注入可信凭据并再次核连接修订，持久任务概要不保存关联值、记录和驱动错误原文。

结构摘要忽略解析器确认的表尾AUTO_INCREMENT计数，保留字段、索引、约束和其它定义；首目录仍与父页原完整结构对照，期间自增计数变化可能保守要求刷新父页重开。前后结构核验不提供原子CAS；父记录使用打开时的可见值快照，不追踪并发数据修改。

验证结果在独立验收记录完成后补充；完整D05、安装包、macOS及公开发行不因本切片自动完成。
