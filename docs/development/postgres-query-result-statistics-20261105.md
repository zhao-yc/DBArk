# PostgreSQL 查询结果列统计

查询返回结果后，点选数据单元格，再点「列统计」。未指定列时使用第一可见列。存在勾选时默认统计勾选行，可以在窗口中更改列或切换到当前结果全部行。当前筛选和结果截断决定可统计的数据范围。

- 摘要显示行数、非 NULL、NULL、不同值和极值。有限整数与 NUMERIC 使用精确十进制合计和平均值，循环平均值按面板说明舍入。浮点统计标记为近似。
- `NaN` 和无穷值仍参与不同值、极值及分布。含特殊值的数值范围只提供这些指标。布尔、文本提供适用的值指标，日期时间、二进制和未知类型提供计数。
- 「值分布」按完整值计数，显示次数最多的 10 项，以及其余值和 NULL。点击「按此值筛选」会用完整原值生成草稿，既有条件保持其分组，并以 AND 追加新条件。勾选决定统计范围，应用筛选后作用于当前已返回结果。
