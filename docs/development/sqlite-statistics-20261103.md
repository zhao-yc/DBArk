# SQLite 全筛选字段概况

## 使用

在 SQLite 表／视图页打开“更多”中的“字段概况”，选择字段后明确“开始统计”。打开、换字段和关闭不会自动读取；统计沿用已应用筛选的全部匹配记录，不使用当前页、未应用条件、未提交草稿或用户查询事务。

显示匹配／非空／NULL 数量，以及 INTEGER、REAL、TEXT、BLOB、NULL 的实际存储数量、类型内不同值数和极值。SQLite 声明类型只作说明，不把 TEXT 强制转成数值。各类型独立分组，INTEGER 和 REAL 的相等数值也不合并；类型内 DISTINCT、TEXT 极值沿用源列排序规则。NULL 的不同值数为 0，不把 NULL 当作一个非空值。

计数及有符号 64 位整数保留原文，REAL 保持原双精度及无穷，TEXT 保留 NUL／Unicode，BLOB 显示准确十六进制。当前不提供求和／平均值、数值直方图、抽样或跨字段联合剖析；D09／R02 仍部分。

## 实现

- 新增受限 `sqlite.statistics` 合同、严格输入／回包校验及 Main 原文档晚发布门，不接收任意路径、SQL、用户会话或写能力。
- 复用原 SQLite 资源账本和只读 utility：独立 BEGIN，读取准确目录／结构指纹，单次 GROUP BY 聚合完整匹配集，最后 ROLLBACK、关闭并确认原进程退出后才发布。
- 最多五类／五行、结果 1 MiB、极值完整 64 KiB；不一次加载全表。超限、坏 TEXT、结构变化或计数不符整份拒绝，不截断极值，也不保留部分概况。
- 数量恒等式、原字段／任务／条件、类型、组顺序和极值边界再次校验。最大两个在途概况，排队及退出未确认的资源仍占槽。
- 父页按原页、连接修订、已应用条件、表单、活动标签和模态绑定；旧 DOM、同名 ABA、失效租约、切换、卸载与迟到回包不接管后继请求。
- 取消同时等待原读取 Promise 和准确取消 ACK，关闭不提前归还占用；不重放查询。独立统计不会提交、回滚或关闭用户查询事务。
- 任务中心使用中文标题，只保存固定进度概要，不保存筛选、极值、统计结果或错误原文。
