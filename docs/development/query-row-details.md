# 查询结果的只读整行详情

在结果网格选中活动单元格，再点击“行详情”。右侧内联区域明确展示“全部已返回字段（包含隐藏列）”，按原返回列顺序及唯一内部 key 读取原行位置。重复显示列名、`__proto__` 等自有属性不会充当行列身份。网格隐藏或重排列不改变详情范围；详情自身每页展示 24 个字段。

详情只读取成功执行后已持有的有限结果或固定快照，不发送 SQL、IPC 或写表请求，不推断表名、主键或可编辑性。不覆盖失败、取消或执行中的部分流式结果。截断结果只可翻阅已返回行，并显示截断提示。

NULL、空字符串、空字节分别标识；精确数值字符串、TEXT 和 JSON 字符串保持原文，不解析 JSON，也不转换精确数值字符串。二进制显示原 Base64。所有内容通过 React 文本节点呈现，不注入 HTML；驱动已返回为 JavaScript number 的值仍受驱动和 JavaScript 数值精度限制。

资源预算：最多 100,000 行、4,096 列；列 key、名称和类型各不超过 4,096 个 UTF-16 单位。字段名/key 标题预览 256 单位、类型预览 64 单位。单值默认预览 256 单位，一次仅展开一个字段，最多 65,536 单位，截断提示保留原长度。截取不会拆开末尾代理对，原数据保持不变。

详情绑定标签、连接版本、执行结果上下文、原数组和原行位置。新执行、切换结果或快照、标签离开/移除、连接变化、忙态、外来模态窗口及卸载会同步撤销旧动作；恢复同一对象或旧版本不能重新启用已撤销回调。已打开行的原值、列元数据或数组身份发生可观察漂移时也撤销详情。侧栏使用 `role="region"`，保留原全局模态保护，不改勾选、复制、查找或列布局。
