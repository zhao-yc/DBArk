## 产品行为

已返回结果 → “筛选已返回结果” → 数值／日期时间字段 → “介于（含两端）”或“不介于（排除两端）”。两个独立输入保存端点原文；不解析分隔符、不执行SQL、不读取未返回记录。文本、JSON、未知和二进制不提供区间。

- 介于为下限≤值≤上限；不介于为值＜下限或值＞上限。两者均排除NULL，需额外NULL条件才纳入。
- BIGINT／DECIMAL、微秒日期时间和负TIME沿用精确键，不转Number／Date；仅原浮点类型按已有有限number规则比较。
- 无效、缺失或颠倒端点不更改已应用视图和排序，不自动互换端点。单值／NULL条件拒绝隐藏上限；换字段或离开区间时移除上限，重新进入区间须明确填写。
- 上限组合输入与下限共享既有草稿租约；组合结束前禁止应用。旧输入不能写入新条件；应用后规则和端点冻结，排除行漂移仍撤销旧视图。
- 每个区间占两个行比较，两个端点共同计入输入和字符工作预算；原100000行、1024列、32条件、2000000比较、4096单值、8 Mi输入／源原文和32 Mi工作上限保持。
