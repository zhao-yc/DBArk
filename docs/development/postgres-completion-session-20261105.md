# PostgreSQL 查询会话补全

在[查询作用域补全](postgres-completion-scope-20261105.md)上接入查询标签的实际会话。首次操作前仍可使用独立目录。标签建立会话后，空闲时按该会话的角色、搜索路径和临时对象补全。

- 在查询标签中执行 `SET search_path` 或 `SET ROLE` 后，继续按 Ctrl+空格补全。未限定的同名关系按 PostgreSQL 实际可见性解析，显式 schema 固定目标。[PostgreSQL 搜索路径与临时 schema](https://www.postgresql.org/docs/18/runtime-config-client.html#GUC-SEARCH-PATH)
- 使用 `CREATE TEMP TABLE` 建立的临时表只出现在创建它的查询标签中。补全插入 `"pg_temp"."表名"`，关闭原会话后随该会话失效。[PostgreSQL 可见性与权限函数](https://www.postgresql.org/docs/18/functions-info.html#FUNCTIONS-INFO-SCHEMA-TABLE)
- 用户事务打开或已经失败时，目录读取暂停。本地 CTE 和已知投影字段仍可补全。事务结束后，下一次请求恢复真实目录。
- 空闲会话的目录读取使用短只读事务及局部语句、锁超时，回滚后核对真实空闲状态。用户操作等待原读取收尾，等待中的查询可取消。目录读取不进入查询历史，结果只交付原窗口、原连接和原数据库。

## 验证

- Mac 类型检查、源码构建和 15 项定向单元通过。定向覆盖目录延后时保留本地 CTE 候选、目录失败时回滚自己的读取事务，以及回滚失效后封住原会话。
- Mac 完整单元回归覆盖 1,317 个测试文件，27,398 项通过，10 项 Windows 系统 tar 检查按平台跳过。
- Server-200 的 PostgreSQL 18 实库回归 5 项通过。覆盖两个会话的临时表隔离、同名对象路径优先级、限制角色的列权限、会话超时恢复、忙时延后、等待补全的写入可取消，以及健康或失败事务均暂停目录读取。成功容器复核原行、零连接后清理。
- Mac 原生 Electron 窗口整例通过。真实按键接纳 `pg_temp` 临时表与改动搜索路径后的字段，事务内显示目录暂停提示，执行历史只包含用户操作。单 worker、120 秒、零重试、trace 关闭，窗口和临时目录已清理。
- 首轮窗口夹具在编辑器仍为只读时输入。复验先等待实际临时表查询结果及执行按钮恢复，沿用原有验收门槛。首次失败现场保留。
- WIN11-TEST 会话不可达，本轮未派发，按约定在 Mac 验证。Windows 原生窗口及安装包尚待验收。
