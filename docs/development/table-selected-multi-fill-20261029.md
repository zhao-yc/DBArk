# 当前页勾选记录的多字段统一填充

## 使用流程

在表页勾选完整的已有记录，点击“批量填充字段”。第一项可沿当前单元格选择字段，用“添加填充字段”设置更多字段；每项独立使用文本、JSON、二进制或 NULL 编辑。已使用字段在其它项中禁用，可移除任意项，但至少保留一项。

“暂存整批草稿”只改变当前页勾选记录的本地草稿，一次操作可一步撤销／重做；其它行和未指定字段保持。仍须在原表页明确预览 SQL 并确认提交。此入口不补取其它页、不读取剪贴板，也不自动执行 SQL。“服务器全部筛选行”是另一个独立入口，不受当前页勾选数限制。

## 数据与来源保护

- 整组先验证所有字段及类型输入，再生成一个行数组并发布一次。后字段非法、重复或缺失时整组不暂存，保留输入供修正。
- 保留可靠键和完整旧值；主键、定位键、自增及生成字段不可选。当前页的新增、待删、缺失记录或不完整来源不具备批量填充资格。
- 精确数值保持文本，JSON只校验词法有效性并保留原文，SQL NULL与文本`NULL`分开；二进制使用Hex输入，包装逐行深复制。
- 沿原1000行／1024列／50000单元格、单值256KiB和合计1MiB线路预算，以及8MiB单步历史预算；二进制输入另沿原Hex编辑预算。计算整组扇出而非每列分别通过后拆批。已准备字段大小乘以勾选行数已必然超限时，停止解析后续字段；超限不先写草稿再清空历史。
- 选择、页、连接、元数据、草稿或活动状态变化使原意图永久失效。添加／移除／切换字段同步撤销旧编辑闭包；关闭后的回调、字段ABA及连点不能覆盖新输入或重复暂存。
- 旧单字段`consume`调用保持兼容，统一进入同一整组校验及发布路径。全部指定值相同返回原数组，不伪造草稿或撤销步骤。
