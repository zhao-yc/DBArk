# PostgreSQL 原值记录视图

在 PostgreSQL 表或视图的网格选中记录，点「记录表单」。在「字段表单」「原值记录树」及「原值整行 JSON」之间切换。原值来自已加载的当前行，切换展示和搜索字段时无需再次读库，跨页仍沿原记录导航。

记录树按目录顺序列出全部字段，可按字段名搜索。JSON、JSONB 和常用字符类型可显式解析原文结构。结构树按成员顺序保留原文中的重复键和精确数字。JSONB 的内容以服务器返回的形式为准。

整行 JSON 包含全部列，包括网格隐藏的字段。用列键和字段数组保留身份与顺序，数值、时间和 JSON 都以数据库返回的文本保存，BYTEA 保留为 Base64，SQL NULL 与空字符串分别表示。完整 JSON 超过 2 MiB 时可继续用记录树逐字段浏览。

原值视图和整行 JSON 用于查看与复制。返回字段表单后可继续暂存或放弃原输入。已有草稿继续由原草稿区管理。
