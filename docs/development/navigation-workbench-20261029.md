# 菜单与工作台导航重整

## 界面结构

完整原生菜单按文件、编辑、查看、收藏夹、工具、窗口、帮助排列；macOS 保留应用菜单惯例。64px 模块栏提供连接、新建查询、表、视图、函数、其他、查询和工具，宽度不足时将完整动作移入更多，不保留隐藏的旧按钮。

查询页保留执行分段、停止、格式化、保存与更多；结果页保留结果集、筛选、排序、列、导出与更多。表页保留刷新、新增、删除记录、筛选、排序、导入、导出与更多。文件及快照控制器常驻，菜单只管理动作展示，关闭菜单不会卸载文件任务或恢复窗口。网格输入尚未结束时更多入口禁用，避免打开菜单造成隐式暂存后执行另一动作。

## 对象与命令归属

对象分类使用左树明确选择的连接和数据库；没有数据库时先显示选择窗口，用户点击读取数据库后才获取目录。每库复用一个对象浏览标签，支持搜索、排序、固定31px行高虚拟滚动、右键菜单、收藏及双击打开。对象浏览只读取元数据，不创建查询会话或事务。

执行、保存、结果整理和事务由当前标签注册原处理器，不能套用树中后来选择的库。命令注册器持有上下文代次，原生菜单仅同步封闭命令的可用及选中状态；重导航、关闭、目标变化及模态出现均撤销旧许可。树和对象列表复用原动作、禁用条件、确认流程与目录租约。

`app.menuState` 接受封闭命令状态与修订；`onCommand` 仅接收命令编号及修订，不携带SQL、密码、文件路径或任意脚本。内部 `onMenu` 保留退出保存、错误通知及菜单状态重新发布事件。

## 配置与验收边界

新增 `objects` 标签，仅保存编号、标题、连接、数据库及分类；旧查询和表页兼容。读取损坏对象标签时只过滤本项并调整返回的活动标签，不隐式写盘；写入拒绝SQL正文、来源授权及其它字段。对象标签参与布局恢复、查找、切换和关闭，不进入查询关闭队列。

新专项 `tests/e2e/navigation-workbench.spec.ts` 默认关闭，显式离线启用后使用原桌面归属及正常退出协议；合成读取只绑定本例虚构loopback配置，拒绝真实数据库、写任务、文件操作及系统剪贴板。另保留原侧栏菜单专项与原业务断言；RAM展示端口只证明接线，不代替原生布局或安装验收。
