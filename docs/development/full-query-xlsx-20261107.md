# SQLite 和 PostgreSQL 完整查询导出为 Excel

在查询页打开「执行并导出完整结果」，选择「Excel (.xlsx)」。单个非空选区优先，无选区时使用正文。SQLite 可通过「更多查询操作 → 执行与分析」进入。查询必须是一条只读 SELECT 或 WITH。需要绑定时，先在「设置导出参数」填写本次值。选择文件后点击「执行查询并保存」。

XLSX 按原结果列序和行序保存。空标题或重名标题会沿用结果导出的规则，按列位置生成可区分的名称。大整数、精确小数及时间仍用文本保存。NULL 写为 `\N`，BLOB 或 bytea 写为 `\B:` 加 Base64，文本开头的反斜线转义以区分这些标记。使用 tabrelio 导入时可选择 DBArk 文本协议还原标记。Excel 的行、单格、总格数和文件预算继续生效，超出时导出失败并保留已有目标。

独立只读会话读取已提交数据。SQLite 在子进程逐批发送原生结果，PostgreSQL 在服务器游标分批获取。写入器只确认已完成编码和背压的行。完整工作簿暂存后，确认独立连接结束才原子发布，取消会等待原任务收尾。SQLite 的 UTF-16LE CSV 和 JSON 补齐了 BOM，便于编辑器识别编码。
