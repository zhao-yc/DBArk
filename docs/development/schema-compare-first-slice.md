# 结构比较首阶段（只读）

这是未接线阶段的历史记录。2026-10-15 后续入口、正式 IPC、复合取消和受限 SQL 预览见 [结构比较接线与预览](schema-compare-connected-preview.md)。下文历史实库结果不能替代后续接线版本的实库或安装验收。

当前模块比较 MySQL/MariaDB 两张明确配对基本表的字段、主键/索引和出向外键。方向为源→目标：“新增”表示目标缺少，“删除”表示目标多出。名称精确且区分大小写配对，不推断重命名，不自动映射父库或父表，不生成或执行同步 DDL。

字段顺序、真实可空性、字符集与排序规则、精确默认值、注释、生成及更新表达式参与比较；索引保留有序键部分、前缀、方向和注释；外键保留父表引用、有序字段映射和动作。读取复用已有完整定义解析器，每侧双读核验；两个独立读取时点不构成跨连接事务快照。

未知类型、未知属性、不可证明的默认值、可执行注释、特殊索引和未知外键片段分类为“不可可靠比较”，即使显示文本相同也不会误报相同。CHECK 及其它未分类约束保留原片段；表尾原定义显式保留在忽略项中。表选项、分区、触发器、入向外键及其它对象未覆盖，因此已覆盖范围相同不代表整表或数据库完全一致。

## 模块与接线契约

- `src/shared/schemaCompare.ts` 提供 `schemaCompareInputSchema`、`SchemaCompareInput` 和纯 JSON 报告 `SchemaCompareReport`。公开输入仅含 `taskId` 和双方 `{connectionId,database,table}`，拒绝额外认证信息或 SQL。
- `readSchemaComparisonTarget(context,target)` 使用调用方提供的私有结构短会话，返回执行层内部快照；它不自行借用用户查询会话。
- `compareSchemaSnapshots(source,target)` 为纯比较入口，返回报告。内部快照中的服务器身份及会话模式不进入报告。
- `SchemaCompareDialog` 通过 `connections`、可选初始双方目标以及 `services.compare(input)` / `services.cancel(taskId)` 注入接线，不硬编码公共命令。新增界面文案集中在专属中文语言文件中。

正式 IPC 命令、可信连接配置注入、跨连接复合取消与资源释放、App 入口和完整 UI 交互尚未接入。接入方应在任一侧失败或取消后等待双方真实终态并严格释放连接，之后才结束公共任务；不能把 KILL 请求被接受当作原命令已结束。

## 已有验证与剩余验收

当前三个专项单元测试文件共 34 项通过，覆盖纯投影、真实驱动回调协议的读取/取消边界以及初始界面投影和文本转义。专属源码、测试文件及其导入依赖图的严格 TypeScript 检查通过。界面测试限于初始服务端渲染，尚未替代实际浏览器交互验收。

主智能体已在六个授权隔离实例完成真实内核集成矩阵：MySQL 5.7、8.0、8.4，MariaDB 10.11、11.4，以及 MySQL 8.4 严格 TLS。每个实例两项，共 12/12 通过，零失败、零跳过（验收轮次 `run110/113/116/119/122/125`）。用例验证精确默认值、生成列、索引与外键原定义比较，以及比较不改变目标、不扰动另一会话的模式、临时表、连接身份和未提交事务；各轮独立隔离库和真实 driverID 残留均为零。

正式 IPC、跨连接复合取消、配置修订、断连与退出、App 入口、UI 关闭和迟到响应及安装交付仍需统一验收。本交付仅为 M02 首阶段，不代表完整 M02 完成。
