# MySQL 和 MariaDB 的 Excel 导入配置

在现有表的 Excel 导入窗口，可将标题行、首末数据行、文本协议和字段映射保存为命名配置。已保存的配置可在同一窗口读取、更新或删除。

1. 选择工作簿和工作表，设置读取范围及映射。展开「导入配置」，读取列表后命名保存。
2. 再次导入时先应用配置，然后选择本次工作簿和工作表。保存的读取设置会自动填入，预览会重新读取文件和当前目标列。
3. 源列和目标列兼容时恢复完整映射。无标题工作表按列位置核对。若不兼容，可改选工作簿、改选工作表，或取消套用后手工设置。
4. 核对预览并点击「开始导入」。应用配置和查看预览只读取文件及目标列。

XLSX 配置可在 MySQL、MariaDB 和 PostgreSQL 的现有表入口之间复用。保存内容仅包含读取规则和字段映射，工作簿路径、文件令牌、工作表 ID、样本行和连接信息均由本次导入持有。

命名配置工作流参考官方手册。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)
