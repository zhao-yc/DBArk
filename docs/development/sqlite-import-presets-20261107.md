# SQLite 文件导入配置

SQLite 现有表的 CSV、JSON、TXT、XML 和 XLSX 导入可以保存命名配置，复用读取设置、字段映射及每对字段的转换类型。同一个源字段可保存多条映射，各自使用对应的转换类型。

1. 选择文件并检查，设置字段映射及转换类型。展开「导入配置」，读取列表后命名保存。
2. 再次导入时，应用配置并重新选择文件。对于 XLSX，选择本次工作表，已保存的标题行、首末数据行及文本协议会恢复。
3. 检查文件。源字段、目标列和类型兼容时恢复完整映射。具名文件允许调整列顺序，无标题文件按列位置复核。配置不兼容时可改选文件，或取消套用后手工设置。
4. 执行新的整文件预检，输入当前目标确认内容后提交。

配置只保存读取设置、源列、字段映射和转换类型。原文件路径、令牌、行值、工作表 ID、数据库身份和预检能力均留在本次导入流程。SQLite 配置通过同一个本机配置仓库管理，导入窗口仅列出能执行当前映射类型的配置。

命名配置工作流参考官方手册。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)
