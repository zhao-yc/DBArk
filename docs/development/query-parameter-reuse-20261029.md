# 参数查询显式内存复用

## 使用入口

查询标签打开“参数执行”，填写参数后可勾选“完成执行后在本标签暂存参数（仅内存）”。默认不勾选。仅完整成功、原会话及默认库重新确认一致时保存一组。再次打开表单仍为空，需要明确点击“填入上次暂存的参数”，核对后再执行；填入本身不发送SQL。填入替换当前整组参数及类型，包含手动添加项。

“忘记上次暂存”只释放副本，不清空表单输入。取消勾选立即撤销暂存选择；来源失效时也可取消勾选，继续按原捕获模板普通执行。未勾选的原参数执行行为保持。

## 正确性和隐私

- 仅当前查询标签的RAM持有一组，沿原九类型校验、200参数、单值64KiB及合计1MiB预算；保留精确数值、NULL、空值和Unicode。重新识别的名称顺序、词法与数据库能力必须一致。
- 编辑器、模型、正文版本、有效选区、连接修订、会话、保存查询或文件来源、默认库变化立即清除。恢复原文或旧来源不会复活旧回调；普通光标移动且仍执行全文不改变来源。
- 执行前的恢复信息仍先持久化为未知。可选暂存先进入不可读候选，只有原任务明确完整成功并在30秒内确认同一默认库后才发布。失败、取消、断线、遇错继续仍含错误、未执行至末尾、来源变化或后继任务都不发布候选。
- 不把参数值传入设置、历史、保存查询或文件；模板原字面量、实际查询结果及用户导出的结果仍可能包含值。关闭标签或客户端释放暂存，不承诺删除用户另行保存的结果。
- 识别和库确认沿原会话的协议缓存读取，不附加诊断SQL，不重连或重放写操作，不自动执行模板。
