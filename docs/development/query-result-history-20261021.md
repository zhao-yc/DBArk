# 查询结果整理的撤销与重做

## 使用入口与行为

结果工具栏新增“撤销结果整理／重做结果整理”。每次已应用的筛选、清除筛选、多列排序、方向／优先级／NULL位置／文本大小写变更作为整步恢复；筛选面板编辑和取消不记步。本检查点当时应用筛选会清除排序；后继[筛选排序联动](query-result-filter-preserve-sort-20261022.md)改为保留完整排序，历史仍按一整步恢复。旧验收仅证明原检查点。

只操作当前已经返回的只读结果，不执行SQL、不撤销数据库写入，也不替代SQL编辑器的Undo。恢复后原勾选、查找和行详情失效，复制及导出改用新视图；空结果不回退全集。正常保存、片段或导出模态不清空规则历史。新查询、切换结果／固定结果、变更列布局、连接修订或标签失活后清空历史，不跨结果或会话复用。

## 实现与边界

历史保留来源引用及配置副本，不复制行或SQL。最多20步，单份配置128 Ki UTF-16单位，全部配置512 Ki单位（按序列化文本计量，不代表堆内存硬上限）；达到总量或步数限制时淘汰最旧步骤。超大单项清空撤销记录并在按钮说明中提示，当前规则完整保持，不截断条件或放宽原筛选／排序预算。历史仅在当前窗口内存，不写配置库，不作为命名方案。

恢复先在独立控制器中完整执行原筛选与排序准入，成功后再次核对原视图、工作区和选择租约，再同步替换两个控制器。失败不移动历史游标、不部分替换视图。历史票据绑定准确来源、控制器及代次；替换后旧按钮、复制、选择和详情闭包不能重放。新的成功操作截断重做分支，原样应用保留分支。
