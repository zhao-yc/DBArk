# 全部筛选行导出的字段选择与顺序

## 使用流程

表数据页应用筛选和多列排序后，点击“导出全部筛选行”。在“导出字段与范围”中勾选字段，使用“上移／下移”调整已选顺序，然后选择文件并开始导出。支持 CSV、JSON、INSERT SQL 和 XLSX。

默认选中全部字段，独立于表格隐藏列。清空后必须至少选择一个字段才能选择文件或开始导出。更改字段、顺序、格式或编码会撤销原文件选择，须重新选择；不会自动开始任务。SQL 自动排除并禁选生成列，仅支持基本表；切回其它格式不会自动补回已取消的字段。

输出列顺序不改变行顺序。未导出的字段仍可参与服务器筛选、多列排序及可靠行键补足。范围仍是服务器上全部匹配行，超过当前页或 1,000 行时不会截取样本；本地未提交草稿不进入文件。

SQL 选列文件只包含所选字段的 INSERT。再次执行前须核对省略字段的默认值、自增规则及必填限制；省略无默认值的必填字段可能导致插入失败，不保证可直接恢复整行。

## 实现与兼容

- `TableFilteredExportInput.columns` 为可选、有序物理列名数组；省略时保持原全字段行为及 SQL 的生成列排除。
- IPC 拒绝空数组、重复字段及超过 1,024 列。引擎按完整元数据目录再次核对未知字段、来源指纹和生成列；显式 SQL 请求含生成列直接失败。
- 仅改变流式 SELECT 的投影，完整筛选树、排序、元数据指纹、只读事务及元数据锁保持原逻辑。
- CSV 表头、JSON 成员写入顺序、SQL 字段列表和 XLSX 列使用同一有序目录；精度、NULL、二进制及原子落盘协议保持。
- 渲染器的字段和顺序变化沿用原草稿代次检查；选择文件及导出期间禁改，旧回调不能复用已撤销的文件令牌。
