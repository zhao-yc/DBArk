# PostgreSQL 物化视图索引

打开物化视图的「查看结构 → 索引 → 编辑索引」。拥有物化视图且对 schema 具有使用与创建权限时，可以新建列索引、改名或受限删除。索引编辑只接受当前物化视图的列，沿用普通表的内置索引方法、键列顺序和包含列设置。[PostgreSQL CREATE INDEX](https://www.postgresql.org/docs/18/sql-createindex.html)

并发刷新可按以下顺序操作。

1. 在索引编辑器选择 B-tree，勾选「唯一索引」，添加能够唯一标识每条记录的键列。
2. 加入改动并预览 SQL。确认后，客户端锁定原物化视图，核对目录版本，在同一个事务内执行并回读索引。索引构建语句上限为 120 秒，其他会话读取可能等待。
3. 若视图尚未填充，先执行普通刷新。视图已填充且存在有效全行唯一列索引时，「刷新物化视图」会开放并发刷新。删除最后一个符合要求的索引会撤去并发刷新资格。[PostgreSQL 并发刷新要求](https://www.postgresql.org/docs/18/sql-refreshmaterializedview.html)

删除索引须另行确认。目录发生变化、索引构建失败或超时时，客户端回滚本批改动并保留错误。回执中断时，请从原数据库重新读取目录。

## 验证

- macOS 上 Node.js 24.17.0 运行时检查、类型检查和源码构建通过。完整单元回归覆盖 1,326 个文件，27,451 项通过，10 项 Windows 系统 `tar` 用例按平台跳过。
- Server-200 独占 PostgreSQL 18 实库回归 5 项通过。验证创建后取得并发刷新资格，重命名保留索引 OID，目录变化拒绝旧预览，唯一键重复导致两项批次整批回滚，删除后重新拒绝并发刷新。只具有 `MAINTAIN` 的委派角色可以刷新，索引入口和预览仍要求所有权与 schema 创建权限。
- macOS Electron 原生窗口 1 项通过，覆盖 42 个观察点。从数据库右键新建未填充物化视图，经索引页创建唯一索引，首次填充后执行并发刷新。独立数据库连接确认索引有效、全行、普通列及唯一性，通过轮次的独占数据库和窗口临时配置已清理。
- WIN11-TEST 会话不可达，本轮 Windows 原生窗口、两平台安装包及旧版 PostgreSQL 实库待验收。
