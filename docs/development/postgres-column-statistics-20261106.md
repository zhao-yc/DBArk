# PostgreSQL 字段概况

在表或视图的记录页点击「字段概况」，选择字段后点击「开始统计」。统计对象是当前筛选匹配的全部已提交记录，页码、排序和未提交的记录草稿不改变统计范围。打开窗口和选择字段只更新界面。 [Navicat 字段统计说明](https://help.navicat.com/hc/en-us/articles/46711325532697-How-to-use-the-Data-Profiling-feature-to-analyze-data)

结果包含字段类型、总记录数、非 NULL 数及 NULL 数。常用内置类型还显示非 NULL 不同值、仅出现一次的值、重复出现的不同值和原生排序极值。文本类型另显示空字符串数。数值类型显示零值数和非有限值数，总和、平均值和总体标准差基于有限值计算。空结果的极值和数值聚合显示 NULL。

统计使用独立只读事务。计数以精确十进制文本显示。数值聚合沿用 PostgreSQL 的返回精度，浮点字段使用服务器的浮点运算。超长结果只展示明确标记的预览。JSON 等未启用原生分组的类型可查看总数与 NULL 统计。

表页和记录草稿在统计后保持。关闭窗口后，仍在途的只读查询完成时释放标签占用。此增量覆盖单列统计，分布图、抽样、异常值高亮及多列联动仍待实现。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时检查、严格类型检查、构建和 36 项定向单测通过。
- 完整单元回归覆盖 1,333 个测试文件，27,490 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 实库通过 5 项回归。新增断言覆盖 502 条筛选记录、NULL 和空字符串、原生极值、重复组、超过 JavaScript 安全整数范围的数值、非有限值、长值预览、只读视图、空结果及旧页权限失效。独立复核原记录和零剩余连接后清理测试容器。
- macOS Electron 通过 1 条端到端测试，共 77 项检查。实际表页每页 1 条，保留一项草稿时读取全范围的 3 条已提交记录。关闭统计窗口后原草稿保持。截图已检查，成功轮已复核数据库原记录、零剩余连接和原生临时配置清理。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
