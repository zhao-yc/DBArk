# 新建表字段字符集与排序规则

## 实际入口

在对象树打开新建表，点击“读取字段编码目录”。目录来自当前服务器的真实排序规则与字符集目录，候选读取的准备快照释放后才显示；此目录副本不携带提交权限。普通CHAR、VARCHAR、TEXT、ENUM、SET字段可选“继承表默认”或明确的字符集／排序规则配对。字段改名、重排保持原配对；改成不兼容类型或生成模式时保留并提示，用户可以清除显式选择，不自动替换数据类型。

确认页重新读取目录并核原候选摘要，逐列显示选择和SQL；目录变化、配对不完整或失效时拒绝继续。表默认编码与字段覆盖分开，未指定字段继承表默认。沿原两项CREATE确认；包含生成字段仍需第三项生成计算确认。

## 引擎与数据正确性

列配对是新建表专属结构化属性，不接收任意SQL；通用结构入口和旧转换器不得静默丢弃。显式列配对必须精确匹配本次实际目录，准备、预览和执行之间重核目录摘要。未知或缺权限时关闭显式选择，原继承创建不增加目录读取。

字段CHARACTER SET／COLLATE由安全生成器渲染；普通键、外键与生成字段继续走原专属计划。MySQL8.4前缀索引按字段自身实际字符集MAXLEN计算整索引字节预算，不按表默认值误算。建表成功后交叉核完整SHOW、TABLES和COLUMNS的真实编码、字段顺序／类型／属性，未知EXTRA或证据矛盾不能报告完整核验。DDL只投一次；断线、取消或后核失败均不重放，不自动删表。
