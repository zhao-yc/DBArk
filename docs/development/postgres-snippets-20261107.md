# PostgreSQL 片段库

在 PostgreSQL 查询页点击「SQL 片段库」，可搜索、分组查看、编辑、复制、导入及导出本地片段。选择片段后点击「插入查询」，正文会替换打开片段库时的原选区；空选区则插入光标处。插入是一次普通文本编辑，可用一次撤销还原，不会自动执行 SQL。

选择查询中的一段 SQL，在编辑器右键菜单或应用菜单中点击「将选区保存为片段」，填写名称后保存。新片段只包含选区原文，不改查询正文。取消未修改的片段草稿不会写入本地片段库。选区须为单一非空选区，且不超过 65,536 个 UTF-16 代码单元。

PostgreSQL 内置模板使用双引号引用标识符。用户保存的片段在各连接间共享，正文保持原样；美元参数、美元字符串和模板占位符均按普通文本插入，请在执行前核对当前方言和表名。

片段插入复用原查询的模型、选区及意图校验。期间若原查询正文、选区、连接、会话或活动标签发生变化，旧插入失效，恢复相同值也不会复活；需要关闭片段库后重新打开。保存片段只维护独立记录，插入不改变查询来源绑定、已有结果或活动事务。
