# PostgreSQL 片段名称补全

在 PostgreSQL 查询编辑器的新语句中，输入至少两个字符的片段名称前缀，即可选择本地片段。用户片段按原文插入，内置模板使用 PostgreSQL 双引号。补全只替换当前名称前缀，不使用 Monaco 变量插值；美元参数、模板占位符、缩进及补充平面字符均保持。插入可一次撤销，不自动执行 SQL。

补全使用当前编辑器和本地片段目录，脚本上限为 65,536 个 UTF-16 代码单元，每次最多返回 20 个匹配；长脚本仍可使用片段库插入。仅单一空光标可请求补全，注释、字符串、dollar 正文、现有语句内部及标识符中间不展开片段。

PostgreSQL 词法判断复用执行扫描器。已有会话时沿用其 `standard_conforming_strings` 缓存，不为片段补全查询服务器；离线或缓存未知时，只有两种模式都确认当前前缀是独立语句才提供片段。等待本地目录期间若光标、模型、活动标签、连接、会话或作业发生变化，旧请求不能交付迟到建议。切换回原位置也不会恢复已失效请求。
