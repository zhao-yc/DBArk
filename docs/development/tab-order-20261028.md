# 工作台标签重排（2026-10-28）

## 使用方式

工作台标签支持拖动到另一标签的左半／右半，分别放在目标前／后。标签名称获得焦点后，可用 Ctrl／⌘＋Shift＋左右键逐位移动，Ctrl／⌘＋Shift＋Home／End 移到首末。只改变顺序，保留原活动标签；关闭按钮和新增按钮沿原入口，不占用编辑器快捷键或系统剪贴板。

拖动期间出现模态、关闭协商、Escape、失焦或外部投放即撤销本轮。标记明确显示投放前后位置，键盘移动后保持焦点和可见性。身份快照异常时完整呈现原标签并说明操作不可用，不隐藏部分标签或回退到同名／同 ID 的新文档。

投放兜底等待整个原生事件派发结束后的下一任务；不能用捕获阶段的微任务提前撤销 React 冒泡处理需要的拖动对象。正常投放与其它取消入口均精确释放该轮定时器，迟到回调不能取消后继拖动。

## 实现与持久化

`tabOrder.ts` 仅投影有界文档身份，内存令牌不进入 SQLite。SQL、标题、结果及来源摘要不用于复制或定位。只有正式 `updateTab` 的同文档修改可继承令牌；换连接／默认库／表／来源、删除后重加、泛设置替换和工作区恢复会永久撤销旧事件。普通输入与同来源保存继续使用当前文档，投放读取提交时的最新标签。

`moveTab` 同步移动最新数组中的原对象，保留 `activeTabId`、Monaco 模型、正文、绑定及任务／草稿对象。实际顺序变化沿原 `commitWorkspaceSettings` 立即提交，取消旧正文防抖计时器；边界和同位操作不发保存请求。Main 按原标签身份保留文件授权，不新增 IPC、表结构或配置迁移。

App 继续以原标签 ID 挂载查询／表内容区。纯重排优先滚动到条带中的当前焦点；外部导航和查找激活仍滚动到活动标签。
