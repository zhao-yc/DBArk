# SQLite 勾选记录多字段填充

## 使用

在可写 SQLite 表格左侧勾选记录，打开“更多 → 数据编辑 → 填充 SQLite 勾选记录…”。勾选要填充的字段，再明确选择类型和值；初次不自动选择字段，也不以第一行值覆盖其它行。

- 范围仅为当前页勾选的已有记录及本地新增草稿，不包含其它页或全部筛选结果。
- 支持文本／JSON文本、有符号64位整数、有限实数、十六进制二进制及 NULL。全部勾选记录均为新增草稿时，另可选择 DEFAULT 省略字段；已有记录不能通过该入口设为 DEFAULT。
- 生成列不参加填充，未选择字段保留每行原值。打开与取消不读取数据库或改变原行；暂存成功后仍须原 SQL 预览及集中提交。
- 多行多字段作为一个本地撤销／重做步骤。同值不制造修改，非法值或超预算不产生部分草稿。最终累计更改继续受500行、10000字段及2MiB文本预算约束。

## 来源和提交保护

入口先核对原 Grid 的准确选择，随后独立冻结原页、行对象、typed 值及字段能力。自身模态禁用 Grid 后不复用已撤销的旧选择凭据。切换标签、连接／结构变化、忙态、外来模态或原行变化均撤销旧输入；失效后仍可取消，旧关闭回调不清后继输入。

表单只创建本地 typed 字段，编辑器对完整目标及最终草稿重新校验后一次发布。不增加 IPC 或数据库写协议；正式提交继续使用原快照、旧值并发检测及整批事务。连接中断或未知提交不重放。
