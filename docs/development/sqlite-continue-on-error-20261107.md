# SQLite 脚本遇错继续

SQLite 查询默认在首条失败语句停止。需要继续时，在查询页的「会话与执行选项」勾选「遇错继续」，然后执行全文、选区或参数查询。选项仅在当前标签生效。当前语句快捷键仍只执行光标所在的语句。

执行前先检查全文的引号、括号和语句边界。脚本逐条在同一物理连接执行，每条 SQL 经过 SQLite 原生单句校验。启用后，普通 SQL、约束及类型错误可以继续。锁冲突、权限、I/O、取消、连接失效和无法确认的执行错误会停止。记录满 100 项错误或保留满 200 组完整结果后，剩余语句也停止投递。错误分类沿用 SQLite 原生结果码。[SQLite 原生错误码](https://www.sqlite.org/rescode.html)

原连接的事务和临时表可由后续语句使用。SQLite 自身可能因冲突回滚，回执显示的是原生确认后的事务状态。客户端不会替用户提交、回滚或重新执行。摘要列出实际尝试数、完成数和原语句序号，可点击定位每条失败。若当前仅显示结果，定位时会恢复编辑器。完整成功的结果及其原始序号会保留，失败语句发出的部分结果不会进入结果区。已开启类型参数的脚本仍通过 SQLite 原生绑定，错误报告只显示错误码。
