# MySQL 和 MariaDB 定义正则定位

从「工具 → 全库搜索」切到「定义正文」，选择「服务器正则」并搜索。双击结果打开只读定义查看器。正文与搜索时一致后，用「上一处定义命中」和「下一处定义命中」查看非空匹配和精确行列。最多保留前 200 处，探到第 201 处才显示截断提示。

对象是否命中继续由数据库使用用户原式和指定大小写规则判断。位置查询在同一服务器对完整原文标注匹配边界，保留捕获编号、锚点和前后顾。MySQL 使用整组替换，MariaDB 在补充位置查询中使用 PCRE2 非空匹配选项，避免替换函数在空匹配处提前停止。[ICU 正则替换](https://unicode-org.github.io/icu/userguide/strings/regexp.html) [MariaDB 11.4 正则替换实现](https://github.com/MariaDB/server/blob/11.4/sql/item_strfunc.cc) [PCRE2 非空匹配选项](https://www.pcre.org/current/doc/html/pcre2pattern.html)

引擎去除边界后逐段核对完整原文，只向搜索窗口交付摘要及 UTF-16 位置。定义变化、位置无法无损映射、仅有零宽命中或旧版服务器缺少位置能力时，查看器保留当前定义的只读展示。MySQL 5.x 的原有正则搜索继续提供对象命中。
