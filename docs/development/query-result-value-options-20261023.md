# 查询结果按不同值勾选筛选

## 使用入口

查询完成后打开“筛选已返回结果”，添加条件并选择字段，点击该条件的“从结果选择值”。选择器显示原已返回全部行的不同值及出现次数，不受当前本地筛选缩窄；查询截断时仍只覆盖已返回部分。

搜索后可逐项勾选，或勾选全部搜索匹配值；每页50项，跨页及搜索保留勾选。选择“只保留勾选值”或“排除勾选值”，点击“写入条件草稿”，最后在外层点击“应用筛选”。写入前后均不重发SQL；取消任一草稿不修改已生效视图。

NULL、空字符串及文字`NULL`分别展示；长值先省略显示，可查看完整提示和展开只读详情再确认。搜索只影响候选展示，不清除隐藏勾选。Ctrl／⌘+Enter只写入本条草稿，Esc只关闭值选择器；输入法组合期间不提交。

## 比较与条件语义

使用已有字段类型和本地精确比较，不使用数据库排序规则或继承旧条件的忽略大小写选项。文本区分大小写，精确整数／DECIMAL不经浮点转换，数值等价的不同文本形式合并计数，并保留首次出现的代表原文；NULL独立计数。原结果数据始终不修改。

包含非NULL值与NULL时生成OR子组。排除非NULL值同时保留未勾选的NULL；勾选NULL参与排除时，生成非NULL约束。仅勾选NULL分别生成NULL／非NULL条件，不将空集合误作全部匹配。

只替换所属条件，保留其它组的括号及该条件原启停意图；生成子组时各叶保留原停用状态。先核整棵32条件／16组／8层预算，失败保留原草稿及选择；外层原子试算保留多列排序、NULL位置及大小写，并接通原整理撤销／重做。

## 有界读取和来源

最多100000原行、1024列、2000种不同值，单次勾选最多128种（含NULL）；候选完整超限即拒绝，不取前N项。另限制单值4096个UTF-16单位、累计原文及比较／搜索工作量，可能早于数量上限拒绝。未知类型、二进制包装或不符合字段协议的原值不猜测比较资格。

捕获绑定原数组、完整列元数据、全行身份／顺序及目标原格，发现漂移永久失效；不读取访问器，不冻结原行列。父草稿根、原叶及选择器代次共同阻止旧输入、勾选、确认和取消操作影响后继窗口。内层期间阻止外层旧应用及改值回调，失效选择器仍可取消。
