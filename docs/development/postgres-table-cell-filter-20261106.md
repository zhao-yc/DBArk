# PostgreSQL 表页按单元格筛选

在表或视图的记录网格右键单元格，选择「按此单元格值筛选」或「排除此单元格值」。也可聚焦单元格后按 `Shift+F10` 或菜单键，用方向键选择并按 `Enter` 确认。按 `Esc` 关闭菜单并回到原格。Navicat 的记录页也提供从单元格右键开始的筛选入口。 [Navicat 记录筛选手册](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/data_rdbms.html#filter-records)

菜单把列、操作符和原值带入「高级筛选」。核对后点击「添加条件」，再点击「应用高级筛选」。添加条件时保留现有分组，新条件追加到最外层，使用该层的全部满足或任一满足规则。若当前使用快捷筛选，面板提示应用高级筛选会替换快捷筛选。应用后从首页读取，并保留当前排序。翻页和全量导出沿用已应用的条件。

大整数、小数、空字符串、换行和文字 `NULL` 都按协议原值传递。真实空值分别使用 `IS NULL` 与 `IS NOT NULL`。普通值的排除条件使用不等值比较，SQL 中的 NULL 不会匹配。二进制值和超过高级筛选合同预算的值不可通过菜单带入。列类型和等值比较由 PostgreSQL 判定。存在待提交记录草稿或需要刷新时，先完成相应处理。

## 验证

- macOS 上 Node.js 24.17.0 运行时检查、类型检查和源码构建通过。新增 9 项单元测试验证协议原值、NULL 区分、合同边界以及失效行列。
- macOS 完整单元回归共 1,327 个文件，27,472 项通过，10 项 Windows 系统 tar 用例跳过。
- Server-200 独占 PostgreSQL 18 实库回归 5 项通过。测试后独立回读原表记录，两次均确认测试连接归零并清理容器。
- macOS Electron 原生窗口回归通过，共 69 项观察。新增检查覆盖鼠标右键、键盘打开和返回焦点、待提交草稿锁定、原值预填后延迟应用、等值和排除的实际结果、保留条件分组以及快捷筛选替换提示。已核对菜单截图、应用正常退出及测试配置清理。
- Windows 虚拟机不可达，本轮按约定切换到 Mac。Windows 原生操作、两平台安装包和较早 PostgreSQL 版本待验。
