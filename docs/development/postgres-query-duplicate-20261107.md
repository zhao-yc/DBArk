# PostgreSQL 复制查询

打开 PostgreSQL 查询，在工具栏点击「复制为新查询」。副本使用当前编辑器的完整 SQL，标题追加「（副本）」，并沿用原查询的数据库上下文。副本是独立草稿，后续可单独编辑和保存。

原标签保留 SQL、撤销记录、查询结果及活动事务。保存查询和 SQL 文件的来源绑定归原标签所有。复制本身不执行 SQL，副本初始显示「尚未连接」。

复制复用现有的查询复制意图和编辑器正文桥。模型、连接、活动标签或操作状态变化时，等待中的复制失效。已有 PostgreSQL 会话的数据库来自该会话的固定目标，尚无会话时使用原标签及连接的明确数据库。
