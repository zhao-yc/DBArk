# 表字段非NULL不同值计数

在表或视图数据页打开“表数据统计”，选择需要核查的字段，再勾选“统计非NULL不同值（可能耗时）”。点击“开始统计”后，结果增加不同值数量；默认关闭，勾选或取消勾选只清除旧展示，不自动查询。

统计范围仍是打开窗口时冻结的全部服务器筛选记录，包含停用条件和分组的原语义，不限于已加载页。父页未提交草稿不参与统计且保持原样；未选择字段时仍只统计总记录数。

## 数值与比较语义

每个支持的字段直接使用服务器`COUNT(DISTINCT 原列)`，与其它计数、极值、合计在同一条聚合内执行。文本遵循原列排序规则，例如大小写不敏感列会将大小写变体视为同值；二进制保留原字节语义，BIT不借数值转换去重。计数以十进制字符串传输，不经JavaScript浮点数。

NULL不参与不同值计数，空字符串参与；空结果或全NULL为0。参见[MariaDB COUNT DISTINCT](https://mariadb.com/docs/server/reference/sql-functions/aggregate-functions/count-distinct)。JSON、空间和未知类型当前仅有非空／NULL数量，新列明确显示不支持。计数用于观察当前数据，不证明已有唯一约束或未来写入仍唯一。

## 校验与取消

原请求冻结字段和不同值开关，不能用后继开关解释旧回包。开启时按原元数据类别要求合法不同值计数，不能缺失、超过非空数，或在存在非空值时为0；关闭或不支持类型意外带计数也拒绝。共享类别判定防止回包把JSON升级或把数值降级为只计数量。

沿用独立RR只读事务、原警告拒绝、结果预算、结构前后核对及严格物理连接收尾。取消ACK不提前释放原请求，改变开关不解除父页占用。
