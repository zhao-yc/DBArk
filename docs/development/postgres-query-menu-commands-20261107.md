# PostgreSQL 查询菜单

打开 PostgreSQL 查询并激活标签后，可在应用「编辑」菜单查找和替换正文，定位行列或匹配括号，切换行注释，转换明确选中文字的大小写，复制、移动或删除行。编辑操作沿用编辑器的撤销记录。格式化沿用 PostgreSQL 方言和原长度限制，并可整步撤销。「文件 → 保存查询」沿用本地查询库的另存或原来源更新。

「工具 → 查询」提供以下入口。

| 命令 | 范围 |
| --- | --- |
| 执行选区或全部 | 有选区时执行选区，光标折叠时执行整份脚本 |
| 仅执行选区 | 需要一个非空选区 |
| 执行当前语句 | 按光标位置由 PostgreSQL 语句分析定位 |
| 执行全部 | 忽略选区，执行当前编辑器全文 |
| 停止 | 请求取消当前标签的原任务，等待原任务结束 |
| 查看估算计划、实际执行分析、位置参数 | 沿用查询页各自的入口，实际执行分析仍需确认 |

菜单随活动标签、连接、编辑状态、查询任务和模态窗口更新。菜单、工具栏及快捷键调用同一查询执行路径，保留原会话和事务边界。

Monaco 查找条在编辑器内保留可访问的对话框角色。工作区命令可以在查找条开启时切换到替换，也可以在关闭查找条后切换标签。应用的保存确认等模态窗口继续锁定查询命令。
