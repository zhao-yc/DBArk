# SQLite 结果定位

执行 SQLite 查询后，选中一个当前结果，在回执中点击「定位结果原语句」。若正在使用「仅显示结果」，会恢复编辑区并选中原语句。成功结果和失败摘要各自定位自己的语句，点击一个按钮不会覆盖另一个按钮的范围。

定位沿用 SQLite 原生准备确认的语句前缀。普通脚本按本次载荷偏移定位，选区会映射回完整编辑器，当前语句会加回原起点，类型参数仍定位带占位符的模板。SQLite 原生返回的 UTF-8 前缀经原文校验后映射成 UTF-16，保留 CRLF、表情及语句终止符的位置。

定位只在原模型、正文和连接来源仍可确认时可用。编辑正文后，已有结果仍可查看，旧定位停用。固定快照和执行计划沿用原视图。切换结果和定位不会重新执行 SQL 或新增执行历史。
