# 查询脚本本地语法检查

## 使用

MySQL／MariaDB 查询编辑器可从“更多 → 本地语法检查 → 检查 SQL 语法”、编辑器右键或原生“工具 → 查询执行与分析”启动。检查整份当前脚本，面板列出行列和问题；点击问题定位原模型，编辑器显示独立警告标记。

这里只运行随安装包提供的 MySQL 语法解析器，不执行 SQL，不检查数据库对象、权限、服务器版本能力或运行结果。MariaDB 扩展语法、解析器尚未覆盖的合法语法可能出现提示；无提示也不代表服务器一定接受脚本。SQLite 不借用 MySQL 解析器，首批不显示该入口，后续另接相应方言。

编辑正文、切换标签、替换模型、原会话／连接变化或开始其它操作，会清除本轮标记并使旧结果永久失效。取消只终止本轮解析线程；“重新检查”是新的一次明确动作，不自动执行或保存查询。

## 解析及资源边界

- 使用原会话当前缓存的 ANSI_QUOTES／NO_BACKSLASH_ESCAPES；只读原缓存前后快照，不创建会话、不读取目录。没有会话时，只有四种模式解释和原文映射一致才报告结果。
- `DELIMITER`、字符串和普通注释分别扫描；复合例程每条完整语句只解析一次，不再由库的 validate 二次按分号拆分。
- 逐 token 保留规范文本到原 UTF-16 的边界映射，并转换 ANTLR 代码点索引；CRLF、补充平面字符、引用名和长字符串不能移位。EOF 保留原零宽位置。字符串、标识符、注释及括号未闭合提供固定问题类别。
- X／B 特殊文字检查真实内容；引用 SQL_MODE 与裸写一致阻止沿旧模式检查。执行／提示注释、客户端命令、不能可靠解释的 DELIMITER 和显式模式切换整份拒绝，不将跳过部分冒充通过。
- 按当前模式快照做静态检查，不能预测 CALL／EXECUTE 或其它执行环境对后续语句的影响，也不能代替完整 MariaDB／服务器 SQL_MODE 方言矩阵。
- 原 262144 UTF-16 源长度、16384 token、64 层嵌套，最多256条语句及100处问题；超过整份拒绝，不截断后声称检查完整。Worker 启动8秒、正文分析2秒，复用现有产物但独占实际线程。
- 回包仅准固定状态、计数、问题类别及原文范围。拒绝额外字段、访问器、无效Unicode及切开代理对／CRLF的位置；不发送 SQL 片段、原始解析错误、凭据或可执行内容。
- 标记使用每轮独立 owner；关闭、失效和旧清理只删除所属标记，不影响其他语言服务。原模型、正文、撤销栈和查询结果不被检查修改。

```powershell
pnpm typecheck
pnpm build
node scripts/sql-syntax-check-ci.mjs
```

固定离线整例保持120秒、worker1、retry0、trace off；默认和列举不启动桌面。仅准备独占空草稿，检查动作走真实菜单、原模型和浏览器 Worker；Main 透传原请求，同时拒绝所有数据库、文件及剪贴板请求和 utility 创建。失败保留现场，不自动重跑、强停或放宽门槛。
