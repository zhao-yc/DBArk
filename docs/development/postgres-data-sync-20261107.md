# PostgreSQL 按所选差异同步

从「工具 → 比较 PostgreSQL 表数据」对两张表做完整比较，勾选要同步的差异。选择可以跨差异类别和结果页。预览逐行列出主键、操作、右侧连接和目标表。输入预览显示的目标名称后才提交。左侧独有行插入右侧，两侧字段不同的行更新右侧，右侧独有行从右侧删除。

同步使用比较时冻结的左侧值。写入事务先锁定右侧目标，复核权限、表结构和所有选中旧行的物理版本及原值，再执行整批写入。插入和更新通过 `RETURNING` 核对实际值，删除核对服务器确认的影响行数。约束失败、并发改写或原值复核失败会拦截提交。连接中断时以事务回执为准，终态未知时重新比较核对。每批最多 100 行、1 MiB，快照有效期最多 5 分钟。[PostgreSQL 表锁](https://www.postgresql.org/docs/18/sql-lock.html) · [PostgreSQL 系统列](https://www.postgresql.org/docs/18/ddl-system-columns.html)

同步支持可写普通表的常用内置类型和 JSON。生成列由数据库计算，回读时仍逐列核对。标识列和序列默认列可保留左侧标识值，显式写入不会推进关联序列。右侧启用自定义触发器或被外键引用时会在写入前拦截。筛选比较和分区表仍可用于只读核对。

## 验收

- WIN11-TEST 会话不可达，本轮未派发，按既有授权在 macOS arm64、Node.js 24.17.0 验证。Windows 原生窗口和两平台安装包待验。
- 严格类型检查、构建和全量单测通过。1,352 个测试文件，27,578 项通过、10 项跳过。
- Server-200 上两轮独立 PostgreSQL 18.6 容器和 macOS 源码窗口各通过 1 项专项。两轮容器和 SSH 回环转发均确认释放。
- 最终窗口确认跨页勾选 101、102 及 9223372036854775807，错误目标名无法提交。一次写入完成插入、删除和更新各一行，独立连接核对原始 BYTEA、18 位小数、NULL、未选行及来源数据，重新比较只剩 26 行未选差异。
- 唯一约束冲突发生在批内更新之后，右侧独立读回确认更新和插入均未提交。同值更新改变右侧行版本，旧预览被拦截。预览后新建的触发器、引用右侧表的外键均在写入前拦截。筛选比较不提供写入入口。
- 显式保留 identity 值 99，生成值回读为 14，右侧关联序列仍为初始值 42，未调用取号。
