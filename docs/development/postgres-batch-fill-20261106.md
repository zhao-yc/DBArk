# PostgreSQL 批量填充字段

在记录网格勾选当前页的记录，再点击「批量填充字段」。选择一个或多个可编辑字段，为整组记录填写文本、NULL、DEFAULT 或十六进制字节。主键、生成列及已标记删除的记录不可批量填充。每批最多勾选 100 条，整份草稿仍受表页原有的行数和大小限制。 [Navicat 批量编辑说明](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/data_rdbms.html#grid-view)

「暂存整批填充」保留同一行其他草稿字段及其原行版本。已与填充值一致的行不产生新增改动。暂存后可用「撤销整批填充」恢复填充前的草稿，下一次编辑草稿会结束这次整批撤销。翻页会清空网格勾选，已暂存的记录仍按原页保留。

点击「预览记录修改」核对整批变化，再确认提交。数据库执行仍使用现有 PostgreSQL 参数绑定、原行冲突检测及单次事务。当前增量以当前页勾选记录和指定字段为范围。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时检查、严格类型检查、构建和 8 项定向单测通过。覆盖草稿字段合并、无变化跳过、字节比较、主键和生成列拒绝以及已标记删除的记录。
- 完整单元回归覆盖 1,334 个测试文件，27,492 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 实库通过 5 项回归。批量填充先生成两条预览，数据库原值保持。提交后复核两条非相邻勾选记录的 NULL、DEFAULT、原始字节和精确主键，未勾选记录保持原值。独立复核原表及零剩余连接后清理容器。
- macOS Electron 定稿通过 1 条端到端测试，共 78 项检查。通过实际网格勾选两条记录、暂存整批并撤销，关闭后独立复核服务器原值、零剩余连接及临时配置清理。首轮截图发现输入区被模式选择器挤窄，修正后保留原断言并新增宽度断言，定稿截图已复核。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包和其他 PostgreSQL 版本待验。
