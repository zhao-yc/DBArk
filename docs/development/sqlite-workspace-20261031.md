# SQLite 接入原连接与查询工作区

## 使用范围

在原“新建连接”中选择 SQLite，并通过文件选择器选取现有数据库。默认只读，允许显式改为读写；锁等待为 0–5000 ms。没有网络地址、用户名、密码、SSH 或 TLS 字段。

连接树读取 `main` 下的表、视图与触发器。后续已接入[只读表浏览、筛选和多列排序](sqlite-table-browse-20261031.md)：双击表／视图打开分页表格，右键“生成 SELECT 查询”才打开带正确转义的草稿。恢复表标签会读取服务器分页；查询草稿和定义不会自动执行。

查询沿用原 Monaco 编辑器、执行选区／整个脚本、分批结果、历史、停止以及开始／提交／回滚按钮。每个查询会话对应自己的原生 utility process，不经过 mysql2。INTEGER 保留有符号 64 位原文，REAL、TEXT、NULL、BLOB 沿用原生驱动的独立编码；结果首版只读。支持保持关键字原文的 SQLite 排版，大小写转换尚未开放。

## 文件授权和失效处理

- Main 仅接受当前窗口文档为准确连接选择的现存普通文件；选择令牌绑定文件身份、连接编号和有效期，保存前后重新核对。
- 配置持久化保存路径和模式，临时令牌不落盘。复制、连接导入导出只带文件名提示，必须重新选择本机文件；直接传入新绝对路径不能取得授权。
- 不开放 ATTACH／DETACH、VACUUM INTO、扩展加载及写入 PRAGMA；不能通过 SQL 获取选择范围之外的文件能力。
- 网络引擎退出只清理网络会话和任务。SQLite 不自动重连或重放；退出未确认时保留准确进程句柄及关闭屏障，明确断开或退出后再核对结果。

## 本轮没有开放的能力

可编辑表格、表结构设计器、创建新文件、参数表单、当前语句解析、执行计划／分析、MySQL 事务设置、遇错继续、警告明细、任意 SQL 结果的本地筛选排序与比较、SQL／完整流式导出、导入、跨库传输和备份恢复尚未接入 SQLite。界面隐藏这些入口，后端也明确拒绝，不能降级到 MySQL。结果的 CSV／JSON／XLSX 导出仍受当前已加载结果的预算限制。
