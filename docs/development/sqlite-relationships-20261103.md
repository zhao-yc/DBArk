# SQLite 表关系图

## 使用

在已打开的 SQLite 物理表页，选择“表格操作 → 设计与结构 → 查看表关系图”。当前表固定选中；打开窗口不读取结构，点击“读取所选表”才生成第一幅图。

- “读取表目录”列出 `main` 中的用户物理表，支持本地名称搜索和每页50项。勾选只是草稿；“刷新图中表”读取上一幅图的范围。
- 箭头从子表指向父表。支持复合外键、自引用、字段显示、缩放、节点选择和更新／删除规则；显示操作不读取数据库。
- SQLite 外键用 `pragma_foreign_key_list` 的编号显示为“SQLite 外键 #编号”，不冒充 DDL 中的约束名称。
- 省略父字段的引用只在父表已选入时按其**声明主键的序号**解析，不推测 `rowid`。父表未读、缺主键、主键列数不符或显式父列缺失时保留声明并提示未确认。
- 未声明类型显示“未声明类型”；字段提示保留目录 `NOT NULL` 标记，不据此推断 `INTEGER PRIMARY KEY` 等列是否实际允许存入 NULL。

这只是目录关系查看，不验证父唯一性、排序规则、业务数据约束、一对一基数，也不提供模型编辑或正反向工程。视图、临时库和附加库不在本入口范围内。

## 只读与生命周期

新增受限 `sqlite.relationships` 命令，输入只有已保存连接ID、`main`、原表结构摘要、所选表及独立任务ID；不接受文件路径、SQL、用户会话或写能力。Main 校验原窗口、连接修订和退出屏障，preload 白名单与合同同步。

每次整图读取使用独立只读 utility process，在同一个 `BEGIN` 结构快照中读取 `sqlite_schema`、`table_xinfo` 和 `foreign_key_list`，随后回滚并关闭。只在准确进程退出确认后发布完整结果，不读取业务行、不执行 `foreign_key_check`、不改变 `foreign_keys` 设置或查询标签事务。源表摘要变化、截断、失败或取消均不发布部分图。

最多40张表、2000个字段、300个外键、每键64个部分和8MiB回包；最多两个在途关系图快照，退出未确认仍占槽。表名按 SQLite 的 ASCII 大小写规则关联。原表页、活动标签、连接或修订曾变化后，旧界面永久失效。关闭等待原读取及取消ACK后才归还所属标签占用。
