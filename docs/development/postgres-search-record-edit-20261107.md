# PostgreSQL 从搜索命中编辑原记录

在「工具 → 全库搜索 → 搜索数据」双击可定位的 PostgreSQL 表记录，在只读详情中点击「编辑命中记录」。表单聚焦命中字段，设定写入方式后点击「加入草稿」。检查 SQL 及待写入值，勾选确认后提交。

编辑沿用普通表页的写权限和事务。入口支持具有可读主键与更新能力的普通表。分区表的命中仍可按原有条件只读定位。每次打开时在同一只读事务核对服务器、数据库、表结构、主键和物理行版本。搜索设置与普通表格的显示设置隔离。提交前重新核对服务器、关系和锁定的完整原行。

命中编辑使用独立凭据，限于更新该行。已有普通表页保留自己的状态和编辑快照。提交完成后返回原搜索，需重新搜索才能获取新行版本。

- 从连接默认库以外的数据库定位并更新主键为 `9007199254740993` 的记录，核对 BYTEA 命中焦点、待写入值和显式确认。角色使用 Asia/Shanghai 会话时区，未选字段为时间戳，搜索后的外部更新会使旧命中失效，预览后的外部更新会在写入前被拒绝。重新搜索后明确提交成功。
- 直接请求验证错库、复用已有表页身份、删除及筛选删除均被拒绝。已有表页的快照可继续预览自己的更新，数据库未执行该预览。保留原有跨库分批、只读详情、视图许可和退出清理检查。
