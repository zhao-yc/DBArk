# SQLite 按所选差异同步

从「工具」进入 SQLite 数据比较。对可写右侧表做完整比较后，勾选差异并点击「预览同步到右侧」。选择可以跨差异类别和结果页。左侧独有的行会在右侧插入，两侧都有的差异行会更新右侧，右侧独有的行会从右侧删除。预览逐行列出操作和主键，并汇总三种操作数量。输入准确的右侧表名确认后才开始写入。

左侧数据来自比较时的冻结快照。右侧文件身份、表结构及完整旧行会在独立写事务内复核。写后逐行复核实际存储值和删除结果，全部通过才提交。约束、目标并发变化或存储类型转换会使整批回滚。每批最多 100 行和 1 MiB 选中数据，预览可用期最多 5 分钟。

同步适用于完整、无筛选的比较和可写普通表。目标含生成列、触发器或被外键引用时仍可查看差异。提交回执只保存目标与执行事实，原值和 SQL 留在当前操作。同步使用 SQLite 的独立写事务和冲突中止语义。[SQLite 事务](https://www.sqlite.org/lang_transaction.html) · [SQLite 冲突处理](https://www.sqlite.org/lang_conflict.html)
