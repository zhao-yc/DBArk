# PostgreSQL 从 CSV 和 JSON 新建表

在 PostgreSQL 数据库节点或对象浏览器的表分类打开「从文件导入新表」。选择 CSV 或 JSON 及文件编码，可用 UTF-8、UTF-16 LE 和 GB18030。向导严格检查所选编码，完整扫描并列出源字段及记录数。样本最多显示 20 行。CSV 可选择逗号、分号或制表符，也可关闭首行表头并按列序号使用第一条记录。JSON 使用对象数组，字段目录包含整个文件中出现的字段。

填写并核对表名，在设计器选择有权限的 schema，检查建议字段。字段初始类型为可空 `text`。需要查询或约束数值时，可改用 `bigint` 或 `numeric`。预览并确认建表后，点击「继续配置导入」。向导复核原文件字节指纹，并根据实际表读取目标列目录。核对或修改字段映射，再单独确认追加。每次写入使用一个 PostgreSQL COPY 事务，文件在映射前发生变化会阻止导入，在映射后发生变化会回滚数据写入。已建表会保留。

新表向导的 CSV 使用 tabrelio CSV 约定，`\N` 表示 NULL，空字段保留为空字符串。映射到 `bytea` 的 `base64:` 值按二进制解码。JSON 中的数字保留原始文本，嵌套对象和数组保留精确的 JSON 文本，省略的已映射字段与显式 `null` 均写入 NULL。将 tabrelio 导出的 `{ "type": "binary", "base64": "…" }` 对象映射到 `bytea` 可恢复二进制值。

设计器可从 1 到 128 个源字段建立初始表结构。已有表的原生 COPY CSV 继续从表页操作，并使用 PostgreSQL 的 CSV 空值约定。[已有表原生 COPY CSV](postgres-copy-preview-20261105.md) · [从 XML 新建表](postgres-xml-new-table-20261107.md)

## 验收

macOS arm64 使用 Node.js 24.17.0，通过运行时检查、严格类型检查、构建及 251 项定向单元测试。Electron 连接 Server-200 的隔离 PostgreSQL 18.6，三项端到端测试通过。新表用例覆盖 UTF-16 LE 分号 CSV、无表头首行、字段改名后的手动映射、JSON 大整数与嵌套小数、`bytea`、空字符串和 NULL。JSON 在映射后被同长度改写时，实库确认回滚并保留空表。另外回归已有表和新表的 XML 导入。PostgreSQL 表工作区实库集成用例通过，含原生 CSV 的导入、回滚和无表头行为。

隔离容器和回环转发已清理。Windows 虚拟机测试会话本轮不可达，Windows 原生和安装包验收待执行。
