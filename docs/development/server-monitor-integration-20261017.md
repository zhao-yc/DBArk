# S02服务器监控正式接线

本批复用既有自主实现`609c886b3abe1bed49b7d2aeb1a5582e8f6ce710`的共享快照契约和只读内核，加入有类型的`serverMonitor.read`、preload白名单、严格参数校验及Engine正式入口。界面不能传入SQL、扩大会话上限或要求结束他人会话。输入仅含连接编号、任务编号和1至100的会话上限。

每次读取使用独立短连接，顺序执行概要、固定白名单状态及有限会话查询，不借用SQL标签的事务和临时表。会话SQL在服务器投影至512字符，总快照另受512KiB预算；计数保留原字符串，NULL与空串分开，账号能看到的会话不标为全部。权限或已知版本缺项逐片降级，断线、格式未知及取消继续失败。这是顺序快照，不计算未经采样证明的速率。

正式入口复用既有独立任务的建连取消、准确threadId取消及严格收尾边界；读取Promise在原连接关闭后才落定。关闭失败拒绝返回快照，不把KILL响应当作原读取结束。持久任务摘要另用固定中文投影，快照、会话SQL、账号和原错误不进入SQLite任务摘要。当前存在的独立任务关闭失败后资源登记缺口正在单独修复；本片不将该继承路径称为已解决，也不接纳异常收尾的真实验收。
