# SQLite 查询结果列统计

## 使用与语义

SQLite 查询页从结果表格的“列统计”进入，统计当前已筛选的返回行，默认使用首次打开时的勾选范围，可明确切换全部范围和可见列。不同显示同名列仍按内部字段键定位；不重发 SQL、不读取全表、不改变筛选、排序、事务或整理历史，关闭清除旧勾选。截断结果明确提示范围。

提供行数、非 NULL、NULL、非空不同值、极值，以及 INTEGER／REAL／TEXT／BLOB／NULL 的独立行数。按原逐格标记判断类型，不能由数字外观猜测 TEXT。数值相等的 INTEGER／REAL 合并不同值，TEXT 和 BLOB 分域；极值沿原比较器的数值、UTF-8 文本、原字节顺序，BLOB 展示完整 `X'HEX'`，不使用数据库 collation。

仅全部非 NULL 值均为有限数值时提供合计和平均值。INTEGER 不经过 Number，BigInt 十进制聚合可保留超出 int64 的本地合计；REAL 沿已返回原文计算并明确近似，有限平均精确扩展，循环平均沿原舍入规则。这是本地原值统计，不能当作数据库 `SUM`／`AVG` 的隐式转换或溢出行为；有文本、字节或无限 REAL 时保留可靠不同值、极值及类型计数，合计／平均留空并解释。依据：[SQLite 存储与比较](https://www.sqlite.org/datatype3.html)、[聚合语义](https://www.sqlite.org/lang_aggfunc.html)。

复用原有界统计扫描器、选中回执与模态保护，每批最多 512 行／32 Ki 原文，保留单值 4096 字符及总量 8 Mi 单元上限；HEX 先核完整长度，不截断。缺失或不匹配类型不发布部分值指标或类型计数。绑定完整原列、行、逐格类型对象及代码；捕获和发布前完整核源，观测漂移后恢复原对象也不能复活。切列、取消、连接变代与旧关闭回调沿原失效规则，没有新增 IPC、驱动或持久化结构。
