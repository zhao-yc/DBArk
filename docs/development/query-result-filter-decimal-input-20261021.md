# 结果筛选小数简写输入开发候选

## 行为与入口

“筛选已返回结果”的数值条件原值、区间上下限和候选值列表接纳小数简写：DECIMAL／NEWDECIMAL／NUMERIC 可输入 `.5`、`+.5`、`-.5`、`1.`；FLOAT／DOUBLE 也可输入 `.5e2`、`1.e2`。输入框重开和已生效规则保留用户原文，只在自有比较输入中补零。

DECIMAL 全程使用字符串及原精确比较器，不经 Number；科学计数法仍只限浮点类型。整数不接纳小数简写，文本条件仍按原文匹配，`.5` 和 `0.5` 不等价。未知类型、NULL、无符号负数及非法格式沿用原准入规则。

## 保持的边界

只放宽条件输入，不修补服务器返回的异常值。原 DECIMAL 返回字符串若为 `.5` 或 `1.`，筛选及排序仍拒绝。补零后的完整精确键继续受4096单位上限约束，条件总预算、旧投影和失败行为保持。

原结果的值、类型、引用、SQL和顺序不变；筛选后的多列排序、复制和导出仍使用原行。没有新增 IPC、数据库执行、文件或剪贴板操作，不自动交换区间端点。

## 验证安排

新增21项控制器RAM用例，覆盖小数20位精度、负零、正负号、浮点指数、整数及非法格式拒绝、原返回值严格准入、区间和列表、文本原文及补零长度边界；另增1项真实QueryTab RAM面板／排序／选择复制／导出组合，确认重新打开保留条件原文及只执行初始化一次合成查询。
