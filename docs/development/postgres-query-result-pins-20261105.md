# PostgreSQL 固定查询结果

选择带列的查询结果并点击「固定结果」，页面切换到新快照。快照保留该结果集已返回的全部原行、原列、类型、截断提示和随附 SQL。固定时的筛选、排序和列显隐属于当时的视图。

- 执行新查询后会显示本次结果。可从「固定快照」栏切回旧结果，查看「快照 SQL」，或对快照进行筛选、排序、查看行详情及导出。切换来源会重置当前视图的布局与整理历史。
- 释放正在查看的快照会返回本次结果。每个查询标签最多固定五份，按序列化数据的 UTF-8 字节合计限 16 MiB。超限会保留已固定的快照。
- 快照存于当前标签内存。关闭标签或修改标签的连接来源时释放。查看、整理和导出快照只使用已经返回的数据。

## 验证

- macOS 类型检查、源码构建和 12 项快照及整理历史定向测试通过。Server-200 独占 PostgreSQL 18 实库回归 5 项通过。
- 完整单元回归覆盖 1,326 个文件，27,444 项通过，10 项 Windows 系统 `tar` 用例按平台跳过。
- macOS Electron 源码窗口 1 项通过，覆盖 32 个观察点。原生窗口在已有筛选和隐藏列时固定结果，实际导出 JSON 并回读原列、原行、相邻 BIGINT 和二进制原值。执行新查询后回看快照与附带 SQL，释放后返回本次结果。原会话序列值、事务和执行历史经过复核。
- 文件对话框使用测试桩提供专用路径，应用实际写入导出文件。通过轮次正常退出，专用配置、数据库和容器已清理。WIN11-TEST 会话不可达，Windows 原生窗口和安装包待验收。
