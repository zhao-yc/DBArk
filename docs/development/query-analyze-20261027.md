# SQL 实际执行分析

## 使用方式与执行边界

查询工作区新增“实际执行分析”，选区优先，无选区则使用完整正文。先建立本标签的固定会话，读取其真实版本和默认库，再展示冻结的 SQL、连接名称、主机端口、账号和实际默认库。必须勾选风险确认后点击“确认并实际执行”。取消保留原结果，不发送用户分析语句。

本功能会真正执行 SQL。服务器允许的数据修改语句可能持久修改数据；函数、触发器和非事务表也可能产生副作用或锁。客户端不隐式开启事务、不自动回滚，取消不保证撤销已发生的操作。需要事务保护时，用户先明确开启事务，分析仍使用原会话，之后由用户明确提交或回滚。

支持服务器接受的单条 SELECT、WITH 和数据修改语句。多语句、EXPLAIN、ANALYZE、不可确认的可执行版本注释及超过20MiB的输入拒绝。语法、权限、格式、取消、断线或结果截断均不自动回退、改写为普通SQL或重发。

## 方言和指标

- MySQL 8.0.18起使用 `EXPLAIN ANALYZE`；8.0.21及以上明确 `FORMAT=TREE`，避免会话 `explain_format` 改为JSON后影响分析。MySQL 5.7及未知版本明确拒绝，仍可使用原估算计划。
- MariaDB 10.1及以上使用 `ANALYZE FORMAT=JSON`，按其自身JSON结构展示。是否接受具体DML形状以原服务器返回为准；拒绝不会降级执行普通DML。
- 本批MySQL8.0.46/8.4.11的多表UPDATE分析成功但跳过目标更新；同SQL的普通UPDATE正对照确实将值从1改为2，并在本例事务内显式回滚。依据是[8.0.46官方实现](https://github.com/mysql/mysql-server/blob/mysql-8.0.46/sql/sql_update.cc)和[8.4.11官方实现](https://github.com/mysql/mysql-server/blob/mysql-8.4.11/sql/sql_update.cc)中对分析阶段更新迭代器的处理，不能套用MariaDB真正更新的语义，也不能把计划返回当成写入或提交回执。函数、锁及其他副作用仍需保留确认边界，不外推所有版本或语句形状。
- 树、节点详情和原始输出区分“实测指标”和“估算指标”。所有数值保留原始十进制/科学计数文本，不转JavaScript浮点数，不将成本解释为毫秒。
- MySQL首行、末行时间及行数在多轮时为每循环平均值，迭代器时间包含子迭代器；MariaDB `r_total_time_ms` 累计包含子节点。节点时间不能直接相加。

语义依据为 [MySQL EXPLAIN 官方文档](https://dev.mysql.com/doc/refman/8.4/en/explain.html)和 [MariaDB ANALYZE FORMAT=JSON 官方文档](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/analyze-and-explain-statements/analyze-format-json)。这是 DBArk 自主实现，不是本机 Navicat 17.0.8 的动态或反编译实证。

## 确认与资源保护

确认绑定原Monaco模型、版本、选区、草稿来源、连接对象及修订、活动标签和固定会话。编辑后撤销、切走后切回等ABA变化不能复活确认。发送前持久化未知恢复上下文仅允许本次单向推进一次；Engine再核真实默认库与确认值，未知或切库即拒绝。

准备阶段的独立 `query.analyzeContext` 仅接受原会话和任务编号，固定执行 `SELECT DATABASE() AS __dbark_analyze_database`，最多一行、一个结果及4096字节。它明确读取错误之后仍然存在的真实默认库，不能夹带用户SQL，也不通过重连或旧标签配置猜测目标；普通 `query.completionState` 继续只读缓存。诊断读取会更新会话查询诊断信息，不提交事务、不修改服务器数据或切换默认库。修正错误语句后必须重新打开并确认新的分析。

任务沿用既有会话互斥、流式结果、编号、取消和原控制连接收尾。执行历史只在驱动收到实际命令后记录完整ANALYZE前缀及冻结语句；发送前拒绝不会留下可误执行的裸DML。原估算计划继续使用独立 `query.explain`，不能通过格式参数请求实际执行。

原文最多192KiB、节点最多300个、层级最多64层，指标逐项有界。驱动或字节预算截断时保留有界原文和警告，禁止从局部前缀生成伪完整树。TREE未知行、JSON未知属性不推测执行顺序。原估算计划的专用快照文件格式、全部平台和安装验收不因本增量自动扩展为已完成。
