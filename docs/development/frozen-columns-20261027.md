# 表格与查询结果冻结列

## 使用与布局语义

在表页“表列偏好”或查询“管理结果列”中，选择“冻结到此列”，可冻结当前可见顺序从第一列到指定列的前缀；“取消冻结”解除数据列冻结。勾选列保留原行为。冻结不重排行、列或更改字段原值，复制和导出继续使用原显示顺序。

冻结边界按真实身份保存：表使用精确列名，SQL 结果使用内部唯一键，重复显示别名不混淆。移动列会按新顺序重算范围；隐藏边界解除冻结，重新显示不会自动恢复旧边界。表元数据删除或歧义变化后安全解除，唯一大小写变更沿原调和规则迁移。非法网格前缀整组关闭，不能让网格自行将非前缀冻结列重排。

表布局立即应用，仍需明确保存才写入本机 SQLite；保存失败保留未保存提示，恢复默认清除冻结。查询结果沿原临时布局寿命，切换准确结果或固定快照后重置；当前固定快照也可独立管理。结果暂存和命名整理方案携带冻结边界，旧方案没有该字段时应用会清除当前冻结。筛选／排序历史保持当前列布局，冻结范围通过列管理调整。

## 实现边界

表偏好、查询列布局及结果方案新增可选 `frozenThrough`，缺省时省略，旧内容可继续读取。沿用原 JSON 持久化和预算，无 SQLite schema 升级。边界必须属于当前可见的准确身份；IPC 严格校验，访问器不会作为合法边界执行。

渲染使用已有 React Data Grid 的冻结前缀，选择列位置不变。仅修改冻结时复用相同可见列对象，保留客户端筛选、排序与行数据；旧网格操作仍因范围换代或模态结束而失效。不新增数据库命令，不把 SQL、行数据、像素坐标或凭据写入布局。
