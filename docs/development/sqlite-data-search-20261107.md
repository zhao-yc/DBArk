# SQLite 全库数据搜索和只读记录定位

从「工具 → 全库搜索」选择 SQLite 文件连接，再点「搜索数据」。在 `main` 中读取对象和字段，勾选范围后开始搜索。普通表和明确允许的视图可搜索，虚拟表、影子表、临时对象和附加库不在目录中。

- 支持包含、完整值、前缀、本地 Unicode 正则及 NULL。普通文字忽略大小写时折叠 ASCII。TEXT 使用库编码无损解码，包括内嵌 NUL。实际 BLOB 始终按大写 HEX 匹配，其他类型选择 HEX 时使用 SQLite 转换得到的原库字节。NULL 与空字符串分别处理。
- 匹配完整值，每处只回传最多 128 字符的预览和完整表示长度。文字条件下，单个原值超过 2 MiB 会报告该字段块失败。每块最多 16 个字段，每批最多 50 处命中或 128 KiB。单轮最多 1,000 处命中或 32 MiB。
- 每个字段块使用专用物理只读会话。窗口确认后才继续消费下一批；取消会等待原会话释放。正则连续 5 秒未收到原生结果批次时停止本次读取，超时计为失败。
- 可定位的表命中使用原生 rowid 或可靠的唯一键。打开前核对文件身份、目录和完整原行摘要，包括未选字段。详情按 SQLite 实际存储类型显示所选字段和键，并聚焦命中字段。视图及无法证明行身份的命中只提供预览。定位引用在内存中最多保留 5 分钟。
