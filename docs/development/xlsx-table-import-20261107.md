# XLSX 工作簿导入

SQLite 和 PostgreSQL 可在可写表的导入窗口选择「Excel（XLSX）」。MySQL、MariaDB、PostgreSQL 和 SQLite 的「从文件导入新表」也可选用该格式。

1. 选择 `.xlsx` 工作簿，等待工作表目录出现，选定要导入的一张工作表。
2. 填写标题所在行，范围为 1 至 1000。标题应非空且唯一，标题之后的数据按列映射。
3. 第三方文件使用「普通工作簿」。由 tabrelio 导出的 XLSX 可选「tabrelio 可逆文本」，以解释 NULL、二进制和前导反斜线。普通工作簿中的空白格按 NULL 处理，显式空文本保留为空字符串。
4. 完整扫描后核对样本和映射。新表流程先确认正式表设计和建表，再确认写入。建表和数据导入分开提交，导入失败后已建的表仍保留。

导入读取工作簿里已经保存的数值文本。Excel 保存前舍入的位数无法恢复。日期样式仍按原数字序列读取，需要日期值时请先将源单元格整理成明确的日期时间文本。所选工作表包含公式或合并单元格时，先粘贴为值或取消合并。

SQLite 使用既有预检、类型映射和整批追加。PostgreSQL 可追加，也可在现有表上按可靠匹配键处理。MySQL 和 MariaDB 的新表写入走 InnoDB 整文件事务。完成扫描后，工作簿字节指纹和选定的工作表设置会用于后续核验，文件变化会阻止提交。

工作表与标题行选项参考 [Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)。
