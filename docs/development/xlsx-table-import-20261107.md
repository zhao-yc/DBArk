# XLSX 工作簿导入

MySQL、MariaDB、PostgreSQL 和 SQLite 均可将 XLSX 导入现有表或从工作簿新建表。

1. 选择 `.xlsx` 工作簿，等待工作表目录出现，选定要导入的一张工作表。
2. 填写标题所在行。标题应非空且唯一。无标题时填 0，按「第1列」「第2列」等列位置映射。首条和最后数据所在行包含首末两端，留空时从标题下一行读到工作表末尾，无标题时默认从第 1 行开始。填写首末行可跳过说明和汇总。
3. 第三方文件使用「普通工作簿」。由 tabrelio 导出的 XLSX 可选「tabrelio 可逆文本」，以解释 NULL、二进制和前导反斜线。普通工作簿中的空白格按 NULL 处理，显式空文本保留为空字符串。
4. 完整扫描后核对样本和映射。新表流程先确认正式表设计和建表，再确认写入。建表和数据导入分开提交，导入失败后已建的表仍保留。

导入读取工作簿里已经保存的数值文本。Excel 保存前舍入的位数无法恢复。日期样式仍按原数字序列读取，需要日期值时请先将源单元格整理成明确的日期时间文本。标题行或所选范围包含公式或与合并单元格相交时，先粘贴为值或取消合并。行号使用工作表的实际行号，缺失的行不会补成空白记录。无标题模式根据所选范围的最宽列确定字段数，稀疏单元格按原列位置补 NULL。

SQLite 使用既有预检、类型映射和整批追加。PostgreSQL 可追加，也可在现有表上按可靠匹配键处理。MySQL 和 MariaDB 的新表写入走 InnoDB 整文件事务。完成扫描后，工作簿字节指纹和选定的工作表设置会用于后续核验，文件变化会阻止提交。

工作表、标题行和首末数据行选项参考官方手册。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)
