# PostgreSQL 查询结果导出

运行查询后，在结果区选择要保存的结果集。点击「导出已返回结果」保存该结果集的已返回行，或勾选所需行再点击「导出勾选结果行」。选好 CSV、JSON 或 Excel 格式及保存位置后开始导出。勾选行按原显示顺序写入，切换结果集会清除旧勾选。

- 导出窗口冻结打开时的行和列。结果已截断时，窗口标明文件范围。仅使用已返回的结果快照，打开的查询事务及数据库会话继续按原状态工作。
- 重复或空列名按列位置分配唯一导出标题。PostgreSQL 大整数和精确小数沿用返回的字符串；JSON 保存二进制对象，CSV 保存 Base64 文本，Excel 用文本保持精度并沿用 DBArk 标记协议。
- 导出沿用结果文件的预算与原子替换。单个字段的导出预算为 256 KiB，完整快照的导出预算为 32 MiB，Excel 另受单元格字符数限制。需要重新获取服务器上的更多行时，在查询页调整查询范围。表页也可[导出全部筛选记录](postgres-table-export-20261105.md)。

## 验证

- macOS 类型检查和源码构建通过。完整单元回归覆盖 1,326 个测试文件，27,428 项通过，10 项 Windows 系统 `tar` 用例按平台跳过。
- Server-200 独占 PostgreSQL 18 实库回归 5 项通过。macOS Electron 源码窗口 1 项通过，覆盖 23 个观察点。原生保存对话框使用测试桩提供专用路径，主进程和数据库进程写出实际文件。
- 窗口复核切换结果集清除旧勾选、逆序勾选按显示顺序写入 JSON、全部已返回行写入分号 CSV 和 Excel。独立回读验证同名列、大整数、NULL、空字符串和 BYTEA。导出前后的执行历史相同，原事务保持打开，序列仍停在原查询执行后的值，随后正常回滚。
- 首轮窗口测试发现第三行复选框受底部状态栏遮挡。调整编辑器和结果区高度后，同一真实点击验收通过。首轮日志与隔离库保留，成功轮次的临时配置、专用数据库和容器已清理。
- WIN11-TEST 会话不可达，本轮按约定在 macOS 验证。Windows 原生窗口和安装包待验收。
