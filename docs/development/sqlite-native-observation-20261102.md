# SQLite 原生验收观察端口回传

## 变化

只读表页原生整例在每个界面动作前后调用完整 `audit()`，虽然调用方丢弃结果，仍需跨 Electron 传输累计的分页、候选和请求历史。历史随步骤增长，两种 Mac 原阶段时间也分散在多个操作阶段。

界面边界现通过 `guard()` 执行同一个 Main `state.check()`，不读取或返回历史；本地 owner、profile、120 秒、单 worker、零重试检查及原事前／事后检查次数保持。显式业务断言与最终附件仍调用完整 `audit()`，包含原请求、回包、拒绝、worker 和目标信息。原 restore 出口的显式事后跳过条件保持，没有静默重试或重建观察器。

两种端口记录调用次数与耗时，各阶段输出累计计数，最终存入独立附件。计时不参与授权、通过条件或延长期限。本轮只改验收脚本，不改产品、数据库执行、IPC、写入、配置或凭据。
