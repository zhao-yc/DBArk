# 保存查询跨页批量删除

## 操作

打开“历史查询”并切换到保存查询列表，勾选记录；选择会跨页保留，最多100条。点击“删除所选查询”，核对完整清单中的名称和编号，包括当前页看不到的选择，再点击明确的确认按钮。不同编号即使同名也分别列出。

预览默认聚焦取消。Escape只取消本轮预览，保留父列表和选择；Enter没有默认删除快捷入口。忙碌时不能重复确认或取消，关闭列表会等待原请求终结并释放游标。

删除仅影响本机保存查询及相应分组成员关系，不删除组定义、磁盘SQL文件或已打开的草稿，不执行数据库SQL。原来源删除后，已打开草稿的覆盖保存会被拒绝，可另存为新查询。

## 一致性

- `queries.deleteSelectedChecked`仅接收1至100个不同的`id`和完整原记录SHA-256，不接收正文、连接或文件路径。
- 同一个SQLite事务内，先核对全部原记录的存在性、摘要和结构，再开始删除。任一条过期、缺失或损坏，整批不删除。
- 每条删除核对影响行数；本地原子发布失败时恢复内存、磁盘和修订，不保留部分删除。成功只推进一次修订，使旧搜索／分页及组织版本失效。
- 原文累计上限128MiB，一次只处理一条原文，超出预算在首条删除前拒绝。未用实际128MiB样本验收预算边界。
- 成功后清除本轮选择并刷新当前范围第一页。已删除但刷新失败会明确提示已保存；错误或数量不符的回执要求手动刷新核对，不冒称成功或未删，也不自动重放。
