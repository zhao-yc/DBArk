# 表页及本页勾选快照导出

## 用户流程

表页新增“导出当前页”和“导出本页勾选记录”。打开时按当前页显示顺序、可见列及列顺序冻结独立快照，再进入既有文件窗口；可预览、选CSV／JSON／INSERT SQL及编码、选择文件、查看进度或取消。其它页不包含在内，全表导出保留原入口。空勾选不回退全页；成功打开后清空原勾选，下一次需重新勾选。

不重新查询数据库，不包含未提交数据或隐藏列；文件窗口与原页后续变化分离。NULL、空串、二进制包装及精确字符串保留；SQL文件沿原显式目标、映射、预览确认和原子文件任务，不执行SQL。列偏好尚未加载、活动输入、数据脏稿、忙任务或过期结构时禁用。点击时同步重核原标签／连接修订／勾选／提交渲染及原始页值；未知勾选、错配行、访问器或超预算拒绝，不截断或自动扩大范围。

快照复用现有32MiB、100000行、1024列、2000000单元格及字段／行预算。当前页全字段身份检查也受行列预算；隐藏字段不克隆到文件或计入输出字段预算。表页即使hasMore，也不冒充被截断的查询结果；文件窗口明确说明本页范围。
