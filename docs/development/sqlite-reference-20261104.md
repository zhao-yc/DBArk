# SQLite外键父记录只读浏览

日期：2026-11-04。基线main `5489980a`。本批补齐D05／R02高频关联浏览的一项实际缺口，保持Electron／React／TypeScript独立客户端，不创建发行、安装包或部署。完整Navicat对标目标和完整D05仍未完成。

## 使用

在SQLite的main物理表选择当前行，进入“更多 → 显示 → 浏览SQLite父记录”。只读源页从准确选中行取值，可编辑源页从当前行已暂存的本地草稿取值；尚未暂存的表单输入须先明确暂存或取消。打开窗口不读取数据库，先点“读取当前表外键”，再选外键声明并点“读取父记录”。选择声明也不自动查父记录。

窗口显示原声明列、父表及显式父列或隐式主键说明。省略父列时按父表声明主键序号解析，不猜rowid；复合元组保留原顺序，父表名称只按SQLite的ASCII折叠解析真实目录。匹配由父字段原亲和性和collation决定，例如TEXT子值001可以匹配INTEGER父值1，NOCASE父文本也按其原规则匹配。BLOB保留字节，NULL／部分NULL不建立关联，缺父表、缺父列或隐式主键数量不符明确失败。

结果只读，默认每页50行，提供上一页／下一页。各次读取均是独立快照，OFFSET不保证跨页稳定；普通数据变化可能造成重复或遗漏。首次父页捕获父结构指纹，后续页遇到结构变化拒绝混用。没有额外COUNT、写表、暂存、提交或自动打开新标签，也不借用用户查询事务。

本功能按声明浏览，不验证外键约束是否可执行、父键是否满足唯一性或整库参照完整性；声明非唯一时可能返回多行。FK字段省略／DEFAULT、超出原typed值预算或不支持的原值会拒绝查找，无关的大BLOB不会阻止其它外键字段。视图、TEMP、ATTACH和跨库引用不在本批范围。当前没有“选父记录写回外键”、子记录反向浏览或多层关联树。

## 实现与生命周期

新增受限 `sqlite.referencePage` 命令和严格catalog／page合同，不能夹带路径、SQL、库名切换或超限分页。Main完整复核当前已保存SQLite连接，绑定准确窗口及连接配置修订，配置保存／目标变化后迟到结果不发布。任务概要使用固定中文消息，关联值、父记录和错误正文不写入本地任务记录。

新读取复用原SQLite Runtime只读资源账本，每个catalog／page任务使用独立只读worker，最多两个未退休任务；BEGIN固定目录和父记录同一快照，ROLLBACK及准确driver／资源退出确认后才发布。复用现有完整物理表目录读取，原关系图继续走原完整校验。父SELECT仅由真实目录及外键声明编译，标识符逐个引用，元组和分页均位置绑定；父列比较没有套用普通typed筛选的typeof限制。TEXT沿原精确字节投影，64位整数、BLOB及实际存储类型逐项校验。

源行捕获原页／列／结构、原行和原值。可写源页保留草稿、撤销栈与原编辑快照；只读源页不从格式化显示猜类型。父窗口自己的活动租约不会撤销来源，外来任务、连接／标签／源值／结构变化留下永久失效标记。原行的大字符串只按原值比较，不在每次store通知时复制BLOB的JSON。

窗口与reader串行占位；旧按钮、旧选择及关闭回调绑定提交后的准确渲染。未发送前停止不取消不存在的任务；已发送任务只取消准确taskId，原读取与取消ACK都终态前不提前归还父标签busy。关闭、卸载或来源失效不会把旧回包交给新窗口。失败／取消原件和资源状态分开，未确认exit仍沿原账本阻断后继读取。
