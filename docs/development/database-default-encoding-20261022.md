# 数据库默认字符集与排序规则（2026-10-22）

## 实际入口

连接展开后，数据库行提供“数据库默认编码”。窗口读取该库当前默认值及服务器实际编码目录；选择新配对后先预览固定 `ALTER DATABASE` SQL，输入完整数据库名并勾选三项确认后才执行。没有变化不能生成预览，修改选择必须重新预览和确认。

这里只改变数据库默认值。以后未明确指定编码的新表继承新默认值，已有表、字段、数据和已有例程不转换；DDL使用独立短会话，不提交其它查询标签的事务。现有表页未提交草稿保留，同库表页仍有活动操作时须等待原操作完成。

MySQL和MariaDB提供这一操作的官方语义，见 [MySQL ALTER DATABASE](https://dev.mysql.com/doc/refman/8.4/en/alter-database.html) 和 [MariaDB ALTER DATABASE](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-database)。本功能是DBArk自主实现，没有新增第三方逆向结论。

## 执行与保真

- 同一短会话交叉核对完整 `SHOW CREATE DATABASE`、`SCHEMATA` 当前值、实际编码目录、服务器身份和会话模式。只引用精确库名及目录中存在的配对，不接收任意SQL。
- MySQL 5.7.44／8.0.46／8.4.11和MariaDB 10.11.19／11.4.13是当前能力基线；未知版本不开放修改。系统库、非法名称、不完整或无法解释的定义拒绝修改。
- 读取、预览、执行均有独立编号和进度；两分钟期限、连接修订和实际快照共同约束。预览前及执行前重新核对原值、定义和目录，已知变化时在DDL发送前拒绝。
- 发送时同步消费原快照和全部派生预览。取消、断线或未知结果都不自动重放；成功响应与后验完整性分开报告，读回不符时保留实际观察值并提示核对。
- 原生窗口和文档代际约束Main能力，拒绝跨窗口、重复ID覆盖、迟到响应及旧修订复用；过期能力不能执行，仍可由原文档精确释放。Main总能力和引擎执行锁均有上限。
- 操作与物理资源全部结算后才解锁；未知资源保留隔离。仅在显式断开、原任务结束且实际资源恢复确认后，才解除该连接的隔离并撤销旧令牌；新的修改须重新读取、预览和确认。

数据库没有可供本功能使用的稳定对象编号。前后复核不能完全识别外部删除重建或同值ABA，也不能消除最后核对到发送之间的并发窗口；界面要求确认维护窗口，并不声称原子比较交换或完整模式同步。
