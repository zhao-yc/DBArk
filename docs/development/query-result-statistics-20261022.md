# 查询结果列统计（2026-10-22）

## 行为与边界

查询结果网格提供“列统计”。默认使用当前活动列；没有活动格时使用第一可见列，空结果也能显示零计数。有已接纳勾选时，默认统计打开时的勾选快照；窗口内可切换可见列及“当前结果全部行／当前结果勾选行”。全部行指已经返回且当前筛选后的行，不重新执行 SQL，不扩大结果上限，不代表数据库全表。截断结果另行提示。

提供行数、非 NULL、NULL、非 NULL 不同值、最小值、最大值；数值类型另有合计与平均值。空字符串和文字 NULL 均不是 NULL。不同值与极值沿用结果比较键：文本按 UTF-16、区分大小写，不声称数据库排序规则；日期时间按原字段比较，不转换时区。字节和未知类型只给计数；不符合声明类型的原值使整份值指标不可用，不保留部分合计或极值。

BIGINT／DECIMAL 使用 BigInt 系数与尺度，保留原最大小数位；有限平均值必要时精确扩展，如 `0.00000000000000000001 / 2 = 0.000000000000000000005`。循环平均值取原尺度与 18 位的较大者，恰好一半向远离零舍入并提示；浮点列说明驱动返回值已经近似，不能恢复原精度。极值保留原返回文字。

## 生命周期与资源

原列对象、唯一键、完整元数据、原行及值和已接纳选择参与捕获；读取自有数据描述符，不执行输入 getter。切换标签／连接／结果、忙态或外来模态撤销所属窗口，旧按钮和迟到定时器不能操作下一窗口。统计不写 IPC、数据库、文件或系统剪贴板，不修改原筛选、排序及整理历史。

上限为 100000 行、1024 列、单值 4096 字符、累计 8 Mi 原文单元；超过时整份拒绝。每批至多 512 行或 32 Ki 原文，期间让出线程，完成后再次完整核源才发布指标；取消／卸载清除定时器、部分不同值与聚合引用。
