# 已返回查询结果的勾选行导出

查询结果工具栏新增“导出勾选行”。CSV、JSON沿用现有文件任务，范围仅包含当前已返回结果中勾选的行，按显示顺序导出；打开对话框时克隆快照，不重新执行SQL。原全结果导出入口保留。原结果被截断时仍显示提示，所选行不代表完整查询数据。

选择绑定准确的结果对象、行列数组和显示代次。新执行、切换结果或固定快照、连接修订、关闭标签后，旧回调不能借新结果导出。空选择不能回退全量；重复列名仍按唯一内部键读取，BIGINT、DECIMAL字符串、NULL和二进制包装保持原值。快照沿用现有行、列、单元格和32MiB总预算。

网格现在等待父组件返回明确的接纳回执再更新勾选，并在回执后重核显示代次。父级拒绝、回执未知或旧代次回调均不改变勾选。没有导出父回调的既有网格继续使用原本地选择。

Root先加入真实网格与生产快照类的回归，修复前1通过、1失败；原报告SHA256为`693be3ad0cf2ee548ea42c799a6a3f004c7447cb09e50652efb5315fa1d7631c`。修复后网格及实际QueryTab处理器端口共13项通过、0跳过，报告SHA256为`39dbc61c374a7ae93f9da27f1fe84e9a004b172a4754e448ad588bf7857a1270`。这两组均为内存测试，不是原生界面或数据库验收。
