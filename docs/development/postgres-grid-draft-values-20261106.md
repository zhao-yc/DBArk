# PostgreSQL 网格草稿值

暂存编辑后，带左侧标记的原格会直接显示待提交的文本、SQL NULL 或二进制值。待应用 DEFAULT 有单独的提示，待删除行划线显示。新增记录在下方草稿列表核对。翻页返回、撤销、重做和从文件恢复时，网格按主键找到当前页对应的原记录。

在网格复制单格或勾选行时使用当前显示状态的完整值。二进制可在查看器查看，应用内粘贴保留字节类型。包含待应用 DEFAULT 的选择会提示等待数据库生成实际值。待删除行仍显示原值。

网格定位、筛选来源和 SQL 预览使用原页能力。提交时仍由引擎核对原行与表结构，再在事务内执行。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时、严格类型检查和构建通过。28 项定向单元覆盖草稿显示、精确值、NULL、剪贴板编码和原查询结果着色。
- 完整单元回归覆盖 1,340 个文件，27,517 项通过，10 项 Windows 专用测试按平台跳过。
- Electron 窗口专项通过 20 项检查。原格显示暂存文本、字节和 DEFAULT，读取暂存 Hex，复制事件返回准确文本和字节。DEFAULT 复制提示已核对，测试数据保留在事件缓冲。待删除行划线，撤销后标记消失，独立查库确认没有提前删除。
- Server-200 隔离 PostgreSQL 18 的 5 项实库回归通过。原生窗口正常退出，临时配置已清理，两轮通过的隔离库均在复核零连接后清理。
- 首轮窗口测试中复制提示遮住了后续按钮，补充核对并关闭提示后通过。失败原件保留，所属 Electron 退出后核对零连接并清理专用库。首轮全量单测的结果网格渲染夹具缺少新增可选参数，补齐后沿原断言复验。
- WIN11-TEST 不可达，本轮使用 macOS。Windows 和安装包待验。
