## 使用与边界

MySQL／MariaDB、SQLite 可编辑查询中，在表别名、派生别名、CTE 声明或已确认的引用上按 `F2`，输入新名称后按 Enter。原编辑器一次修改声明及全部确认引用；Ctrl／Cmd+Z 一次撤销整组，支持重做。只修改当前查询草稿，不保存或执行 SQL。

```sql
SELECT s.id, s.name FROM subject AS s WHERE s.id = 1;
WITH q(n) AS (SELECT 1) SELECT q.n FROM q;
```

例如将第一条的 `s` 改为 `new_alias`，四处名称一起变为引用标识符；字符串和注释保持。SQLite 保留 ASCII 大小写等价、双引号／反引号／方括号及非 BMP 名称；MySQL 使用原会话模式和现有 BMP 名称规则。别名预算 256／512 UTF16，MySQL CTE 新名称最多 64 UTF16。

仅修改当前语句的局部声明，不重命名物理表／视图／字段／变量或数据库对象，不生成 DDL。当前语句存在其它作用域的同名词、未确认同名引用、名称捕获或歧义时，整份拒绝并显示原因；不会只替换已找到的部分。新名称与语句中已有标识符冲突也拒绝，可能保守拒绝互不相关的同名词。完整作用域重构及跨文件／全库重命名仍待开发，O05 保持部分。

## 实现与保护

- 复用原声明解析器和本文引用索引，以准确原声明范围为身份；内部类型证明只区分别名、CTE、物理来源，不改变原声明回包。
- 同语句完整同名词必须全部属于本声明，超出 256 候选或不确定则无编辑。新名称始终作为单个引用标识符转义，拒绝控制符、孤立代理及超长输入。
- MySQL 复用补全编译产物、SQLite 复用本地引用编译产物，每次准备／提交仍独占物理 Worker。保持启动 8 秒／分析 2 秒；握手前不发送正文，取消、替换、超时、失效及卸载终止准确线程。
- MySQL 仅前后读取既有会话模式缓存并核代次；SQLite 不读会话／目录。没有新 IPC、数据库请求、凭据或写入协议。
- F2 准备与实际编辑均核原模型、版本、光标词、连接上下文、取消及模态；workspace 编辑只携原模型 URI 和原版本。旧请求不能清除继任保护或覆盖提示。
- 使用原 Monaco F2 和撤销栈，不用全文 `setValue`。引用分析租约阻止迟到补全，拒绝原因在原编辑器显示可关闭的中文状态提示；提示不抢焦点，Escape 或正文／目标变化清除。
