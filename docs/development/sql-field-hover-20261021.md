# SQL字段悬停信息

## 使用入口

在可编辑SQL工作区将鼠标停留在字段标识符上，查看字段来源、完整类型、NULL、默认值目录文本、属性及备注。信息只读，不替换SQL、选择文本或执行正文。默认值为NULL时明确保留“无显式默认值或默认NULL”的目录歧义，不把文字表达式解释成可执行SQL。

复用现有词法／AST作用域，支持表别名、跨库、完整引用名及单来源星号转发。未限定同名字段显示候选来源；计算投影／输出别名只说明来源和类型待确认，不借用基础列类型。字符串、注释、函数名、限定段、AS声明及未闭合名称不读取目录；未知默认库不套用连接配置库。

临时表先走原物理会话目录，未知或不完整时不回退同名永久表。完整属性只来自用户在“会话临时对象”的显式结构读取；仅声明缓存时显示基础类型和未确认说明。ALTER撤销旧完整属性，缓存预算满时先丢可选属性，保留原字段补全。

## 边界

语义解析在原本地Worker执行，用户SQL不进入元数据IPC。键盘补全优先，模型、正文版本、连接修订、默认库、会话模式及对象代次变化后不交付迟到信息；取消沿原任务通道等待真实收尾。悬停目录使用`details:true`，与普通补全缓存隔离；永久字段固定参数精确读取，最多两行识别歧义，不取DDL或行数据。

完整属性上限：类型4096、默认值4096、属性1024、备注2048个UTF-16单位；文本多取一字符检测截断，无法确认时不展示截断定义。最多8个作用域来源，继续使用原4MiB短缓存和本地解析预算。字段内容以缩进代码块显示，明确关闭HTML及受信命令；备注不能变成图片、链接或动作。
