# PostgreSQL 实际执行分析

查询标签的「实际执行分析」打开确认框，显示原连接、数据库和冻结的单条 SQL。选中时使用选区，未选中时使用光标所在语句。核对后勾选确认才能运行。取消关闭确认并撤销本次令牌。

- 确认后在原物理会话发送一次 `EXPLAIN (ANALYZE TRUE, VERBOSE TRUE, BUFFERS TRUE, FORMAT JSON)`。原事务、临时表和搜索路径继续生效。该命令会执行底层语句，写入和其他副作用遵守 PostgreSQL 原会话规则。[PostgreSQL EXPLAIN](https://www.postgresql.org/docs/18/sql-explain.html)
- 同会话启动其他操作、切换标签、编辑正文、重连或超时后，原确认失效。开始后的停止沿用原查询取消链，服务器确认的成功回包与取消请求分别处理。
- 分析树区分实测行数、时间、循环次数、缓冲块、估算行数和成本。节点时间及行数按每循环平均显示，根节点另列整条语句的执行时间。原始 JSON 可单独查看。
- 执行历史保存实际发送的分析命令。打开或取消确认、切换树和原文均保持执行历史。

带位置占位符的直接绑定、实际计划快照和比较仍在后续范围。可分析已经准备好的 `EXECUTE` 语句。

## 验证

- Mac 类型检查、源码构建和 262 项定向单元通过。覆盖单条 SQL、确认契约、计划数值精度及已有 MySQL／MariaDB 分析流程。
- Mac 完整单元回归覆盖 1,318 个测试文件，27,402 项通过，10 项 Windows 系统 tar 检查按平台跳过。
- Server-200 的 PostgreSQL 18 独占实库回归 5 项通过。确认前原行保持，取消、同会话后续操作及已消费令牌均无法执行旧确认。实际写入可在原事务内读取并回滚，运行中的分析可取消。成功容器复核原值和零连接后清理。
- Mac 原生 Electron 窗口整例通过。真实点击核对冻结 SQL、勾选前禁用、取消不写历史、确认后只写入一次、指标分组、原始 JSON 和回滚。单 worker、120 秒、零重试、trace 关闭，窗口退出及临时配置目录清理已核对。
- WIN11-TEST 会话不可达，本轮未派发，按约定在 Mac 验证。Windows 原生窗口和安装包尚待验收。
