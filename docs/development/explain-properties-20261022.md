## 边界与正确性

- 计划保持原 192 KiB、64 层、16000 解析项及 300 节点预算，原包含关系／数组顺序和精确数值不变。
- 属性使用预算检查后的原类型树，避免数值保精度处理把 `1` 误当字符串条件或字符串列表。
- 本轮提取 15 个明确字段，每项最多 2048 个 UTF-16 单位，列表最多 32 项；逐项有限编码，截断明确提示，原文保留。
- 查找最多 200 个 UTF-16 单位，只匹配节点及属性展示内容，不搜索未生成节点或属性被截掉的后文。超长程序赋值整次拒绝，保留原关键字与选择，不静默改写查找词。
- 结果或计划对象换代会重建交互 owner；A→B→A 也不能复活旧查找、收起状态或文本请求闭包。保存当前查询等保持同一计划对象的操作继续保留视图状态。
- 成本与行数均为优化器估算；节点连接表示 JSON 包含关系，不表示测量出的执行时序。排序／临时表标志不直接等于性能故障。
