## 修复

新增固定入口：

```sh
node scripts/foreign-key-join-ci.mjs
```

运行器只启动一次原 Playwright spec，子进程删除模块注入、数据库／SSH 认证、用户资料路径和 Playwright 重定向变量，再设置固定离线门及报告路径。父环境保持；日志只记录被移除的字段名。入口不接受参数、其它测试文件、可执行程序、目标库或超时覆盖。

保留原十二例、每例 120 秒、worker1、retry0、trace off、取消保护、失败目录保留及正常退出流程。启动失败、信号或未知终态不当作通过，不自动重试。原 spec 的环境守卫与业务断言没有修改。

三平台工作流改用该入口，并为运行器文件增加路径触发。对应单元直接计算原 spec 的守卫表达式，覆盖大小写、模块注入、认证清洗、父对象保留、固定命令、退出码及未知终态。
