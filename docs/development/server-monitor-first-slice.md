# S02 服务器监控首阶段

本阶段提供 MySQL/MariaDB 的只读服务器概要、固定白名单全局状态和会话列表快照，支持手动及每 5 秒受控刷新。各项顺序读取，属于非原子快照；累计计数保留精确字符串，不计算速率。页面隐藏或窗口关闭时取消当前读取，并等待真实任务收尾；手动、自动和重新打开不会重叠轮询。

会话默认最多 50 条，允许上限 100 条；SQL 在服务器端截取前 512 个字符，同时返回真实字符数和截断标记。字段长度、返回条数和序列化快照总字节均受限，快照最多 512 KiB。NULL 与空字符串分别保留。会话列表始终标注“当前账号可见范围，完整性未确认”，不根据少数返回行推断 PROCESS 权限；权限或版本缺项逐项显示不可用，不使用高权限补查。

引擎入口为 `readServerMonitor(context, input)`，由调用方提供独立短连接及真实命令取消边界，不复用用户查询会话。独立 `ServerMonitorDialog` 注入稳定引用的 `services.read(input)` 和 `services.cancel(taskId)`；外层隐藏标签页时应设置 `open=false` 或卸载组件。正式接线还须保证自动刷新不会挤占持久化任务历史，SQL 明文和错误原文仅保留在当前窗口。

验证结果：15 项专属单元测试和专属 TypeScript 检查通过；200 开发服务器的六个授权隔离实例上，内核真实读取矩阵 12/12 通过，零失败、零跳过，覆盖 MySQL 5.7、8.0、8.4，MariaDB 10.11、11.4，以及 MySQL 8.4 严格 TLS。每个实例均验证固定状态与会话读取、长 SQL 的服务器端投影。该结果仅代表内核读取矩阵，正式 IPC/App 接线、原生 UI 和安装仍未验收，不能替代完整生命周期验收。

当前尚无正式 IPC 命令或 App 入口，尚未完成原生 UI、完整回归、实际安装及发布验收。结束会话、执行任意查询、修改服务器变量均不在本阶段范围；性能图、日志和高级管理等仍属 S02 后续工作，本阶段交付不代表完整 S02 已完成。
