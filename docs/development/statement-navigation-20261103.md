# 查询脚本语句导航

## 使用

查询页“更多 → 脚本导航 → 语句导航”、编辑器右键及原生“工具 → 查询执行与分析”可打开当前脚本目录，支持 MySQL、MariaDB 和 SQLite。目录在编辑器右侧，共享原分栏高度，不修改高度偏好。每页10条，按完整语句正文搜索；点击条目跳转，点击“选中正文”选择原模型中的准确范围。普通前导注释不占预览空间，原文和位置保持。

导航不会执行、格式化或保存 SQL，也不创建连接、会话或事务。选择正文不包含客户端分隔符；执行复杂例程时仍应使用原脚本的“执行当前语句”，保留 DELIMITER 上下文。导航不是语法检查，语句出现在目录不代表服务器一定接受。

编辑正文、切换标签、替换模型、会话或连接变化、模态阻挡及开始其它操作，会使原目录失效。撤销正文也不恢复旧目录，须明确刷新。语句导航和本地语法检查互斥显示，取消只终止本轮导航线程。

## 分段与资源

- 将原 MySQL 流式扫描器及 SQLite 位置扫描器的纯逻辑提取到 shared；引擎原导出路径、类身份、原20MiB检查及当前语句的1000条限制保持。浏览器不加载引擎、Buffer、ANTLR或数据库驱动。
- MySQL／MariaDB 沿原字符串、注释、DELIMITER及当前模式解释；SQLite 沿原触发器 BEGIN／END、CASE及引号规则。仅有原会话时只读前后模式缓存，无会话零IPC。未知模式需原扫描器的全部解释一致。
- 只按当前模式快照分段，不预测前面 SET／CALL 对后续执行环境的影响。目录不验证对象、权限或服务器语法。
- 最多262144个UTF-16单位、1000条语句，预览最多160个代码点；超限或无法可靠分段时整份拒绝。搜索完整正文，不限于预览。
- 独占 Worker 启动8秒、分析2秒，取消、替换、卸载准确终止本轮线程；回包仅固定状态及原文数值范围，不传SQL片段、原始错误或可执行内容。拒绝额外字段、访问器、乱序／重叠及切开代理对或CRLF的边界。
