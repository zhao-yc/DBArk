# D07 二进制实库验收入口

新增 `tests/e2e/binary-cell-live.spec.ts`，只增加测试与本说明，不修改产品代码、既有预算、公共 helper 或全局超时。复用真实桌面夹具、连接表单和随机隔离库清理流程。

默认未设置 `DBARK_INTEGRATION_ENABLED=1` 时，四项测试在自动桌面夹具启动之前跳过。实库 helper 仅由启用的测试体动态加载；默认不会读取其凭据文件，也不会创建应用、连接或数据库。启用后还必须显式注入 `DBARK_TEST_HOST=192.168.31.200`、合法 `DBARK_TEST_PORT`、`DBARK_TEST_USER` 和 `DBARK_TEST_PASSWORD`，缺一就拒绝运行，不回退业务库配置。

每个用例使用独立 `dbark_e2e_*` 随机数据库与 InnoDB 表，包含接近无符号 BIGINT 上限的精确主键、BLOB、VARBINARY、BIT、NULL、零字节 BLOB、精确 DECIMAL，以及由本地 Canvas 生成的 2×3 PNG。旁观连接只建本例夹具、读取断言、制造第二行并发更新和精确清理，不替代应用查询或集中提交。

四项用例覆盖：

- 通过真实单元格和记录表单查看 Hex、严格文本及小 PNG，区分 NULL 与空 BLOB；暂存和 SQL 预览后旁观断言数据库零变化，明确确认后逐项比对 HEX、主键和 DECIMAL。
- 两行修改形成同一集中批次；旁观连接在预览后修改第二行，使确认提交发生冲突，验证第一行回滚、第二行保持旁观值，确认按钮禁止重放。
- 真实 SQL 查询结果中的二进制只读，没有暂存入口，也不会投递表预览或表提交命令。
- 有打开标签时真实连接修改被拒绝，保留未暂存 Hex；刷新经过确认并等待读取完成后清除旧编辑，数据库不变。正常 UI 会阻止此时改变连接目标，因此这里核对真实保护；外部强制连接版本变化的旧缓存失效由已有离线用例覆盖。

观察包装只记录 IPC 命令名及是否完成，始终调用原处理器，不记录 SQL、参数、凭据或替换返回。虚拟列先滚动挂载，再读取实际列头的 aria 坐标；列头附带类型和选择列不会引发固定偏移。模态关闭与提交后等待读取完成，不增加产品等待时间。
