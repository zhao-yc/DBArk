# PostgreSQL 独立关联表页

在 PostgreSQL 父记录或子记录弹窗中点击「在关联表页打开」。父记录标签定位到一条引用记录。子记录标签沿原外键约束读取子表，继承已应用的搜索，可清空搜索并继续翻页。标签可展开单条完整字段值，后续增加了[编辑选中的关联记录](postgres-related-edit-20261106.md)。[Navicat 数据编辑器的外键导航](https://www.navicat.com/en/products/data-editor-for-rdbms?product=navicat-for-oracle#foreign-key-navigation)

关联页与普通表页可以同时打开。关闭源标签后，关联页仍可重新读取。每次刷新都会复核连接、原行、约束和读取权限。源行被外部改动、应用会话结束或关联页打开满 30 分钟后，需要从源记录重新打开。关联键值和搜索条件仅在会话内保存。子记录每页最多 40 条，宽表按当前账号可读字段和读取预算展示。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0。运行时检查、严格类型检查、构建和 7 项定向单测通过。
- 完整单元回归覆盖 1,337 个文件，27,505 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 实库最终回归 5 项通过。覆盖精确父行、关闭源页后独立翻页、超出弹窗字段上限的可读宽表、跨窗口及连接版本拒绝、普通全表入口隔离、主动关闭和源行变化。两轮均核对数据库零连接后清理。
- macOS Electron 双向关联专项通过 8 项检查。父记录独立页显示一条命中记录及 BYTEA 原值，子记录独立页继承搜索并能在源标签关闭后翻页，普通子表页可同时打开。外部修改源行后刷新返回明确错误并清空旧结果。已核对窗口退出、临时配置清理和零剩余连接。
- 同一构建的 macOS Electron 复制记录与回滚修正专项另通过 9 项检查，独立核对写入结果及正常退出。
- WIN11-TEST 不可达，本轮采用 macOS。Windows 原生操作、安装包和其他 PostgreSQL 版本待验。完整 79 项工作区整例沿用既有 120 秒超时记录，本轮验收覆盖双向关联与复制、回滚专项。
