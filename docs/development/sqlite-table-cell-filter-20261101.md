# SQLite 按当前单元格筛选（开发源码）

表或视图中选中一个原单元格，在“更多 → 按当前单元格筛选”选择“等于当前单元格”或“不等于当前单元格”。入口仅把准确原值加入条件草稿并展开筛选区；检查类型、AND／OR 关系及排序后，点击原“应用 SQLite 筛选排序”才从首页读取。

## 数据与来源

- 读写连接、只读连接和视图沿同一来源合同。INTEGER 与 REAL 不由显示文本推测，TEXT `2` 不变成整数；64 位边界、空文本、NUL／CR／LF／Unicode 和原始 BLOB 字节保持。
- NULL 分别生成 IS NULL／IS NOT NULL。其它值沿既有 SQLite typed 比较：先匹配存储类型，再比较值；不等于不会跨存储类型扩大范围。不改变列原有排序规则。
- 新分页响应附可选 `storageTypes`，每行字符串的 n／t／i／r／b 对应 NULL／TEXT／INTEGER／REAL／BLOB。每格只传一个 ASCII 字符，最多 1000 行 × 1024 列，与结果一起受原 16MiB 对象预算约束；事实来自同次真实协议，不额外查询 typeof() 或猜列亲和性。旧页缺少事实仍可浏览，快捷筛选明确不可用。
- 可编辑页仅接纳原行的未修改格。新增、待删除、改值、过期页及旧回调拒绝；生成列可作为筛选值，粘贴起点仍不可写生成列。保留其它行或字段的未提交修改，后续 Apply 继续走原放弃确认。
- 非有限 REAL、非法类型／编码、超长原值、坏页及失效来源不提供动作。整组条件仍验证 32 条及总值预算，失败不发布半条条件，不消费准确选择。原连接、页面、行列、类型或草稿数组变化后，已观察到失效的来源不能复活。
- 不新增 IPC 命令，不传路径或凭据，不改变写入协议与存储格式，不自动执行或写库，不使用系统剪贴板。

## 本轮验证

WIN11-TEST 远程会话不可达，未派发同轮任务。按既有连接不稳定时的回退授权，本机 Windows 串行运行合成数据测试；原生仍为 120 秒、单 worker、零重试，失败保留现场。

- 最终严格类型检查和构建退出 0；保留既有第三方注解及包体积警告。SQLite 相关与直接涉及 ResultsGrid 的 **198 份测试、4042 项全部通过**。覆盖真实混合类型比较、表／视图分页与磁盘 typeof() 对照、边界和预算、生成列、改值／删除／新增拒绝、旧来源永久失效、React 原事件端口及整组条件原子发布。
- 扩展原 `table` Windows 窗口用例 **47.5 秒通过**：真实鼠标选 TEXT／BLOB／NULL 原格，经“更多”加入正确 typed 草稿，加入前后页请求数量不变；明确 Apply 后逐项核对预期行。原启停、多列排序、分页、视图与零自动 SQL 断言继续通过。
- 扩展原 `edit` Windows 窗口用例 **32.3 秒通过**：实际 INTEGER 原格仅生成 INTEGER 条件，Apply 后与同文本 TEXT 行区分，清除条件恢复准确五行；读阶段零编辑预览／提交。其后原增改删、预览取消、并发冲突整批回滚、重启不重放断言全部保持并通过。
- 两个原生轮次均 1 通过、0 失败／跳过／重试，四次原 owner 正常退出、两个临时目录精确清理均有报告原件。源码与全部构建文件 SHA-256 指纹在执行后保持一致，日志、退出码和报告保留于忽略的 `.cache/sqlite-cell-filter-20261101/`。

既有失败单独保留。本轮未验 macOS 两架构、系统原生文件对话框输入、明亮主题／窄窗口专项、安装包及全仓测试，不以相关结果代表全量验收。不打包、不安装、不创建 Release，持续目标保持进行中。
