# MySQL／MariaDB 表关系图

## 使用

在已打开的物理表页，进入“表格操作 → 设计与结构 → 查看表关系图”。初始图直接展示本页已读取结构，不额外访问数据库。

- 点击“读取表目录”，搜索并勾选同一数据库的表，再点击“读取所选表”。勾选、搜索和翻页只修改本地选择，不自动读取表。
- 图中显示字段、类型、主键和外键标识；箭头从引用表指向被引用表。点击表节点可筛选相关外键，展开关系查看复合字段的准确顺序以及更新／删除规则。
- 未选择或跨库的目标显示虚线框“目标结构未读取”；这是外键声明，不代表已经验证目标存在、可访问或其主键结构。不会自动跨库读取。
- 可切换全部／关联键字段、缩放、适应宽度及滚动。非相邻节点的关系绕过中间卡片，自引用独立绕行；显示操作不发数据库请求。
- “刷新图中表”重新读取上一幅图的表；当前勾选草稿需另点“读取所选表”。停止和关闭等待读取及原取消请求终结后收尾。

当前仅接入 MySQL／MariaDB 物理表；SQLite、视图及其它驱动尚未提供此入口。这里查看实际目录外键，不推断业务关系或一对一基数，不编辑模型、不修改数据库，不替代完整 ER 正反向工程。

## 实现边界

复用 `metadata.objects`、带独立 `taskId` 的 `metadata.table` 与 `query.cancel`。同一轮串行读取、一个在途表任务，完整成功才发布新图；权限失败、取消、目标不符或结构不完整时不拼接部分结果。目录接口本身没有取消编号，停止仍须等待原目录请求终态。

绑定原表结构、标签、连接对象及修订；切换、删除或原地改写后旧读取永久失效，恢复同名对象不复活旧操作。父表草稿和活动计数保持，退出沿用原工作台任务保护。不新增 IPC、数据库驱动、凭据或存储格式。

每轮最多 40 张表、2000 个字段、300 个外键，每键最多 64 个部分，最多 100 个未读目标；超限整份拒绝。目录最多 20,000 项，搜索结果每页 50 张，视图与例程不混入选择。名称按结构数组身份区分，纯文本渲染，不用于 DOM 路径、HTML 或执行内容。分次读取不构成事务一致快照。
