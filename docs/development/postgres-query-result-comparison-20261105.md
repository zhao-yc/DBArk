# PostgreSQL 固定结果对比

在同一查询标签固定两份结果后，点「固定结果对比」。选择左右快照和 1～8 个匹配键，再点「开始对比」。左右快照的完整列键、名称、类型和顺序须一致，每侧的键组合须唯一且所有键值均须非 NULL。

- 匹配键支持文本、整数、NUMERIC 和布尔值。精确数值使用原精度，NUMERIC 的 `NaN`、正无穷和负无穷分别匹配。日期时间、浮点和 BYTEA 等字段可出现在差异明细中。
- 结果列出新增、移除、修改和未变化的行数，默认展示差异，可按类别分页。明细保留两侧原值，区分 NULL、空字符串、整行缺失和 BYTEA 的 Base64。
- 对比只读取两份固定快照已返回的行。已截断的快照会提示范围，扫描可以停止。
