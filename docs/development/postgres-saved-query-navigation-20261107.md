# PostgreSQL 保存查询导航与插入

从「工具 → 全库搜索 → 搜索保存查询」查找保存的 SQL。选中结果后点击「打开查询（不执行）」。新 PostgreSQL 标签沿用保存的来源和数据库，并把光标移到第一处正文命中。「上一处命中」和「下一处命中」可循环跳转。正文、来源或连接修订变化会使命中失效，撤销编辑后需重新搜索打开。

若要沿用当前 PostgreSQL 草稿，先选中一段 SQL 或放置光标，再进入全文搜索或「历史与查询 → 保存的查询」。点击「插入当前查询选区」，会把该条查询的完整 SQL 放到原位置。可用一次撤销恢复草稿。连接和数据库保持原值，执行仍需显式发起。

查询页复用保存查询高亮组件及历史插入注册表。导航由原文摘要、连接修订和模型版本约束。插入绑定原标签、模型、选区与查询会话。执行、关闭、换源或编辑会撤销已有的插入资格。搜索结果和保存列表均在插入前复核保存来源。
