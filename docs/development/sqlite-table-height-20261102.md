# SQLite 表格展开筛选后的可操作高度

## 修复

原 CI 在定位到 `mixed` 原单元格后，正常点击持续被分页状态栏及编辑底栏拦截。筛选区原有 `flex-shrink: 0`，工作区较矮时仍占用完整高度，把网格挤到只剩列头。

筛选区现可缩小并在内部滚动；网格保留至少 128px，供列头、数据行与横向滚动条使用。编辑和分页底栏仍在正常文档流中，不通过覆盖、隐藏表单或强制点击解决。只读和可编辑表格共用高度修正。

首轮真实截图另发现窄窗口将修改计数挤成竖排；可编辑底栏现按需换行，计数与各原操作保持完整，不溢出到分页或应用状态栏。没有修改业务处理器、筛选／排序、数据库协议、写入、IPC 或凭据。
