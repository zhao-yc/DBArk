# 查找已打开标签（2026-10-28）

## 使用与范围

主工具栏新增“查找已打开标签”，快捷键为 Ctrl／⌘＋Shift＋A，空工作区也可查看空态。按标题、连接名称、数据库、表名或类型进行本地搜索，空格分隔的词同时匹配；保持原标签顺序，不搜索 SQL 正文或结果。列表区分已知数据库、明确无默认库、未知及遗留上下文，并显示当前标签和未提交／未保存提示。

在搜索框使用上下箭头、Home／End 选择，Enter 或鼠标激活，Esc／取消关闭。激活只修改准确原标签的 activeTabId，条带将该项滚到可见；不新建查询、不复制正文或连接，也不执行 SQL。连接已删除时仍可切回原标签查看，不回退到其它连接。表标签切换仍遵循原有生命周期，不能据此承诺表永不刷新。

## 实现约束

Registry 只投影有界的自有元数据字段，条目不持原标签或连接对象，不读取 SQL、结果或秘密。最多 100 标签、10000 连接，搜索限 1024 UTF-16 单元／64 词；格式或预算异常整组拒绝，不显示悄悄截断的列表。主 App 观察每次标签目标变化，删除、换绑及异常后的旧令牌不可复活；普通正文、标题或保存摘要更新不改变文档令牌，但旧显示条目仍须重新核验。

窗口与点击均有归属校验，最终 App 入口重新读取当前 store 并解析原令牌，不按标题匹配或选相邻项。列表变化使原选择消失时不自动激活替代项，须重新选择。同步窗口引用防连点，旧窗口不能关闭或激活后来的窗口；输入法组合、模态叠层及修饰键不误触发导航。
