# PostgreSQL 本会话事务默认设置

在 PostgreSQL 查询页点击「事务默认设置」，读取当前查询会话的默认隔离级别、只读和 DEFERRABLE。窗口展示实际数据库及物理后端 PID。选择新的默认值，点击「应用本会话默认值」；设置前重新读取旧值及物理身份，设置后读回确认。原查询结果、草稿及执行历史保持。

这些设置仅作用于原会话后续事务，当前事务可以自行覆盖。关闭标签或重连后，使用新会话的服务器默认值；不会保存为连接配置。READ UNCOMMITTED 在 PostgreSQL 中按 READ COMMITTED 处理，DEFERRABLE 仅在 SERIALIZABLE 与 READ ONLY 同时启用时有实际作用。[PostgreSQL SET TRANSACTION](https://www.postgresql.org/docs/18/sql-set-transaction.html)

读取只发送三条固定 SHOW，不执行 SELECT、提交、回滚或保存点。健康活动事务可以读取，但需先明确提交或回滚，再重新读取后才能修改。失败事务、未知状态、断线或原来源变化会拒绝操作；不会自动处理用户事务。若 SET 已发送但读回失败，显示「设置可能已改变」，必须显式重新读取，不自动重发。

Main 按真实文档核对原查询会话，Engine 在原会话串行队列执行。IPC 只允许固定枚举、布尔值和有界快照；旧值及 PID、后端启动时间、数据库不同均拒绝 SET。设置任务可沿原任务通道取消，取消不代表设置没有生效。快照及草稿仅存在弹窗内存，关闭后释放。
