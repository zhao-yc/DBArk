# 导入文件时批量映射字段

MySQL、MariaDB、PostgreSQL 和 SQLite 的文件导入窗口在显示字段映射后提供以下操作，适用于现有表和已创建新表的写入阶段。

- **按同名字段匹配**使用完全相同的字段名。一个目标列只会匹配一次。
- **按目标列顺序映射**使用文件预览的源列顺序与目标表的可写列顺序。源列多于可写列时，多余源列保持未映射。PostgreSQL 的原生 CSV 导入要求源列全部映射，可写目标列不足时无法使用该顺序操作。
- **清空映射**移除当前配置，可从头逐列选择。

这三个操作只修改导入草稿。已有的整文件预检报告或匹配键需要基于新映射重新确认。SQLite 的转换类型可逐列调整，批量匹配会保留相同字段对已有的类型选择，新映射以目标列声明为初值。整数和 NUMERIC 亲和列初选整数，REAL 亲和列初选实数，声明为 BLOB 的字段初选 Base64。全部记录仍按所选类型预检。

批量映射操作参考官方手册。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)
