# PostgreSQL 未完成语句定位

PostgreSQL 查询在首个错误处停止后，会显示本次失败序号、此前完成语句数和保留的完整结果。点击「定位未完成SQL」可选择原编辑器中未完成的整条语句，并滚动到可见位置。仅显示结果时会先恢复编辑区。定位不会修改 SQL、执行查询、重放脚本或改变事务。

定位支持执行全部、执行选区、光标当前语句及位置参数模板。引擎按当时实际会话字符串模式扫描，回传原输入的 UTF-16 数值范围；选区输入再由原模型捕获的基址映射。定位范围从正文开始，省略前导空白和注释；实际投递的 SQL 保持原文，不按重复文字搜索。参数值仍按协议绑定，参数错误只显示通用失败及可确认的 SQLSTATE，防止服务器转换错误把填写值带入任务及历史。

仅已确认完整语句边界时提供定位。词法未闭合、投递前取消或范围无法确认时，按钮明确禁用。编辑正文、替换模型、变更连接或数据库、重连、关闭标签或开始新执行会撤销旧定位；撤销编辑回到相同文字也不会恢复旧能力。切到其它标签、打开模态、执行中或查看固定结果时不能定位。

此前完整成功结果保持可查看和导出；失败语句的未完成结果不作为成功结果保留。已经提交的修改不会因后句错误而自动撤销。活动事务仍按 PostgreSQL 原协议状态显示，失败事务需用户明确回滚或处理。此入口不推测服务器错误的具体字符位置。
