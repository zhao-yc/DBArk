# 已保存查询插入当前选区（2026-10-28）

## 行为与边界

本批补齐 Q03 的高频复用操作：历史与查询面板的“已保存查询”列表，以及“全库搜索 → 搜索保存查询”，均提供“插入当前查询选区”。只插入完整 SQL 文本；选区为空时插入光标位置，非空时替换原选区，使用原 Monaco 编辑事务支持一次撤销。不执行 SQL、不新建标签、不使用系统剪贴板，也不把保存查询的来源绑定附到目标标签。

列表沿用打开历史与查询面板时捕获的原模型；在历史和保存列表之间切换只更换子租约，不重新捕获模型或选区。全文搜索在明确进入保存查询搜索时捕获一次；返回结构搜索就结束该权限，再次进入属于新的明确操作。没有可编辑查询时仍可浏览或在新标签打开。

原标签、活动标签、模型版本、选区、连接对象及修订、会话或执行编号变化后权限永久失效，恢复同值不会复活。插入保留目标标题、连接、默认库和已有文件／查询库绑定；插入文字中的数据库名、参数及语句不会自动改写。

## 正文读取与收尾

新增严格的本地 `queries.readText({ id, digest }) → { query }`。与原打开流程共享 SQLite 原记录读取、字节预算、SHA256 和完整记录解析；拒绝过期摘要、已删除或非法记录，不能用预览替代原文。不需要源连接存在，不签发来源绑定，不进入数据库引擎。

插入沿原组件的任务和分页收尾：占用原 Promise，等待读取终态和准确游标释放后，最后核对原目标和页面归属，才消费一次编辑权限。关闭、Escape、卸载或模式切换撤销旧子租约；旧回包和清理不能修改新页面的目标。正文及插入后模型均受原 20000000 个 UTF16 单元上限约束，超限整项拒绝，不截断。
