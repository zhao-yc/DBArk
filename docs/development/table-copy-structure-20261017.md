## 用户入口与实际范围

普通表的对象树行及TableTab工具栏新增“复制表结构”。打开后只读取来源完整DDL、物理表编号、服务器、目录和依赖，展示只读源定义及范围。输入准确的同库新表名，显式预览固定DDL；填写逐字相同的“数据库名.新表名”并确认三项风险后，才能单次创建。

首片仅开放MySQL 8.4.11、Linux或debian-linux-gnu、lower_case_table_names=0、非系统库、ASCII名称、永久非分区InnoDB普通表。新名为1～64个ASCII字母/数字/下划线，首字符不能是数字；不trim、不跨库、不补后缀，也不接受与来源相同或仅大小写不同的名字。

仅创建空表，复制已核普通列、普通/唯一/主键BTREE索引及已解析的表选项。含自增列或自增计数、生成/隐藏/未知字段、CHECK、外键、特殊/表达式/不透明索引、未知/特殊物理表选项、已知入向/出向外键、触发器、视图引用均只读。未知目录、身份、角色、部分撤销、字符属性或权限能力不能推断为支持。首片要求显式全局SELECT、SHOW VIEW、TRIGGER、CREATE及可读取物理身份的目录权限；不借重命名任务要求ALTER/DROP/INSERT，不发GRANT，也不自动扩权。

不复制行数据、外键、触发器、授权或其它对象，不宣传为完整克隆。MySQL官方说明CREATE LIKE创建空表并保留列属性和索引，但不会复制外键；参见[MySQL 8.4 CREATE TABLE LIKE](https://dev.mysql.com/doc/refman/8.4/en/create-table-like.html)。本片进一步收窄支持范围，不把官方支持列表直接当成本产品验收。

## 身份、计划与执行

- 独立用途为 `schema.tableCopyStructure.get/preview/apply/release`，不接收客户端SQL、路径、修订或新目标元组。main按可信令牌归属解析连接并注入连接修订；旧用途不能套用/释放新令牌，新用途也不能清理其它编辑器。
- 复用 `readTableRename(..., 'verify')` 的完整物理表、依赖和只读可见性读取，并独立核对规范服务器UUID、实际会话线程、完整身份摘要、显示模式、utf8mb4/bin、GIPK关闭、autocommit开启和partial_revokes关闭。复用完整DDL/列属性核对，不以哈希或名字替代TABLE_ID。
- 快照和预览绑定来源、新名、完整原定义、物理编号、UUID/服务器身份、连接修订、能力及两分钟TTL。缓存用途独立，复用既有全局结构缓存的数量/字节预算；原始授权仅在内存解析，不进入快照、输出或任务记录。
- 预览重读来源与依赖，确认真实目标不存在。执行在第一个await前消费该快照的全部预览，准确确认或风险项错误也消费；同快照不能并发执行两次。执行再重核来源、能力、权限、TTL和目标不存在，并通过既有共享结构锁同时占用来源与准确新名，覆盖连接关闭等待；关闭异常沿既有任务协议报告资源收尾失败，不把该异常描述为已证明真实断开。
- 唯一写语句为 `CREATE TABLE 新目标 LIKE 来源;`，没有IF NOT EXISTS、OR REPLACE、INSERT、SELECT源行、DROP或自动重试。最终检查后出现的外部同名竞态仍由这条CREATE原子拒绝，不覆盖已有表/视图，不改名重试。
- 发送即记录可能已执行；取消等待真实命令终态和资源关闭。断线、取消或错误不会重放；主进程/引擎退出保留已发送、已完成和核验事实。Promise失败不能证明“未执行”。
- 成功响应后重读来源及新表完整定义、属性、依赖、UUID/能力与TABLE_ID，要求来源未变、新编号不同，定义逐字仅差CREATE头部表名，并以 `SELECT 1 FROM 新表 LIMIT 1` 核对空表。不会读取源行。警告、后核验失败或关闭失败均保留DDL已完成事实，不删除新表、不自动重建；只有全部核验通过才显示完整成功。

维护窗口仍是显式确认项。应用锁只覆盖同一连接配置内的本产品结构任务，无法锁住外部客户端，CREATE LIKE也不提供跨多次读取的永久身份锁。本片没有消除外部DDL并发窗口，不把离线后核设计描述为实库线性一致性证明。
