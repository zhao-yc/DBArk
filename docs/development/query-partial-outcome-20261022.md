# 脚本失败后保留完整前序结果

## 用户行为

普通查询和类型参数查询仍在首个错误处停止；不会自动继续后续语句、重试、重连重放或回滚。错误提示显示失败序号、此前完成语句数和未继续执行范围。此前已提交的修改保留；失败语句可能已部分执行，不能据此认定未执行。

此前完整成功语句返回的结果仍可切换、固定、筛选、多列排序及导出，沿用原行数、字节和结果集预算。某条语句在报错前可能已传输部分行，这些片段不会进入可固定或导出的最终结果；取消也不产生部分成功回包。状态结果不等于可导出的行结果。

## 跨进程契约

`QueryOutcome.failure` 记录 `statementOrdinal`、`statementsCompleted` 和有界中文消息；完整成功时省略该字段。仅 `query.execute`、`query.executeParameterized` 使用部分结果回包，结构变更及其它共享执行器仍按原异常路径结束。参数错误继续隐藏服务器可能包含的参数值，结果声明保留模板。

引擎只将已完整结束的前序 `streamQuery` 返回值加入结果，首错后忽略失败语句迟到流事件。取消等待原控制请求收尾后拒绝，原任务标识和会话占用不提前释放。物理连接错误或结束标记失效会话；不自动新建连接。

Main 将部分结果响应记为失败任务、失败历史；当前语句模式仍只保存已实际投递的片段。界面优先使用完整前序结果，清除临时流，沿用原错误及缓存会话状态处理；读取缓存不发送诊断 SQL。服务器 ERR 后旧事务位不作为已确认状态，用户可明确执行回滚。原结果选择、导出及模态租约保持。
