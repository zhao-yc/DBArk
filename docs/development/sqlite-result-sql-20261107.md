# SQLite 已返回查询结果导出 INSERT SQL

从 SQLite 查询页的「导出已返回结果」或「导出勾选结果行」选择「SQLite INSERT SQL」。填写目标数据库名、表名和当前可见列的目标字段。生成预览、选择文件，再输入准确的目标名并确认保存。文件使用 UTF-8，范围以打开导出时的可见列、显示顺序和所选行为准。

预览和文件共用生成器。SQLite 类型标记按原结果逐格投影，文本数字与整数分别生成。旧快照缺少存储类型时仍可使用 CSV、JSON 和 Excel。文件只写出已经返回的行，保留原查询历史。目标表的字段亲和性和约束在运行脚本时生效。[SQLite 存储类型与字段亲和性](https://www.sqlite.org/datatype3.html)

主进程预览绑定原值、存储类型、列顺序、目标和编码。预览签发的一次性文件令牌随来源变化撤销，文件使用原有原子替换流程。

## 验收范围

- Node.js 24.17.0 运行时检查、严格类型检查、源码构建和 263 项相关测试通过。扩大回归的 72 项失败与变更前逐项一致。
- macOS arm64 Electron 源码以真实 SQLite 查询执行一次，勾选两行并保存 INSERT 文件。独立 SQLite 回放逐格核对相同显示内容的整数与文本、64 位边界值、实数负零、BLOB、NULL 和含 NUL 的文本。文件与预览一致，源 SQLite 文件 SHA-256 和执行历史核对通过。另一项原生文件测试覆盖无穷、空 BLOB 和带双引号的目标名。
- 专项同时回归了从选区导出完整 JSON 和按光标导出完整 Excel。Windows 测试会话不可达，本轮使用 macOS arm64。Windows、macOS x86_64 和安装包待验。增量暂未正式发布。
