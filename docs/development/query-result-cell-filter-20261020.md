# 从当前单元格追加筛选条件

## 使用入口

SQL结果网格选中一个支持比较的单元格后，点击“追加等值条件”或“追加排除条件”。先打开现有筛选面板，只有点击“应用筛选”才生效。取消不改变当前筛选或排序，打开草稿仍按原规则撤销勾选等旧操作许可，不执行SQL或任务。

新条件与现有整棵表达式按AND组合：原AND直接追加，原OR保留为括号子组，再与新条件组合。空根生成单条件AND。仍共同受32条条件、16组、8层及应用时的原工作预算限制，结构超限不开面板，不更改原视图。

## 原值与生命周期

- 以当前显示位置的原行引用及可见列唯一key定位，不按重复别名猜字段。
- BIGINT、DECIMAL、微秒及负TIME保留原文；仅原协议浮点按原表示往返核对。NULL填入NULL／非NULL判断，空串及NULL字样保持普通文本。
- 字节、未知非NULL、布尔包装、不可靠数字、缺失或访问器原值及超长内容不能快捷填入，不解码、不截断，也不影响既有查看和复制。
- 每次选择捕获原格及元数据，观察到漂移即撤销旧快捷动作；恢复值不能复活旧按钮，必须重新选择。仍核原结果／模态／连接／标签租约，父级在开面板前再次核对原格。

快捷草稿只保存独立条件树；已生效view仍为面板租约依据，不把未应用草稿冒充当前结果。复制工具栏可换行，继续由已修布局观察实际高度，为网格保留空间。其它网格消费者未提供回调时没有此入口。
