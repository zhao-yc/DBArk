# SQL模板选列与字段顺序

在表数据页点击“生成查询SQL”，选择模板类型，在“模板字段”中勾选需要的字段。编号代表写入SQL的顺序；新勾选字段追加到末尾，“上移／下移”调整完整顺序。搜索和每页50项只改变列表显示，不缩减已选字段；“恢复默认字段”恢复当前模板的默认顺序。

## 各模板规则

- SELECT可选择普通、生成和自增字段，至少选择一个；保留当前结果上限作为LIMIT。
- INSERT只提供普通、非生成、非自增字段；清空后明确生成默认值插入语句`INSERT INTO ... () VALUES ();`，默认值和约束仍由数据库校验。
- UPDATE额外排除可靠定位键字段，至少选择一个更新字段；WHERE始终包含完整非空主键或可靠唯一键，保留`LIMIT 1`。
- DELETE不提供选列，继续保留完整可靠键条件与`LIMIT 1`。视图和未知对象只允许SELECT。

写入模板按选中顺序使用`:value_1`等ASCII参数，键参数仍按完整键原顺序生成。200个参数上限包含键参数；256Ki UTF-16文本和元数据预算保持。默认可写列过多的宽表可以先清空，再选择少量字段生成模板。

## 草稿与打开边界

字段选择只使用已加载结构，不读取表数据或执行SQL。预览后“打开新查询”仅创建同连接、明确默认库的新查询，保留原表未提交草稿；需用户审阅并明确执行。父组件使用同一冻结选列重新生成SQL并逐字核对。

模板类型、字段、顺序、搜索或分页改变后，旧控件回调不能操作新选择；连接、标签、结构或结果上限失效不能通过切回原值恢复旧模板。保留100标签上限。显式选列拒绝重复、越界、稀疏、访问器和带额外自有属性的数组，不消费调用方迭代器。
