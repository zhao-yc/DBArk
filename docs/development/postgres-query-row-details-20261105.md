# PostgreSQL 查询结果行详情

在查询结果网格选择一个数据单元格后，点击「行详情」。侧栏显示该行的全部原字段，包括隐藏列。同名列按原结果的位置和唯一列键区分。

- 「上一行」「下一行」和行号跳转沿用网格筛选与排序后的已返回行。字段搜索在同一结果内翻行时保留。应用筛选、排序或列布局，切换标签或结果集，或重新执行查询后，请从当前结果重新选行。
- 可切换字段列表、记录树和整行只读 JSON。整行 JSON 保留全部原列、协议类型和返回值。BIGINT 等以字符串返回的值保持原文，空字符串、NULL 和二进制各有独立表示。超过 2 MiB 预算时可回到字段或记录树查看。
- 展开字段、查找、翻行和生成只读 JSON 均使用已返回的值。截断结果的行号仅覆盖已返回行。

## 验证

- macOS 类型检查和源码构建通过。完整单元回归覆盖 1,326 个文件，27,436 项通过，10 项 Windows 系统 `tar` 用例按平台跳过。Server-200 独占 PostgreSQL 18 实库回归 5 项通过。
- macOS Electron 源码窗口复验 1 项通过，覆盖 27 个观察点。原生窗口在筛选与降序后的两行结果中翻行，在树中找到网格隐藏的 BYTEA，核对整行只读 JSON 中的重复别名、相邻 BIGINT、空字符串、NULL 和空二进制。清除筛选后撤销旧侧栏与活动行，原事务、历史和序列值经过复核。
- 展开详情时缩短编辑区，为记录正文留出更多高度。复验窗口正常退出，专用配置、数据库与容器已清理。WIN11-TEST 会话不可达，Windows 源码窗口和安装包待验收。
