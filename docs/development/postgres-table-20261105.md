# PostgreSQL 表页与记录事务

本批推进 Navicat 对标矩阵 R01。数据库目录和对象列表中的表与视图现在打开独立记录标签。查询编辑器及 SQL 草稿入口仍可从表页进入。

## 使用

1. 展开已保存的 PostgreSQL 连接和数据库，打开表或视图。表页可刷新、回到首页或翻页，支持每页 1 至 200 行。点击表头按列排序，也可选择列按服务器文本结果做包含筛选。
2. 选择网格记录，再点击「编辑所选记录」或「删除所选记录」。新增从「新增记录」进入。表单可区分保持原值、文字（含空串）、NULL、DEFAULT 和 BYTEA 十六进制。生成列与始终生成的标识列由数据库提供。
3. 记录草稿先留在当前页，可撤销单项或放弃整组。点击「预览记录修改」核对操作、参数语句和填写值，再选择「确认提交整批修改」。存在草稿时先处理草稿再刷新或翻页。
4. 事务确认提交后刷新页面。原记录冲突、约束错误或提交终态未知时保留草稿供核对，旧预览失效。核对数据库后可放弃旧草稿、刷新并按新的页面重新编辑。

## 数据范围和一致性

- 普通表按主键顺序分页。没有主键时按当前物理位置浏览，更新和删除需要普通表的有效主键。普通表读写限定为自身记录；分区父表、分区子表、视图、物化视图与外表以只读方式开放。关系没有稳定分页键时，刷新可能改变顺序。[PostgreSQL 继承与 ONLY](https://www.postgresql.org/docs/current/ddl-inherit.html)
- 每个可写页面绑定原窗口文档、标签、数据库、关系及连接配置。引擎保留行版本与行值摘要。预览签发一次性提交许可，应用在独立事务中锁定关系，复查结构，并先核对整批的所有原记录，再发送 DML。值使用 PostgreSQL 协议参数绑定。断开连接等待已经进入执行的写入事务结束。[PostgreSQL 显式锁](https://www.postgresql.org/docs/current/explicit-locking.html)
- 保留服务器返回的大整数、高精度数值与字节值。翻页用有限偏移与额外一行判断后续页，当前页达到显示字节上限时请缩小页长。新增、修改、删除能力由目录和权限决定，实际写入仍受服务器约束、权限、行级安全策略与触发器控制。
- 本批覆盖表内分页和当前页的记录事务。跨页草稿、更多筛选规则、结果集导入导出、表结构编辑、完整对象与补全矩阵继续推进。

## 实证

- 严格类型检查和产品构建通过。完整单元共 1315 个文件，27386 项通过，0 项失败，10 项既有平台条件跳过。最终独占 PostgreSQL 实库 2 项、Mac 源码窗口 1 项通过。
- 独占 PostgreSQL 18 位于 Server-200，Mac 经 SSH 回环连接。实库覆盖分页与排序、文本筛选、BIGINT、NUMERIC、BYTEA、NULL、DEFAULT、生成列、只读视图和混合写入。独立连接核对预览阶段零 DML、成功提交、外部改行整批拒绝、CHECK 错误整批回滚、结构变更拒绝和令牌隔离。用独立连接锁住原记录，实证断开等待在途写入结束，事务提交后由独立连接读取确认。
- Mac Electron 源码窗口用例覆盖表单连接、从目录打开表、真实表页筛选翻页、录入草稿、预览、提交、重新读取，以及既有查询工作流和正常退出。保持单 worker、120 秒、零重试、trace 关闭。独立连接核对最终原表行和零活动连接。
- WIN11-TEST 不可达，本轮未派发，按约定在 Mac 验证。Windows 和安装包待验收。
