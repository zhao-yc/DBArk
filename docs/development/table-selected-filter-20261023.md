# 按勾选行原值筛选与排除

在表或视图数据页选择一个可见列的单元格，勾选本页需要取值的行，再点击“按勾选行值筛选”或“排除勾选行值”。预览展示当前列、原勾选行数、去重后的非NULL值和NULL状态；空字符串用`""`显示，换行等保留JSON转义。

打开和取消预览不查询服务器，也不更改原筛选或数据草稿。只有“应用勾选值筛选”才沿原丢稿确认，从第一页重新读取全部匹配记录，保留多列排序。它按字段值筛选，不按勾选行身份定位；其它页中的同值记录也会匹配，字符串比较遵循服务器字段类型与排序规则。

## NULL语义

| 勾选原值 | 包含 | 排除 |
| --- | --- | --- |
| 只有非NULL值 | `IN (...)` | `NOT IN (...) OR IS NULL` |
| 非NULL值和NULL | `IN (...) OR IS NULL` | `NOT IN (...) AND IS NOT NULL` |
| 只有NULL | `IS NULL` | `IS NOT NULL` |

新值条件作为完整组，与原筛选整体做AND；原筛选的OR、嵌套组和停用状态保留，不把新条件直接混进旧OR。排除是包含的完整补集，因此没有勾选NULL时会保留NULL记录；这与普通SQL不等于条件的NULL行为不同。

## 原值与预算

只使用本页已加载原行，字符串不经过浮点数、不修剪；布尔和安全有限数值沿手工筛选转换。二进制包装对象、缺失值、新增／删除行或所选字段已有修改时整份拒绝，不静默跳过。其它字段的已暂存修改可以保留到明确应用时确认处理。

最多读取当前页1000个原行身份、200个非NULL唯一值；NULL独立成无参数条件。全部旧条件，包括停用条件，仍占30条件、1000值、100万字符、16组／8层预算，单值最多4096字符。超限拒绝整份，不截断成部分筛选。

连接、页、列、勾选、原值或条件变化会撤销旧提案。普通翻页、排序和手工条件操作在排队渲染前同步撤销；应用自身仍在确认前后复核来源。面板支持Ctrl／⌘+Enter和单独Esc，输入控件、组合输入和已消费事件不触发快捷动作。
