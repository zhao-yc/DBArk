# 每列文本排序的大小写选项

## 行为与入口

已有多列排序优先级列表为文本列提供“忽略大小写”。默认仍按原UTF-16代码单元排序；显式开启后，只把该列比较键做无区域设置的Unicode小写映射，再比较映射后的键。不去重音、不做字符规范化，不采用数据库排序规则；例如SS与ß、é与组合形式仍是不同键。映射后并列继续比较下一优先级，全部并列才按原返回位置稳定排列。

该选项与每列NULL位置、升降序及优先级独立；RDG只回传列与方向时仍继承同列选项，移除再添加恢复默认。原行引用、原文、列和源SQL不变，复制／导出不使用转换键。不新增共享IPC或服务端ORDER BY合同，不持久化设置。

## 预算和失效

只对明确文本类型开放；数字／日期／时间等列拒绝该选项，非布尔输入明确报错并保留前视图。原文字及转换结果共同消耗原8 Mi UTF-16单位预算；转换可能扩展字符，因此原文能进行大小写敏感排序并不保证开启选项后仍在预算内。超限不退回部分排序或悄悄忽略选项。

沿用当前排序与选择租约，选项改变同样撤销旧勾选、查找和行详情；旧控件不得修改替换后的排序。源值即使只改变大小写、转换键相同，仍按原始快照漂移失效，不恢复旧复制来源。
