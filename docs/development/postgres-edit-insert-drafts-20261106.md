# PostgreSQL 编辑新增草稿

在 PostgreSQL 表页暂存新增记录后，在下方清单找到要修改的条目，点击「编辑新增草稿」。表单预填该草稿的字段，可以填写文本、SQL NULL、二进制或 DEFAULT。省略的字段继续由数据库处理默认值。

点击「保存草稿修改」会在原位置更新该条目，保留原页和批次顺序。可在当前标签的其他页打开编辑。取消或原样保存时保留已有草稿和历史。非法值或整批预算超限时保留旧草稿，当前表单可继续修正。

每次实际修改计入一步撤销和重做。检查最终字段后，点击「预览记录修改」并明确确认，才会执行整批数据库事务。

## 验证记录

- macOS arm64，Node.js 24.17.0。运行时检查、严格类型检查、构建和 15 项定向单元通过。完整单元回归 27,517 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 的 5 项实库回归通过。最终 Electron 窗口专项通过 23 项检查。两个原页各暂存一条新增记录，跨页编辑第一条。取消及原样保存保留已有步骤，非法十六进制输入保留草稿和当前输入。修改后可以一步撤销、重做并再次打开核对。
- 独立连接确认编辑和预览期间原行保持。明确提交后仅新增两行，按原顺序读回精确小数、字节、显式 NULL 和默认值。原生窗口正常退出，专用库核对零连接后清理。
- 首轮断言把省略字段误判为 NULL。补充显式 NULL 并核对另一行的默认值后复验通过。截图核验发现模式选择器挤占文本框，调整布局并在最终窗口验收输入区宽度。首轮日志保留，专用容器已清理。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包和其他 PostgreSQL 版本待验。
