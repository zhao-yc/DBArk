# CSV表导出字段选择与顺序

后续独立审查确认了父版继承的CSV取消提交窗口，已追加[取消与文件提交修复说明](csv-export-cancel-commit-20261017.md)。原选列验收中的流读取取消不能代表sync/close/rename窗口安全，修复证据以该说明为准。

固定基线为 `f9dfa3c4f877b6b58f218d3d8c1b69b451014f71`。原 `TransferDialog` 的CSV导出表单没有选列或排序，后端固定按全部元数据字段生成SELECT。本片在原表导出入口增加勾选、上移/下移及只读字段顺序预览；不预加载表数据，不增加任意SQL结果导出的能力。

## 使用与边界

打开表页“导出”，保持CSV格式后读取实际字段目录。初始按目录选择全部字段，可取消勾选并调整输出顺序；重新加入的字段放在末尾。至少选择一列，选择必须逐字属于目录，不trim、猜列名或用显示行号定位字段。预览展示字段顺序；它不是样本数据或完整文件内容预览。选择文件后仍由原“开始导出”按钮显式执行。

目录未知、读取失败、过期、目标/连接修订改变或已经用于一次导出时，按钮禁用并明确要求重新读取。重读重置选择，不自动重试导出。目标或连接修订改变也清除旧文件选择；迟到目录只释放自己的令牌，迟到文件选择不能覆盖当前目标。导出期间选列、顺序、格式和文件操作锁定，双击沿原同步锁只投递一次。

CSV格式始终导出数据，不沿用从SQL格式隐藏的数据复选状态。JSON、SQL及Excel的参数和导出路径保持原有行为。API调用省略新参数 `csvSelection` 时，原CSV全列行为保持；任意SQL的已返回结果、完整流式结果及CSV ZIP路径均未接入本选择。

## 协议及流式实现

- 新增只读 `files.exportColumns` 和内存释放 `files.releaseExportColumns`，返回目录令牌、精确目标、两分钟期限和字段名称/类型。main注入可信连接修订，公开参数拒绝客户端修订或路径。目录读取使用独立短任务，真实关闭后才发布能力。
- `ExportOptions.csvSelection` 是可选的 `{ catalogId, columns }`，仅允许CSV数据导出。空、重复、越界、未知字段及非CSV使用均拒绝。目录用途独立，复用现有结构缓存的总预算；字段上限4096，字段目录2 MiB、原DDL4 MiB，不截断后继续猜候选。
- 目录绑定逻辑目标三元组、连接修订、服务器版本/模式和真实字段定义。摘要包含字段顺序、类型、字符集、默认值、生成属性及原列定义；表尾自增计数不作为字段变化，正常数据插入不使选列伪过期。这里不声称验证表物理ID或服务器UUID。
- 开始时消费目录令牌；失败、取消或目标变化后只能明确重读。独立导出连接先开启原有一致性读取事务，用 `SELECT 1 … LIMIT 0` 取得同事务元数据锁，再重读目录并核对。字段变化在打开临时文件前拒绝，原文件保持。
- 数据SQL只投影已选择的字段并按该顺序返回数组，之后沿原逐行编码写入；没有先全表加载再过滤。每行字段数异常拒绝原子替换。字段锁、读取事务及文件仍沿原任务和finally收尾，取消不假装撤销已经完成的文件提交。
- 原 `serializeCell/csvHeader/csvCell`、编码器、逗号分隔、CRLF、引号/换行转义、NULL反斜线协议、BLOB base64、BIGINT/DECIMAL/时间字符串均未重写。所选字段含浮点时沿原二进制协议；进度500行一次、流背压、取消、partial清理和最终rename保留。

共享接线限于 `contracts/commands/validation`、缓存新增CSV目录用途、Engine命令及表文件导出、main可信修订、原TransferDialog。元数据读取、序列化、任意SQL导出模块、版本、依赖、dist、ROOT与共享fixture未改。新建库/对象DDL等其它管理能力不属于此片。
