# PostgreSQL 不同值次数排序

在表或视图的「高级筛选」中打开「按不同值筛选」，选择字段和候选排序后，点「读取不同值」。默认按字段值，可改为出现次数最多或最少。同次数沿用原字段值顺序，其中 NULL 排在同次数的其他值之前。

服务器对当前已应用筛选范围内的记录分组计数，按候选搜索和选定顺序取前 500 项。搜索按原文字面匹配，区分大小写。次数使用 PostgreSQL 原始整数排序，显示为精确十进制文本。候选翻页只浏览本次已返回的结果。

更改字段、搜索或排序只修改窗口输入，原勾选暂时保留。新输入与候选不一致时，须重新读取才能继续勾选或加入草稿。重新读取前可以保留现有勾选，或确认清除后读取。加入筛选草稿后，仍需在表页点击「应用高级筛选」。

## 验证记录

- macOS arm64，Node.js 24.17.0。运行时检查、严格类型检查、构建和 5 项定向单测通过。定向测试覆盖排序输入白名单、默认兼容及不同值筛选的 NULL 补集和分组。
- Server-200 隔离 PostgreSQL 18 的 5 项实库回归通过。样本有 503 个匹配分组，原值序前 500 项不包含高频值。最多优先将 12 次排在 3 次和 2 次之前，最少优先返回 500 个一次分组。测试另核对同次数 NULL 顺序、字面搜索和原筛选范围。
- macOS Electron 专项通过 26 项检查。新步骤核对排序改动不自动读库、保留勾选和确认重读、加入草稿后明确应用，以及数据库记录不变。窗口正常退出。两次独占实库均独立核对原行和零连接后清理。
- macOS 全量单测运行 1,341 个文件，27,521 项通过，10 项 Windows 条件测试跳过，0 项失败。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
