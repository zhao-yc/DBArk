# 全表数值分布

## 使用

在 MySQL／MariaDB 物理表页打开“表格操作 → 数据 → 表数据统计”，在“数值分布（可选）”选择数值字段及5、10或20个目标区间，再点击“开始统计”。分布覆盖当前**已应用筛选的全部匹配行**，不使用已加载页，不包含本页未提交草稿。

- 分布字段与上方最多12列的聚合选择独立；默认不统计分布，不会自动选择第一列。选择字段、区间或统计列只改草稿，须明确开始；改变选择后旧回执立即撤下。
- 显示每个数值区间、准确记录数、非NULL占比及条形图，保留零数量区间。NULL单独计数；空集或全部NULL不生成假零区间。
- 区间左闭右开，最后包含最大值。整数、BIT按整数单位，DECIMAL按声明小数位量化边界；相同边界合并，因此常量、相邻可表示值等情况下实际区间可能少于目标数。
- 整数、DECIMAL和BIT的极值、边界与计数不经过浮点运算。FLOAT／DOUBLE／REAL明确显示近似说明，不能恢复原十进制精度；极值使用原binary协议，避免服务器CHAR显示舍掉有效位。
- 条形相对本图最大数量缩放，占比向下保留两位小数；数量和边界原文不变。图只查看，不自动改变父表筛选或修改数据。

本入口只接受已知数值类型的物理表。任意视图可能重复求值，当前不提供其多次读取分布；原视图统计入口仍保留。SQLite分布、时间／类别分布、抽样及交互筛选继续开发，D09保持部分。

## 读取与正确性

复用 `table.statistics`，仅增加可选 `histogram: { column, bins }`。未选择时不增加查询或回包字段，不改变配置、写入协议、用户会话、事务或SQL历史。

沿原独立只读任务、固定REPEATABLE READ事务，先读原计数／所选聚合，再读取分布列极值和非空／NULL数，最后以单个有界聚合SELECT统计全部区间。每条聚合后立即核原警告；读取后再次核原表定义，正常路径回滚并等待准确物理资源关闭。原取消号覆盖当前实际命令，不自动重放。

区间由元数据白名单及本次极值生成，不接受自定义SQL或任意边界。重用原筛选、启停、嵌套分组和精确值编译器。SQL与总回包沿8MiB预算，不完整、截断、警告、源变化、行数／非空／NULL矛盾、越界行、区间和不相等或极值端区间变空时，整份失败，不拼接旧极值和部分分布。

InnoDB一致读使用同一事务快照；非事务表不保证快照一致，数量和范围探针只能发现部分并发变化。上方所选SUM／AVG等原聚合仍保持原警告与溢出保护，失败时不单独发布分布。关闭／取消等待原请求和取消ACK均结束后才释放父标签忙态。

## 验证

WIN11-TEST本轮不可达且未派发，依已有授权回退本机Windows x64。

- 最终10份相关单元共322项通过，含真实Engine／metadata／事件流的RAM边界、极值精度、原统计、Main透传、父表草稿、ABA与取消双终态。严格类型和源码构建通过。
- 六个Server-200专用端点各33向量、5种严格SQL模式，最终合计2880次常量派生聚合SELECT通过：MySQL 5.7／8.0／8.4、MariaDB 10.11／11.4和严格TLS端点。每端先核主机／版本／serverId／适用UUID，原线程关闭后另建观察器再次核实例身份及线程不存在。
- 真实服务器验证仅替换唯一物理FROM为常量派生关系；产品聚合、原筛选、边界与解码器保持。覆盖UINT64、65位DECIMAL、末位小数、BIT数值转换、浮点代表值、极大异号DOUBLE、NULL、常量及内部别名同名列；不是物理列元数据、真实BIT存储、权限或完整实库UI验收。
- Windows原生源码组件明暗各1例通过，0跳过／重试，原120秒、单worker；正式TableTab菜单／对话框／回包校验／图参与，只有统计服务为明确合成端口。验证选择零读取、精确区间、零数量、6／10区间缩减、浮点／NULL及关闭双终态。两个原Electron进程正常退出码0、所属目录清理；最终截图已检查。合成百万行计数不代表百万行性能验收，也不代表真实Main／数据库／安装包。
- 原生默认2跳过，`--list`仅登记2例；只读实库专项默认1跳过。可用 `node scripts/table-histogram-ci.mjs` 运行固定离线原生用例，三平台CI已配置，Mac结果另验。

原失败保留：首轮内存DOM缺select.options，补两个准确DOM端口后原业务断言通过；首轮原生字段精确标签不可达，修正真实控件无障碍名称后通过；独立Node CI入口缺类型声明已补齐，没有忽略类型错误、提高超时或重试。未操作剪贴板、安装版配置、Docker、服务器DDL／DML或用户权限，未创建Release。
