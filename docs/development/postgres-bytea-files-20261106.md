# PostgreSQL BYTEA 文件操作

在 PostgreSQL 表或视图的记录表单中，从 BYTEA 字段点「查看 BYTEA 原字节」。可以分页看 Hex、按编码严格解码文本、预览支持的图片，或另存完整原字节。查看与另存使用 2 MiB 完整值上限。只读视图提供原值查看和另存。

在可写记录表单或常规记录弹窗选择十六进制赋值，再点「查看或载入 BYTEA」。选取文件后，只有当前字段输入被替换。也可另存输入中的完整字节。空文件表示零字节，SQL NULL 和 DEFAULT 通过字段模式明确设置。

载入沿用 32 KiB 字段写入上限，超限候选整次拒绝。原值超过编辑上限时，可用「从空缓冲替换 BYTEA」明确开始新赋值。实际写库仍需暂存、预览并确认提交。
