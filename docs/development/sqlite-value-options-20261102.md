# SQLite 全表不同值勾选筛选（开发源码）

表／视图页展开“筛选与排序”，点击“从数据库不同值筛选”。选择字段和搜索原文后明确“读取SQLite不同值”，勾选候选并加入筛选草稿，最后点击原表页“应用”。打开、选列、输入、勾选与加入草稿均不自动读取表页或提交数据。

## 范围和原值

- 候选读取符合**已应用筛选**的全部记录，不限当前页，不含未提交行修改。与尚未应用的条件表单分别绑定，加入保留原表单，并使用其当前AND／OR关系；不是强制覆盖或隐式改为AND。
- 每次最多返回500组，多读一组确认截断，每页显示50组，最多选择128组。搜索在数据库中对全部匹配记录先过滤再分组，计数是搜索后的记录数，不是在前500组内搜索。
- 文本搜索区分大小写，`%`与`_`是原文；数值使用SQLite文本表示，BLOB使用十六进制原文，非空搜索不含NULL。条件本身继续使用原typed绑定，不根据显示文字推断类型。
- 分组键包含真实存储类型，并沿原列排序规则：INTEGER、REAL、TEXT、BLOB与NULL分别分组；同一文本组可能包含大小写、重音或尾部不同但原排序规则判等的记录，代表值匹配该原生组。
- 64位整数使用十进制字符串，BLOB保留完整字节，NUL和Unicode原文保持；TEXT代表值通过原driver私有函数逐字节核对UTF-8／UTF-16源编码，坏编码明确拒绝，不把替代字符当原文。无穷REAL可以展示，但不能勾选为原有限数值筛选。超出单值、总回包或参数预算明确失败，不截断值或转换成NULL。

## 条件和任务

新增“属于勾选值／排除勾选值”作为一条完整条件，支持逐项修改真实类型、NULL及原文。包含是各原类型值的并集，排除是整个集合的补集，包含未被选择的NULL和其它存储类型。原同类型IN／NOT IN语义保持。停用保值，分页、完整导出、生成SELECT及命名方案共用同一条件合同。

候选任务复用原SQLite独立只读utility、任务编号墓碑、连接关闭与取消账本。准确结构指纹、原Main文档、连接修订和父级来源分别验证；原读取Promise与取消ACK均结算、回滚及进程关闭确认后才释放自己的租约。未提交记录保留，应用条件仍沿原脏页确认流程。任务概要不保存搜索、筛选、候选、SQL或驱动错误原文。
