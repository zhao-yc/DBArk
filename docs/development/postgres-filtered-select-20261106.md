# PostgreSQL 当前筛选 SELECT

在 PostgreSQL 表页应用筛选或排序后，点击「从当前筛选生成 SELECT」。对话框列出已应用条件、排序和输出字段，可搜索、勾选和调整字段顺序。选择「打开新查询」将 SQL 放入原连接和数据库的独立标签，待确认后由用户执行。

草稿从完整匹配范围的开头读取，沿用查询结果上限。快捷筛选保留字面子串语义，高级筛选保留条件分组并忽略停用项。排序沿用列方向、NULL 位置及表页补序，普通表的继承子表仍在范围之外。尚未应用的输入及待提交的表格值留在原表页。

已应用的筛选值作为 PostgreSQL 转义字面量进入查询正文。保存或分享查询前，请核对这些值。

## 验证记录

- macOS arm64，Node.js 24.17.0。运行时检查、严格类型检查、构建和 60 项定向单测通过。定向测试覆盖条件树、停用条件、字面子串、反斜杠转义、NULL 顺序、主键补序和原模板窗口。
- Server-200 隔离 PostgreSQL 18 的 5 项实库回归通过。对包含 NULL、精确大整数、相同排序值及反斜杠的合成记录，生成查询在 `standard_conforming_strings=off` 时返回与表页相同的四行、字段投影及顺序。查询保留完整范围及复合主键补序。
- macOS Electron 专项通过 25 项检查。从筛选结果第二页生成选列 SQL，独立查询显示已应用的条件和补序，原未应用输入及待提交草稿保持。窗口正常退出，独立查库核对原行及零连接后清理测试容器。
- macOS 全量单测运行 1,341 个文件，27,521 项通过，10 项 Windows 条件测试跳过，0 项失败。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
