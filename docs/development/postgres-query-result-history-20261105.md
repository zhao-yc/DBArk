# PostgreSQL 查询结果整理历史

结果区的「撤销结果整理」和「重做结果整理」恢复当前已返回结果的筛选与排序。网格获得焦点时，可用 `Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 重做。Windows 也可用 `Ctrl+Y` 重做。输入框保留自身的撤销操作。

- 应用筛选、清除筛选、列头排序、多列排序和恢复原返回顺序均可产生历史步骤。快捷筛选和列统计回填的条件在确认应用后记入同一历史。
- 每一步恢复筛选和排序的完整配置，并按已恢复的显示范围重新生成网格绑定。撤销后提交新的整理操作会清除原重做分支。
- 最多保留 20 步。执行新查询、切换结果集、连接配置变化或可见列投影变化时重置历史。历史保存在当前结果的内存中，操作只读取已返回的行。
