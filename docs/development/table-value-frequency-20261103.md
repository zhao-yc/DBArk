# 服务器不同值按次数排序

## 使用

打开表页“从服务器不同值筛选”，选择“出现次数最多优先”或“出现次数最少优先”，再明确读取。服务器对当前筛选的全部匹配分组排序后取前 500 组，同次数按原列值顺序；可以据此定位常见值或少见异常值，再勾选并应用筛选。

排序切换不自动查询。旧候选和勾选保留供核对，但须重新读取才能应用；已有勾选时仍先确认丢弃。切回原排序也不能让旧回执复活。NULL、空串和文本“NULL”继续独立，未提交草稿不计入服务器统计。

默认仍为原列值顺序。支持范围沿用原不同值能力，二进制、BIT、JSON、空间等未证明类型不放开。本轮不提供直方图、抽样、百分比或完整数据剖析。

## 实现

- `table.valueOptions` 新增可选固定 `order`：`value`、`count-desc`、`count-asc`；旧缺省请求和回包不增加字段，不改变配置、凭据或写协议。
- 次数排序使用内层原 `COUNT(*)`，在 `LIMIT 501` 之前生效；外层继续按数值计数及原值／ENUM、SET 序号排序，不按展示用的十进制字符串排序。
- 原列与内部 `n/v/b/s` 聚合别名同名时增加原表限定，防止值序被内部计数或字节别名遮蔽。
- 回包绑定原对象、列、LIKE 原文和排序；计数保持十进制串，并用 BigInt 核单调性。缺少／错误排序、未知 SQL 字符串或倒序计数均拒绝。
- 保留原独立只读会话、冻结筛选、前后元数据／身份、警告、字节预算、501 组探测、取消及严格收尾。界面只在显式读取时提交排序，原任务和取消均结算前不释放占用。
