# SQLite SQL 结构与数据导出

## 使用

在 SQLite 表或视图页打开“导出全部筛选行”，选择 SQL 格式。普通表提供“仅数据”“仅结构”“结构及数据”；视图提供“仅结构”。原数据模式继续只输出 INSERT，不隐式增加建表语句。

入口沿原表页，打开表页仍会读取有界浏览数据；仅结构导出任务本身不读取数据，不应用筛选、排序或字段投影。结构及数据读取已应用筛选下的全部匹配行，保持多列排序，包含全部非生成列并允许调整顺序。生成列由导出的原表定义恢复，不直接 INSERT。切换内容或格式后需重新选择文件；取消选择保留原配置和文件。

结构包含原 CREATE、目标关联的显式索引与触发器，以及原 AUTOINCREMENT 高水位。两种结构模式均保留该高水位，避免数据筛选或空表使后续编号回退。原库不存在对应序列行时不伪造。

## 脚本与执行边界

- 独立物理只读连接在同一事务内核对原表定义与列摘要、读取结构并流式读取数据；不借查询会话，不执行导出的 SQL，不写源数据库。
- 脚本顺序为 BEGIN、CREATE、显式索引、可选数据、准确目标表的序列、触发器、COMMIT。触发器在数据之后恢复，避免回放已有记录时重复触发副作用。不生成 DROP、IF NOT EXISTS、关闭外键或 ATTACH；在新目标中执行，遇错必须停止并回滚，不能选择“遇错继续”，否则后续数据与序列语句仍可能作用于已有对象。
- 外键父表、视图依赖、触发器引用的其它对象需要先准备；本功能是单对象导出，不能代替整库备份。执行前审阅原定义和目标环境，发生错误时核对并回滚该脚本事务。
- 附属对象使用导出开始时的目录快照，不声称与先前分页属于同一时刻。虚拟表、影子表和系统表不提供结构导出。
- 定义与名称按原 SQLite UTF-8／UTF-16 字节严格核验；坏编码、定义 NUL、无法确认对象归属或目录预算超限时失败，保留旧目标文件。目录最多 1,000 个对象、2MiB 定义。
- 原 DDL 原文完整写入文件。若原定义以尚未换行的 `--` 注释结束，必须补一个换行再写分隔符，否则后续语句会被注释吞掉；回放后的 SQLite 目录可能保留这一个必要换行，不能宣称该情形目录字节完全相等，其余定义继续严格比对。
- 继续使用原文件令牌、文档归属、跨入口目标占用、严格编码、逐批 ACK、取消和原子替换协议。数据库退出确认后才发布文件；失败或未知不自动重放。
