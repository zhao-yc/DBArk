# PostgreSQL 逐条编辑勾选记录

在表页网格勾选当前页的记录，再点击「逐条编辑勾选记录」。窗口左侧列出勾选的原行号，右侧展示当前记录的原主键、原字段值及已有草稿。切换记录会保留各自的输入。每批最多 100 条，整份草稿仍受原有行数、页数和大小限制。 [Navicat 记录表单说明](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/data_rdbms.html#form-view)

普通字段可分别填写文本、NULL、DEFAULT 或十六进制字节。选择「保持原值」会撤回该字段的已有草稿。主键和生成列不开放批量编辑，之前在单条表单暂存的其他字段仍保留。取消窗口保留原草稿。

点击「暂存整批编辑」后，窗口输入一次写入本机草稿。即使本次撤回了最后一条草稿，仍可点击「撤销整批编辑」恢复。下一次编辑或成功刷新、翻页后结束该撤销机会。预览和提交沿用原行版本复核和原事务。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时检查、严格类型检查、构建和 7 项定向单测通过。定向验证不同值、旧行身份、既有字段保留和撤回最后一条草稿。
- 完整单元回归覆盖 1,336 个测试文件，27,497 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 实库通过 5 项回归。两条非相邻记录在预览前后保持原值，确认后分别写入文本、空字符串、NULL 和原始字节，未勾选记录保持。独立核对原表和零剩余连接后清理容器。
- macOS Electron 逐条编辑专项通过 5 项检查。核对取消、撤回最后一条草稿、切换保留输入、整批撤销及明确提交后的大整数主键和逐行原值。截图已检查，退出后独立复核数据库、零剩余连接和临时配置清理。
- macOS Electron 原 PostgreSQL 工作区整套用例按既有 120 秒、零重试门槛通过 79 项检查，包含原批量填充和删除、表页导航及正常退出。成功轮复核原数据、零剩余连接和临时配置清理。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
