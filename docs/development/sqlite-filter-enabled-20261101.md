# SQLite 筛选条件启停（开发源码）

SQLite 表或视图的“筛选与排序”增加单条条件启用、全部启用和全部停用。启停仅编辑表单，点击“应用 SQLite 筛选排序”后从首页读取；刷新、翻页、列头排序、完整导出和生成查询继续使用已应用条件。停用条件保留字段、运算符、类型、原值和位置，修改停用条件不会自动启用。

## 实现与兼容

- 原有严格条件合同增加可选布尔字段 `enabled`，省略时沿用启用行为，不改写旧请求或设置格式。NULL 比较仍省略值。
- 共同 SELECT 构造器先验证完整条件和列白名单，再跳过停用谓词及其绑定值；全部停用不生成 WHERE，AND／OR、多列排序及分页上限保持。完整导出仍走原只读流，不改成逐页拼接。
- 停用条件仍占 32 条条件和总值预算，非法类型、越界整数、非有限实数、坏十六进制、非法 Unicode 和失效字段均拒绝；不截断原值，不隐式转换精度。
- 筛选组件只拥有草稿更新端口，按原父标签、忙态、模态、渲染和卸载状态检查；不创建会话或事务。未提交修改仍走原放弃确认，取消不改变当前页或已应用条件。
- 完整导出预览标明启用数量和每条状态；全部停用明确提示读取所有记录。结构单独导出不应用数据条件。
