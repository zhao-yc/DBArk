# PostgreSQL CSV 导入样本与无表头文件

打开表页「导入 CSV」，选好分隔符和「首行是字段名」，再选择 UTF-8 文件。有字段名的文件会预填同名目标字段。无表头文件将首条记录作为数据，源列按位置命名。可逐列映射，也可点击「按目标列顺序映射」后再核对字段。

- 选择文件时只读预览。预览区显示最多 5 条完整数据记录和前 12 列，长值在完整字符处截短。未加引号的空字段显示为 NULL，带引号的空字段显示为空字符串。采样前缀约 256 KiB，表头或无表头文件的首条完整记录需在此范围内。超过预览范围或遇到不完整记录时，已有完整样本仍可查看。解析器使用字段引用状态区分两种空值。[CSV Parse 字段引用状态](https://csv.js.org/parse/options/cast/)
- 更改分隔符或首行模式会清除文件选择、样本与映射。重新选择后确认追加。文件能力绑定首行模式，服务端以匹配的 `HEADER` 选项执行原生 COPY。预览只在当前窗口显示，提交阶段使用原文件字节，数据库负责校验整份文件。[PostgreSQL COPY](https://www.postgresql.org/docs/18/sql-copy.html)
- 表级写权限、目标列复核、独占事务及提交回执沿用[表页 CSV 导入](postgres-copy-import-20261105.md)。
