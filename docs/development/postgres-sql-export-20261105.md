# PostgreSQL 表页 SQL 数据导出

在普通表或分区表的表页应用筛选和排序，点击「导出数据」并选择 SQL。勾选输出列、选择保存位置后开始导出。脚本以 UTF-8 保存，包含当前筛选的全部匹配记录，并以原 schema 和表名为写入目标。

- 回放前准备结构兼容的同名表，并使用一条无活动事务的 UTF-8 PostgreSQL 连接。脚本使用单一事务和有界多行 INSERT。用 psql 回放大文件时，可使用 `-v ON_ERROR_STOP=1 -f 文件名.sql`。
- 标识列可保留原值，GENERATED ALWAYS 标识列使用 `OVERRIDING SYSTEM VALUE`。计算生成列由目标库重新计算，省略的普通列由目标库按其默认值或 NULL 处理。脚本范围是数据行，建表、索引和序列当前值属于独立恢复步骤。[PostgreSQL INSERT](https://www.postgresql.org/docs/18/sql-insert.html)
- PostgreSQL 直接解释文本字面值。NULL、空文本、二进制、数组和 JSON 保留数据库语义。回放事务内设置源会话的日期、时区、间隔、搜索路径及相关格式，以匹配源数据文本解释。源会话的 `extra_float_digits` 须大于 0，目标 PostgreSQL 也须支持脚本所用的时区和区域设置。
- 文件先写同目录暂存，游标事务和连接正常结束后再原子发布。沿用表页来源及列权限校验、取消和大小预算。视图可继续使用 CSV、JSON 或 XLSX，COPY 导出属于后续工作。

## 验证

- Mac 类型检查、构建和 3 项定向单元测试通过。SQL 格式的公开请求固定 UTF-8，沿用原表页和文件令牌。
- Mac 完整单元回归覆盖 1,325 个测试文件，27,424 项通过，10 项 Windows 系统 `tar` 检查按平台跳过。
- Server-200 独占 PostgreSQL 18 实库 5 项通过。对同名兼容表执行生成脚本，核对 67 条筛选记录，包括显式标识列、重算生成列、NULL、空字符串、带引号与换行的文本、BYTEA、数组、JSONB、精确小数、浮点位模式、货币值和跨时区时间。
- 后一批 INSERT 违反目标约束时，第一批已写入的记录随事务回滚。分区表的脚本回放将两条记录路由到各自分区。低精度源会话拒绝导出并保留此前文件，视图和计算生成列的 SQL 请求也被拒绝。
- Mac 原生窗口用例 1 项通过，21 个观察点，单 worker、120 秒、零重试且关闭 trace。第二页发起导出后实际 SQL 包含全部两条匹配记录。原窗口正常退出，独占库和临时配置目录已清理。
- 首轮回放对比将主键转换成文本排序后截取记录，误将未匹配行纳入基准。只读核对原保留库的实际值后，改用数值主键排序和真实筛选构建基准，复验通过。两轮失败现场均保留。
- WIN11-TEST 会话不可达，本轮未派发，按约定在 Mac 验证。Windows 原生窗口和安装包尚待验收。
