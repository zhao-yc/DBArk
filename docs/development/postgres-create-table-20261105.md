# PostgreSQL 图形化建表

本批推进 Navicat 对标矩阵 R01。PostgreSQL 数据库右键菜单和中央表列表提供「新建表」。

## 使用

1. 在目标数据库打开「新建表」。从当前账号可创建对象的 schema 中选择目标，填写表名和可选表注释。
2. 依次添加字段，选择类型和可空性。可配置 varchar 长度、numeric 精度与小数位、主键、唯一、整数标识列、默认值和字段注释。勾选多个主键字段时按表单顺序组成复合主键。
3. 默认值可用文字，日期和时间字段另可选择当前日期或当前时间。标识列可选始终生成或默认生成。文字值由 PostgreSQL 校验实际类型。超过字段长度的 varchar 默认文字会在预览时拒绝。[PostgreSQL CREATE TABLE](https://www.postgresql.org/docs/18/sql-createtable.html)
4. 点击「预览建表 SQL」，核对数据库、schema 和生成的语句。点击「确认创建表」才执行。确认成功后原目录刷新，客户端打开新表记录页，可再用「查看结构」核对。
5. 若结果提示待核对，先在原库目录确认实际状态，再决定下一次操作。

## 范围

- 本批支持普通持久表和 15 种内置类型，最多 128 个字段。表名、schema 与字段名按原字符引用，按 63 个 UTF-8 字节限制名称，执行前核对服务器标识符限制，提交前核对实际 schema 和字段顺序。[PostgreSQL 标识符规则](https://www.postgresql.org/docs/18/sql-syntax-lexical.html)
- 预览只读，核对 schema 权限、名称占用和文字默认值。确认使用同一份由引擎生成的 SQL，预览与原文档、连接修订和目标 schema 身份绑定，且只能消费一次。创建、注释与实际对象核对位于同一事务。
- 自定义类型、外键和 CHECK 设计、生成表达式、表分区设计、现有字段和索引编辑仍在对标范围内。它们可通过已经接入的 PostgreSQL 查询工作区执行相应 SQL。
