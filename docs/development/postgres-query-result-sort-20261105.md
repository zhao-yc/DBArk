# PostgreSQL 查询结果排序

查询返回结果后，点击列头可依次切换升序、降序和取消该列排序。「多列排序」可先设置规则，再一次应用。上方规则优先，同值时比较下一列，所有键相等时维持原返回顺序。点击「恢复原返回顺序」可清空当前排序。

- 支持整数、NUMERIC、REAL、DOUBLE PRECISION、布尔和常见文本列。整数与 NUMERIC 的有限值按原数字文本精确比较。浮点按数据库已返回的值比较。对支持特殊值的数值列，NaN 等值且排在正无穷之后。日期时间、二进制及未知类型保持禁用。[PostgreSQL 数值类型](https://www.postgresql.org/docs/18/datatype-numeric.html)
- 默认升序 NULL 在后、降序在前。可在草稿中显式指定 NULL 在前或在后。文本默认按本地 UTF-16 顺序比较，也可为单个文本键选择忽略大小写。文本顺序可能与数据库排序规则不同。[PostgreSQL ORDER BY](https://www.postgresql.org/docs/18/queries-order.html)
- 排序只重排当前已返回记录，包括已经截断的结果。排序后旧行位置对应的勾选会清空，重新勾选后导出按显示顺序写出。排序期间数据库查询历史和事务状态保持。
