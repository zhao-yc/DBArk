# 查询结果快照文件（开发中）

## 用户流程

在查询页保存当前已返回结果或固定结果，也可在没有活动数据库会话时打开快照文件。打开后新增一份固定结果，复用现有网格、筛选排序、原 SQL 查看和固定结果比较；不替换编辑器正文、当前执行结果或事务，不建立连接或执行 SQL。

文件按原样保存结果值及源 SQL，其中可能含敏感内容。只保存已经返回的范围，保留结果截断标记，不能代替完整流式导出；不会额外附带连接配置、单独的认证字段或会话身份。打开只把源 SQL 当文字展示，不执行。

## 格式与边界

- 版本化 UTF-8 JSON，类型为 `dbark.query-result-snapshot`，建议扩展名 `.dbark-result.json`。
- 保留内部列键、重复显示名、类型、NULL、空字符串、二进制及精确文本；所有 Number 用显式标签保留有限值和负零，`insertId` 保持字符串。
- 文件总量最多 16MiB，10万行、4096列、100万格；字段、字符串及 Base64 都有界。沿用固定结果最多5份、累计16MiB的独立内存预算；超限拒绝整份，不截断或替换旧结果。
- 严格拒绝不支持的版本、额外运行状态、访问器、非法 UTF-8、损坏 Base64、重复解码后的 JSON 字段名及不完整行。原型同名的真实列键作为自有数据保存。

## 文件与异步行为

渲染进程只传声明文档，文件路径由原生选择器提供。主进程进行单句柄有界读取及文件身份复核；保存通过同目录独占临时文件、分批写入、同步、关闭和替换提交，不静默覆盖已知变化的目标。

原选择器、IO和清理结束前保持占用。切页、换源、关闭或撤销只废弃本地发布，不假称已取消在途文件操作；旧回包不能清除新任务。保存结果未知时保留提示并禁止自动重发，后续明确手动保存属于新的操作。

## 验证计划

单元测试覆盖编解码精度、边界与损坏输入、真实临时文件读写及迟到资源收尾、正式 Main IPC 归属门和 QueryTab 接线。Windows离线 Electron 两条专项已验证真实文件保存、正常退出、新进程重开及准备／文件流程零数据库请求；安装包、macOS和活动事务组合另验，当前暂不发布。

当前类型、构建、11文件269项相关单元及八文件100项旧查询回归已分轮通过；两新进程保存／重开后的文件哈希相同，原查询保持，精确临时文件清理闭合。原局部类型声明、RAM测试选择器和Windows launcher身份断言失败保留，默认／列举只验证关闭门；范围及原件见[分轮验收](../../tests/integration/acceptance-query-result-snapshot-20261028.md)。
