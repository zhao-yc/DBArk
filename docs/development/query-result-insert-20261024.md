# 将已返回查询结果写入已有表

## 功能与操作

查询结果工具栏提供“写入已有表”和“写入勾选行”。输入是当前筛选、排序和显示列对应的已返回行副本；不会重新执行源SQL，也不会包含因结果上限而未返回的数据。打开窗口不连接数据库或执行写入。

依次选择目标连接、数据库、基本表，显式读取目录和结构。按源列位置及内部键配置映射，避免重名展示列匹配错误；可跳过源列，不可重复映射目标列。预览列出准确目标、全部映射、总行数及最多20行SQL样本；样本不是完整执行清单。确认前须准确输入“库名.表名”并勾选风险说明。

目标TIMESTAMP按用户指定数值时区解释，默认`+00:00`，不推断来源时区。BIGINT、DECIMAL、日期时间原文、NULL、空字符串和二进制使用类型化值；不经过浮点数转换。JSON保留输入原文传给服务器，但服务器原生JSON的规范化、重复键和数值语义仍由目标数据库决定。

## 写入边界

- 只追加INSERT，允许无主键表；不更新、替换、忽略冲突或创建目标表。
- 目标必须为可证明完整定义和事务边界的InnoDB基本表。生成列不可映射，遗漏列须可空、自增、生成或具有可用默认值。
- 当前要求直接TRIGGER或相应ALL授权，以证明触发器目录完整；存在触发器或无法证明无外部副作用的默认表达式、生成式、CHECK等定义时拒绝写入。角色间接授权与未知表达式不推测安全。
- 预览校验全部行；确认后独立连接取元数据锁，重核实际服务器身份、完整定义及映射，再在一个事务内逐行参数化INSERT，整批只COMMIT一次。
- 任一插入警告、冲突或不明确状态均停止。只有原事务受保护且收到ROLLBACK确认，才报告整批回滚；断线、取消KILL或提交响应丢失时保留未知状态，不自动重放。
- COMMIT发送后取消只能等待原动作和连接真实收尾；已确认提交优先于晚导航、取消和附加收尾异常。源查询、父结果、原会话事务和系统剪贴板保持。

## 预算与归属

沿用结果导出预算：最多100000行、1024列、200万单元格、单字段256KiB、单行1MiB、总数据32MiB。引擎最多8个预览，含在途数据及元数据总预留64MiB；预览有效期120秒。SQL样本最多4MiB，目标定义最多2MiB。

令牌绑定真实IPC主文档、连接修订、断开代次、目标完整定义及实际服务器。应用在首次等待前消费令牌；更改来源、目标、映射、时区、导航或连接配置均使原预览失效。任务历史只记录进度和结果概要，不保存行值、生成SQL或驱动错误原文。
