# 定位未完成的 SQL 语句

## 操作及边界

查询发生部分失败后，提示区提供“定位未完成SQL”。按钮只选择、滚动并聚焦执行时的原编辑器，不修改正文、撤销栈或结果，不创建任务、历史，不执行、继续或重放SQL。选中的是已确认的整条语句，不把服务器消息中的行号当作准确错误字符。

支持全文、选区、当前语句和类型参数模板。重复SQL使用执行调度确认的数值位置，不能搜索第一份同名文本。范围不确定、模板预检失败、尾部未闭合或读取后续模式失败时，不猜测位置，按钮禁用。失败语句可能已部分执行，定位不表示它尚未执行。

光标、选区移动不影响定位。正文修改、Undo恢复同文、模型替换、关闭标签或连接修订变化使旧定位永久失效；非活动标签、忙碌、模态或关闭处理中暂时禁用。定位失效不阻止原查询执行，不自动切换到其它模型。

## 实现

`QueryFailure.sourceRange`为可选的UTF16半开区间，相对实际发送的原始模板输入，不含客户端终结符；当前语句模式相对完整输入。参数展开不改变模板位置，不附带参数值。Main任务、历史和配置格式保持原行为。

`SqlScriptScanner.pushLocated`与原`push`采用相同SQL文字一致性要求。未知模式候选位置不同则省略范围，不增加执行拒绝；逐句消费和动态`sql_mode`保持原调度。完整模板后、绑定前确认位置，语句结束及下一次模式读取前撤销，不能将已完成位置错误标给后续扫描失败。

渲染端捕获真实Monaco模型、版本、全文和实际选区基址，参数对话框打开时捕获，执行时转交。独立定位租约只接受安全整数、原模板及全文边界，拒绝拆分CRLF、代理对和迟到结果；与执行当前语句的短期意图分开管理。
