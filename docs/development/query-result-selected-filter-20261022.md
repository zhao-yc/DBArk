# 查询结果勾选值加入筛选

本批开发在查询结果工具栏增加“勾选值加入筛选”。先勾选需要的行，再点击目标列中的任一单元格；活动格只指定列，不要求属于勾选行。点击按钮生成草稿，审阅后点击“应用筛选”才整理已返回快照，不重新发送 SQL。取消保留原筛选与排序。

## 条件语义

- 非 NULL 原值按显示行顺序精确去重，生成 `IN` 条件；逗号、换行、空串及文字 `NULL` 均为普通原值，不拆分或猜测。
- 全部为 NULL 时生成空值判断；混合时生成 `(IN (...) OR IS NULL)` 子组，再与旧完整表达式整体按 AND 组合。旧 OR 保留括号，停用条件保留原文。
- BIGINT、DECIMAL、日期和时间复用已有类型往返检查，不转换成浮点数或 JavaScript 日期。字节和未知类型仅支持全部勾选值为 NULL。
- 最多 128 种值（含 NULL）、100000 行、1024 列，单值 4096 UTF-16 单元、累计原文 8 Mi 单元；重复值仍计扫描预算。超过预算整批拒绝，不截断。条件树继续限制为 32 个条件、16 个组、8 层。

## 选择与历史

捕获绑定当前真实行列和父级已接纳的精确勾选索引。换选择、换列、排序、筛选、换结果、连接或任务变化后，旧按钮不能提交后来选择。观测到原值漂移后即使恢复也不复活原捕获；读取自有数据描述符，不执行 getter。

结构预算通过后才打开草稿；失败保留原选择、视图和排序。实际应用沿既有完整筛选与多列排序共同试算，成功记一次历史，可整体撤销和重做。表数据编辑页不提供此查询快照入口。
