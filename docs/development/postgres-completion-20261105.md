# PostgreSQL 查询补全

本批推进 Navicat 对标矩阵 R01。PostgreSQL 查询编辑器可用 Ctrl+空格或键入点号、双引号请求补全。候选包括 PostgreSQL 常用关键字、schema、表、视图及直接关系字段。

## 使用

1. 在 `FROM`、`JOIN`、`UPDATE` 或 `INSERT INTO` 的关系位置输入前缀。接受 schema 后继续选表或视图。未限定位置选中表时会插入明确的 schema 和关系名。
2. 在 `SELECT`、条件表达式或直接写入列列表中，可以根据语句中直接引用的关系补全字段。例如 `SELECT o.` 可结合 `FROM "销售"."订单" AS o` 查找 `o` 的字段。候选显示 PostgreSQL 返回的数据类型。
3. 补全插入的带引号名称保留大小写和内部引号。多个可访问的 schema 含有同名关系时，请写明 schema。显式限定也可固定搜索路径变更后的目标，但补全仍按默认角色检查目录权限。[PostgreSQL schema 搜索路径](https://www.postgresql.org/docs/18/ddl-schemas.html)

## 范围

- 元数据通过目标数据库的独立连接读取，适用该连接默认身份及搜索路径。补全不会占用查询标签的事务，查询标签专属临时对象、会话内角色和搜索路径变更暂未进入补全目录。[PostgreSQL 可见性与权限函数](https://www.postgresql.org/docs/18/functions-info.html#FUNCTIONS-INFO-SCHEMA-TABLE)
- 词法屏蔽注释、字符串、dollar-quote 和位置参数。当前识别直接关系、显式 schema、逗号表清单和常见别名。CTE、子查询和集合运算的完整字段推断仍待推进。
- 请求只传解析后的目录目标和前缀。切换标签、修改连接或编辑 SQL 后撤销原建议，单编辑器串行等待原请求收尾。目录有条数和时间预算，超过条数可继续输入前缀。
- 函数签名、字段悬停、查询定义导航和 Windows 安装包验证仍在后续范围。
