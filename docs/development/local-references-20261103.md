## 使用与边界

在可编辑 SQL 查询的关系限定段、别名声明或 CTE 名称上按 `Shift+F12`，或使用编辑器右键的查找引用入口。列表包含本文声明及已确认引用，双击定位并选中原词；正文、模型身份及撤销栈保持。

```sql
SELECT s.id, s.name FROM subject AS s WHERE s.id > 1;
WITH q AS (SELECT 1 n) SELECT q.n FROM q;
SELECT d.n FROM (SELECT 1 n) AS d WHERE d.n = 1;
```

支持原声明分析器已确认的别名、CTE、派生表、相关子查询、遮蔽和 UNION 分支，以及明确库限定的本文物理表绑定。`q.col → FROM q → WITH q` 归到同一声明；显式别名保持自己的身份，不合并同名但不同作用域的对象。

这里只索引当前语句内已支持的关系引用，不是全库依赖、字段引用、输出别名、变量引用、重命名或 SQL 诊断。名称按原文精确匹配，不猜服务器大小写规则。嵌套 WITH 等原解析器不支持的形态继续不可用；没有语义边时不以文本匹配补齐，也不推断“零引用”。SQLite 本轮不注册此入口。

## 实现与资源

- 在独占 Worker 内反向索引已有声明解析结果；不修改普通补全、悬停及 F12 的语义。最多 256 个同名候选，超过预算整份拒绝；不截断列表冒充完整结果。
- 启动保持 8 秒、分析保持 2 秒；ready 后才发送有界正文。完成、替换、取消、异常、超时及卸载均终止准确所属线程，超时不交付部分列表。
- 回包严格核对字段、当前语句内完整同名 token、声明和有序无重复引用；只允许原模型 URI，不接受文件地址、SQL 或执行内容。
- 无会话草稿只用缓存连接事实；已有会话仅读前后两份 `query.completionState`，核模式、库、版本及对象代次。没有连接、元数据、查询执行、历史、任务或配置协议变更。
- 模型编辑／替换、标签作用域变化、模态、取消及卸载使迟到结果失效。
- 原生验收发现 Monaco 0.55.1 的树活动节点 Delayer 在关闭列表时产生未处理取消。正式补丁只消费该 Promise 的真实 `CancellationError`，普通错误、同名 `Canceled` 和字符串仍交正式报告通道；原三处高亮修复保持。补丁、锁文件及两个实际源码文件均受构建字节门保护。
