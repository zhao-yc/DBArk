# PostgreSQL 会话查询超时

在查询工具栏打开「查询超时」。语句超时限制服务器处理每条 SQL 的时间，锁等待超时限制每次获取锁的等待时间。两项均使用 0 至 2,147,483,647 之间的整数毫秒，0 表示禁用相应超时。两项都启用时，语句也可能在锁等待达到上限之前先触发语句超时。[PostgreSQL 语句和锁等待超时](https://www.postgresql.org/docs/18/runtime-config-client.html#GUC-STATEMENT-TIMEOUT)

窗口显示实际数据库、物理 PID、当前值和会话默认值。原事务空闲时可修改或恢复。客户端从服务器目录读取毫秒数和默认值，应用前核对物理会话和旧值，用一条 SQL 设置两项，再读回确认。回执不完整时需重新读取。设置仅作用于当前查询标签的物理会话。[PostgreSQL pg_settings](https://www.postgresql.org/docs/18/view-pg-settings.html)

应用设置期间保留原结果和执行历史。后续 SQL 的超时由服务器执行，并沿原查询错误和事务状态展示。显式开启遇错继续时，语句超时仍会停止本次脚本。
