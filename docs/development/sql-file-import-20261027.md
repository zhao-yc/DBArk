# SQL 文件导入：失败位置与真实回执

## 使用入口

在表的“导入”窗口选择 SQL 脚本、编码及文件，再明确开始。SQL 仍按文件自身事务
边界执行；CSV／JSON 的分批或整文件选项不作用于 SQL，不自动重连、重放或补提交。
结果改为 SQL 专用报告，分别显示完整返回语句数、服务器累计影响计数、停止阶段和
原语句编号。累计影响计数不代表最终提交或保留的行数，溢出或非法计数显示未知。

文件失败位置来自原扫描器的连续范围，不用重复 SQL 文本搜索。行列从 1 开始，范围
末端不含，按所选编码解码并移除 BOM 后的 UTF-16 字符计数；不是原编码字节偏移。
CRLF 跨块仍只计一个换行，emoji 占两个 UTF-16 列，DELIMITER 控制行不计作执行语句。
当前位置未知时明确省略，不猜服务器错误中的 line 数。

## 事务与来源边界

初始模式、读取、解析、执行、模式刷新及最终状态确认分别记账。成功语句之后刷新
模式失败仍关联已完成语句；文件读取、解析和 EOF 收尾失败不虚构下一条 SQL 失败。
服务器 ERR 先到时仍等原 command end 后才处理回滚，失败 CALL 的部分响应不当成
完整语句影响数。完整响应之后才到的取消保留已完成前缀，不伪造下一条执行失败。

附加 ROLLBACK 仅在原连接尝试一次。完整合法 ACK、零警告、零影响计数及原连接
新鲜 IN_TRANS 关闭状态全部成立才显示确认；断线、ACK 缺失或警告均不能称已回滚。
即便本次回滚确认，也不能据此推断原 COMMIT 是否执行，或撤销此前提交、DDL、
非事务表及外部副作用。任务取消和连接收尾错误不能抹掉已有回执。

报告只消费原任务、文件配置、目标和连接修订仍有效的回包；连接或目标 ABA、卸载
以及迟到成功／错误都不能恢复旧报告。缺失或矛盾回执显示“未确认”，不借通用行数
显示成功。原请求真正结束前保持 busy；取消始终指向原任务，明确重新选文件后才可
发起新执行。消息同时限制字符、UTF-8 与 JSON 转义预算，不额外保留原文件全文。

## 内存与兼容

复用现有 SQL 模式及扫描器，不引入另一套分号解析。源位置队列最多 65 Mi UTF-16
码元，随扫描器最早保留偏移释放前缀；支持原 64 Mi 码元单语句范围，不保存全文件
行索引。超预算或范围歧义只省略位置，不能制造错误坐标。

SQL 专属回执是 `files.import` 的可选扩展；旧 `rows` 保留兼容估算，不能作为 SQL
提交证明。CSV／JSON 的输出、映射、提交策略及导入配置不变。

来源守卫，再修行为。首轮组件复验 39 通过／1 失败，是新 RAM 夹具遗漏原有计时器
端口；仅补端口后原断言通过。首轮核心类型检查因闭包阶段变量窄化报 TS2367，增加
显式阶段读函数，未关闭检查或改状态机。

完整回归首次 18273 通过／1 失败／1 平台跳过：新运行期包装误吞了非 CSV 夹带标题
参数的原拒绝。恢复建连前校验，保留内部防线和旧断言。同时独立审阅发现旧非严格
关闭不能捕获真实传输退出错误；先用真实 `closeMysqlConnection` 加传输替身复现
两红例，再仅为 SQL 独立连接开启严格关闭，不把 QUIT 当成事务 ACK。

1554 项相关、完整 18276 通过／1 项 POSIX 跳过、构建通过。默认双门关闭时两个
专项均跳过，列表明确发现 1 个正式窗口整例。其后只修两个独立默认关闭专项夹具，
产品、单元和原构建逐字不变；再次类型／列表／默认门验证通过，不冒称重跑完整单元。

首个 MySQL 5.7 实库整例在取消断言失败：单独的 SLEEP 被取消后正常 ACK，产品正确
保留第 4 条已完成事实。MySQL [官方语义](https://dev.mysql.com/doc/refman/8.4/en/miscellaneous-functions.html#function_sleep)

PROCESSLIST 行的实际表上下文探针在六实例全部取得 1317 并物理关闭。仅替换取消
夹具，不接受两种阶段任选，也不改变产品；原 completed3／execute4／回滚等门保留。

最终六端口各 1 个真实 Engine 复合例通过，0 跳过；13484 严格 TLS。覆盖三编码、
BOM／CRLF／emoji、420 KiB 跨块 DELIMITER、重复 SQL 精确位置、已提交前缀保留、
未提交尾事务回滚、原 ERR 和真实取消／尾句未发，以及原命令 end、流和线程收尾。

正式窗口首轮观察夹具误把建表 ACK 当行数组，尚未执行产品导入；原失败和现场保留。
原窗口正常退出后，依据起始资源附件两次独立盘点唯一空表、无其他对象／外键／会话，
精确恢复随机库，没有补写 owner 或降低测试保护门。仅修 ACK 分类和观察连接关闭

残留，核对连接均物理关闭。首版 DUAL 探针第二组线程 ID 未落盘，不计逐 ID 总数，
