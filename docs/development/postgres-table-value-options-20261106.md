# PostgreSQL 表页按不同值筛选

在表或视图的「高级筛选」中点击「按不同值筛选」，选择字段后点击「读取不同值」。服务器在当前已应用的筛选范围内分组并返回每个值的记录数，包含当前页之外的记录。候选每页显示 50 项，最多显示 500 项。输入文字再读取可在完整范围内查找，搜索区分大小写，`%` 和 `_` 按字面匹配。 [Navicat 值列表筛选说明](https://pgsql.navicat.com/en/company/aboutus/blog/1862-navicat-16-improvements-that-maximize-productivity)

勾选一个或多个值，再点「加入筛选草稿」。可选择排除，NULL 和空字符串分别处理。新条件和草稿已有条件同时生效，已有的「任一满足」及子组会保留。检查草稿后点击「应用高级筛选」，从第一页读取并沿用原排序。已有快速筛选时，沿用高级筛选面板显示的替换提示。

支持常用内置数值、文本、布尔、UUID、日期时间、BYTEA 和 JSONB 字段。字段的原生比较规则用于分组，次数和可选值以精确文本返回。超过筛选长度限制的值只展示预览。服务器以舍入模式输出浮点数时，该字段的读取会给出精度提示。多行值从勾选到再次编辑均保留原换行。 [PostgreSQL 浮点输出说明](https://www.postgresql.org/docs/current/datatype-numeric.html#DATATYPE-FLOAT)

候选查询与原表页及连接版本绑定。读取失败、原页切换或权限变化时，应从当前表页重新打开。打开面板、翻阅候选和加入草稿不重新读取数据页。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时检查、严格类型检查、构建和 34 项定向单测通过。
- 完整单元回归覆盖 1,332 个测试文件，27,488 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 实库通过 5 项回归。新增断言覆盖超过 500 组、字面搜索超出初始范围的候选、长值预览、数值精度、二进制和 JSONB 原值、NULL 补集、换行、跨窗口能力拒绝及 DDL 后原页失效。
- macOS Electron 定稿通过 1 条端到端测试，共 76 项检查。窗口读取并勾选当前页之外的记录，确认加入草稿时原表页保持，显式应用后才显示匹配记录，清除后返回原表页。独立复核原表记录、零剩余连接及窗口临时配置清理。验收截图展示勾选状态和服务器次数。
- 首轮原生定位读取了字段标签中的选项文字，补充独立可访问名称后保留原断言、时限和零重试配置复验。失败日志和临时配置保留，专用容器确认零连接后停止并保留。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包和其他 PostgreSQL 版本待验。
