# SQLite 列表筛选（开发源码）

SQLite 表、视图及读写／只读连接的筛选增加“属于列表”和“不属于列表”。明确选择文本、INTEGER、REAL 或 BLOB 类型，逐项填写列表；每条最多 128 项。编辑、增加或删除值均只修改草稿，点击原“应用”后才从首页读取，保留原排序及未提交修改确认。

## 语义与保护

- 每条列表保持同一明确类型，数字原文不经浮点转换；空 TEXT 与空 BLOB 是合法的一项，空列表、混合类型和 NULL 项拒绝。需要 NULL 时使用原“为空／非空”条件。
- 原生 IN／NOT IN 外保留 `typeof` 限定。NOT IN 仅匹配所选类型的不等值，不隐式纳入 NULL 或另一存储类型；多个类型可分别建立条件。原列排序规则保持，重复值不重复返回同一记录。
- 原严格合同增加 `values`，列表不夹带旧单值或第二界，其它运算符也不能夹带被忽略的列表。切换运算符保留列表草稿，停用仍验证类型、格式及预算。
- 列表先按稠密数组、自有数据描述符、数量及累计长度检查，再解析复制；过大数组不会深复制，数组元素或列表项的访问器不会被执行。所有条件原值合计仍受 131072 个 UTF-16 单元预算约束。
- 保持 utility 原 1024 个位置绑定上限，分页预留两个，类型参数和启用值共同计数；超限在投递前拒绝，不提高原 driver 资源门槛。停用值不生成绑定，但仍计原值预算。
- 分页、完整流式导出和生成查询共用构造器；导出摘要以带引号的原值展示完整列表，空字符串与非空字符串可区分。生成意图持有列表及各项引用，已观察失效后不复活。
- 不新增 IPC 命令、不改凭据或设置格式、不自动执行或写库，不访问系统剪贴板。

## 验证

WIN11-TEST 本轮远程会话不可达，未派发同轮任务；按既有回退授权，本机 Windows 串行验证合成 SQLite 数据。原生继续采用 120 秒、单 worker、零重试及失败现场保护。

- 最终严格类型检查、构建退出 0；保留既有第三方注解及包体积警告。首轮类型检查因新测试夹具的字面量推断过宽失败，仅补明确类型声明后通过，原日志保留，未改产品逻辑或验证门槛。
- SQLite 相关 **169 份测试、3530 项全部通过**。覆盖四类原值、空 TEXT／BLOB、重复值、非法／混合／空列表、getter 与巨型数组、停用、预算与引用失效；三种源编码及不同亲和性保持，真实流式 JSON 文件逐行读回、精确值和源文件字节保持。
- 1024 个绑定的准确边界经过真实 utility 执行并确认正常退出；1025 在投递前拒绝。保持原 worker 的参数保护，未通过调大底层上限来接纳列表。
- 扩展原 `table` Windows 窗口 **69.2 秒通过**：列表编辑零读取、INTEGER／TEXT 同文区别、NOT IN 同型语义、BLOB 字节匹配及清除恢复逐项核对；原范围、原格、启停、多列排序、分页、视图及重启断言保持。
- 扩展原 `edit` Windows 窗口 **36.6 秒通过**：列表筛选只读分页，清除恢复准确原行，读阶段零编辑预览／提交；随后原范围、原格、增改删、预览取消、并发冲突整批回滚及重启不重放继续通过。
- 两轮各 1 通过、0 失败／跳过／重试，四次原 owner 正常退出与两个成功临时目录清理均有原件。源码及全部构建 SHA-256 在执行后保持一致；原始日志、退出码、报告和汇总保留在忽略的 `.cache/sqlite-list-filter-20261101/`。

既有失败及旧失败目录单独保留。本轮未验全仓测试、macOS 两架构、安装包、系统原生文件对话框输入及明亮／窄窗口专项，不以相关结果代表全量验收。不打包、不安装、不创建 Release，持续目标保持进行中。
