# PostgreSQL 记录表单视图

在表或视图的记录页选择「记录表单」。表单打开当前选中的记录，未选中时显示本页第一条。「上一条记录」和「下一条记录」在页边界读取相邻页，并停在对应的末条或首条。跨页仍按当前筛选和排序读取。选择「网格视图」可返回对应记录。 [Navicat 表单视图手册](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/data_rdbms.html#form-view)

用字段导航定位字段，或按名称搜索。表单默认遵循网格的可见列顺序，勾选「显示网格隐藏字段」可临时查看其余字段。较长值可展开查看完整原文，SQL NULL 与空字符串分别标识。

在具备更新能力的普通表中，选择字段写入方式并编辑。字段支持文本、SQL NULL、DEFAULT，以及 BYTEA 的十六进制输入。未暂存输入须先暂存或放弃，才能切换记录、页或视图。「暂存本行」将本行改动交给原记录草稿，可跨页保留。最后用「预览记录修改」核对 SQL 并确认整批提交。新增和删除仍由表页工具栏发起。只读关系、生成列及待删除记录可查看原值。

## 验证

- macOS 上 Node.js 24.17.0 运行时检查、类型检查及源码构建通过。
- macOS 完整单元回归共 1,329 个文件，27,479 项通过，10 项 Windows 系统 tar 用例跳过。
- Server-200 独占 PostgreSQL 18 实库回归 5 项通过。原生用例通过独立连接核对了表单暂存期间的原值、确认后的修改及恢复后的原值。两次测试均确认原记录与零连接后清理容器。
- macOS Electron 原生窗口回归通过，共 73 项观察。覆盖只读视图、字段导航和完整原值、隐藏列、未暂存输入的标签脏标记、双向跨页草稿、返回网格定位及正常退出。已核对截图和临时配置清理。
- Windows 虚拟机不可达，本轮按约定使用 Mac。Windows 原生操作、两平台安装包和较早 PostgreSQL 版本待验。
