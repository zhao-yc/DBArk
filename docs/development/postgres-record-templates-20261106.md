# PostgreSQL 记录模板

在支持新增的 PostgreSQL 表页选中一行。需要复用尚未写入数据库的字段时，先暂存该行编辑，再点击工具栏的「记录模板」。勾选所需字段并命名保存。全部字段默认不选，生成列、标识列、序列默认列和明确暂存为 DEFAULT 的字段会省略。

选择已保存的模板并点击「预览模板」。核对字段后，输入要生成的条数，再点击「生成新增草稿」。已有模板也可在没有选中行时应用。批量条数计入表页当前草稿上限。使用「撤销本批模板草稿」可恢复应用前的草稿。准备写库时，继续点击「预览 SQL」，核对本次所有变更后明确提交。

模板按原连接、数据库、架构和表保存在本机，包含所选字段的实际值。源连接配置或所选字段的目录属性变化后，需要重新核对。PostgreSQL 数值使用原有精确文本，二进制、零字节及 SQL NULL 分别保存。未选字段由数据库处理默认值。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时检查、严格类型检查、构建和 77 项定向单测通过。定向用例覆盖配置库冷重开、库与架构隔离、连接重绑定、精确值、列变更和超限拒绝。
- 完整单元回归覆盖 1,337 个文件，27,508 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 的 5 项实库回归通过。macOS Electron 专项通过 12 项检查，覆盖已有的复制和回滚修正，以及模板保存、超限拒绝、整批撤销和刷新后的无选中行应用。
- 独立连接核对模板保存、草稿生成、撤销及 SQL 预览阶段的数据库原行。明确提交后只新增两行，原行保持，长小数、`bytea`、NULL、标识列和默认值均准确读回。Electron 正常退出，临时配置清理，两轮隔离库均在零连接复核后清理。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包和其他 PostgreSQL 版本待验。
