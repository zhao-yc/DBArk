# SQLite 全部筛选行流式导出

## 使用

SQLite 表／视图页的“导出全部筛选行”读取全部匹配行，而“导出当前页”仍只保存当前已返回数据。完整导出使用**已应用**的 typed 筛选和多列排序，与当前页码无关；尚未应用的表单条件不会进入文件。

在独立窗口选择 CSV、JSON、SQLite INSERT SQL 或 XLSX，勾选字段并调整输出顺序，再选择文件和明确执行。CSV 支持逗号、分号、Tab；文本格式支持 UTF-8、UTF-16LE、GB18030，不能无损编码时停止并保留旧文件。XLSX 使用 UTF-8 内部编码及现有 Excel 文本协议。

SQL 默认“仅数据”只包含 INSERT，不含建表、索引或触发器定义，也不会自动执行。先在目标 SQLite 库准备相同结构；视图不提供数据 SQL 导出，生成列不能列入 INSERT。新增“仅结构”和“结构及数据”的用法见[结构导出](sqlite-schema-export-20261101.md)，视图仅支持其中的仅结构。SQL 字面量保留存储类型、64 位整数、REAL、原二进制、空文本、NULL 和包含 NUL 的文字；CSV／JSON／XLSX 沿原工作区精确字符串与二进制协议，不承诺由文本文件恢复动态存储类型。

TEXT 在同一次 SELECT 中按源库实际 UTF-8／UTF-16LE／UTF-16BE 编码核对原字节，保留字段中的 U+FEFF。无效编码明确拒绝，不静默替换为 U+FFFD；旧目标文件保持。含 NUL 的 SQL 使用 `char(0)` 和平衡连接表达式，避免依赖回放目标库的编码，也避免大量 NUL 导致表达式深度线性增长。

## 执行与安全边界

- Main 只接受结构化条件、有序物理列名、目录摘要及对应格式的原生文件选择令牌，不接受 SQL、任意路径、凭据或私有回调。
- 独立强制只读 SQLite 连接在同一事务快照读取真实目录和一次无 LIMIT 的 SELECT。逐批 ACK 等待文件写入，不循环分页、不把整表送进渲染层，不借查询标签事务，也不添加用户 SQL 历史。
- 导出开始时重新核对原定义与完整列事实摘要；导出期间使用自己的快照，不承诺与先前浏览页属于同一时刻。
- 源数据库连接正常关闭并确认准确进程退出后，才原子替换文件。替换开始前可取消，替换完成是既成事实，不因迟到取消改称“未执行”。失败需重新选择文件并人工重试。
- 导出目的不能是任何已保存 SQLite 数据库及其 WAL、SHM、journal 文件，真实目录链接和硬链接也受保护。配置／主文档失效会精确取消原任务；清理未确认时保留资源及跨入口目标占用，不能提前交给下一次导出。
- 普通查询保留原 100 万行、32MiB 结果上限；完整导出使用独立只读流式通道，单个序列化行／批次不超过 1MiB，文件不超过 10GiB。XLSX 另外保留原 Excel 行列、单元格、总文本和 ZIP 预算。超限明确失败，不保存被截断文件。
