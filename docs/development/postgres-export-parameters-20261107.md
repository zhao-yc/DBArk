# PostgreSQL 参数查询完整导出

在完整查询导出窗口点击「设置导出参数」，为 `$1`、`$2` 等连续位置参数填写类型和值，再点击「采用本次导出参数」。核对格式、编码及文件后执行导出。参数表单提供文本、整数、小数、布尔、日期时间、字节和 NULL 类型。

参数按 PostgreSQL 扩展协议绑定，整数和小数保留十进制文本，二进制转换为字节，NULL 绑定为空值。同一编号可重复使用。表单识别会跳过字符串、dollar 正文及注释，并要求两种字符串模式都同意语句边界和参数编号。引擎投递前按独立导出会话的实际模式复核数量、顺序和类型预算。

修改参数后需重新选择保存文件。值只保留在当前导出窗口内存中，关闭窗口后释放。导出沿用独立只读会话、分批游标及原子文件发布。普通 PostgreSQL 参数查询与完整导出共用绑定验证，统一支持参数表单允许的 38 位小数精度。
