# SQLite 表格复制与粘贴新增草稿

开发源码为 SQLite 读写编辑网格增加单元格／勾选记录复制，以及有映射和预览的多行新增草稿。数据库写入仍复用原集中提交事务，不增加 IPC、任意 SQL、自动提交或新的凭据路径。暂不发布，不更新已安装客户端。

本增量提供粘贴为新增记录；覆盖已有多格区域的粘贴继续开发，不将这一子能力计为完整 SQLite 或完整剪贴板工作包。

## 日常操作

- 聚焦单元格后使用系统复制快捷键，复制准确原值；勾选记录后复制整行，按当前页显示顺序导出。生成列也可复制。普通程序得到 TSV，DBArk 通用格式保留 NULL／二进制，自定义 SQLite 格式另保整数、实数原文、DEFAULT 和来源列名。
- 在编辑网格粘贴，或从“更多 → 数据传输 → 粘贴为新增草稿”打开窗口。可以直接粘贴，也可以手工输入 TSV；不会读取后台系统剪贴板。
- 逐来源列选择目标字段和写入类型，再明确预览。SQLite 原生列名按准确名称建议映射，自动跳过目标生成列及不存在的列；普通文本按可写列顺序建议，不猜表头或数字。来源较宽时可以跳过多余列。
- 自增／主键不会被猜测省略，复制到同表时请明确跳过键列或选择 DEFAULT。NULL、空串、文字 `NULL` 和 DEFAULT 各自不同；未映射字段用默认值，生成列不能写入。
- “暂存新增草稿”只在本地追加全部记录，可一步撤销／重做。再通过底栏原“预览 SQLite 修改”核对 SQL，并输入准确原表确认提交。关闭本窗口不会丢弃已有行修改。

“保留来源类型”指保留绑定类型；最终存储仍受目标字段的 SQLite 亲和性、约束和默认值影响，例如 TEXT `001` 写入 INTEGER 字段可能转为整数 1。显式类型转换不能以近似 Number 改写 int64；不支持的转换整组拒绝。未知或损坏的 DBArk 专用格式不会静默降级为普通文字。

## 保护与限额

复制最多 1,000 行，粘贴最多 500 行；源矩阵最多 10,000 格，每种 MIME 和整组有效值最多 2MiB UTF-8，单值最多 65,536 个 UTF-16 单位。新草稿与已有增删改合并后，还须通过原 500 项修改／10,000 实际字段／2MiB 输入门。先验证再分配行编号并一次发布；输入、预算或行编号校验失败不产生半批草稿、不消费原撤销记录或预览。

窗口绑定准确编辑器、原页和整批行引用。失活、连接修订、结构变化、后台占用或卸载会撤销原粘贴票据；恢复同名目标不复活。新窗口可以使用仍有效、已接管的原编辑草稿，不依赖浏览器已经释放的只读页令牌。复制、输入及预览不投递数据库写操作；提交未知不自动重放。
