# 复制已返回结果的筛选条件

## 操作与约束

每条条件旁新增“复制条件”。副本紧随原条件，保留同组 AND／OR 关系、字段、比较方式、区间端点、候选值及大小写选项。修改副本只改草稿；显式应用前保持原筛选、排序和选择，不重发 SQL。

副本拥有全新稳定节点 ID 和独立候选值数组。移除原条件后，旧按钮不能复制占据相同显示编号的新条件；取消、结果或连接修订变化后，旧面板动作不能进入新草稿。输入法组合期间禁止复制，全部组仍共用原32条条件上限，未扩大比较／文本预算，不增加持久化或 IPC。
