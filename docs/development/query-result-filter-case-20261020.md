# 已返回结果的文本大小写选项

## 入口与语义

在SQL工作区的“筛选已返回结果”内，为具体文本条件勾选“忽略大小写”。默认关闭；包含、前后缀、相等、不等于、多值及其否定均可独立设置，嵌套组内也可混合敏感条件。数值、时间、NULL与空文本判断不显示选项；切换到这些判断或更换字段会移除隐藏设置。

比较仅对控制器自有键使用无区域设置的 `String.toLowerCase()` Unicode小写映射，不进行完整大小写折叠、重音消除或字符规范化。例如 `I` 与 `i` 相等，`İ` 对应 `i` 加组合点，`ß` 不等于 `SS`。不采用数据库collation，不发送SQL。NULL仍仅通过显式NULL条件纳入，否定条件不包含NULL。

原结果、规则输入、排序、复制及导出保留原文。默认区分大小写的旧规则不变；同一字段可同时参与敏感及忽略大小写条件。草稿重开保留设置，取消不更改已应用视图；旧回调、输入法组合和视图撤销沿用原租约。
