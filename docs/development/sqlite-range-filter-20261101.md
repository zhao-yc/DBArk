# SQLite 范围筛选（开发源码）

SQLite 表、视图及只读／可编辑连接的筛选增加“介于（包含两端）”和“不介于”。明确选择 TEXT、INTEGER 或 REAL 类型，填写起始值与结束值；编辑仅改变表单，点击原“应用”按钮后才从首页读取，原排序和未提交修改确认保持。

## 实现与边界

- 复用原严格条件合同增加 `between`／`notBetween` 和可选 `secondValue`；范围必须有两个同类型的边界，不接受 NULL 或 BLOB。其它比较不能在公共请求夹带第二值，旧请求和旧行为保持。
- INTEGER 保留有符号 64 位十进制原文；REAL 两端都要求有限数；TEXT 保留空串、控制字符、Unicode 及日期时间微秒文本，不转换 JavaScript Date。
- 共同构造器使用原生 BETWEEN／NOT BETWEEN，并保留 `typeof` 限定与原列排序规则。BETWEEN 包含两端，不自动交换逆序边界；NOT BETWEEN 仍仅比较同一存储类型的原值，NULL 使用原 IS NULL／IS NOT NULL 条件。
- 两个边界均受原单值格式及长度限制，并共同计入全组 131072 个 UTF-16 单元预算，停用条件仍完整验证；停用后两端都不进入 SQL 或绑定参数。换成普通比较／NULL 时，表单保留结束值但不提交隐藏边界，切回范围可继续编辑。
- 分页、完整流式导出和生成查询共用谓词；导出摘要显示两端，生成查询捕获第二值及准确对象引用，旧值变化后计划失效。完整导出不继承当前页长度或偏移。
- 不新增 IPC 命令、不改驱动或写入协议，不自动执行，不使用系统剪贴板，不改变设置存储格式。
