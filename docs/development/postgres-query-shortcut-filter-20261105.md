# PostgreSQL 查询结果快捷筛选

选中结果网格中的数据单元格后，可以用「追加等值条件」或「追加排除条件」把原值填入筛选草稿。选中 NULL 单元格时，对应条件为「为 NULL」或「非 NULL」。

勾选一批行并点选目标列中的单元格后，使用「勾选值加入筛选」。勾选行决定候选范围，活动单元格决定使用哪一列。勾选值同时包含非 NULL 与 NULL 时，草稿将候选列表和 NULL 判断放入同一个 OR 子组，再整体以 AND 加入已有条件。

筛选草稿保留整数、精确小数、浮点特殊值、布尔和文本的返回原文，按 PostgreSQL 结果的类型校验。二进制、日期时间及未知类型可使用 NULL 判断。查看或取消草稿时保留已有筛选，点击「应用筛选」后更新当前已返回结果。

## 验证

- macOS 类型检查、源码构建和 72 项快捷筛选定向单元测试通过。Server-200 独占 PostgreSQL 18 实库回归 5 项通过。
- 完整单元回归覆盖 1,326 个文件，27,440 项通过，10 项 Windows 系统 `tar` 用例按平台跳过。
- macOS Electron 源码窗口最终复验 1 项通过，覆盖 28 个观察点。窗口核对相差最后一位的 NUMERIC、取消等值草稿、应用排除条件、将勾选的 `NaN` 与 NULL 组成 OR 子组，并把后续条件以 AND 追加。执行历史和原结果范围经过复核。
- 最终截图核对候选列表与 NULL 子条件可同时审阅。通过轮次正常退出，专用配置、数据库与容器已清理。WIN11-TEST 会话不可达，Windows 原生窗口和安装包待验收。
