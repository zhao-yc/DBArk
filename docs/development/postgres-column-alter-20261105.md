# PostgreSQL 已有字段属性与删除

从表页或对象菜单打开「查看结构 → 编辑字段」。选择字段和操作，使用「加入改动」暂存，再预览实际 SQL 并确认。同一批可混合新增、重命名、修改和删除，后续操作使用前序操作产生的字段名。

- 类型支持常用内置类型、varchar 长度、numeric 精度和小数位。PostgreSQL 使用赋值转换处理已有行和默认值，已有文本排序规则在目标为 text 或 varchar 时显式保留。需要自定义 `USING` 表达式的转换仍使用 SQL 编辑器。
- 空值约束可设置或移除。存在 NULL 或其它约束阻止修改时，按 PostgreSQL 错误处理。默认值可设置为文字常量或清除。字段注释可替换，留空会清除注释。
- 删除字段须在预览后额外勾选确认。执行 `DROP COLUMN … RESTRICT`，外部依赖会阻止删除。本表内直接引用该字段的索引和约束可能随字段移除。[PostgreSQL ALTER TABLE](https://www.postgresql.org/docs/18/sql-altertable.html)
- 锁定后复核原表身份和目录。提交前回读字段名、保留字段序号及已修改的类型、空值状态、默认值存在状态和注释。晚期失败时回滚已执行的同批操作。

编辑范围是有管理权限的普通表。任意表达式默认值、用户自定义目标类型、主外键及索引设计仍需使用查询编辑器。视图、分区和继承表可查看结构。

## 验证

- Mac 类型检查、构建和 5 项定向单元测试通过。覆盖同批名称及类型跟踪、文字转义、默认值长度限制和保留字段序号。
- Mac 完整单元回归覆盖 1,320 个测试文件，27,408 项通过，10 项 Windows 系统 `tar` 检查按平台跳过。
- Server-200 独占 PostgreSQL 18 实库 5 项通过。外部视图依赖使删除失败，回滚同批类型、默认值、注释和空值约束改动。解除依赖后，核对保留的文本排序规则、原记录、索引和新插入行的默认值，也验证默认值、注释和空值约束可清除。
- Mac 原生窗口用例 1 项通过，16 个观察点，单 worker、120 秒、零重试且关闭 trace。验收覆盖实际 SQL 预览、删除单独确认、真实目录及原表页刷新。原生窗口正常退出，复验测试库及临时配置目录已清理。
- 首轮实库断言把依赖详情中的视图名当作主错误消息，复验以依赖冲突摘要和实际视图及结构作为证据。首轮窗口断言遗漏网格列头可访问名称中的数据类型，按原始页面快照改为匹配完整列头后复验通过。两处首轮失败现场保留。
- WIN11-TEST 会话不可达，本轮未派发，按约定在 Mac 验证。Windows 原生窗口和安装包尚待验收。
