# SQLite 参数执行当前语句

在 SQLite 查询编辑器中将光标放进含 `:name` 的语句，打开「执行方式」，选择「参数执行当前语句」。弹窗显示该条原始 SQL 及参数名称。重复名称共用同一个值。核对类型和值后，点击「执行参数 SQL」。

识别只读取原会话状态和 SQL 词法。Main 用全文与 UTF-16 光标重新定位，原生 SQLite 在执行前检查语句尾部，并在同一物理会话中绑定值。原临时对象、事务和标签语句超时继续生效。光标或正文变化后需要重新打开表单。成功回执和原生错误的位置仍对应原编辑器中的全文坐标。

相邻语句既不参与参数识别，也不会执行。历史只保存原生回执中的本条模板。值保留在执行期间，结果和显式固定的快照可能包含实际值。现有参数执行入口继续按选区或全文运行。

## 验收范围

- Node.js 24.17.0 的运行时检查、严格类型检查、源码构建和 216 项相关测试通过。扩大回归的 95 项通过、72 项失败均与变更前基线逐项一致。
- macOS arm64 Electron 源码通过参数和当前语句两个专项。新增场景核对相邻写入未发生、只绑定当前参数、保留有符号 64 位整数原值、仅记录执行模板、返回全文范围。光标移开后恢复原位，原表单仍拒绝发送。另验证原有选区、全文、原事务及重启不重放。
- 测试通过 Monaco API 设置合成脚本和光标，执行经真实窗口菜单及表单触发。SQLite 文件和 Electron 配置均为专项独占，退出后核对清理。
- Windows 测试会话不可达，本轮使用 macOS arm64。Windows、macOS x86_64 运行和安装包待验。本增量尚未正式发布。
