## 匹配与传输

包含、整个字段相等、前缀、JavaScript Unicode正则及大小写语义沿用现有实现。只有包含/正则枚举后续非重叠命中，整个字段/前缀仍只有起点匹配；不将正文转小写后再套位置。普通文字仍完整转义；零宽正则按Unicode码点推进，末尾零宽保留，不拆代理对或无限循环。跨度为原字符串UTF16的offset/length，行列由实际Monaco模型换算，不用渲染后的换行反推索引。

每条SQL最多200处，额外探一处以区分“正好200且完整”与“仍有未显示命中”。只传有界数值跨度，不传每处正文；原结果概要仍只显示每字段首处。整个结果页仍最多128KiB，密集命中导致更早续页，未消费记录留给下一页，不丢弃或重复。上限提示明确说明仅在已显示范围内循环，不伪造总命中数。

用户正则仍只由原固定 `savedQuerySearchWorker` 执行：单条2秒、初始化5秒、256MiB/32MiB线程堆、每页25记录、1000查询命中、2活动页/16句柄、5分钟期限不变。超时、取消、退出仍等待真实terminate，页间无活动匹配线程。主进程和渲染进程没有新增用户正则求值或SQL执行通道。

## 模型与来源绑定

仍经 `queries.read` 用原文SHA256/CAS复核，再生成独立新SQL标签；来源缺失须明确选替代连接，替代后默认库未知。原草稿、结果、会话和事务不变。只名称命中的查询没有SQL高亮。

内存导航绑定保存查询ID/原文摘要、完整SQL、目标连接及其修订。安装装饰前必须与实际当前模型全文、工作区原文和来源绑定一致；若Monaco对混合行尾做了规范化而全文不再完全相同，保守拒绝高亮，不能继续套旧位置。模型对象和版本固定，范围先核有界、整数、顺序、非重叠及代理对边界，并复制为本租约快照。每次导航重核；设置装饰/光标等可重入步骤也再核，防止外部监听同步编辑后发布旧ready。

模型内容变化、换模型、销毁、工作区换源/摘要/连接修订、连接删除或标签关闭同步清理装饰与监听。失效为终态，撤销、切回来源、迟到回调不能恢复。组件效果重挂载也保留原模型/版本及终态，不能重新安装旧范围；同一模型同版本的React严格模式重订阅不冒充用户关闭。明确关闭高亮也永久结束本租约。导航只移动光标，不选择覆盖命中文本、不改SQL、不触发执行。高亮/范围/搜索条件不写入工作台设置。
