# 执行历史插入当前查询（开发中）

## 操作与边界

执行历史保留“打开为新查询”，另提供“插入当前查询选区”。后者复用打开历史窗口时的活动查询和Monaco选区，读取经原摘要校验的完整历史SQL，再以一次编辑替换选区；不执行SQL、不切换当前连接或默认库，也不新建标签。插入后支持一次撤销。

历史记录的连接及数据库仅说明来源，插入仍处于当前查询上下文。用户应检查SQL再自行执行。非查询页、未就绪编辑器、运行或关闭中的查询不能接收插入。

## 实现要求

- App按标签登记编辑器捕获工厂；旧注册清理只能删除自身，不影响新注册。
- 捕获原标签、活动导航、模型、版本和选区；编辑、切页及ABA、连接或会话变化、取消和卸载永久撤销旧请求。
- 历史读取复用 `history.read` 的编号与摘要，迟到响应不得覆盖当前草稿。
- 使用原Monaco `executeEdits` 和撤销边界，保持其它查询状态；不增加可写历史或执行SQL的IPC。

独立审查发现的“读取成功后、分页资源释放期间关闭仍插入”竞态已修复：普通关闭先撤销插入权限，资源释放晚返回只完成关闭。组件回归分别延迟读取回包及分页释放，不能用窗口消失代替未发生编辑的断言。

## 验证安排

定向单元覆盖归属失效、旧工厂清理、摘要失败及原打开新标签流程。真实Monaco验收复用现有离线合成历史fixture，核对完整SQL替换、一次撤销、关闭后迟到读取不插入；合成记录不代表数据库执行成功。没有真实活动事务或结果时，只能声称原无事务、无结果状态保持。

WIN11-TEST类型、165项相关单元及构建通过；原五项历史页回归通过，新增真实Monaco复合例在修正测试配置与精确定位后单独通过，原失败分别保留。确认完整正文替换、一次undo、关闭后迟到响应不改模型以及原未连接/无结果状态保持。3796提交完整CI也已通过：18773项单元、三平台源码/安装legacy各83通过/376跳过。实库活动事务/结果和公开发行另验，尚未发布；详见[分轮验收](../../tests/integration/acceptance-history-insertion-20261028.md)。
