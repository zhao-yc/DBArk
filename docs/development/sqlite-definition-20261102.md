# SQLite 本文声明跳转

## 使用

在 SQLite 查询正文中，把光标放在别名或 CTE 引用上按 F12，或按住 Ctrl 点击引用（macOS 对应 Command 入口已接入，待实际平台验证），跳到当前 SQL 内的声明。

```sql
SELECT s.id FROM subject AS s; -- 引用 s 跳到 AS s
WITH c(id) AS (SELECT 1) SELECT * FROM c; -- 引用 c 跳到 WITH c
SELECT d.id FROM (SELECT * FROM subject) AS d; -- 引用 d 跳到派生别名
```

支持显式／隐式别名、三种 SQLite 标识符引用、Unicode、同名内层遮蔽、相关子查询、嵌套／递归 CTE、复合查询各自分支，以及明确的 main／temp 表限定。只定位本文声明，不读取目录或打开物理表定义，不执行 SQL。

字段末段、未限定普通字段、未知绑定、同层重名、schema 段、字符串／注释／参数及声明自身不会被当作跳转目标。复合查询尾部 ORDER／LIMIT、表函数等未确认作用域不猜测目标；本能力不替代查找引用、诊断或重命名。

## 实现与保护

- 复用原 SQLite 词法和作用域模型，记录 CTE 头、FROM／JOIN 来源及别名的原 UTF16 范围；不按全文字符串搜索定位声明。
- 本地 Worker 新增固定 `definition` 意图；普通补全和悬停继续拒收声明范围，原补全／悬停不因本功能放宽复合查询限制。
- 对声明范围核数量、坐标、Unicode 边界、闭合标识符与同名关系，拒绝子串、出界、未知字段或 URI。Monaco 链接只使用原模型自身 URI。
- 独立分析 Worker 不借元数据读取或查询会话；模型、版本、取消、模态及卸载均撤销旧结果，继任须等待原线程终态。原 8 秒启动／1.5 秒分析预算保持。
- 不改 IPC、数据库引擎、配置格式、凭据或写协议。
