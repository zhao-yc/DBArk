# PostgreSQL 命名查询结果

在语句开头写 `-- NAME: 月度汇总` 并换行，或写 `/*NAME: 月度汇总 */`，执行后即可用名称辨认结果。单组行结果在操作栏显示名称，多组结果在选择器中同时显示序号、名称、命令及行数。同名结果可按序号分别查看。固定结果的标签保留名称，便于再次查阅和比较。

名称取自已返回结果的实际执行语句，后续编辑草稿时仍显示该次执行的名称。解析只读取语句开头最多 4096 个 UTF-16 单元，名称最多 80 个 UTF-16 单元。PostgreSQL 支持 `--NAME:` 和嵌套块注释。只有外层的名称标记有效，未命名结果与事务回执沿用原有显示。
