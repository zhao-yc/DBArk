# PostgreSQL 复制勾选记录

在 PostgreSQL 表页网格勾选当前页的记录，再点击「复制勾选记录」。窗口按原页顺序列出待新增的副本，带入每条记录的原值和已暂存字段。切换副本时保留各自输入，可以逐条调整手动主键、唯一字段及其他值。生成列、标识列及序列默认列初始省略。

点击「暂存整批副本」只生成新增草稿。取消窗口保留原草稿。暂存后可用「撤销整批副本」恢复暂存前状态。之后通过表页预览确认提交，任何一条副本写入失败时回滚整个事务。

每批最多勾选 100 条完整记录，整份草稿仍受现有行数、页数和大小限制。已标记删除或原页不完整的记录无法复制。此操作从当前页读取值。 [Navicat 网格追加记录说明](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/data_rdbms.html#paste-data-into-grid-view)

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时检查、严格类型检查、构建和 7 项定向单测通过。覆盖无行键复制、原页顺序、逐副本默认值、已删除来源和旧页拒绝。
- 完整单元回归覆盖 1,337 个测试文件，27,501 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 实库通过 5 项回归。预览时原值保持，第二个副本触发唯一约束后整批回滚，修正唯一字段后仅新增两条。首轮夹具页长为两行，第三行正确被拒绝，改为三行后复验；原日志和已停止的失败隔离库保留。
- macOS Electron 单条及批量复制专项通过 7 项检查。核对取消、分别编辑、整批暂存与撤销，提交后独立读回 2 条原记录及 2 个副本，包括精确主键、生成字段和二进制值。截图、正常退出、临时配置清理和零剩余连接均已复核。
- macOS Electron 原工作区用例按既有 120 秒、零重试门槛通过 79 项检查，原数据、退出和零剩余连接均已复核。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
