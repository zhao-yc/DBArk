# PostgreSQL 文件导入配置

在 PostgreSQL 现有表的导入窗口，CSV、JSON、TXT、XML 和 XLSX 都可以将读取设置及字段映射保存为本机命名配置。

1. 选择文件并完成字段映射，展开「导入配置」，读取列表，再命名并保存。已有配置可以明确更新或删除。
2. 重复导入时选择配置并应用，再选择本次文件。XLSX 会恢复标题行、首末数据行和文本协议，工作簿及工作表由本次显式选择。
3. 当前文件的源列和目标表的可写列均兼容时，程序一次填入全部映射。具名字段可以重排，无标题文件按源列顺序复核。不兼容时可改选文件，或取消套用后手工配置。
4. 核对字段映射并选择本次追加或匹配键策略，最后明确确认导入。

配置仅记录格式、编码、读取选项、源列和映射。文件路径、文件令牌、工作表 ID、行值、连接信息及写入策略都不会保存。PostgreSQL 原生 CSV 使用 UTF-8，非 UTF-8 的 CSV 配置可在支持该编码的入口管理。此功能复用本机配置仓库及其并发修订检查。

命名配置工作流参考官方手册。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html)
