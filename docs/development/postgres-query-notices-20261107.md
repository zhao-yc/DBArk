# PostgreSQL 查询服务端消息

在 PostgreSQL 查询页执行 SQL 后，如果服务端发来了消息，展开当前结果中的「服务端消息（数量）」。可查看级别和 SQLSTATE，搜索正文、详情、提示或上下文。每页显示 25 条；字段有内容时可单独展开。首错停止前收到的消息仍然可见，错误摘要和已完成结果保持原状。

点击「定位消息所属第 N 条语句」可选中原编辑器的语句模板，无须重新执行。只有原编辑器、来源和范围仍可确认时才允许定位。实际执行分析也能收到消息，但分析语句由客户端包装，消息不提供原文定位。

服务端决定发送哪些消息。客户端监听当前原语句的 PostgreSQL `NoticeResponse`，查询结束时解除监听，不另发诊断 SQL。`LISTEN` 收到的 `NotificationResponse` 属于不同协议消息，不进入此面板。[PostgreSQL 协议消息格式](https://www.postgresql.org/docs/18/protocol-message-formats.html) · [错误和提示消息字段](https://www.postgresql.org/docs/18/protocol-error-fields.html)

消息仅在当前执行结果中保留，不写入历史、任务记录、配置或固定结果。位置参数执行显示固定级别和有效 SQLSTATE；正文、详情、提示及上下文全部隐藏。驱动返回无法识别的级别时显示「未知级别」。普通执行中的已知连接认证材料在截断前清除。

每次最多保留 200 条消息及 512 KiB 报告。正文最多 4 KiB，详情、提示、上下文各最多 1 KiB；页面显示收到和保留的数量。超过上限只影响消息保留，原脚本仍按所选执行模式处理。
