# 表格草稿文件与显式恢复

本批已实现显式保存与恢复。WIN11-TEST 的 380 项相关单元及构建通过；后续审计适配和恢复页跳转修正的 168 项定向单元及构建也通过。实库首端因测试收尾审计不兼容而整例失败，六版本及正式窗口尚未闭合。当前继续开发，尚未发布，不计完整 D02／D04 工作包完成。

## 使用流程

表数据工具栏提供“保存表格草稿”和“恢复表格草稿”。只保存已暂存的新增、修改及删除；尚在单元格或表单输入框中的内容须先暂存。保存不会清除未提交标记，也不会发送数据库写入。

草稿文件未加密，含完整旧行和待提交值。界面须明确确认后才打开保存位置选择器；连接密码、私钥、连接证书及会话令牌不写入文件。文件格式为版本化 `.dbark-draft`，最大 8 MiB、1000 项变化；省略新增字段保持 DEFAULT，NULL、二进制、精确数值文本、时间文本及 JSON 原词法保留。

恢复要求当前表没有已有草稿或未暂存输入。选择文件后先查看增改删数量，再明确核验与恢复。主进程比较原连接 ID、库表及端点配置摘要；独立只读会话在一致快照中持有表元数据锁，核对当前结构和每条保存旧行。变化、缺失、重复原行、告警及取消均整次拒绝，不静默跳过。

恢复进入明确标识的独立草稿视图，只显示文件中的变更记录，不按当前页位置套用。分页和原分页导出关闭，保存时的完整 `before` 保持原样。记录生成新本地编号，恢复新增仍走复制键保护。恢复本身不执行 DML；用户仍须预览 SQL 并明确提交，提交时再次执行原完整旧值保护和整批回滚。

## 资源与失效边界

- 文件能力绑定原主窗口文档，不接受渲染进程指定磁盘路径。普通文件、严格 UTF-8、单句柄有界读取、同目录独占临时文件、同步和原子替换沿用既有安全范式。
- 标签、连接、结构或草稿变化永久撤销原租约；变回相同值不复活。已有父页草稿不合并、不覆盖。
- 核验取消仅投递原任务编号，原操作及取消请求都结算后才释放占用；不另建连接重试。
- 文件已经保存后原页失效，仍保留“文件已保存”的事实；磁盘替换结果未知时不自动重试。
- 端点摘要绑定连接配置，不证明 DNS 或故障转移后的物理服务器 UUID。新增行通过结构校验，不承诺提交时一定不发生唯一键或外键冲突。
