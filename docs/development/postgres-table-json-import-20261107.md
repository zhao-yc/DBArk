# PostgreSQL 现有表导入 JSON

打开有写入权限的 PostgreSQL 普通表或分区表，点击「导入数据」，选择 JSON 和文件编码。支持 UTF-8、UTF-16 LE 和 GB18030。文件顶层为对象数组。向导完整扫描文件，显示总记录数和源字段，预览最多显示 5 行、12 列。文件选项变化后需重新选择文件。

同名字段会自动匹配。核对映射，按需改选目标字段或跳过源字段，再点击「确认追加并导入」。完全未映射的目标字段使用数据库默认规则，计算生成列由 PostgreSQL 填充。已映射字段在某条记录中省略时写为 NULL，显式空字符串保留。二进制对象 `{ "type": "binary", "base64": "…" }` 映射到 `bytea` 后恢复为字节。

精确数值从源文本交给 PostgreSQL。嵌套 JSON 值可以映射到 `jsonb`。数据库检查字段类型、约束和权限。文件内容与预览时不符、类型无效或遇到重复主键时，整批数据回滚。成功后表页自动刷新。[从 JSON 新建表](postgres-csv-json-new-table-20261107.md)

## 验收

macOS arm64 使用 Node.js 24.17.0，通过运行时检查、严格类型检查、构建及 251 项定向单测。Electron 连接 Server-200 的隔离 PostgreSQL 18.6，通过四项端到端测试，另有一项 PostgreSQL 表工作区实库集成测试通过。现有表 JSON 用例覆盖 GB18030 和编码错选拦截、精确整数和小数、嵌套 `jsonb`、二进制、NULL 与空值、生成列和默认值、改名映射、提交后刷新，以及同长度源文件变化和主键冲突的回滚。XML 和 CSV／JSON 新表导入，以及已有表原生 CSV 路径通过回归。

隔离容器和回环转发已清理。Windows 虚拟机测试会话本轮不可达，Windows 原生和安装包验收待执行。
