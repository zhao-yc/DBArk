# 将已有筛选条件移至其它组

## 使用行为

已有多个条件组时，每条条件显示“分组”选择框，可移至最外层或任意已存在子组末尾。例如把 B 从 `A AND B AND (C)` 移入 OR 子组，得到 `A AND (C OR B)`，无需重新填写条件。只有点击“应用”才改变已返回结果；取消保留原树。移动原条件节点，保留字段、操作符、列表成员、上下界原文、大小写和启用状态；跨组重新挂载后恢复原选择框焦点。源组为空时继续显示，应用仍按原空组校验拒绝，用户可补条件或移除空组。

仅修改本结果快照的草稿，不重新查询、不转换精确值、不改变扫描预算或 IPC。组名按可见层级显示，身份使用内部稳定编号；旧事件、无效目标和组合输入期间拒绝移动。
