# PostgreSQL 关系结构查看

本批推进 Navicat 对标矩阵 R01。PostgreSQL 的表页、左侧目录和中央对象列表提供「查看结构」。右键入口直接读目录，适合只检查关系结构的场景。

## 使用

1. 在表页点击「查看结构」，或右键表和视图后从「设计与结构」进入。弹窗显示实际库、关系种类及关系注释。
2. 「字段」显示原始序号、类型、可空性、默认表达式、生成表达式、标识列、排序规则及注释。「约束」包括主键、外键、唯一、检查、排除和支持版本上的显式非空约束，并显示延迟、未验证和继承状态。「索引」显示方法、服务器定义、关联约束及有效状态。
3. 分区表显示分区键，分区子关系显示边界。视图和物化视图可切到「视图查询定义」，查看服务器还原的 SELECT。点击「将定义打开为查询草稿」才把这段 SQL 放进原数据库的查询标签，执行由用户在查询页明确触发。
4. 「刷新结构」重新读取当前关系。读取在独立只读会话中完成。服务端返回表达式和定义，界面按关系范围展示，便于核对已有结构。[PostgreSQL 系统信息函数](https://www.postgresql.org/docs/18/functions-info.html)

## 范围

- 支持普通表、分区表、分区子关系、视图、物化视图和外表的目录查看。支持已保存连接及用户可访问的 schema，要求关系的表级 SELECT 权限或可使用的所有者角色。
- 目录读取按原数据库和 schema 限定，字段、约束和索引共用一次目录查询的快照。连接配置或窗口文档变化时拒绝迟到结果。结构回包超出预算时整份拒绝，防止把不完整目录当成完整定义。
- 视图查询定义是服务器还原的 SELECT。可重建的全表 DDL、权限或触发器迁移、图形化结构编辑及函数等对象工作流继续推进。
