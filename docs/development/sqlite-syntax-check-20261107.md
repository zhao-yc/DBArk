# SQLite 原生语法检查

在 SQLite 查询页的「更多查询操作」里选择「检查 SQL 语法」，也可通过编辑器右键菜单或应用的查询菜单打开。检查使用编辑器全文。标签已有 SQLite 会话时复用它，首次使用时会打开该标签的会话。点击任一提示可选中对应的原始语句。编辑正文或切换来源会撤销旧提示。

检查逐句用 SQLite 原生接口准备并释放语句，不绑定参数或执行 SQL。已有临时表和当前事务仍可用于对象解析。同一脚本里的建表或设置不会改变后续检查的目录。提示覆盖整条原语句，准备失败可能来自语法、对象或当前权限。成功只表示准备通过，运行时约束和结果仍需实际执行才能核实。[SQLite 语句准备接口](https://sqlite.org/c3ref/prepare.html)

PRAGMA、ATTACH、DETACH 和受授权限制的语句会标为「未检查」。部分 PRAGMA 在准备阶段即可生效，因此即使带 EXPLAIN 也会跳过。检查可协作取消，不用结束原进程来中断检查。检查正文和诊断原文不写入任务概要或查询历史。[SQLite PRAGMA 行为](https://sqlite.org/pragma.html)
