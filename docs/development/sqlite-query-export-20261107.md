# SQLite 完整查询导出

在 SQLite 查询页打开「更多查询操作 → 执行与分析 → 执行并导出完整结果」。选中一条 SQL 时导出该选区，光标没有选区时使用编辑器全文。导出窗口可核对本次 SQL。带有 `:name` 的模板，先点「设置导出参数」，填写全部名称对应的类型和值，再点击「采用本次导出参数」。

选择 CSV 或 JSON、文件编码和保存位置，点击「执行查询并保存」。CSV 支持逗号、分号和 Tab 分隔符，按原结果列顺序写表头，可以保留重名列。JSON 生成对象数组，要求列名唯一。JSON 中整数和实数用字符串保存，NULL 用 `null`，BLOB 用带 Base64 的对象保存。导出以 SQL 实际返回的行数为准。需要固定行序时在 SQL 中写明 `ORDER BY`。

导出在独立的物理只读连接执行一条 SELECT 或 WITH 查询，读取已提交的数据。原查询会话内的临时表和未提交变更不随查询转移。参数通过 SQLite 原生接口绑定。任务按批次写入同目录的暂存文件，独立连接正常退出后才原子替换目标。替换开始前可取消任务。保存的 SQLite 库和对应的 WAL、SHM、Journal 文件受覆盖保护。执行 SQL、参数、结果和路径只在本次导出使用，任务概要仅保留状态和固定文案。
