# SQLite 全库结构搜索

从「工具 → 全库搜索」选择保存的 SQLite 文件连接，库范围自动固定为 `main`。可选结构名称或定义正文，再输入文字、前缀、完整值或本地 Unicode 正则。普通文字忽略大小写时只折叠 ASCII，百分号和下划线按原文匹配。

- 名称模式覆盖表、视图、字段、显式索引和触发器。字段命中可打开所属表或视图，显式索引与触发器命中可直接打开对象定义。
- 正文模式搜索表、视图、显式索引和触发器的目录 SQL。每个对象最多 2 MiB，支持 UTF-8、UTF-16LE 和 UTF-16BE。重新打开时核对当前正文摘要，文字命中可逐处导航。正则命中可查看当前定义。
- 名称每批最多检查 50 项，正文每批最多检查 10 项。续页只保留搜索条件、文件身份、目录版本和游标，批次间释放只读文件会话。文件被替换、目录版本变化或连接修改后需重新搜索。
- 使用独立只读会话，搜索不扫描用户数据。目录和定义的错误按所选策略处理，超限或失效会明确提示。临时对象、附加库和系统自动索引不在结构搜索范围内。切换「搜索数据」可读取已选表字段。[SQLite 数据搜索](sqlite-data-search-20261107.md)
