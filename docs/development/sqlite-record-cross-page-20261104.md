# SQLite 可编辑表记录表单跨页连续浏览

日期：2026-11-04。基线为 main `c0c3dbcb`，继续完善 D04／R02 高频记录工作流，保持 Electron／React／TypeScript 独立桌面架构。本批不创建正式发行、标签、安装包或部署，不代表完整 D04 或 Navicat 目标完成。

## 使用方式

在 SQLite 可编辑 `main` 表选中已有记录并打开“编辑 SQLite 当前行”。当前页的普通“上一条记录／下一条记录”继续跳过待删除行，修改可明确暂存后在本页切换。到达真实页边界时，按钮改为“上一页末条记录／下一页首条记录”，点击后沿用当前已应用筛选、排序和页长读取相邻页，准确打开新页首条或末条。

跨页要求当前表单没有尚未暂存输入，且本页所有记录没有新增、修改或删除草稿；其它行的草稿同样阻止跨页。拒绝时保留原字段正文、草稿、当前页和撤销历史，不自动暂存、询问放弃或提交。请先取消输入并明确处理草稿，再继续浏览。未应用的筛选草稿保持，但不会带入跨页请求。

只读取一次相邻页，不读取COUNT、不扫描空页或追踪其它对象。服务器数据变化仍可能导致分页重复／遗漏，不提供数据库快照分页。空页明确结束，可用原表页分页按钮返回；读失败清除自动打开意图，恢复原对象后仍需明确刷新并重新选行。

字段区改用通用Modal的可滚动正文，标题与底部导航／保存／取消栏留在窗口内，错误提示固定在操作栏上方，避免多字段表单把操作与拒绝原因裁切。

## 来源与交接

新增 `sqliteRecordPageNavigation.ts`：页内已有行定位、真实边界偏移和一次性续读意图。意图绑定原页对象、准确连接／表、结构键、来源及目标偏移、页长、方向、原标签／profile对象、连接及结构修订、已应用条件的引用和值，以及唯一原模态。只保存内存引用，不复制记录原值、不写配置。

旧表单先通过原 `inputCurrent` 和唯一模态校验，跨页前检查整页 `editor.changes` 及未暂存输入。干净时关闭自己的输入票据、释放原编辑器快照，再由原 `SqliteTableBrowser.load` 取得独占busy租约并读页；不增加IPC或引擎接口。只有准确新页结束读取并由新 `SqliteTableEditor` 实际接管后，才能消费一次首末行对象并建立新输入票据，不借同名行ID或页内序号复活旧行。

工作区同步订阅和模态MutationObserver留下永久撤权墓碑；标签／连接ABA、条件变化、普通刷新／分页、结构变化、停止、外来模态、空页、错页和卸载均不能让旧续读自动打开表单。未接管的迟到快照仍由原Browser准确释放，旧意图不取消或释放别的任务。新页初始化保留空页／失效提示，普通显式读取才清掉旧提示。

记录表单与原集中预览／提交协议保持，IPC白名单、数据库schema、任务持久格式及凭据处理均未变化。本批续读不保存到settings，重启不恢复未完成意图或旧记录表单。
