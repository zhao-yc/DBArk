# 外键 JOIN：分组与聚合查询

## 使用方式

表页进入“按外键生成 JOIN 查询”，明确预览父表结构后，勾选“生成分组聚合查询”。分组字段及指标独立于原明细选列；可选择双方真实字段、调整分组顺序，再添加 COUNT(*)、COUNT、COUNT DISTINCT、SUM、AVG、MIN、MAX 和自定义输出别名。没有分组字段时生成全体汇总，也可只分组不加指标。

空汇总不会用旧明细替代，打开按钮保持禁用。明细和聚合分别保留选列、排序及指标草稿，切换模式后逐字恢复；同一外键重读保持，换外键清空分组、指标及两类排序。修改别名不会把已有排序悄悄指向其它指标，失效排序明确保留旧目标，修正后才恢复预览。

原 WHERE（含嵌套组）在聚合前生效，GROUP BY 后可按所选分组字段和当前聚合输出多列排序、指定 NULL 位置；LIMIT 限制汇总结果，不是先截取输入。预览后仍只打开同连接独立查询，审阅后自行执行，不自动执行、保存或改变全局上限。

COUNT(*) 统计 JOIN 后行数，COUNT(父字段) 忽略 NULL，包括未匹配父行。父表值可能因多条子行重复参与合计／平均；COUNT DISTINCT 只对所选单字段按数据库规则去重。SUM／AVG 对整数及 DECIMAL 为精确值，对浮点数仍是近似结果，客户端不转换为 JavaScript 数字后再汇总。语义参见 [MySQL 聚合函数说明](https://dev.mysql.com/doc/refman/8.4/en/aggregate-functions.html)。界面提供独立说明，不把 JOIN 汇总误标成父表去重统计。

## 编译及来源保护

最多 20 个不重复分组字段、32 个指标。函数为固定白名单，SUM／AVG 仅接受整数、小数或浮点列，文本、日期、JSON、二进制不能隐式转换。别名按标识符独立引用、拒绝损坏 Unicode、NUL、空名、超长和大小写重复，也不能碰撞稳定分组输出别名；不允许原始表达式或任意 SQL 片段。

所有普通输出完整列入 GROUP BY，不猜函数依赖；排序只允许分组键或已声明指标。指标排序按原聚合表达式编译，避免别名与输入列同名，或 NULL 分桶时解析成其它来源。未选择分组的普通字段不会因关闭 ONLY_FULL_GROUP_BY 而获得随意取值的机会，相关服务器规则见 [MySQL GROUP BY 说明](https://dev.mysql.com/doc/refman/8.0/en/group-by-handling.html)。

明细模式的生成字节保持；聚合模式不继承隐藏明细投影。新增配置只在渲染层保存于本次草稿，不改 IPC、配置格式、数据库引擎或写协议。原完整 SQL 256KiB 预算继续生效。预览深冻结分组、函数、来源、别名和排序，独立打开前重读双方相关元数据并重算 SQL。未输出指标源列的类型变化同样撤销回执；忙态、旧输入／行回调、来源变化及一次性消费保持。

HAVING、任意表达式、多列 COUNT DISTINCT、ROLLUP／窗口聚合、任意多表与查询转视图继续开发，不计完整 O04。特殊类型的 MIN／MAX 等最终由服务器执行规则决定；本轮不宣称全部类型组合已验。
