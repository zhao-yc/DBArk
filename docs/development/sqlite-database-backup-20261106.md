# SQLite 整库备份与恢复

在已保存的 SQLite 连接行打开操作菜单，选择「备份 SQLite 整库」，然后选择一个新文件名。连接可处于只读状态。备份采用 SQLite 在线备份接口，从独立只读连接固定读取快照，包含快照时已经提交的 WAL 数据。当前连接里的未提交事务和临时表不在备份范围内。[SQLite 在线备份接口](https://www.sqlite.org/backup.html)

使用侧栏标题旁的「从 SQLite 备份恢复」，先选择备份文件，再选择一个尚不存在的目标文件。恢复完成后，在新建 SQLite 连接时选择恢复出的文件。备份和恢复都生成可独立打开的 SQLite 文件，保留原有数据库对象和数据。客户端在发布前执行完整性检查，已有主库及日志文件会拦截。

任务中心可查看进度状态或取消。文件先写到目标目录下的私有暂存目录，成功后用同卷硬链接原子发布。目标文件系统须支持硬链接，单次复制和完整性检查的进程时限为 5 分钟。
