# 按当前单元格值筛选表数据

## 完整操作

在表数据页选中普通单元格，点击“按此单元格值筛选”或“排除此单元格值”。入口打开原条件面板，带入字段、等值／不等值和原值；NULL改用IS NULL／IS NOT NULL。审阅或修改后点击原“添加条件”，才追加到既有条件并从第一页重新读取服务器。沿用当前全部／任一组合和排序，不把当前页当作全表。手动关闭再打开条件面板不复用旧快捷草稿。

使用原参数化`table.page`，不拼接单元格SQL。精确整数、小数、日期和文本字符串不转成JavaScript数值；空串、文字NULL和真正NULL分开。服务器按自身类型和排序规则比较；普通不等于也不包含NULL，界面明确提示。二进制、DEFAULT、非有限及已失精度数值不带入。字段／行缺失、隐藏列、重复身份、修改格或访问器拒绝；不读取getter。

有未提交数据、活动编辑器、表单输入、忙任务或过期结构时禁用快捷入口。点击时再次核原选择、已提交渲染、标签目标、连接修订及同步草稿，旧按钮回调不能带入后来单元格。预填只复制独立条件草稿，不自动读取、丢弃数据或提交。
