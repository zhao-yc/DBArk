# CSV 导入首行配置

## 功能与入口

表数据页选择“导入”，格式选 CSV。默认勾选“首行是字段名”，沿用已有按标题同名匹配的行为。文件没有标题时取消勾选，预览按“第1列”“第2列”…显示源字段，第一条记录保留为数据；逐列选择目标字段后执行。

无标题模式始终要求手动映射，即使目标字段也叫“第1列”。未映射的源列不写入；生成列不能作为目标，多个源列不能指向同一目标。切换首行选项保留所选文件，重新读取预览并清空映射，旧预览、迟到响应和原执行回调不能复用；改回原选项也需要当前预览。

## 文件与事务规则

- 支持 UTF-8、UTF-16 LE、GB18030，以及逗号、分号、Tab；不自动猜测标题或分隔符。
- `csvHasHeader` 仅适用于 CSV 导入预览与执行；省略等于 `true`，`false` 必须原样传递。JSON、SQL、Excel 和导出接口拒绝夹带该配置，显式 `undefined` 也拒绝。
- 按 CSV 记录解析，引号内换行属于同一条记录。每条记录列数须一致；无标题时空文件为零条，仅一个换行为一条空字符串记录；空白记录在多列文件中会因列数不符而失败。有标题模式保持既有空行跳过规则。
- 数值先保留为字符串；继续使用既有数据库类型与警告校验。`\N` 表示 NULL，`\\N` 表示字面 `\N`，空字符串独立保留；二进制目标可接收已有 `base64:` 协议。
- 预览最多20条，提前结束释放原文件流；正式导入流式读取完整文件。仍限 InnoDB，每500行提交一批，失败回滚当前批，先前提交保留并报告。整个文件不是单一原子事务，连接中断后不自动重放。
