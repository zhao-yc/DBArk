# SQLite 查询回执

执行 SQLite 查询后，选择当前结果即可查看语句序号、本条耗时和行变更计数。带结果列的语句还会显示 SQLite 产生的完整行数，以及客户端保留的行数。脚本达到行数或字节预算时，两者可能不同。筛选后的数量继续在结果工具栏显示。

行变更计数来自原连接在该语句前后的 `total_changes()` 差值。它可包含触发器和外键动作。SQLite 对 REPLACE 冲突处理删除的行等有自己的计数规则。事务可能在之后回滚，判断提交结果应结合事务状态与后续回执。[SQLite 连接变更计数](https://www.sqlite.org/c3ref/total_changes.html)

每条耗时从客户端原生工作进程准备语句开始，到读取完整终态和交付结果为止。底栏的本次总耗时覆盖整个操作。遇到首错时保留此前完整语句的回执。固定结果、执行计划和离线快照各自沿用原视图。
