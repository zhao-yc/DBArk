# SQLite 从搜索命中编辑原记录

在「工具 → 全库搜索 → 搜索数据」找到 SQLite 表记录，双击打开只读详情。读写文件连接可点「编辑命中记录」，进入现有 SQLite 表格记录表单，焦点落在命中字段。保存暂存内容后先查看 SQL 预览，再勾选确认并提交。

编辑入口用短期搜索引用复核文件、表结构、可靠键和完整原行。复核与读取编辑原值在同一只读事务完成。签发的编辑快照只允许更新原来的一行。提交沿用 SQLite 表格的独立写事务，写入前重新核对完整原值。外部改动未选字段也会阻止提交。

搜索表单独立于已打开的表格标签。已有草稿与查询事务不会被搜索编辑替换。提交确认后返回原搜索结果，需重新搜索才能取得新记录的引用。无可靠定位、只读连接和视图继续提供原只读流程。

## 2026-11-07 验收

- Windows 测试虚拟机不可达，本轮使用 macOS arm64 源码 Electron 和一次性本地 SQLite 文件。
- 在每页 100 行的表中，从搜索直接编辑第 150 行。表单聚焦命中字段，确认前可查看仅更新原行的 SQL。提交后数据库中只有目标行发生本次修改，已打开表页的第 1 行草稿仍留在原标签且未写入数据库。
- 用同一引用请求另一张表或删除命中行均被拒绝。搜索后改动未选字段会阻止打开编辑，预览后外部修改会触发整批回滚并保留草稿。首轮用例按提示文字匹配失败，调整为核对实际回滚回执和原记录变更提示后，完整用例通过。

- 首轮全量单元测试发现 6 个工作台入口夹具漏传搜索编辑的草稿状态。补齐状态输入后，这 6 个文件的 70 项断言均通过。
