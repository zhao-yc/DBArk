## 用户入口和范围

在查询结果、固定结果或表当前页的“导出结果／导出勾选行”窗口中选择“Excel (XLSX)”。沿用打开窗口时的完整只读快照及实际行列顺序，隐藏列不导出；20 行预览不限制实际写出行数。此入口不重新执行 SQL、不读取完整表或建立数据库连接。完整表 Excel 任务仍是另一个入口。

XLSX 使用固定 Unicode 格式，编码控件不可修改；协议请求中的 `utf8` 是固定标记。切换格式同步撤销旧文件和 SQL 预览能力，旧回调、迟到保存选择和 A→B→A 不能复活旧授权。Main 只允许本窗口明确选择的 `xlsx` 导出令牌，实际路径由 Main 注入，不能使用渲染器路径或其它格式的文件选择。

## 数据表示

直接复用既有表 Excel 的 `dbark-v1` 文本协议和流式写入器：

- 所有数字写为文本，包括普通 number 的往返文本和负零；BIGINT、DECIMAL、日期时间原字符串不经 Number／Date，布尔值保留为布尔单元格。
- NULL 写作 `\N`，空字符串仍是显式空文本；原文本以反斜线开头时增加一个反斜线。二进制写作 `\B:` 加原 Base64，空二进制为 `\B:`；重新导入明确选择 DBArk 协议可区分原始文字、NULL 与字节。
- 标题使用原结果导出的确定性唯一命名，保留同名列和原型同名键；公式样式的标题和值均为文本，不创建公式、链接或宏。

沿用 100000 行、1024 列、2000000 格、32 MiB 原数据预算。完整快照在保存选择和写入前校验；Excel 单格 32767 字符（包含协议标记／转义）、单行 1 MiB 及合法 XML 标量另行限制，任何坏值整份拒绝，不截断或只检查示例。执行进程在开临时文件前再用原 `encodeExcelCell` 完整准入，非规范 Base64 不会晚写部分文件。
