# SQLite 当前页勾选批量删除

## 使用

在可写 SQLite 表格左侧复选框勾选记录，打开“更多 → 数据编辑 → 删除 SQLite 勾选记录”。菜单显示准确数量；确认后仅标记本地待删除，实际写入仍需原 SQL 预览和集中提交。

- 范围仅为当前页及本地新增草稿，翻页不继承旧勾选，不表示删除全表或全部筛选行。
- 已有记录保留并标记待删除；勾选的本地新增记录直接从草稿移除。两者合并为一个撤销／重做步骤，撤销恢复原本已保存的本地修改。
- 取消确认不清勾选、不改草稿，也不发送读取、预览、提交或释放请求。只读连接、视图、正在编辑字段或运行任务时不提供删除资格。
- 最终全部草稿沿原500条修改、10,000字段及2MiB输入预算核验，超限整组拒绝。删除本地新增可以释放预算；不截断为部分删除。

复选框通用文案改为“勾选 SQLite 记录／当前页”，原 typed 复制与粘贴沿同一选择继续工作；原“删除当前行”保留。

## 来源与原子性

Grid签发冻结的 `SqliteCheckedRows`，绑定准确页、原草稿数组、完整非删除行对象与勾选修订；回调读取最新已提交上下文，父级接纳引起重渲染不撤销合法勾选。临时禁用、模态或失活使旧凭据永久失效；恢复时仅在原来源仍准确的情况下签新凭据，不复活旧回调。

父级菜单绑定选择代次。确认期间同步观察 workspace，确认返回后重新核对原页、勾选和任务占用；不会把旧确认应用到后继目标。`editor.removeRows` 先验证完整目标和最终累计差异，再一次发布，无任务／IPC／ID分配。原值、快照、行数组、历史及预览若被重入修改则整批拒绝，失败保留原输入、预览和撤销栈。
