# PostgreSQL 本标签参数暂存

在 PostgreSQL 查询页点击「参数执行」，填写连续位置参数对应的 `p1`、`p2` 等类型和值。默认仅用于本次执行。需要重复使用时，勾选「完成执行后在本标签暂存参数（仅内存）」再执行。

仅原任务完整成功、原物理会话和数据库仍确认一致时保留一组参数。下一次打开表单不会自动填入，也不会自动勾选暂存；点击「填入上次暂存的参数」后核对类型和值，再明确执行。填入和忘记均不执行 SQL。「忘记上次暂存」只清除副本，当前表单输入保持。

暂存属于当前查询标签的内存，关闭标签或应用即释放。修改正文后即使撤销回原文，原组也失效。有效选区、模型、连接版本、会话、数据库、保存查询或 SQL 文件来源变化会撤销旧来源。重新识别时核对实际会话字符串模式，模式变化不能继续读取旧组。失败、取消和无法确认会话状态时不发布本次候选。

执行仍使用 PostgreSQL 原生位置绑定及原查询事务。参数值不进入设置、工作区、执行历史、任务概要或查询文件；结果本身可能包含填写的值。完整查询导出使用独立只读会话，仍需在导出窗口单独填写本次参数。
