# 关闭左侧与右侧查询

查询标签提供“⋯”按钮及右键操作菜单，可关闭该标签左侧或右侧的查询。锚点不必是活动标签；所有表标签和锚点均保留，没有目标的方向禁用。菜单支持方向键、Home、End、Tab及Escape，关闭菜单不自动执行SQL。

## 关闭流程

范围按点击时的标签对象与顺序捕获，后来新增的查询不加入当前批次。每项仍进入原有关闭入口，检查运行任务、编辑器、事务和会话状态；未保存内容沿原保存、放弃和取消流程处理。取消、保存失败或来源变化立即停止后续关闭，不跳过失败项，也不直接批量删除标签。

保存后产生的新标签对象只接受原保存握手明确授权的更新。原弹窗卸载并完成React提交后，才可打开下一项确认；旧回包不能推进或停止另一个请求。原“关闭其他查询”的范围及入口保持原行为。

## 状态变化

菜单捕获标签对象、文档令牌、相对顺序、来源及连接修订。重排、换绑、删除、新增、连接变化、失焦、拖动、外来模态或阻断使旧菜单失效；状态恢复也不能重放旧动作。模态插入后移除、已有节点切换为模态角色后恢复，均保留撤销记录。

开始关闭后，只忽略本队列已确认移除的目标及后来新增的标签；原标签顺序变化仍停止当前批次。原生输入、窄窗口、菜单焦点和重启布局须另外验收。
