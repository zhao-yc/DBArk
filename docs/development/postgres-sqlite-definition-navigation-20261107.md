# PostgreSQL 和 SQLite 定义正则定位

从「工具 → 全库搜索」切到「定义正文」。PostgreSQL 选「服务器正则」，SQLite 选「本地 Unicode 正则」。打开命中后，定义正文与搜索时一致才显示高亮。可通过「上一处定义命中」和「下一处定义命中」跳转，并查看准确行列。最多显示前 200 处，确认第 201 处后才提示截断。

PostgreSQL 使用原有服务器谓词判断对象是否命中，再以相同大小写规则标注整组匹配。去除标记后的文本须逐段还原原文，最终位置按 UTF-16 计算。[PostgreSQL 正则函数](https://www.postgresql.org/docs/18/functions-matching.html)

SQLite 在原有受限工作线程中枚举 Unicode 正则匹配。遇到零宽匹配时跨过一个完整 Unicode 码点。返回主进程的只有有界位置，命中仍由原来的匹配判断确认。补充定位超时时，关闭原线程并保留已确认的对象命中，用户可以打开当前定义。
