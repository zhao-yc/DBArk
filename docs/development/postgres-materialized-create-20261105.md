# PostgreSQL 新建物化视图

右键 PostgreSQL 数据库，选择「新建 PostgreSQL 物化视图」。选择目标 schema，填写名称、单条定义查询及可选注释。使用带 schema 的名称引用业务对象，例如 `public.orders`。

- 默认勾选「创建时填充数据」，确认后执行定义查询，创建完成即可在记录页读取数据。
- 取消勾选会创建未填充的视图。记录页显示提示，可从「查看结构 → 刷新物化视图」执行首次填充。

预览只核对目标 schema 和同名关系。确认后，创建和注释在一个事务内执行，客户端提交前核对目录中的对象类型、注释和填充状态。立即填充模式的语句上限为 120 秒。若提交回执中断，请到原数据库目录核对创建结果。[PostgreSQL 创建物化视图说明](https://www.postgresql.org/docs/18/sql-creatematerializedview.html)

## 验证

- 首轮实库发现，立即填充的 PostgreSQL 命令回执为 `SELECT` 加处理行数，旧校验将其误判并回滚。独立连接确认目录项不存在，定义中的测试序列已推进一次。已按立即填充模式接收对应回执，提交前继续回读目录验证。[PostgreSQL 18 命令回执实现](https://github.com/postgres/postgres/blob/REL_18_STABLE/src/backend/commands/matview.c#L349)
- 首轮原生测试在前一个删除操作的目录刷新期间打开菜单，菜单因目录更新失效。测试改为等待已知对象重新出现在目录，再进入真实菜单。失败轮次的独占容器已停止并保留诊断数据。
- Server-200 独占 PostgreSQL 18 实库回归 5 项通过。覆盖带引号名称、行尾注释、重名拒绝、预览零写入、令牌重放拒绝、立即填充查询只在确认后运行一次、目录类型与注释，以及定义执行失败回滚。另验证新建未填充的视图可以后续刷新。
- macOS 上 Node.js 24.17.0 运行时检查、类型检查和源码构建通过。完整单元回归覆盖 1,326 个文件，27,451 项通过，10 项 Windows 系统 `tar` 用例按平台跳过。
- 最终 macOS Electron 原生窗口 1 项通过，覆盖 41 个观察点。右键菜单两种创建模式均通过。独立连接确认两个实际对象的类型、注释与填充状态，并读回立即填充视图的真实记录。通过轮次的临时配置与独占测试库已清理。
- WIN11-TEST 会话不可达。本轮 Windows 原生窗口、两平台安装包和旧版 PostgreSQL 实库待验收。
