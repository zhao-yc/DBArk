# SQLite 普通脚本失败定位

普通 SQLite 脚本执行到首个错误时，错误摘要会显示失败语句序号和已完成语句数量。「定位未完成SQL」会选中原编辑器里的对应语句，有分号时包括分号。定位只移动光标及选区。之前完整返回的结果仍可查看。

运行时错误沿用原生确认的语句范围。准备失败时，客户端从原生实际尝试的位置寻找边界明确的第一条语句，跳过前导注释和分隔符。若未闭合引号等导致边界无法确认，则只显示错误和完成数量。UTF-16 范围经过原载荷和编辑器双重核对。[SQLite 原生语句准备接口](https://www.sqlite.org/c3ref/prepare.html)

修改编辑器内容、切换来源或执行新查询后，旧位置不能重新绑定。定位不会重新发送 SQL。脚本沿原首错规则停止，原事务状态和先前写入遵循数据库实际回执。
