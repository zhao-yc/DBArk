# 执行历史预览与批量清理

## 使用入口

在“历史与查询”中选择卡片的“删除此条”，或跨批次勾选后“删除所选历史”。也可先应用全文、来源、结果、时间及耗时筛选，再选择“删除当前筛选全部匹配”。三种操作都须点击“预览删除范围”，核对准确数量与有限样本，勾选确认后才永久删除。

所选最多100条；筛选全集覆盖本地保留的最多1000条，不限当前25张卡片。筛选草稿变化会清除原选择，未应用草稿不能清理全集。取消保留原页与选择；成功释放旧游标，按原已应用条件刷新第一页。保存查询、片段、打开的SQL草稿和服务器数据不在删除范围。

## 实现与边界

- `src/main/historyDelete.ts` 只处理本地存储，使用真实匹配线程复用原全文及筛选语义。全集先枚举所有保留记录、核验原索引，再按原条件匹配，防止坏连接索引被预筛选隐藏。损坏记录、超时、取消或来源变化不签发部分删除授权。
- 预览仅保留准确ID、原文SHA256及最多3个概要样本；累计原文预算128MiB、预览期限30秒、确认期限5分钟。能力绑定原主文档、当前启动实例和历史／连接复合修订，只能消费一次。
- `storage.ts` 在同一SQLite事务内重新核对全批原索引、正文和摘要，准确删除ID；临时文件完成后、原子替换前再核归属与期限。失败恢复内存、磁盘事实和会话秘密；成功仅推进一次历史修订。
- 预览与取消请求均实际结束后才释放；退出等待原匹配线程终止后关闭存储。已落盘的删除事实不被迟到导航改报为未执行。不写数据库任务或新增执行历史，不自动重试删除。

真实窗口以独占配置预置83条合成历史：预览取消后保留原记录，单删1条，跨页选择删除3条；全文匹配标记位于2048字符后，首批25条无命中，全集预览仍准确扫描79条、匹配并删除37条。原Main处理器透明审计确认三次提交为1／3／37，原预览取消只释放令牌。正常退出及所登记进程消失后，在独占副本用真实SQLite逐条核对最终42条原文，保存查询、片段、连接保持，任务仍为空；实际配置库原件在读回期间只读、字节与文件身份保持。

类型、构建及窗口使用同一套产品字节；窗口之后仅补旧退出测试夹具，最终类型和完整回归覆盖该补充。提交时另核原始输入SHA256、Git既有文本行尾过滤及暂存对象，避免把其它候选的证据算入本轮。

保留原失败：首次相关测试3项Main夹具缺少生产闭包、1项未观察拒绝；补齐RAM端口并明确等待原请求后，原断言全过。首次完整回归有旧退出夹具缺少新增服务，以及旧Engine旁观用例5000毫秒超时；补充异步关闭顺序断言，原超时和业务断言均不放宽，独立复验及最终完整回归通过。原React测试警告和Vitest弃用提示保留在日志中。

私有日志与摘要位于 `.cache/history-delete-*-20261023/`；合成配置、原日志、截图和产物不入库。专项 `tests/e2e/history-delete.spec.ts` 默认及 `--list` 不加载桌面或SQLite；实际运行需 `DBARK_HISTORY_DELETE_UI=1`、`DBARK_INTEGRATION_ENABLED=0` 和独占输出／批准源码清单配置。

未验范围：新安装包、macOS、打开草稿的GUI保持（本例为空标签，仅RAM／存储用例覆盖）、真实窗口中运行期间取消／并发改动及自然写盘失败。128MiB边界按硬预算算术验证，未物化超大SQLite样本；原Main审计只证明观察期间未转发数据库命令，不等同物理网络抓包。本轮没有连接实库、访问剪贴板或制作发行包。完整Q03工作包和发行计数不增加，暂不发布。
