# SQLite 只读表浏览、筛选和多列排序

## 使用方法

左树或对象列表双击 SQLite 表／视图，在原表格标签中浏览数据。顶部提供刷新、停止、筛选与排序、生成 SELECT、导出当前页，以及[导出全部筛选行](sqlite-table-export-20261031.md)。表格保持只读；右键“生成 SELECT 查询”仍只打开草稿，不执行用户 SQL。

展开“筛选与排序”，选择字段、运算符和值类型，明确点击“应用”。支持 AND／OR、最多 32 个条件及 8 列有优先级的排序；增删、方向和上移下移只改草稿，应用后回到首页。每页 1–1000 行，下一页依据额外读取的一行判断，不计算全表 COUNT，也不显示未经证明的总页数。条件不跨重启持久化；恢复表标签会重新读取无条件首页。

值类型明确区分 TEXT、INTEGER、REAL 和 BLOB，NULL 使用独立条件。类型筛选只匹配所选存储类型，文本 `2` 不冒充整数 `2`。TEXT 等值比较沿 SQLite 列排序规则；“包含”使用原文字面匹配，百分号和下划线不是通配符。整数支持完整有符号 64 位；REAL 为有限浮点数；BLOB 输入完整十六进制字节。排序由 SQLite 对实际值执行，不能用前端字符串排序代替。

## 执行与正确性边界

- `sqlite.tablePage` 仅接收已保存 SQLite 连接、main、表名及结构化条件，不接收 SQL、路径或凭据。Main 和 broker 在进入网络引擎前拒绝错误方言。
- 每页使用独立、强制只读的 utility／物理连接，在同一 BEGIN 读快照中核对 sqlite_schema、table_xinfo 和数据。元数据白名单引用标识符，所有条件值及 LIMIT／OFFSET 都绑定参数。生成列可见，虚表隐藏列不冒充普通列。
- 传输读取 `limit+1` 行；原生数据与实际 QueryResult 都受 16 MiB 预算约束。预算不足、列变化或不完整结果明确报错，不自动缩页或把截断伪称没有下一页。跨页不保证数据／结构冻结，每页重新核验。
- 取消只作用于本任务准确 driver／transport；清理阶段不取消自身 ROLLBACK，也不借用用户查询事务。正常返回必须取得回滚、关闭及真实退出确认。退出未确认保留资源并阻止新建；结束后只保轻量任务编号墓碑。
- 切换条件、标签或连接时旧回包失效，新读取等待原 Promise 终态。不会因取消 ACK 先到就释放占用，也不自动重放。浏览不进入用户 SQL 历史。
