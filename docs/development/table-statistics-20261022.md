# 当前筛选范围的表数据统计

## 入口与范围

表或视图的数据页提供“表数据统计”。窗口冻结打开时的服务器筛选，包括启停和嵌套分组；不使用当前加载页的行数组计算。用户可选择0～12个字段并显式开始，0个字段只统计匹配总行数。父页未提交草稿保留，不计入统计。

每列提供非空／NULL计数；已证明可比较的数值、文本、时间和二进制类型提供MIN/MAX，数值另有SUM/AVG。JSON、空间和未知类型仅计数。数量和数值聚合保持服务器文本，FLOAT/DOUBLE/REAL明确标为近似；空集／全NULL的极值及合计、平均值保持NULL。

## 查询与精度

`table.statistics`只接收连接、库表、字段和标准筛选，不能注入SQL、排序、分页或用户事务会话。过滤与普通表页共用同一构建器，值沿原精确参数处理。单条派生聚合读取全部匹配行，返回一个有界结果行。

MIN/MAX在服务器先计算实际输出字节，超过256KiB不返回原大值，后端收到超限事实即拒绝整份结果，不静默截断或替换为NULL；整份结果最多8MiB。聚合后立即读取原警告，无法证明无警告时不发布可能转换或溢出的值。前后读取真实元数据和SHOW摘要，视图定义参与身份；不承诺外部同值DDL的原子CAS。

## 独立只读事务与生命周期

统计在新独立连接先设置REPEATABLE READ，再开始READ ONLY事务，正常结束明确ROLLBACK且禁止CHAIN/RELEASE。不共享或提交用户的事务。视图可能调用存储函数，单纯生成SELECT不足以限制其数据库写入，因此使用数据库自身的只读事务约束；参见[MySQL事务说明](https://dev.mysql.com/doc/refman/8.0/en/commit.html)和[MariaDB事务说明](https://mariadb.com/docs/server/reference/sql-statements/transactions/start-transaction)。失败或取消后只收尾原连接，不另开连接补做或重放。

原页、筛选、草稿、结构、连接修订或活动标签变化使窗口永久失效，恢复原值不复活。取消ACK不释放原Promise占用，关闭等待原任务和严格物理连接收尾。主进程拒绝修订变化后的迟到结果，任务概要不保存筛选值、统计值或驱动错误原文。
