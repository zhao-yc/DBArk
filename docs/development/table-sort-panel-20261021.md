# 表数据多列排序编辑

## 使用流程

表数据页工具栏新增“多列排序”。面板从当前列头排序载入独立草稿，支持添加、切换字段、升降序、提高／降低优先级、移除及清空。字段不能重复，最多20项，与正式分页IPC约束一致。编辑及取消均不查询、不改表数据；字段改变或优先级移动保留对应控件身份。

“应用排序”保留当前全部筛选及组合方式，从第一页执行一次正式`table.page`读取；网格列头同步显示相同排序。与已应用规则完全一致时直接关闭，不重新查询。有未提交记录或表单输入时沿用整页丢弃确认，拒绝时保留数据及排序草稿。清空只清空显式规则，服务器分页仍按已有可靠行键补足并列项；无可靠键不保证稳定分页。NULL、文字及时间按数据库语义排序，与SQL结果的本地快照排序区分。

排序面板绑定原表、页面、连接修订、筛选及已应用排序。任何一次目标切换、连接ABA、页或条件变化均使原草稿失效，不能覆盖后继页面。旧渲染、双击应用和已取消回调不能多发请求；面板不拼接SQL、不提交数据。现有命名方案继续保存同一份已应用排序，无配置迁移。
