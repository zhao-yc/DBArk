# 对象树紧凑布局与右键菜单

本次仅调整渲染层：连接、数据库及对象固定 31px 单行，操作迁入 Portal 菜单，没有隐藏的旧行内按钮。顶栏及收藏面板保留。

## 选择与动作归属

`SidebarTreeProvider` 管理一个菜单和树节点选择；节点键包含连接、数据库、对象种类及名称，同名表与视图不会混淆。右键先同步原连接／数据库选择，再打开菜单，不调用左键展开或打开标签的处理器。菜单关闭保留高亮，编辑标签、SQL 和事务不因右键而切换。

原按钮通过 `actions` 提供给菜单，保留禁用、确认及业务回调；收藏复用 `FavoriteButton` 与原持久化接口。每行租约随目录、配置及节点生命周期变化，动作执行前再次核对原目标，消费菜单后才执行原操作。模态、外部点击、Escape、失焦、树滚动及窗口尺寸变化都会关闭菜单。

## 验证入口与边界

现有 E2E 使用 `tests/e2e/sidebar-menu.ts` 真实右键打开菜单；未保留旧按钮或放宽原超时。组件接线夹具读取生产动作定义，只说明接线及请求门，不能代替实际 Portal、布局或原生焦点证明。

独立专项 `tests/e2e/sidebar-context-menu.spec.ts` 默认只注册一条跳过占位。显式启用后运行四个真实 Electron 复合用例：

```powershell
$env:DBARK_INTEGRATION_ENABLED='0'
$env:DBARK_SIDEBAR_CONTEXT_MENU_TEST='1'
pnpm exec playwright test tests/e2e/sidebar-context-menu.spec.ts --workers=1 --retries=0 --trace=off --reporter=line,json
```

须先清除实库认证环境并构建新源码；安装载荷专项通过 `DBARK_EXECUTABLE_PATH` 指定本次准确打包应用。用例保持原 45 秒限制，使用新临时配置及明确的虚构 `127.0.0.1:1` 连接，只在 Main 层返回合成元数据；不访问真实数据库或系统剪贴板。失败保留所属窗口并停链，不把观察超时当退出。

专项记录节点选择与原工作区、31px 盒模型、明暗主题、180／260／420px 侧栏、长名称、边缘菜单、键盘、忙态、旧菜单失效、同名对象收藏及例程入口。Windows 与两种 Mac 原生平台的实际结果分别记录；合成目录回包不构成实库或全部功能验收。此前全量 CI 失败独立保留，不据本专项改判。

原生失焦段先取消 Playwright 默认的焦点模拟，再核实原窗口和页面真实聚焦；最小化原窗口后，必须同时确认最小化、原生失焦、页面失焦及菜单消失。结束后恢复窗口和测试默认焦点设置。仅调用 `blur()` 或在焦点模拟下读取状态不能证明发生了系统失焦，不据此改动产品或放宽菜单关闭断言。四例按串行组运行，首例失败后后续跳过，避免失败后更换 worker 继续启动应用；每例最早附加原 Main 身份，退出仍走原所有权检查。
