# PostgreSQL 已有表字段编辑

从表页或对象菜单打开「查看结构」，在有编辑权限的普通表中点击「编辑字段」。可新增字段或重命名字段，使用「加入改动」暂存多项修改。先查看实际 SQL，确认后在同一个事务中提交。

- 新增字段支持常用内置类型、varchar 长度、numeric 精度和小数位、是否允许空值、文字默认值和注释。重命名保持原字段序号，索引表达式和约束关系由 PostgreSQL 更新。[PostgreSQL ALTER TABLE](https://www.postgresql.org/docs/18/sql-altertable.html)
- 预览绑定所查看的完整原结构、原关系身份、窗口和连接修订。提交锁定准确表名，随后再次核对原身份与结构。同名替换、结构漂移、旧令牌和连接修订变更须重新预览。
- 确认后逐条执行，核对实际字段和原列序号再提交。后续语句失败会回滚同批前序修改。无法确认结果时，先刷新结构核对。原表页存在草稿或仍有操作时须先处理，干净表页在确认后重读新结构。

本批编辑覆盖有管理权限的普通表。分区、继承表、视图和外部表继续通过结构查看入口阅读。删除字段、已有字段类型或约束编辑仍在后续范围。

## 验证

- Mac 类型检查、源码构建和 4 项定向单元测试通过。覆盖转义、原字段序号、重复名称、旧结构及建表编译回归。
- Mac 完整单元回归覆盖 1,320 个测试文件，27,407 项通过，10 项 Windows 系统 `tar` 检查按平台跳过。
- Server-200 的 PostgreSQL 18 独占实库回归 5 项通过。验证第二条 DDL 失败时回滚已执行的重命名、锁等待后拒绝已变化的结构、拒绝结构相同的同名替换表及其他窗口的令牌，核对引号字段、默认值、索引与旧行。通过实例复核原行、零连接后清理。
- Mac 原生窗口复验通过。同批预览新增与重命名，明确提交后从原结构和原表页核对新字段和注释。单 worker、120 秒、零重试、trace 关闭，窗口与临时配置目录已清理。
- 首轮窗口未定位到操作下拉框。为下拉框补充明确的可访问名称后，沿用原验收门槛复验。首轮失败现场保留。
- WIN11-TEST 会话不可达，本轮未派发，按约定在 Mac 验证。Windows 原生窗口和安装包尚待验收。
