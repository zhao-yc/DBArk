# SQLite 本文关系引用

## 使用

SQLite 可编辑查询中，在关系限定段、别名声明或 CTE 名称上按 `Shift+F12`，或使用编辑器右键查找引用。列表包含已确认声明和引用，双击选中准确原词；打开列表会收起尚未选择的补全候选，不修改正文。

```sql
SELECT s.id, S.name FROM subject AS S WHERE s.id > 1;
WITH q(n) AS (SELECT 1) SELECT q.n FROM q;
SELECT d.n FROM (SELECT 1 n) AS d WHERE d.n = 1;
```

支持 SQLite 三种标识符引用、512 UTF16 名称、非 BMP 字符、嵌套／递归 CTE、相关子查询、遮蔽、复合查询分支及明确 main／temp 绑定。只折叠 ASCII 大小写；`S` 和 `s` 可指同一声明，`Ä` 和 `ä` 不合并。

这里只查当前语句内原声明解析器支持的关系引用。字段／输出别名／变量、跨文件或全库依赖、任意 SQL 语义及零引用证明仍未实现；普通同名词不能当作引用。字符串、注释、参数、schema 段、表函数和不确定绑定不猜目标，触发器体保持原拒绝边界。

## 实现

- 共用声明范围索引，MySQL 保持原词精确匹配；SQLite 使用自己的词法、语句和作用域，不能回退 MySQL 引号、大小写或 DELIMITER 规则。
- 独立 SQLite 引用 Worker 只接收编号、正文和位置，不接收 MySQL 模式／能力。实际 bundle 无 MySQL 解析器；没有 IPC、目录、文件、连接、会话模式或 SQL 执行端口。
- 引用保持启动 8 秒、分析 2 秒和 256 个同名候选预算；超限整份拒绝。原 SQLite 补全／悬停／F12 的独立期限保持不变。
- 回包核当前语句、完整闭合 token、UTF16 边界、有序唯一引用、字段白名单及同名身份；只用原模型 URI。取消、切换、编辑、替换、模态和卸载使迟到结果失效，终止准确线程。
- 首轮发现原 SQLite F12 对 `s.f()` 的函数限定段误跳；已在原声明路径排除该形态，并保留拒绝断言，引用也不再收录它。
- 不改 IPC、凭据、配置或数据库写协议。
- 引用解析期间持有原取消信号的临时租约，面板打开后按原编辑器的 peek 状态阻止迟到补全；取消立即释放，旧请求清理不能解除继任保护。首尾收起现有候选，关闭后恢复原补全，不修改偏好。
- MySQL 引用复用原补全 Worker 的编译产物及固定 `references` 意图，仍单独创建和终止物理 Worker；SQLite 保持独立本地方言产物。避免同一 MySQL 解析器重复打包，不共享分析状态。
