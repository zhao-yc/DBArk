# PostgreSQL 语句导航

打开 PostgreSQL 查询页，在工具栏或「工具 → 查询」点击「语句导航」。可以按正文筛选、逐页浏览，点击行号跳到语句正文，或点击「选中正文」。在编辑器按 `Ctrl/⌘+E` 可选中光标所在语句。原生查询菜单也提供上一条和下一条，首尾停止。

导航复用执行当前语句的 PostgreSQL 分段器，识别嵌套块注释、双引号及 dollar-quote 正文。行号和选区跳过前导注释，光标归属仍按原执行范围判断。[PostgreSQL 词法规则](https://www.postgresql.org/docs/18/sql-syntax-lexical.html)

目录只读原查询会话的 `standard_conforming_strings` 缓存，无需另发 SQL。没有会话时，只有两种字符串模式都得出一致边界才显示目录。目录反映分析开始时的模式，脚本中的 `SET` 等语句仍需明确执行后再刷新。每次最多分析 262,144 个 UTF-16 单元和 1,000 条语句。修改草稿、切换来源或开始执行会使旧目录失效。
