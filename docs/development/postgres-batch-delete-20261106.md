# PostgreSQL 删除勾选记录

在表页网格勾选当前页的已有记录，再点击「删除勾选记录」。确认窗口列出原行号和原主键，包含复合主键的各字段。每次可勾选 1 至 100 条记录，整份草稿仍受原有的行数和页数限制。已标记删除的记录需要从勾选中移除后再操作。单条记录可继续用「删除当前记录」。 [Navicat 记录删除说明](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/data_rdbms.html#grid-view)

若目标行已有更新草稿，窗口会提示替换数量。点击「暂存整批删除」后，目标行的更新草稿被删除草稿替换，其他行草稿保持。取消确认保留原草稿。「撤销整批删除」可恢复暂存前的状态，包括被替换的更新。下一次草稿编辑会结束本次整批撤销。

翻页会清空勾选，已经暂存的记录仍绑定各自的原页。最终使用「预览记录修改」核对整批 SQL，再确认提交。引擎复核原行版本，按单个事务执行；任一约束失败会回滚整批。

## 验证记录

- macOS arm64 使用 Node.js 24.17.0，运行时检查、严格类型检查、构建和 8 项定向单测通过。定向验证原复合主键、超出 JavaScript 安全整数范围的编号、已有更新草稿计数、只读及已标记删除来源拒绝。
- 完整单元回归覆盖 1,335 个测试文件，27,494 项通过，10 项 Windows 专用测试按平台跳过。
- Server-200 隔离 PostgreSQL 18 实库通过 5 项回归。两条非相邻记录生成两条删除预览且原值保持。第二条触发复合外键限制后整批回滚，解除测试限制并从新页重新预览后准确删除两条。独立核对中间未勾选记录及零剩余连接后清理容器。
- macOS Electron 通过 1 条端到端测试，共 79 项检查。确认窗口展示两条勾选记录的主键及替换一条更新草稿的提示。取消保留原更新，暂存后撤销整批恢复原更新。截图、服务器原记录、零剩余连接及临时配置清理均已复核。
- WIN11-TEST 不可达，本轮使用 macOS。Windows、安装包及其他 PostgreSQL 版本待验。
