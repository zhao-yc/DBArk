# PostgreSQL 查询结果筛选

查询返回结果后，点击「筛选已返回结果」，选择字段、比较方式和值，再点击「应用筛选」。可用 AND、OR 和子组组合条件，也可从当前结果的不同值中选择。页面显示原返回行数和筛选后的行数。

- 整数及 NUMERIC 按原值精确比较，浮点支持科学计数法以及 NaN 和无穷值。布尔接受 `true`、`false` 或原值 `t`、`f`。日期时间、二进制和未知类型可使用 NULL 判断。[PostgreSQL 数值类型](https://www.postgresql.org/docs/18/datatype-numeric.html)
- 文本支持字面匹配、通配、大小写选项及候选值。NULL、空字符串和文本按各自的条件判断。不同值来自原已返回的行，选择后仍需确认应用。
- 应用或清除筛选时，在新显示范围上重新使用当前排序。两步都成功才更新视图，出错时保留当前筛选、排序和勾选。成功后清除旧勾选，导出按实际显示范围和顺序写入。数据库查询、历史和事务状态保持。
