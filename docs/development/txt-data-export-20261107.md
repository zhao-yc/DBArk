# TXT 数据导出

查询结果的「导出已返回结果」「导出勾选结果行」和表页当前页导出可将当前快照保存为 `.txt`。MySQL、MariaDB、PostgreSQL 和 SQLite 的完整查询及表数据导出也可选择「TXT 文本」。全量表导出使用原表页已应用的筛选、排序和选定字段。

1. 选择 UTF-8、UTF-16 LE 或 GB18030。UTF-16 LE 文件带 BOM。
2. 选择字段分隔符、记录换行和文本限定符。支持 Tab、逗号、分号、竖线、空格及 1 至 8 个字符的自定义分隔符。换行可选 CRLF、LF 或 CR。
3. 按需取消「写入字段名」。带引号字段中的同种引号会写两次。选择「无」时，含分隔符、换行或边界歧义的字段会使导出停止，原目标文件保留。
4. 选择保存位置并确认。MySQL 和 MariaDB 的「新执行并完整导出」还需指定行结果集序号，语句回执不计入序号。SQLite 和 PostgreSQL 的完整查询可将 TXT 参数保存为命名方案。

回导时选择「TXT 文本 → 分隔文本」，使用同样的编码、字段分隔符、文本限定符、记录换行和表头选项。`\N` 表示 NULL，空文本保留为空文本，以反斜线开头的数据会额外写一个反斜线。二进制使用 `base64:`，回导时请选择适用的目标列类型。TXT 按文本表达数据，目标类型由导入映射决定。固定宽度文件仍可通过 TXT 导入向导读取。

原子发布前发生写入、编码或读取错误时保留原文件。完整流式 SQL 导出中的数据库写入仍由原 SQL 和事务控制。

格式选项参考 [Navicat 导出向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/export_wizard.html)。
