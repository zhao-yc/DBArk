# 当前筛选的完整流式导出

2026-10-28 开发源码新增[字段选择及顺序](table-filtered-export-fields-20261028.md)。下文保留原全字段版本的行为与验收记录；新功能的实际验证单独登记。

## 使用方法

1. 在表或视图的数据页应用筛选及多列排序。
2. 点击工具栏“导出全部筛选行”，核对完整筛选、停用条件、排序和字段范围。
3. 选择 CSV、JSON、INSERT SQL 或 XLSX；文本格式可选 UTF-8、UTF-16LE 或 GB18030，CSV 可选逗号、分号或 Tab。
4. 选择目标文件，再明确开始导出。成功消息显示完整写入行数。

范围是服务器上满足已应用条件的全部行，不限当前页、勾选行或 XLSX 样本。CSV、JSON、XLSX 包含全部字段，不受隐藏列影响；SQL 不写入生成列，且仅接受基本表，视图请选择另外三种格式。旧的当前页导出、CSV 字段选择和整表导出入口继续按原有范围工作。

导出使用独立只读会话，不包含 SQL 标签尚未提交的数据，也不提交或丢弃本地表格草稿。文件选择期间不能偷换来源；原表页、连接、筛选或排序曾变化后，须重新打开导出窗口。

## 正确性与取消

`table.exportFiltered` 接收有类型的完整筛选树和排序，不接收渲染器 SQL 或文件路径。Main 校验文件用途和确切格式、绑定原主文档与连接修订；数据库进程在独立只读事务取得元数据锁，核对原字段目录及前后定义，一次流式 SELECT 读取数据。

驱动使用二进制协议保留 FLOAT/DOUBLE 原数值，BIGINT、DECIMAL 和日期文本保持精度；NULL 和二进制使用原格式协议。未知字段类型、警告、超预算或来源漂移整份失败，不截取样本后声称完整成功。

数据库原命令及连接严格收尾后才原子替换目标文件。替换前可取消；替换开始后等待实际结果，已保存的文件不能改报成“没有执行”。关闭窗口等待原导出及原取消请求均结束。

## 范围限制

- 文本导出文件预算 10 GiB，单字段 8 MiB、单行 16 MiB；XLSX 沿用现有单元格、行列、总格数和压缩包预算，采用自身 Unicode 编码。
- SQL 是筛选数据的 INSERT 子集，不含结构，不是完整备份。再次执行可能发生主键冲突；自增零值需要 `NO_AUTO_VALUE_ON_ZERO`，TIMESTAMP 需要与源会话一致的时区规则。文件不会自动修改或恢复这些设置。
- 不发布安装包，不执行生产部署。
