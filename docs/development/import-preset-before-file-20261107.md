# 先应用导入配置，再选择文件

MySQL 和 MariaDB 的 CSV、JSON、TXT、XML 导入允许先选择已存配置并点击「应用配置」。如果尚未选文件或格式发生变化，窗口先恢复读取设置，再等待本次文件。

- 取消文件选择会继续等待。选到不兼容的文件时会显示错误，并保留这次套用意图，可直接换一份文件。
- 首个通过核验的文件会恢复完整映射。之后再换文件需要明确应用配置。
- 已有同格式文件时，应用配置会重新核验当前文件及目标列。任何一次实际写入仍由用户明确确认。
- 点击「取消套用配置」或手工修改读取选项后，可按普通流程配置映射。

字段兼容性按当前预览提供的源列核对。JSON 预览从样本发现字段。需要检查所有记录时可执行整文件预检。
