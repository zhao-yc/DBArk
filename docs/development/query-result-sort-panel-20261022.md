# 查询结果多列排序面板

## 实际入口与行为

SQL工作区结果工具栏增加“多列排序”。独立草稿支持选择字段、升降序、每列NULL位置、文本忽略大小写、优先级移动和移除；清空仍须明确应用。重复显示名按内部唯一键区分，选项同时显示可见位置和类型，不允许同列重复或二进制等不可靠列。

打开及编辑只复制配置，不扫描单元格、不发SQL；取消保留原筛选、排序和整理历史。应用保留当前筛选，完整比较成功后一次发布排序，记录一条可撤销／重做的整理步骤。打开即清旧勾选及行详情，应用后复制、查找、详情和导出继续沿同一视图。

每页十条规则，跨页移动保留完整配置；没有把已有排序裁剪为十条。全部规则仍受原100000行、1024列、2000000比较单元及8Mi UTF-16单位等预算约束。组合大小写转换超预算时拒绝整次应用，旧视图及可修改草稿保持；不自动减少字段或截断原文。

## 生命周期

面板同时绑定准确排序及筛选view、实际可见列、连接修订和工作区。草稿期间禁止列头排序、筛选、列管理、旧选择／导出及整理历史回调穿透；新查询、结果切换、模态、连接ABA及标签失活撤销原草稿。组件另核渲染票据、草稿身份和输入法组合，旧页、旧按钮或重复点击不能覆盖新配置。取消只关闭所属面板，不恢复旧权限。

不改变数据库ORDER BY、IPC合同、驱动比较或原SQL；只有已返回的结果参与整理。原列头与快捷键入口继续支持。
