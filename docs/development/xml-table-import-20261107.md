# MySQL 和 MariaDB 表导入 XML

在可写的 MySQL 或 MariaDB InnoDB 表页打开「导入」，选择 XML，然后核对「XML 记录标签」。tabrelio 记录布局默认使用 `RECORD`。外部文件可填它实际使用的标签，例如 `entry`。根元素下的记录必须使用同一标签，记录子元素作为字段。选中「将记录属性作为字段」可同时使用属性和子元素。字段重名时，需先修正源文件。[Navicat 导入向导](https://www.navicat.com/manual/online_manual/en/navicat_18/win_manual/import_wizard.html#source-file-settings)

选择文件后，向导扫描整份文件取得列集合，预览最多保留 20 条及 2 MiB 样本。核对字段映射后，可点「校验整份文件」检查数据类型、空值和无损转换。导入方案可保存文件解释和映射。需要更新、跳过或新增时，可按现有冲突策略明确选择主键或唯一键。方案不会保存源文件、目标连接、匹配键或数据值。

映射字段在某条记录中省略时写入 NULL。该字段须在整份文件中出现过。空属性或空子元素保留空文本。数字按原文本进入目标类型校验。源文件包含 Base64 编码的二进制时，勾选相应选项，解码仅作用于映射到二进制目标列的值。

XML 导入固定使用整文件事务。文件在执行时重新读取，解析、字段校验或写入失败会停止并尝试回滚。提交或回滚无法确认时，需核对目标库后再决定是否重试。触发器对非事务表或外部系统的副作用仍需独立核查。

当前接受 UTF-8 XML 1.0 的扁平记录。文件上限 64 MiB，单字段 8 MiB，单行 16 MiB，整文件最多 1,024 个不同字段。DTD、命名空间和嵌套子字段会被拒绝。MySQL 和 MariaDB 从 XML 新建表、位置映射「XML 文档」导入及 PostgreSQL XML 导入仍待补齐。SQLite 已有独立的现有表和新表流程。[SQLite 导入 XML](sqlite-xml-import-20261107.md)

## 验收

- macOS arm64 使用 Node.js 24.17.0。运行时、严格类型检查、源码构建和 970 项相关单元测试通过。XML 用例覆盖属性与子元素混合、末行才出现的列、异常编码、取消以及拒绝 DTD 和嵌套字段。
- MySQL 8.4.11 和 MariaDB 11.4.13 各通过一个原生界面实库用例。通过独立连接核对新增及按主键更新后的数据，验证 64 位无符号整数、定点小数、NULL、空文本和二进制。两种数据库均确认预检后损坏源文件时整文件回滚。Server-200 隔离容器、测试库、会话和转发均已核对清理。
- Windows 测试会话不可达。本轮验证使用 macOS 源码版，macOS x64 和安装包待验。
