# MySQL／MariaDB 按所选差异同步

从「工具 → 比较 MySQL／MariaDB 表数据」做完整比较后，可以跨页勾选差异。预览列出右侧连接、表名、操作和主键。输入预览显示的目标名确认后，左侧独有行插入右侧，字段不同的行更新右侧，右侧独有行从右侧删除。

一次确认使用比较时冻结的左侧原值。独立 InnoDB 事务取得右侧元数据锁，重新核对真实服务器、表定义、触发器目录、选中旧行的完整原值及必要的外键目录。写入后复核右侧行。遇到并发改值、约束冲突、服务器警告或回读不符时，依据原事务回执报告回滚或未知终态。[MySQL InnoDB 锁](https://dev.mysql.com/doc/refman/8.4/en/innodb-locking.html) · [MariaDB 锁定读](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation/selecting-data/for-update)

每批最多 100 行及 1 MiB，比较快照最多保留 5 分钟。支持完整主键和可无损绑定的常用字段。目标需要相应数据权限及可证明的直接 TRIGGER 目录权限。含更新或删除的批次还需要直接全局 SELECT 以核对入向外键。目标含触发器或被外键引用时，相应写入会被拦截。显式插入标识值可能推进右侧自增计数，事务回滚会撤销行修改，自增计数依数据库行为变化。

## 验收

- WIN11-TEST 会话不可达，本轮未派发。按既有授权在 macOS arm64、Node.js 24.17.0 验证。Windows 原生窗口、两平台安装包及旧数据库版本待验。
- 严格类型检查、构建通过。1,352 个单测文件中 27,578 项通过、10 项跳过。双实库原生专项 1 项及 PostgreSQL 18.6 原生比较与同步回归 1 项通过。两端账号的剩余连接数为零，专用容器和转发均确认释放。
- Server-200 上用独占 MySQL 8.4.11、MariaDB 11.4.13 容器经 SSH 回环验证。两个方向的跨连接同步，以及 MariaDB 同连接跨库同步，均独立读回。跨连接分别选中插入、删除和更新各一行，保留 26 条未选差异。核对了无符号 BIGINT 最大主键、18 位小数、相邻浮点值及字节。
- 唯一约束冲突使本批先执行的更新回滚。并发改值阻止旧预览写入。级联外键、预览后新建的触发器、错误目标名分别被拦截。同步确认区自动进入可视区。
- 首轮 MariaDB 用例在外键检查处拦截。实库探针查明 MySQL 直接转字符返回 `1`，MariaDB 返回 `ON`，数值转换后均得到 `1`。修正后保持严格核验并复验通过。
