# 从表结构生成查询SQL模板

## 完整操作

表页“生成查询SQL”打开只读预览，选择SELECT／INSERT／UPDATE／DELETE，再点击“打开新查询”。新标签绑定同一连接和明确数据库，不继承保存查询来源、文件来源或会话；原表及已暂存数据草稿保留。打开／关闭和创建查询都同步接管工作台导航，迟到的收藏或对象链接不能抢回焦点。生成只消费已载入结构，不读取表数据或执行SQL。

SELECT列出全部字段，并使用当前结果上限生成LIMIT。INSERT使用普通非自增、非生成字段的SET参数；只有默认列时生成空列VALUES。UPDATE默认不改键，仅设置普通非键字段；UPDATE／DELETE要求已确认的非空主键或可靠唯一键，完整复合键参数定位并保留LIMIT 1。视图或未知对象仅支持SELECT，无可靠键不生成危险写入草稿。实际写入权限和约束仍由数据库在用户执行时校验，模板不替代网格旧值冲突检测。

参数名采用独立ASCII序号，与原字段名隔离；数据库／表／列用反引号完整引用。生成后用户审阅并通过原“参数执行”选择类型和填写值，默认不执行写入。相关元数据、标签、连接修订、页代次或结果上限变化后原预览永久失效，旧选项／按钮回调不能创建另一份查询。查询标签达到100个时明确报错。

当前SQL适用于MySQL／MariaDB，最多4096列、512个索引、256Ki UTF-16模板正文及200个值参数；索引中未知表达式不作为可靠键，但不阻断普通SELECT或已确认主键。超限明确拒绝，不截断。此能力尚不代表完整O01／O05工作包完成。
