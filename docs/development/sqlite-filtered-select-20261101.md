# SQLite 从已应用筛选生成 SELECT

## 使用

在 SQLite 表或视图页面打开“更多 → 生成查询 → 从 SQLite 当前筛选生成查询…”。选取字段、上下移动投影顺序，并在只读预览中核对完整 SQL，再选择“打开查询草稿”。只读连接也可使用。

- 仅使用已经应用的类型筛选、AND／OR 和多列排序；未应用的表单条件、当前页 OFFSET 和本地数据修改不进入 SQL。
- 默认不写 LIMIT，可明确限制前1至1000000行。实际执行仍遵循查询页结果上限；完整导出继续使用独立流式任务。
- 打开和取消不读取数据或执行查询。新标签绑定原表页连接和 `main`，不会采用左树后来选中的其它连接，也不继承原表页事务、保存来源或数据草稿。
- 原普通 SELECT 入口保留。生成期间目标、字段、原已应用条件或忙态变化会撤销旧计划；失效输入仍可关闭，不清除父页修改。

## 实现与边界

共享 `sqliteReadSql` 构造原分页绑定查询及新字面查询，保留原 SQL、参数类型顺序、导出投影与分页语义。使用明确的绑定 token，不在 SQL 文本中猜问号；字段白名单、`typeof` 和字面 `instr` 条件保持。

整数不经过 Number；REAL 明确保留浮点类型，BLOB 使用十六进制字面量。普通文本按 [SQLite 字面量规则](https://www.sqlite.org/lang_expr.html)引用；NUL、回车、换行通过最多三层 replace／char 重建，避免编辑器 EOL 规范化改变值，也不依赖将 UTF8 BLOB 强转 TEXT。连续65536个NUL不会展开为巨量表达式。

生成上限为4MiB UTF8及2MiB UTF16字节。当前编辑器不能原样保持标识符中的回车／换行，因此本入口明确拒绝这类名称；这项能力仍待补齐，不能宣称全部 SQLite 名称已支持。没有新增 IPC、数据库任务或配置格式。
