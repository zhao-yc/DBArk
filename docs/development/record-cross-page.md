# 记录表单跨页连续浏览切片

基于 ROOT `2938c7c20a2e7dff3709fdd77b9c45c4aed095b2`。本片补 D04 的跨页连续浏览，不代表 D04 全部完成。当前页最后一条的“下一条”读取下一页并选择首条，第一条的“上一条”读取前页并选择末条；沿用当前筛选、组合方式、排序和页大小。页内导航及其输入三选守卫保持原行为。

跨页前检查当前页所有行和记录输入缓冲。修改、新增、删除、新增后删除、其它行的草稿及非法 JSON 原文均阻止跨页，显示输入已保留；不询问自动放弃、不自动暂存或提交。记录只保存在当前页，不携带草稿跨页。

读取中同步锁住连续点击并清除旧页展示。意图绑定连接/表、连接版本、结构刷新版本、筛选排序、页大小、来源/目标页、用户动作及实际加载代次。真实新页提交后才兑换一次本地 UUID 选择，正常选择仍生成原有 `selectionRef` 令牌。普通翻页、刷新、筛选、结构变化、切换对象/标签、收起面板、显式网格/查找导航或卸载撤销旧意图；条件恢复也不复活。失败清空页与选择并提示明确重试；空页结束读取，可明确返回前页。末页不猜测总量、不循环查找其它页。服务器变化仍可能造成跨页重复/遗漏，本功能不提供数据库快照分页。

## 接口和集成位置

无新增 Engine、IPC、存储或 schema。仅复用 `connections.open`、`metadata.table`、`table.page` 和已有记录控制器。新状态机位于 `src/renderer/recordPageNavigation.ts`；`RecordFormPanel` 只有可选导航回调与独立的 `note` 提示，不占用原暂存 `status` 角色。

`TableTab.tsx` 的修改分为以下块，ROOT 可与员工3的自增工具栏顺序合并：

1. 新 import、导航 ref/提示状态，以及记录控制器后的当前上下文读取和失效观察。
2. `jumpToMatch`、JSX 的 `onCellKeyDown` 适配层和显式 `onCellClick` 撤销旧自动选择；原键盘函数及选择令牌处理不改。
3. 原 `load` 开头领取意图，成功分支绑定真实 `nextRows`，失败分支记录明确状态；没有第二条读取路径。
4. `canReload` 的撤销、新 `navigateRecordPage` 和新页提交后的兑换 effect。
5. `RecordFormPanel` 增加 `pageNavigation` 参数。原工具栏按钮、表自增接口、设计入口和其它 JSX 属性均不改。
