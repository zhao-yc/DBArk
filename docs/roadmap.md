# 持续开发路线图

2026-10-13 用户将目标扩展为覆盖 Navicat 全部功能，高频功能优先。首版发布只是里程碑，完整清单验收完毕前目标保持进行中。首批公开版本为 0.1.x，0.2.0 已完成三平台原生构建、安装验收及公开文件校验，实际下载以 GitHub Releases 为准。

目前没有真实使用统计。优先级依据日常开发流程、已确定的 MySQL/MariaDB 起点及数据正确性影响确定，后续按使用反馈调整。

| 顺序 | 工作范围 | 完成标准 |
| --- | --- | --- |
| P0 日常操作 | 查询与结果、浏览编辑、筛选排序、对象管理、常用文件任务、连接便利性 | 实际界面与实库验收，精度、权限与失败边界 |
| P1 常用扩展与迁移 | PostgreSQL/SQLite、传输、结构/数据比较同步、备份、会话监控、权限、Excel | 独立兼容矩阵；差异预览、取消及失败报告 |
| P2 专业数据库与工作流 | SQL Server/Oracle/MongoDB/Redis、可视化查询、ER、计划任务、字典、生成、脱敏 | 专用操作入口；验证任务释放及恢复方式 |
| P3 低频和高级能力 | Snowflake/兼容厂商、专用认证、其他格式、调试器、完整模型、BI、协作、AI | 逐平台/驱动实测，不以占位页面标记完成 |

同级先处理已有驱动的高频路径与可靠性，再扩新驱动；依赖项可提前。P3 仍属于持续目标。

5. 依完整清单推进 P1、P2、P3；每批保留测试、文档、提交与可下载版本。

详见 [全功能覆盖清单](navicat-coverage.md)；[首版功能对照](feature-matrix.md) 不能代替全功能验收。

## 约束与完成条件

在现有 DBArk 目录自主开发，不使用工作树，独立于 YZP；Electron/React/TypeScript 桌面，Windows/macOS。服务器网页版未纳入桌面交付；协作服务如有需要将自主实现。计划任务默认仅在客户端或托盘运行时执行。

开发 Docker 先核对 200 服务器，使用隔离实例、随机库及可清理资源。密钥证书按项目要求备份到 E 盘并附用途和恢复说明。第三方程序、反编译原始产物、凭据及测试数据不能公开。

全部清单子能力有实现、实际入口和测试证据，声明的跨驱动/版本/平台组合分别验收，源码、文档及安装包公开校验后才完成目标。未验组合保留待验收，未实现功能保留待开发；未具备证书的构建明确标注，不把构建通过当作发行签名或公证完成。
