# 路线图

## 第一阶段：日常开发客户端

连接与安全通道、对象树、多标签 SQL、事务、数据表格、对象定义与表设计、文件导入导出、本地配置及 Windows/macOS 打包。实际实现和验证状态以功能对照及验证记录为准。

## 第二阶段：迁移与运维

结构差异与同步、数据差异与同步、跨连接传输、备份恢复、数据库用户权限和会话监控。每次同步先生成差异与执行计划；数据库备份明确源版本、目标版本和恢复限制。

## 第三阶段：高级工作流

任务编排、本地定时任务、ER 图与模型正反向工程、可视化查询构建、数据字典、数据生成及脱敏。计划任务仅在客户端或托盘进程运行时执行。

当前不包含服务器网页版、云账号、云同步及其他数据库驱动。增加新驱动时沿用现有会话、元数据和任务接口，并单独建立方言测试矩阵。
