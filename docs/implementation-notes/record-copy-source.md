# D02后续：完整复制源只读补取

本次实现ROOT已批准的[方案](record-copy-source-proposal.md)，基于`a370224`继续开发，属于0.19后续候选代码。0.18封存输入、包、运行器保持不变。纯测试、构建与UI定义不等于真实数据库验收。

## 接口与普通查看

- `table.page`原输入行为保持兼容。只有TableTab显式提供`copySource: true`与独立任务UUID时才进入新增只读任务；所有显式复制页都在同一只读事务/MDL内复核目录及读取页面，附上`copyMetadataKey`。发现普通INVISIBLE字段可能缺值时，再核物理身份并签发行租约。
- 页结果可带`copySource`。`ready`包含`pageRef`、与行对齐的`rowRefs`（不可定位行是null）、`expiresAt`、`metadataKey`、`missingColumns`；`unavailable`只含固定原因与缺列。权限/身份/能力不足只使补取不可用，原普通查看仍可继续。没有缺列时不签发。
- `table.copySourceRead`严格接收`{ connectionId, taskId, pageRef, rowRef }`。目标、键、列与证明均来自引擎租约，不接受SQL或自造键。主进程内部注入的profile只用于建连，在进入公开严格输入前剥离；其余额外字段仍拒绝。
- 成功为`{ target, pageRef, rowRef, metadataKey, readAt, complete: true, values }`。不返回截断/部分值冒充complete，不经搜索展示、文件或通用查询历史绕行。
- `table.copySourceRelease`严格接收`{ connectionId, pageRef }`，核归属并幂等撤销。翻页、刷新、卸载释放；连接保存/关闭和引擎退出撤销旧来源，TTL兜底。

两个读取入口只在主进程内存占任务号，不保存任务/SQL历史，不发送任务事件。沿原`query.cancel`，等命令、取消控制连接和独立连接实际收尾才返回。metadata查询回调与表页终态等待都是可选端口，旧调用维持原行为。

## 身份、完整性与精度

页面SELECT、目录/实例/物理表证明、原键与已加载字段指纹签发在同一个REPEATABLE READ只读事务及MDL内完成，不能在SELECT结束释锁后给同名对象追签。补取再持MDL，重核身份、规范DDL与目录；先查长度，再显式完整投影。两次定位共用原可靠键及同一快照，LIMIT 2，必须恰好一行；0/2行、字段缺失、非支持值或原已加载字段变化均拒绝。

复用现有`prepareDataSearchRecord`的保守范围：已支持的Linux、区分大小写目录、ASCII库表名、非分区InnoDB，以及MySQL 5.7/8.0/8.4、MariaDB 10.11/11.4物理目录。没有足够权限或无法证明时只读查看，不扩大授权、不凭同名或DDL摘要猜物理身份。

BIGINT/DECIMAL/微秒保持驱动精确字符串；完整投影经带参数的二进制预处理协议读取，FLOAT/DOUBLE保留真实值，BIT使用类型化字节绑定。TIMESTAMP可靠键在页面事务内额外捕获UTC秒数；内部列剥离不展示，补取沿原时区和精确epoch定位。未加载可靠键不能用OFFSET、行号或文字猜测。

NULL是自有完整值，undefined不是；特殊属性名用自有属性构造，二进制独立深复制，不经剪贴板。新缺列以本次快照为准，界面明确显示读取时间；叠加本页显式暂存修改，只追加一条新增草稿。原行、其他草稿、选择、表单与布局保持不变；生成/自增列仍省略，后续沿原完整性门、集中预览和用户显式提交。

## 预算与意图失效

| 边界 | 限制 |
| --- | --- |
| 原始行/序列化结果 | 256KiB/512KiB，超限拒绝，不裁短 |
| 可靠键/DDL/列数 | 8KiB/2MiB/1024列 |
| 来源缓存 | 4000行引用，按序列化元数据/键/指纹计32MiB；不缓存完整行 |
| 生命周期 | 5分钟，每连接4页，同一行租约1笔在途 |
| 执行 | 15秒总期限及原取消；取消控制失败保留无法确认服务器终止的错误 |

前端在第一个await前同步占门，捕获目标/连接修订、加载代次、目录、来源对象、选择令牌、草稿引用与原值快照。输入、选择、草稿、导航、连接、取消或卸载变化永久失效，切走再切回不能复活；一次回包只能消费一次，不自动提交或重试。

## 7660独审P2修正

`7660c4b`的并行目录与来源页可能来自不同结构版本；仅把不一致的补取资格置false，会使旧目录误判普通字段已完整并走本地复制，遗漏新INVISIBLE值。原提交和员工3报告/正确安全期望保留，不改写旧失败。

修正后，按钮、实际处理器和异步回包先核同一个页绑定：目标、连接修订、加载代次、同MDL目录标识，以及行来源元数据标识；缺列名单也必须属于该完整目录。比较覆盖已知表/列字符集、排序规则、注释与原写入字段属性。结构未知或不一致时保留查看，但无草稿、任务号和补取请求；不自动回落本地，也不自动重读。完整普通行只有证明同结构才走零IPC快捷路径。事务/权限降级的普通查看页不补签标识，故不能作为复制源。

回归执行真实load、按钮、处理器及补取消费，覆盖旧目录/新来源（含unavailable）、一致结构正例、本地完整正例、未知/空标识、字段属性变化、渲染后才变化和结构/页面/来源标识ABA。员工3原正确安全断言仅适配新增协议字段和VM依赖，修前仍为原`false`对`true`失败，修后通过；适配与原件哈希记录在`.cache/d02-copy-metadata-7660/`。本次修正只跑纯测试和类型检查，不运行构建、GUI、实库或CI。
