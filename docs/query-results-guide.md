# 查询结果排序与筛选速查

本文对应当前 main 源码的 SQL 工作区，尚未随新安装包发布。操作对象是执行完毕后已经返回的结果；截断提示存在时，只处理已返回部分。任意 SQL 结果保持只读。

## 多列排序

1. 点击列头，依次切换升序、降序、清除；聚焦列头后也可按 Enter 或空格。
2. 按住 Ctrl（macOS：⌘）再点击其它列头，追加排序列。按“当前排序优先级”从上到下比较，同值再比较下一列。
3. 在优先级列表提高或降低优先级、切换方向、移除某列。每列可选择 NULL 默认位置、在前或在后；显式位置不随升降序变化。
4. 点击“恢复原返回顺序”清除排序。有筛选时，恢复筛选后的原顺序。

例如先按 `customer_id` 升序，再按 `created_at` 降序，可在每个客户内查看较新的记录。文本键可单独勾选“忽略大小写”；比较采用本地 Unicode 小写映射，不采用数据库排序规则。空字符串与 NULL 分开处理，精确整数、小数及微秒时间保持原精度。

当前源码也可点击结果工具栏“多列排序”，在独立草稿中一次选择多个字段、方向、NULL位置和文本大小写，再用上下箭头调整优先级。点击“应用排序草稿”或在面板内按Ctrl+Enter（macOS：⌘+Enter）才生效并保留当前筛选；Esc取消并保持原排序，清空仍须应用。普通Enter、输入法组合和长按不提交，完成输入后再按快捷键。规则每页十条，分页不会删掉其余规则。此入口的原生／安装验收边界见[开发记录](development/query-result-sort-panel-20261022.md)。

## 条件筛选

点击“筛选已返回结果”，选择字段、比较方式和原值，再点击“应用筛选”。编辑过程只改变草稿，取消保留已生效视图。面板内 Ctrl+Enter（macOS：⌘+Enter）应用，单独按 Esc 取消；带修饰键的 Esc 保留草稿，输入法组合期间先完成输入。该键盘保护的最新验收范围见[开发记录](development/query-result-filter-keyboard-20261022.md)。

每组可选“全部满足（AND）”或“任一满足（OR）”，并可添加子组，例如 `(status=待处理 OR status=处理中) AND amount>=100`。字段类型决定可用方式：文本包含／开头／结尾／通配、精确比较、区间、多值列表及 NULL 判断。区间包含两端；普通否定条件也排除 NULL，需要 NULL 时显式添加空值判断。

- **候选值列表**：逐项填写，逗号、换行及引号保留原文，空文本是独立值。
- **文本通配**：`%` 匹配任意长度，`_` 匹配一个 Unicode 码点；`\%`、`\_`、`\\` 匹配对应文字。其它文本比较按字面处理。
- **复制条件**：在原条件后生成独立副本，区间、成员和大小写选项保留。
- **移动条件**：有多个组时，在条件的“分组”选择框中选择最外层或子组，原条件移至目标组末尾，原值与启用状态保持。点击应用才生效；空源组需补条件或移除。
- **暂时停用**：取消条件的“启用”勾选，保留原值。“全部停用／全部启用”覆盖所有子组，仍须应用；全部停用后显示全部已返回行。
- **按单元格追加**：选择单元格，点击“追加等值条件”或“追加排除条件”，审阅草稿后应用。

应用或清除筛选保留完整多列排序（含 NULL 位置和大小写），重置勾选、查找和行详情。条件最多32条、16组（含根）、8层；无效值或超限会保留原视图并提示。放宽筛选后若原排序无法比较新行，整次保留旧筛选和排序；可检查规则或先点击“恢复原返回顺序”再调整筛选。详见[联动与验证范围](development/query-result-filter-preserve-sort-20261022.md)。

## 撤销与重做整理

点击结果工具栏的“撤销结果整理／重做结果整理”，按整步恢复已应用的排序和筛选。取消草稿不记步，新操作会清除重做分支；最多保留20步，条件过大时会缩减历史或清空记录，当前条件保持完整。此操作不执行SQL，也不撤销数据库写入或编辑器正文。

聚焦结果网格后，也可按 Ctrl／⌘+Z 撤销、Ctrl／⌘+Shift+Z 重做；Windows另支持 Ctrl+Y。输入框保留自身撤销行为，长按不连续跨步；新快捷键的窗口验收范围见[开发记录](development/query-result-history-keyboard-20261022.md)。

恢复会清空旧勾选、查找和行详情；复制、导出沿恢复后的视图。新查询、切换结果或列布局，以及连接修订／标签失活会清空历史。记录只保存在内存，不能作为命名方案跨查询复用；实现及验收范围见[整理历史](development/query-result-history-20261021.md)。

## 复制、导出与范围

网格、查找、行详情、复制和“导出勾选结果”共用当前筛选与排序后的视图。导出窗口关闭后应重新勾选，再执行下一次导出；CSV／JSON保留各自的 NULL、二进制和精度表示。

这些整理操作不会重发 SQL。若需要对数据库全部记录筛选排序，请在查询中明确写出 WHERE／ORDER BY 后重新执行；完整流式导出属于独立任务。列类型、原值或结果大小超出本地比较预算时，界面会说明原因。
