## REA / Ghidra

已在隔离工具目录配置 REA 6.4.0、Ghidra 12.1.4 和 JDK，并校验官方工具产物。REA 健康检查和 PE 资源提取成功；本机 Navicat Premium 17.0.8 x64 随附的 `libmariadb.dll` 分析成功，可取得连接、查询、取消、提交、回滚导出函数的伪代码及引用。

85 MiB 主程序的 Ghidra 分析超过 15 分钟限时，未取得可用主程序反编译结果，不能据此宣称完整 UI 调用链已经验证。证据、哈希和限制见 [逆向分析记录](reverse-engineering.md)。本机程序、原始产物和测试数据位于忽略目录，不进入公开源码。

## 发布边界

已按用户授权创建公开仓库 [zhao-yc/DBArk](https://github.com/zhao-yc/DBArk)，采用 MIT 许可证。当前是开发预览，兼容矩阵和发布产物的记录随实际验收更新。

GitHub Actions 配置了类型检查、单元测试和 Windows/macOS 构建，产物上传为工作流附件，不自动发布。Windows 主机尝试构建 macOS ZIP 时，electron-builder 明确拒绝并要求 macOS 构建机；将通过 macOS 工作流生成产物，不把本机失败视为平台通过。签名、macOS 公证和自动更新尚未接入；首版手动安装升级。
