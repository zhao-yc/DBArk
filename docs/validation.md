三平台源码及真实 NSIS/DMG 安装验收：[工作流 38410500102](https://github.com/zhao-yc/DBArk/actions/runs/38410500102)，全部通过。公开分发文件以版本标签发布工作流生成的附件及校验清单为准。

离线桌面测试实际启动 Electron，检查 Windows/macOS 渲染进程的系统沙箱标志、上下文隔离、不可访问 Node、参数校验、数据库进程请求、凭据落盘/重启、布局和 SQL 恢复，以及退出后进程释放。系统加密不可用时，验证会话密码不落盘。七项离线通过不能替代数据库连通性证明。

两条 Windows 实库界面测试使用 MySQL 8.4.11，通过实际连接表单、对象树、Monaco 和表格完成操作，再由独立观察连接核验数据库值；包括尚未展开连接时创建数据库、选中 SQL、多结果集、事务提交/回滚、取消后复用、预览后集中提交、多行粘贴、CSV 字段映射、JSON/SQL 导入导出及 SQL 实际恢复。测试只创建随机隔离库，结束后确认残留为零。

新增实库界面回归验证：已有查询会话时，通过表单和直接 IPC 修改地址/端口均被拒绝，存储配置未变，原查询仍能在原库执行；修改连接名称可正常保存，重启后新名称及真实加密凭据恢复。该轮本机 NSIS 的 SHA256 为 `8f6a5911ca5b551d7c49cb84522f4c1c9ca0ef47cc1e843df75a616fa7984fdb`。发布工作流重新构建的附件以随包 SHA256 清单为准。

Windows 开发测试机曾遇到 Chromium AppContainer 对项目运行时目录的读取权限冲突；仅给本项目 Electron 运行时增加“所有应用程序包”只读/执行权限，没有关闭沙箱。实际 NSIS 安装目录无需额外调整 ACL。

## 数据库兼容性

全部真实测试使用用户指定的 200 开发服务器。通过 `ssh server-200` 核对服务器身份，每次 Docker 操作前再次检查；未执行本机 Docker。仅创建 DBArk 专用容器、网络、测试库和临时账户。

| 数据库 | 服务端实际版本 | 核心套件 |
| --- | --- | --- |
| MySQL 5.7 | 5.7.44 | 12 项通过 |
| MySQL 8.0 | 8.0.46 | 12 项通过 |
| MySQL 8.4 | 8.4.11 | 13 项通过，边界另 3 项通过 |
| MariaDB 10.11 | 10.11.19 | 12 项通过，边界另 3 项通过 |
| MariaDB 11.4 | 11.4.13 | 12 项通过 |

核心套件验证精确值、重复结果列、脚本总上限、临时表/事务会话隔离、乐观锁整批回滚、宽松排序规则冲突、latin1、取消后复用、CSV/JSON 往返、DELIMITER、导入未闭合事务回滚、EXPLAIN 及巨大字段保护。以下独立边界也已实测：

- SSH 私钥认证及固定指纹：完整 12 项通过；错误指纹正确拒绝。
- MySQL 8.0 严格 TLS：完整 12 项通过；不受信 CA 和错误 IP SAN 正确拒绝。
- SELECT 账户写入被拒绝，无写入副作用。
- 已提交 INSERT 后强制断开：旧会话失效，写入保持一条，不自动重放。
- SQL 结构与数据导出后实际恢复，BIGINT、DECIMAL、中文及 BLOB 逐值一致；原型同名字段正常往返。
- 百万行末页读取 500 行耗时 1.604 秒；CSV 完整导出 1,000,000 行、188,888,905 字节，耗时 45.923 秒。采样 RSS 增长约 61.64 MiB。取消另一次导出后，目标和临时文件均清理，源表行数不变。

详细条件、指标与清理情况见 [数据库引擎验收记录](../tests/integration/acceptance-20261013.md)。这些数字属于该环境及数据分布，不是所有设备的性能保证。SSH 密码认证、双向 TLS 客户端证书、百万行表格人工滚动等没有单独实测，不据此宣称全部连接组合通过。

## REA / Ghidra

已配置 REA 6.4.0、Ghidra 12.1.4 和 JDK，校验官方工具产物。REA 健康检查及 PE 资源提取成功；本机 Navicat Premium 17.0.8 x64 随附的 `libmariadb.dll` 分析成功，取得连接、查询、取消、提交和回滚导出函数的伪代码及引用。

85 MiB 主程序分析超过 15 分钟限时，未取得可用主程序反编译结果，完整 Navicat UI 调用链及所有操作行为尚未验证。证据、哈希和限制见 [逆向分析记录](reverse-engineering.md)。公开仓库只包含自主实现、取证工具和脱敏结论；第三方程序及原始反编译产物不进入源码。

## 发布边界

公开仓库为 [zhao-yc/DBArk](https://github.com/zhao-yc/DBArk)，采用 MIT 许可证。发布产物为 Windows x64 NSIS、macOS arm64/x64 DMG/ZIP、源码 ZIP、中文文档和 SHA256 清单。维护者推送版本标签后，由全部平台检查通过的工作流发布开发预览。

Windows 未发行签名；macOS 仅 ad-hoc 签名，没有 Developer ID 与公证。首版手动安装升级。macOS 已在对应原生架构的 GitHub 构建机验证应用，未在用户实体 Mac 上检查 Gatekeeper 首次安装交互，也没有从 macOS 构建机连接内网测试数据库。连接/编辑/导入导出的真实界面验收目前来自 Windows。

服务器网页、同步、备份恢复、权限管理、计划任务和建模属于后续里程碑。现有复杂表结构通过 SQL 定义编辑，不能把简化表设计器当作任意 DDL 的无损编辑器。
