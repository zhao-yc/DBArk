# 使用指南

## 安装和升级

Windows 使用 `DBArk-版本-win-x64-unsigned.exe` 安装。macOS 构建按 arm64（Apple Silicon）和 x64（Intel）区分。当前为开发预览：Windows 无发行签名，macOS 仅 ad-hoc 签名、未公证。三种架构已完成原生构建与随包应用测试，实体 macOS 设备的 Gatekeeper 首次安装仍待单独验证。

首版采用手动升级：退出 DBArk 后安装新版，配置库保留在当前用户的应用数据目录。升级、卸载或迁移前，退出应用并备份整个用户配置目录，包含 `dbark.sqlite` 及目录内其他文件；密码密文依赖原电脑的系统账户，迁移后通常需要重新输入密码。不要把配置库上传到公共仓库。

0.3.0 SQL 片段功能将 SQLite 配置格式从 schema 1 升级到 schema 2。升级保留已有连接、查询、历史和偏好设置；迁移或写盘失败时保留原配置文件，不提交失败的内存修改。旧 0.2.0 客户端不能读取 schema 2，不能通过删除新数据库、手动降低版本号或重置配置来回退。需要回退时先保留当前完整用户配置目录，再恢复升级前的完整目录备份；备份之后新增的片段等内容不会自动回到旧版本。

## 建立连接

点击“新建连接”，填写连接名称、主机、端口、用户名和密码。“连接分组”和“标识颜色”用于区分开发、测试等环境。先“测试连接”，再“保存连接”；测试操作不会保存配置。

SSH 模式填写 SSH 主机、端口、用户名和密码或私钥文件，并填写从可信渠道获得的 `SHA256:…` 主机指纹。数据库主机填写从 SSH 服务器可达的地址，例如数据库监听在隧道服务器上的 `127.0.0.1`。私钥口令与数据库密码分别保存。

TLS 默认验证服务端证书。私有 CA 或自签证书使用 CA 文件；服务端要求双向认证时再提供客户端证书和私钥。“安全保存密码”使用系统加密服务；服务不可用时密码只在本次应用会话存在。

保存的密码不会显示在编辑表单中。留空保持原密码，使用“清除”明确改为空密码，再保存连接。

编辑已有连接时，只要该连接还有打开的查询或表数据标签，就不能保存主机、端口、用户名、默认数据库、数据库类型、密码或 SSH/TLS 配置的变更，避免旧会话和当前显示的服务器配置不一致。请先保存需要保留的查询、提交或放弃数据草稿、提交或回滚事务，再关闭此连接的全部标签后修改。拒绝保存不会关闭标签或清除草稿；名称、分组、标识颜色和“安全保存密码”偏好仍可修改，测试连接也仍可使用。

### 连接概要复制与迁移（0.7.0 开发中）

侧栏连接菜单的“复制概要”打开新连接表单，只复制主机、账号、分组、颜色及 SSH/TLS 设置；保存时生成新 ID。数据库密码、SSH 密码、私钥口令、已保存秘密标记和原连接表列偏好不复制，也不会自动测试或建立连接。

“连接导入导出”可选择所需连接，导出 DBArk 自主 JSON 概要格式。文件不包含密码、密文、私钥或证书内容，认证文件只写文件名提示。导入先显示目标、同 ID/同名/同目标候选及缺认证提示，逐项选择“新增”或“跳过”；新增始终生成新 ID，不替换既有连接。明确勾选仅暂存概要后最终确认，一批一次保存；失败不自动重试。首批不支持覆盖已有连接、秘密迁移或 Navicat 私有配置格式。

源文件在预览后变化不会改变已显示快照；本地连接配置在预览后变化会使确认失效，须重新预览。预览有效期十分钟，最终确认尝试一次后失效。单文件最多 500 条连接、2 MiB UTF-8 JSON，未知字段、秘密字段、绝对认证路径、重复来源 ID、非法版本或编码均拒绝。

复制或导入的私钥、CA、客户端证书和证书私钥须在编辑连接中通过本机选择器重新选择，保存后才可连接。文件名提示或手工输入同名路径不能完成重新选择；缺文件标记即使暂时关闭 SSH/TLS 也保留，以后开启仍阻止误连。严格证书验证及 SSH 指纹设置会保留，不因迁移而改用系统 CA 或密码方式。密码需自行补充，导入新增默认不持久保存密码。

开发版将用户配置升级至 schema 4，以保证旧版不会忽略缺认证文件标记后误连。0.6.0 及更早版本拒绝读取升级后配置；升级前退出应用并备份整个用户配置目录，回退恢复升级前完整备份，另行保留升级后目录，不能修改数据库版本号。上述功能尚待本批实际桌面、安装包及公开版本验收，结果见对应发布说明。

## 浏览对象和数据

打开左侧连接，展开数据库和对象分类。表可打开数据标签；视图、过程、函数、触发器和事件通过 SQL 定义查看或编辑。连接搜索按名称、分组、主机和用户筛选。

表数据分页由服务器完成，客户端仅持有当前页。点击列标题排序；使用“筛选”组合字段条件。切换页码、排序、筛选或刷新前，先提交或放弃当前草稿。

0.2.0 支持选择“满足全部条件”或“满足任一条件”，点击已有条件可修改，叉号移除条件。集合使用逐行输入，逗号和前后空格作为值保留；空行表示空字符串，也可勾选“包含空字符串”。区间上下限分别输入，NULL 使用专用空值条件，不能把文本 `NULL` 当空值。整数与精确小数筛选接受普通十进制字符串，不接受科学计数法或超出精确范围的值。

页码输入后点击“跳转”直接读取目标页；不会为获得总页数而自动扫描整表。超出实际数据的页可以为空，仍可跳回已有页。筛选、排序或页大小变化从第一页开始，取消放弃草稿确认时不会切页或更改已应用条件。

双击单元格或使用键盘进入编辑。“单元格”对话框提供文本/精确数值、JSON、十六进制二进制和 NULL 模式。BIGINT、DECIMAL 与日期时间以文本保留原精度。空字符串与 NULL 是不同值。

新增行尚未填写的字段显示“默认值”，表示提交时省略该字段，由服务器决定缺省行为；它与 NULL 和空文本不同。DBArk 内部复制保留该状态，粘贴到新增行可恢复字段缺省，粘贴到已有记录则明确拒绝整组修改，需显式填写值。跨应用的 TSV 无法表达数据库默认值，未填写字段输出空文本；从其它应用粘贴空文本不会被猜测为 NULL 或默认值。合法的 `__proto__`、`constructor` 等列名按真实单元格处理，不读取对象继承属性。

“新增”“删除”和粘贴只形成当前页草稿。点击“预览并提交”核对 SQL，随后“确认提交”。更新或删除会比较读取时的完整原值；发现其他会话修改时整批回滚，重新读取后再决定如何处理。

没有可靠唯一键、非事务存储引擎和视图以只读方式打开。任意 SQL 结果也只读；需要写入时执行明确的 SQL 或打开对应表数据标签。

## SQL 工作区

创建查询时选择连接和可选数据库。每个标签保持独立会话，因此临时表、会话变量和事务不会在标签间共享。Monaco 提供本地高亮、元数据补全和格式化。

执行前选择 SQL 文本；没有选择时执行整个编辑器脚本。脚本解析支持注释、字符串及 MySQL `DELIMITER`。多语句返回多个结果集，总显示行数受偏好设置的上限约束；大结果还有内存限制，完整数据使用导出任务。

“执行计划”仅接受一条可解释语句，不执行 `EXPLAIN ANALYZE`。事务可以开始、提交或回滚；DDL 通常隐式提交，执行前核对 SQL，不能依赖回滚撤销结构变更。

“停止”按任务编号取消查询。连接中断后客户端不会重放写入语句，先核对服务器状态，再手动建立新会话。历史与保存的查询位于“历史与查询”。

0.2.0 支持“固定结果”：成功执行后保留已返回的只读快照，重新执行后可以从“固定快照”切回旧结果，或返回“本次结果”。“快照 SQL”显示原语句，查看窗口内的执行快捷键不会执行后台 SQL。失败或取消后的流式片段不能固定。每标签最多 5 组、合计 16 MiB，超限拒绝新快照，不截断已有快照；达到查询上限的快照同样只包含已返回数据。固定结果不写入配置库，关闭标签或退出后释放，不改变事务及数据库数据。

0.3.0 起支持“打开 SQL 文件”和“另存 SQL 文件”。先打开查询标签，再从工具栏选择文件和 UTF-8、UTF-16LE 或 GB18030；UTF BOM 优先确定读取编码。打开总是新建同一连接、数据库下的查询标签，保留原 SQL 和事务；另存仅保存打开对话框时的全部 SQL 正文，不执行语句或提交事务，也不修改原标题。文件最多 20 MiB、2000 万字符，更大脚本使用 SQL 文件导入任务。无效编码、NUL、UTF-16BE 或无法无损保存的 Unicode 会拒绝；保存写完临时文件后替换目标，失败不先删除原文件。“保存查询”仍保存到本地查询库。

0.3.0 起支持“导出已返回结果”：选择当前成功结果集或固定快照，在对话框核对行数、列名及最多 20 行预览，选择 CSV/JSON、编码及保存位置后开始。此操作不重新执行 SQL、不读取服务器上其余行，断线后的旧快照也可导出。截断结果明确只包含已返回部分；失败或取消查询的流式片段不可导出。重复和空列名会生成唯一标题/键，预览显示对应关系；CSV 沿用 `\N`、反斜线及 Base64 协议，JSON 保留精确字符串、NULL 和二进制对象。结果导出限定 100000 行、1024 列、2000000 单元格、单字段 256 KiB、单行 1 MiB、输入总预算 32 MiB。任务面板显示进度，取消或失败保留原文件；原子替换已经开始后不能撤销成功保存。

### 完整流式导出（0.5.0 开发版）

点击查询工具栏的“完整流式导出”。打开时固定当前选区，没有有效选区时固定全文；选择文件、编码或配置参数不会执行 SQL。最终“执行 SQL 并完整导出”会在当前查询标签会话进行一次新的执行，保留其临时表、变量与事务。它不续读旧结果，也不自动开始、提交或回滚事务。

JSON 保存全部异构结果集与状态结果，文件包含 `DBArk-query-results` 版本封装、列位置、原名和唯一输出名。该封装与表 JSON 导入的对象数组不同，当前不能直接作为表数据恢复。CSV 选择本次执行的第 N 个行结果集，从 1 开始；空行结果仍占序号，写入状态包不占行结果序号。其它结果和后续 SQL 仍完整执行一次，选中结果不存在会保留原文件，但不能撤销此前已提交的写入。

默认“文本严格模式”保持普通文本执行和诊断，不增加预处理。遇到 FLOAT/DOUBLE 会停止完整导出并保留原文件，因为服务器文本格式可能合并相邻浮点值；本条 SQL 可能已经执行。需要这些类型时明确选择“二进制模式”并确认其首次准备可能改变警告诊断。诊断和控制语句预先走文本，不在失败准备后自动回退执行；这部分文本路径遇浮点也会明确拒绝。

如需值参数，先点击“配置类型参数”，填写九种支持类型，再“应用参数”返回最终确认；此步骤不执行模板，参数只在本次操作内保留。历史保存 SQL 模板，失败任务概要不保存服务端展开错误或实际填写值。

完整文件不受工作台显示行数限制；工作台预览每结果最多 200 行、合计 16 MiB。当前完整任务最多 200 个含状态的结果、1024 列，原始及序列化字段分别限制 8 MiB、单行 16 MiB、文件 10 GiB；Base64、JSON 转义或编码可能使实际预算更早达到，超限明确失败，不截断文件后报告完整。进度使用已执行语句、已写行和字节，没有自动 COUNT 或百分比预扫描。

“取消任务”等待实际命令及文件清理结束；取消、断线和磁盘失败都不会重放 SQL。文件替换开始后的迟到取消不能撤销已保存的文件。失败后“再次执行”需要重新确认，是新的数据库操作，先核对已提交部分及事务；客户端不把它包装为单独重试文件写入。同一目标文件被其它保存或导出占用时明确拒绝并发操作。

### SQL 片段库（0.3.0 起）

查询工具栏的“SQL 片段库”保存可复用 SQL。新建时使用当前选区，没有选区时使用当前查询正文；填写名称、分组、说明和正文后保存。可以按分组筛选，并搜索名称、分组、说明或正文；同名、同组片段允许并存，编辑只修改所选记录。“复制为新片段”创建独立副本；删除需要确认，关闭或切换尚未保存的编辑时可取消或明确放弃。

内置 MySQL/MariaDB 模板提供读取、分组统计和执行计划示例，可查看、插入或复制为用户片段；先根据实际数据库修改表名、列名和条件。片段不绑定具体连接，也不执行 SQL。“插入查询”替换打开片段库前的查询选区，或在当时光标位置写入；正文中的 `$`、JSON、注释和引号按原文保留，不作为编辑器插值。插入保留查询撤销栈，可以用撤销恢复，已有结果、事务和会话保持不变。预览窗口中的执行和保存快捷键不会作用于后台查询。

用户片段单独持久化，不占用保存查询或工作台设置字段。最多保存 500 条；名称、分组分别最多 100 字符，说明最多 2000 字符，单条正文最多 65536 字符，全部用户正文最多 4 MiB UTF-8 字节。内置模板不计入用户配额；达到条数上限仍可以编辑原片段。保存失败保留输入和原记录，可处理错误后重试。

### 类型参数查询（0.3.0 起）

在 SQL 中用独立的 `:name` 表示一个值，点击“参数执行”。当前选区优先，没有选区时使用全部 SQL；表单打开后本次模板固定，不跟随后台草稿变化。名称为 1～64 位 ASCII 字母、数字或下划线，首字符不能是数字；名称区分大小写，同一名称多次出现共用一个值。普通注释、字符串和引号包裹的标识符中的 `:name` 不绑定；可执行版本注释内部按 SQL 分析。

```sql
SELECT :id AS id, :keyword AS keyword, :id AS repeated_id;
```

例如为 `id` 选择“整数”并填入 `9007199254740993`，为 `keyword` 选择“文本”并填入查询文字，然后点击“执行参数 SQL”。参数只能代表 SQL 值，不能替换数据库、表、列名、排序方向、SQL 关键字或整个表达式；这些结构直接写在模板中。参数执行继续使用当前标签会话，因此现有事务、临时表和会话变量仍在同一会话内。

| 类型 | 输入约定 |
| --- | --- |
| 文本 | 普通文字；空字符串、引号、反斜线按实际值处理。 |
| 整数 | 普通十进制，可带正负号，最多 65 位有效数字；不经 JavaScript 数值转换，拒绝指数和 SQL 表达式。 |
| 小数 | 普通十进制，保留精度；最多 65 位有效数字，小数位上限依据服务器为 30 或 38。 |
| 布尔值 | `true` 或 `false`。 |
| 日期 | 有效 `YYYY-MM-DD`，年份 1000～9999，不接受零日期。 |
| 日期时间 | `YYYY-MM-DD HH:mm:ss[.微秒]`，最多 6 位微秒，不接受时区后缀或零日期。 |
| 时间 / 时长 | `[-]HH:mm:ss[.微秒]`，小时 00～838，最多 6 位微秒；端点是否接受非零微秒由服务器类型决定。 |
| 二进制（Hex） | 偶数位十六进制，例如 `00ff`，不带 `0x`；空值表示空二进制。 |
| NULL | 不填写值；与空文本、空二进制不同。 |

最多 200 个不同参数，每个值最多 64 KiB UTF-8 字节，所有值合计最多 1 MiB；单条语句的占位符最多 100000 处，模板及展开后 SQL 合计各有 20 MiB 上限。孤立 Unicode 代理项会被拒绝，不静默改写输入。识别失败可重试；手动重新识别按参数名保留已填写的值。表单预览过长时只显示前 65536 字符，执行仍使用完整模板。

静态可分析脚本会在发送第一条用户 SQL 前核对完整模板的参数、缺参、多余参数及展开预算。明确的常量 `SET sql_mode` 可以预演词法模式；无法静态确定模式的 `SET`、程序调用或可执行版本注释会提示名称预览可能不完整，可手动添加后续语句需要的参数。动态脚本执行时按每条语句完成后的协议状态继续扫描、绑定。关闭会话变量跟踪或服务器错误可能使模式无法确定；此时只执行各候选模式下语句和参数边界均一致的 SQL，实际歧义会明确停止，不能猜测引号边界。后续缺参、模式或语法错误、累积预算超限和最终多余参数错误会停止脚本，**此前已提交的语句及 DDL 不会撤销，未提交事务也不会自动回滚或重放**。静态参数校验通过同样不保证服务器后续语句成功；执行写入前须核对整个脚本，失败后先检查事务和已提交数据。

服务器错误包不提供当前事务状态，界面会显示“事务状态需核对”，关闭时继续保护该标签。可以明确选择“提交”或“回滚”；后续成功查询也会按实际协议状态更新提示。客户端不通过内部 `SELECT` 或 `DO` 探测状态，以保留 `ROW_COUNT()`、`FOUND_ROWS()` 和警告诊断，也不会把上一次事务状态当作错误后的确定事实。

参数值不写入工作台、保存查询、历史或任务记录；这些位置保留 SQL 模板，任务和历史错误不会保存可能含值的服务器详情。模板中直接写入的字面量仍属于 SQL 正文，并不会被删除。查询结果、只读快照和用户导出的结果文件可能包含实际参数值；关闭标签只释放内存结果，不删除已导出的文件。已有会话的参数识别和语句间模式读取使用协议缓存，不插入额外诊断 `SELECT`，以保留 `ROW_COUNT()`、`FOUND_ROWS()` 和警告状态；连接已经失效时不自动重放语句。

## 页内查找替换与列布局（0.6.0 开发版）

表标签点击“当前页查找替换”，选择文字、SQL NULL 或未填写 DEFAULT，再选择可见列范围。文字支持大小写和整格匹配，读取完整原值而非截断的单元格预览；使用上一处、下一处跳转，未渲染行会继续通过虚拟滚动显示。范围仅是当前已加载页，包含未提交草稿、排除待删除行；其它页使用“打开服务器筛选”，不会因查找悄悄扫描全库。

网格活动时 Ctrl/Cmd+F 聚焦查找、Ctrl/Cmd+H 聚焦替换。单元格编辑器、其它输入框或模态内不会触发后台查找。文字 `NULL`、实际 SQL NULL、空串和 DEFAULT 分开；BIGINT/DECIMAL 不作数值转换，二进制不参与文字搜索。

填写“替换为文字”后先“预览当前页替换”，再“确认形成替换草稿”。首批只替换有可靠键的可写 InnoDB 表的非生成 CHAR、VARCHAR、TEXT 字符串列；JSON、数字、日期、ENUM、SET、NULL、DEFAULT、二进制不会被文字替换。确认只改本地草稿，仍需原“预览修改”和集中提交才能写数据库；其它连接改过旧值时整批提交回滚。页面、目标行或已加载结构变动会使替换预览失效。查找词最多 512 字符、替换词 4096 字符，扫描和计划有 16 MiB/50000 次匹配预算，超限明确拒绝，可缩小列范围后重新预览；首批不支持用户正则或单处替换。

“表列偏好”可显隐、前移/后移并设置 64～2000px 列宽；网格也可拖动列和调整宽度。布局立即用于当前页，点击“保存表列偏好”成功后才可重启恢复；未保存或保存失败会持续标明，关闭标签前按需保存。隐藏或重排不会刷新数据或丢草稿；勾选行复制与矩阵粘贴遵循当前可见列顺序，隐藏主键仍保留数据库提交定位。至少留一列；新增列自动追加、删除列忽略旧偏好，恢复默认只重置当前表布局。

0.6.0 将本地配置升级到 schema 3，布局按连接、数据库和表独立保存，不保存搜索值、筛选、行数据或凭据。0.3～0.5 不能读取 schema 3，升级前备份完整用户目录，回退按前文使用升级前备份；不要修改版本号或删除新库。当前为开发批次，实际验收状态见 D06 记录。

## 外键值选择与关联浏览（0.4.0 已发布）

在表标签选中一个外键单元格，点击“选择外键值”或“查看关联记录”。同一列参与多个外键时，在窗口明确选择约束。窗口显示来源与目标列的有序映射；跨库目标按真实外键定义读取，不根据连接默认数据库猜测目标。

候选默认每页 50 行，可筛选、排序、切换页大小或直接跳页。选择父行后点击“使用选中关联值”，客户端复核当前外键定义和父记录，并一次更新复合键的全部列。此时只形成原表的本地草稿，其它字段及已打开父表的草稿保留；通过原表“预览修改”和“确认提交”才写入数据库。提交仍使用可靠唯一键和完整旧值冲突检测，失败不覆盖其它连接的新数据。

“查看关联记录”只显示当前行的完整外键元组匹配结果，普通筛选的“任一”不会扩大到其它父记录。NULL 或尚未填写的默认值表示没有完整关联，不发送无条件父页查询。来源只读表仍可查看关联；无可靠非空唯一键的父表当前明确拒绝分页，需要使用 SQL 查看。

整组字段均可空且可写时，可点击“清空关联值”并确认，两列或多列一起暂存 NULL。父表 SELECT 权限不足不阻止合法清空，仍会复核最新源定义；其它父表读取错误显示实际错误，不返回替代候选。约束或源行草稿变化、父行删除时拒绝旧选择，保留原草稿，需重新读取。

读取期间可取消或关闭窗口。客户端等待本次独立服务器连接结束才允许原表继续操作；取消不提交或回滚查询标签里的事务。控制连接失败时明确说明不能确认服务端任务已结束，不伪报取消成功。

## 结构修改

新建或设计表时配置字段、主键、索引和外键，先生成 SQL 预览再执行。复杂已有结构（例如生成列、表达式默认值、部分特殊索引）通过 SQL 定义编辑，避免设计器丢失无法保留的属性。数据库创建和修改也先显示 DDL。

旧“设计表”流程（0.2.0）保留没有变化的索引与外键。同名外键的定义确需修改时，预览会先删除旧外键，再执行主体 ALTER 添加新约束；这两步不能保证原子完成。若第二步失败或被取消，需根据原定义恢复外键，执行期间应暂停相关写入。必须核对预览中的警告与全部语句。下述独立“外键差异”窗口采用新的受控计划，同名替换规则见对应章节。

### 字段差异编辑（0.8.0）

从对象树数据表操作，或表标签工具栏打开“字段差异编辑”。先读取实际定义，选择已有字段并勾选确需修改的属性，或新增普通字段、标记删除。未勾选的属性保留原值；“应用本行草稿”只暂存修改，不发送 DDL。默认值分别选择无 DEFAULT、SQL NULL、文字量或受控 CURRENT_TIMESTAMP；空字符串、文本 NULL 与 SQL NULL 不同，精确数字使用原数字文本，二进制使用偶数位 HEX。

点击“生成字段差异预览”，逐项核对只读 SQL、删除或转换风险及维护窗口确认，再点击“确认执行本次字段差异”。本次令牌只能使用一次，外部结构或连接配置改变会拒绝旧计划，必须重新读取与生成预览。该操作使用独立短连接，查询标签的事务及临时表保持；目标表有未提交数据草稿或活动操作时先阻止入口，其它表的草稿保留。

界面区分已执行并核验、已执行但未核验、尚未发送，以及结果未知。取消、断线或核验失败都不等于结构回滚；保留 SQL 和结果提示，独立核对数据库后再决定下一步，客户端不会自动重放。未核验或未知时目标表页过期，已有数据草稿保留，需手工刷新。

MariaDB 某些默认表达式即使只改旁列或原生改名，也可能改变后续默认值。因此存在风险默认值时整表字段 ALTER 受保护，只有能够可靠定位并完整覆盖全部风险默认值的单批显式替换/删除才可能开放；语法本身无法可靠解析时仍只读。MySQL 5.7/MariaDB 的部分二进制文字默认值在服务器定义和目录中已丢失原字节，客户端将原值标为不可可靠解析，禁止重述该列及自动结构导出；显式替换/删除默认值和旁列操作按能力开放，但不能证明结果时仍显示未核验。不要直接把不可靠的 SHOW CREATE 文本复制用于重建。

首批暂不通过此窗口编辑索引、外键、生成表达式、列字符集/排序规则、可见性、空间属性、分区及表选项。具体版本、平台和验收范围见 [0.8 版本记录](releases/v0.8.0.md) 与 [O01 验收](../tests/integration/acceptance-o01-columns-20261014.md)。

### 索引与主键差异（0.9.0）

从对象树数据表操作或表页工具栏打开“索引与主键差异”。已有索引可按实际能力编辑、改名或标记删除，也可新增普通、唯一或主键 BTREE。逐项选择字段并用上/下移调整顺序；前缀留空表示完整字段，字符列按字符、二进制列按字节。TEXT/BLOB 必须指定前缀。主键名称固定为 PRIMARY，只接受已经 NOT NULL 的普通完整字段；MySQL 5.7 不开放 DESC。

“应用索引草稿”只暂存本行。多项差异完成后生成只读 SQL 预览，核对字段顺序、约束影响及中文风险确认，再明确执行。单纯改名使用原生 RENAME INDEX；需要重建时 SQL 会明确展示 DROP/ADD。替代支持键等组合必须整批预览通过，能形成草稿不代表能够执行；界面保留单项依赖限制的原因。

独立短会话不借用查询标签。目标表有未提交数据草稿或活动操作时阻止入口，执行前再次检查；已核验后精确刷新目标表页并重新判断可靠键。取消、断线、真实重复值错误或核验失败不能当作回滚；一次性计划不能重试，应核对实际定义后重新读取。

首批仅开放已实证五个精确基线版本、InnoDB/DYNAMIC/16 KiB 页，其它能力显示只读；全文、空间、表达式、不可见/忽略、生成及陌生属性旧索引保留原片段只读。无权读取完整入向外键目录时会说明不完整，不能据此删除可能支撑依赖的旧键。Maria 风险默认值及旧版二进制默认保护继续适用。具体版本、当前验收与限制见 [0.9 说明](releases/v0.9.0.md)。

### 外键差异（0.10.0）

在左侧对象树的数据表操作区点击“外键差异”，或打开表数据标签后点击工具栏的同名按钮。窗口读取实际外键、子表字段及可读取的父表定义，保留每条约束的“原外键片段（只读）”和受限原因。子表有数据草稿或活动操作时先处理完再进入；执行前还会检查全部已加载父表的工作区，隐藏标签里的草稿也受保护。

新增或替换外键前，先显式准备并确认已存在的支持索引。子表需要完整字段、升序、可见且可识别的 BTREE 索引，外键字段按顺序位于该索引开头；父表必须有字段数量和顺序精确匹配的完整 PRIMARY 或 UNIQUE 键。前缀键、普通非唯一父键或无法确认属性的键不能充当本批支持键。字段类型、长度、精度、字符集及排序规则采用严格相容检查。缺索引时先通过“索引与主键差异”等明确操作创建，再重新读取外键；外键窗口不会自动建索引、改字段或修复现有数据。

1. 需要另一个父表时，在“候选父表数据库”和“候选父表名称”中分别填写真实名称，点击“加载候选父表并重读”。同库或跨库均需明确目标，名称保留大小写与空格，最多添加 16 个额外候选父表。已有外键的父表按实际定义读取。加载或移除候选会重读整个快照；有草稿或本行输入时，弹窗内先选择“保留当前编辑”或“确认继续”。新读取失败时旧草稿保留供核对，旧快照不能继续执行。
2. 点击“新增外键”，或对可编辑的已有外键点击“编辑外键差异”。填写“外键名称”，选择“父表”。新名称限 64 位以内 ASCII 字母、数字和下划线，首字符不能为数字。父表列表包含当前子表本身，可直接选择它建立自引用；自引用仍需符合相同的支持索引、类型和动作要求。
3. 在“有序父子字段映射”中逐行选择“子表字段”和“父表字段”，用“添加字段映射”、移除及上下移调整复合外键。每行两侧共同组成一对，移动同时改变两侧顺序；任一侧不能重复字段。父表显示的唯一键用于核对，最终是否符合精确顺序由预览裁决。切换父表后须重新核对映射，不能把另一父表的同名列当作原列。
4. 分别设置“父键更新时”和“父行删除时”，点击“应用外键草稿”暂存本行。删除已有约束使用“标记删除外键”，在窗口内确认后也只形成草稿；“撤销外键草稿”可撤销该项。以上步骤均不发送 DDL。
5. 点击“生成外键差异预览”，核对固定只读 SQL、目标和全部警告，再逐项勾选本次显示的风险确认。最后点击“确认执行本次外键差异”，本次计划只允许尝试一次。

| 引用动作 | 选择含义 |
| --- | --- |
| 限制（RESTRICT） | 对存在相关子行的父键更新或父行删除施加限制。 |
| 不操作（NO ACTION） | 明确使用服务器的 NO ACTION 动作，界面不自动改写为 RESTRICT。 |
| 级联（CASCADE） | 让服务器按所选更新或删除动作级联处理相关子行。 |
| 置空（SET NULL） | 将相关子字段置为 NULL；映射中的全部子字段必须已经允许 NULL。 |

窗口显示当前版本已经确认的省略动作默认值，新增草稿据此初始化；用户仍需核对两项动作。修改已有外键以同一条 ALTER 中的 DROP/ADD 表示，但首批**不支持同名替换**，必须由用户指定不同的新名称，仅改变字母大小写也不接受。同批“删除旧外键再同名新增”同样拒绝；客户端不自动起新名、不拆成两次执行，也不在失败后切换策略。

风险确认共四类，按计划显示并要求全部勾选：DDL 隐式提交、维护窗口与外部 DDL 并发、删除或替换旧约束、引用动作变化。前两项始终出现，删除增加第三项，替换包含全部四项。预览和执行前会再次核对父子定义、支持键及名称；名称目录不完整时会明确提示，空目录不能证明名称可用。能形成草稿或看到可编辑按钮不代表计划一定获准执行。快照过期、连接配置或实际结构变化后，需“重新读取实际外键”并重新预览。

执行使用独立结构连接，保留查询标签事务。点击“取消外键任务”后等待原请求和资源释放结束；DDL 可能已隐式提交，取消、断线或服务器报错都不能当作已回滚。界面分别报告未投递、已执行并核验、已执行但未完整核验及结果未知。后两种情况先独立核对实际定义，不能把旧计划当作未执行重新提交；客户端不会重放。已核验后更新目标子表页，未核验或未知时标记其需要核对刷新，父表数据页不会因此自动重载。

当前受控写入的版本门槛为 MySQL 5.7.44、8.0.46、8.4.11，以及 MariaDB 10.11.19、11.4.13，并要求已确认的 InnoDB、DYNAMIC、16 KiB 页与非临时表能力。新增或替换不开放分区或分区状态未知的父子表；其它版本和未证明能力只读。未知旧语法、未知属性或不符合受控命名规则的旧外键保留原始片段及原因，不能猜测后重建。MariaDB 风险默认值、不可证明的旧版二进制默认值及不完整目录仍可能阻止计划或使完成结果无法完整核验。实际版本、平台与操作验收范围见 [验证记录](validation.md)。

## 导入导出

从表标签打开“导入”或“导出”。通过本机文件选择器选择 CSV、JSON 或 SQL 文件，编码支持 UTF-8、UTF-16LE 和 GB18030。

CSV/JSON 导入先检查预览并建立字段映射；同一目标字段不能被多个源字段映射。JSON 顶层必须是对象数组。CSV 第一行为列名，`\N` 表示 NULL，反斜线开头的文本用额外反斜线转义；二进制使用 `base64:` 表示。数据库的数字、日期校验由服务器完成。

数据导入每 500 行提交一批，失败会回滚当前批并报告已提交行数和失败明细。取消不会撤销之前已经提交的批次；再次导入前核对已有记录，避免重复。

SQL 文件按顺序执行，支持 `DELIMITER`。文件结束时若仍有未提交事务则回滚并报告；已经提交的语句与 DDL 不会撤销。

导出以流式任务读取完整表，不受工作台页大小或查询显示行数限制。SQL 导出可以独立选择表结构和数据。文件先写临时输出，完成后替换目标；失败或取消时清理临时文件。

0.8 对已证无法保真重建的 MariaDB 默认表达式、旧版二进制文字默认及隐藏属性的兼容模式拒绝含结构 SQL 导出，保留原目标文件；可独立导出数据。视图的原定义与数据导出另有兼容检查。0.7 及更早文件没有本批保护，遇到这些表须独立核对建表默认值。

## 工作台恢复和退出

明暗主题、侧边栏宽度、查询文本和标签布局自动保存。退出时有待提交数据、活动事务或运行任务会提示；配置保存失败时可返回工作台处理，也可明确选择放弃未保存配置退出。

重启会恢复工作台布局，连接需重新建立。上次未完成的任务标记失败并要求核对数据库，客户端不会自动续跑写操作。
