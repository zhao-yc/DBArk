# 使用指南

MySQL／MariaDB 可编辑表已支持多页草稿：普通翻页保留原页修改和各页撤销／重做；上方“多页草稿”可返回原缓存，返回不重新读取。记录表单到页边界可点“暂存并查看下一页首条／上一页末条”；非法输入保持当前页。任意当前页（包括干净页）都可“预览并提交”，一次审阅全部有修改的保留页并明确提交；任一记录冲突整批回滚，草稿保持。提交结果未知时整组只读，须核对并明确重新读取。

最多保留16页，原值与当前值合计64 MiB／100000格；有修改或撤销记录的页不会自动淘汰。每页沿原100步／8 MiB历史。多页统一预览最多5000条变化、50000个新值格和1 MiB新输入。每页旁的“×”明确放弃该原页；后台页不读库，放弃当前页优先返回另一缓存，最后一页才重新读取。更改筛选、排序、页长或刷新会确认放弃全部保留页。各页不是同一数据库快照，来源变化后不能沿旧稿继续写入。

“保存表格草稿”会收集全部保留页的已暂存变化，仍沿原文件的1000条／8 MiB等限制，超限会明确拒绝，不保存部分页；文件未加密，须先确认知情。新版多页文件还保存有修改的原页分组、原页长及活动分组，原活动页没有修改时打开第一个有修改的分组。关闭表页后，可在原连接的同一表选择“恢复表格草稿”，先独立核验全部旧行，成功后按原页号显示草稿分组；分组切换不读数据库，各组可继续编辑、独立撤销和明确放弃，全部变化仍统一预览并明确提交。再次保存保留剩余有修改的原页分组，旧版文件继续恢复为单一列表。

恢复页号只表示保存时的变更归属，不代表当前服务器分页；干净页、未暂存输入、原选择和保存前的撤销历史不会恢复。文件含完整原行和待提交值，须妥善保管；关闭／重启不会自动恢复内存工作区，也不会自动提交。详见[多页文件分组恢复](development/table-draft-groups-20261105.md)及[多页工作区范围](development/table-edit-workspace-20261105.md)。

MySQL／MariaDB 表页提交后若出现异常，会只读查询本地提交记录。同批回执确认已提交时重新读取；读取失败则保留提交前草稿并暂停编辑。结果未知时，即使关闭旧预览，也不能从原草稿再次预览或提交。可用“查看本次提交记录”核对，再点“核对后重新读取当前表”；取消确认或读取失败仍保持保护，成功读取后才恢复编辑。若回执明确未发送或已回滚，可修正原草稿后重新预览；不会自动重试。详见[提交结果核对](development/table-apply-recovery-20261105.md)。

MySQL／MariaDB 可写表页勾选多条当前页记录，点工具栏／“更多”中的“批量编辑勾选记录…”，可逐条填写不同值。上一条／下一条只浏览勾选记录；“保留本条输入”只进窗口缓冲，切换时可保留后继续、放弃本条未保留输入或留在当前。取消全部不改变原页草稿；“暂存全部勾选记录”完整校验后形成一步可撤销修改，再沿原“预览修改”和明确确认提交写入数据库。生成列只读，DEFAULT仅新增记录可用；没有自动跨页读取，关闭不会自动恢复窗口输入。详见[批量表单范围](development/record-batch-edit-20261105.md)。

SQLite可写表页勾选当前页多条记录，在“更多 → 数据编辑 → 批量编辑 SQLite 勾选记录…”可逐条填写不同值，上一条／下一条只经过勾选记录。表单、整行 JSON 和记录树共用当前输入，切换只保留窗口内输入；取消整组不改变原草稿。“暂存全部 SQLite 勾选记录”完整验证后形成一步可撤销草稿，失败时输入保持。最后仍须“预览 SQLite 修改”并明确提交才写入数据库。生成列只读；新增记录可取消字段勾选保留默认值。此窗口不跨页读取，关闭前若需跨重启保留请先暂存并保存 SQLite 草稿文件。详见[逐条批量表单范围](development/sqlite-record-batch-20261105.md)。

SQLite可编辑表底部可“保存 SQLite 草稿文件”，保存所有保留页已暂存的新增、修改和删除；文件未加密，含完整原始行和可靠定位，须先勾选知情确认。保存不提交数据库，也不清除当前草稿。文件不要保存到数据库或WAL／SHM／Journal；程序会拒绝覆盖已保存SQLite库及其日志。

关闭后重新启动不会自动恢复。当前表没有草稿及撤销／重做历史时，点“恢复 SQLite 草稿文件”，选择原文件、核对操作统计并明确确认只读核验。原文件、结构、定位或任一旧行已变化会整份拒绝。新版多页文件保留有修改的原页归属、原页长及活动分组；每组领取独立新编辑快照，切换组不读数据库，可分别撤销／重做、继续编辑和明确放弃，再次保存仍保留有变化的分组。旧版文件继续显示单一恢复列表。全部分组仍须统一“预览 SQLite 修改”并明确一次提交才写入数据库；任一记录冲突整批回滚。返回服务器数据会确认处理全部恢复草稿。

原页号仅表示保存时变更归属，不是当前服务器分页；干净页、未暂存输入、旧选择及保存前的撤销历史不恢复。文件只适用于原连接／原文件，不能当自动重放脚本。详见[多页分组保存恢复](development/sqlite-draft-groups-20261105.md)及[原文件范围](development/sqlite-table-draft-files-20261105.md)。

SQLite可编辑表已支持[跨页草稿工作区](development/sqlite-multipage-workspace-20261105.md)。普通切页保留原页草稿与撤销／重做，底部可返回各保留页，缓存返回不重读。整行表单有合法输入时点“暂存并查看下一页首条／上一页末条”先留到原页草稿；非法输入保留并阻止切页。任意当前页都可点“预览 SQLite 修改”，集中审阅全部有修改的原页，再明确一次提交；任一行冲突整批回滚，各页草稿保持。结果未知时整组锁定，先核对数据库，勿重复提交。

最多保留16页有输入／修改／撤销历史的原页，全组共用500条修改、10000格和2MiB输入预算；只有无历史的干净页可自动淘汰。刷新、改页长或应用新筛选／排序会确认放弃全部保留页，取消可保持。各页仍是分别读取的原页，不保证数据库快照分页。未保存为文件的草稿只在本标签内存；关闭／重启不会自动恢复，须明确选择先前保存的文件核验恢复。过期、结构或来源变化时不会自动换新原值重试。

每个保留页旁的“放弃此页”可只清除该页。确认显示页号、修改数和是否含撤销／重做记录；取消会保持。放弃后台页不重新读库，放弃当前页会重新读取同一偏移，其它页草稿保持；若重读失败且有其它有效保留页，会回到该原页并显示错误。16页满额时可明确放弃一页以继续翻页。输入／预览窗口打开、任务在途或结果未知时不能逐页放弃。详见[逐页放弃范围](development/sqlite-workspace-page-discard-20261105.md)。

查询结果选中一行后，从“更多结果操作”打开原记录详情，可切换“查询记录树”或“查询整行JSON”。完整JSON包含隐藏列和同名列，不受搜索影响；字符串须明确选择才按JSON查看。页内翻行保留展示方式，当前结果及固定快照均可查看，不增加SQL执行。格式仅供查看，2MiB超限不生成部分文档，详见[使用与验收范围](development/query-readonly-record-20261104.md)。

SQLite表或视图的“查看记录详情”新增“SQLite只读记录树”和“SQLite只读整行JSON”。明确选择TEXT字段后查看JSON结构；完整JSON包含所有字段，与搜索或网格隐藏列无关。只读展示不重新查询，翻行保持展示方式，不提供编辑或恢复；超过2MiB不生成部分JSON，可返回树或字段。详见[使用与验收范围](development/sqlite-readonly-record-20261104.md)。

SQLite可写记录窗口可选择“SQLite记录树”，查看全部字段输入；明确选择TEXT字段后才解析JSON。可按原文序号编辑重复成员、改名／追加／移除、移动对象成员及操作数组。先应用节点修改到当前输入，再保存整行；最后仍需预览并明确提交。未完成节点输入须先应用或取消，再切换或保存。详见[使用与验收范围](development/sqlite-record-tree-20261104.md)。

SQLite编辑、新增或复制记录时，可选择“SQLite整行JSON”，与字段表单共享当前输入。只修改value，保留字段顺序及说明；整数、实数和HEX均用字符串，新增default表示省略，NULL单独表示。非法文档保留原输入，保存只暂存，最终仍须预览并明确提交。见[完整格式与验收范围](development/sqlite-record-json-20261104.md)。

SQLite关联窗口明确读到子记录后，可点击“在独立表页打开关联子记录”。新标签显示固定父键范围，支持原表页筛选、分页、编辑、统计与导出；修改先暂存并预览，明确提交后才写库。原父表及普通子表草稿保留，新增行预填子键。关联值只在当前进程，重载后须从父记录重开，不自动读全表。导入及整表维护仍针对物理表，详见[使用与验收范围](development/sqlite-related-table-20261104.md)。

SQLite已保存行可从“更多 → 显示 → 浏览 SQLite 关联记录”进入关联浏览器。明确读取当前方向的目录和记录，选中结果行后，可继续查看该行的父记录或子记录；返回／前进恢复已读页、声明和行选择，不自动查询，另走分支会替换后续历史。全程只读，源行草稿保持，历史是本地缓存。见[连续关联浏览说明](development/sqlite-relations-20261104.md)。

SQLite父记录可从“更多 → 显示 → 浏览 SQLite 子记录”打开反向关联窗口，先明确读取反向外键目录，再选择子表声明并读取子记录。每页50行，可往返分页；打开或切换声明不读取子记录。关联使用当前页读取时已保存的父键，本地草稿和撤销栈保持；尚未保存的新行不开放入口。父行删除或键变化后可能无结果，请核对并刷新源页。见[使用与验证范围](development/sqlite-incoming-20261104.md)。

SQLite物理表可写页选择当前行后，从“更多 → 显示 → 选择 SQLite 外键值”打开窗口，明确读取外键目录和父键候选；支持按父列字面子串搜索及分页。选父行后“使用所选键值”会先复读父键，再将整组外键一次暂存，保留其它草稿并可一步撤销；最终写库仍须原 SQL 预览及提交。全部子键可空时，可勾选确认后整组清空为 NULL。只读页及可写页均继续支持“浏览 SQLite 父记录”。见[本轮使用与验证范围](development/sqlite-reference-choice-20261104.md)。

SQLite表单的BLOB字段可使用Hex、按编码查看文本、静态图片预览，以及“从文件载入字节／原字节另存为”。载入只进入表单缓冲，取消不改草稿；仍须保存草稿、预览SQL并明确提交。SQLite每字段最多编辑32768字节，超限整次拒绝；较大原值仅完整只读查看或另存，最多2MiB。空文件是零字节BLOB，NULL和默认值须明确选择。只读表／视图双击实际BLOB也可另存，详见[使用及验证范围](development/sqlite-binary-fields-20261104.md)。

SQLite只读表和视图的“行详情”可连续跨页：页内“上一行／下一行”只使用已加载数据，到达真实边界时改为“上一页末行／下一页首行”，明确点击后沿已应用筛选、排序和页长读取一次。未应用筛选正文保持；新页字段搜索按页重置。停止、失败、空页或切换来源后不会自动重开旧详情，可用原表页分页或刷新后重新选行。见[使用及验证范围](development/sqlite-row-detail-pages-20261104.md)。

SQLite可编辑表的整行编辑支持连续跨页。到达本页首尾时，可沿已应用的筛选、排序及页长查看相邻页；有合法输入时按钮明确为“暂存并查看上一页末条／下一页首条”，只保存到原页内存草稿，再返回缓存或读取未缓存页，不自动提交数据库。各页已有草稿与撤销历史保留；空页不继续扫描，读取失败保持原草稿并提示。字段区可独立滚动，底部操作栏保持可见。见[当前使用与验证范围](development/sqlite-multipage-workspace-20261105.md)及[早期跨页记录](development/sqlite-record-cross-page-20261104.md)。

在 MySQL／MariaDB 可编辑表页的「更多 → 数据编辑 → 记录模板」，或 SQLite 可编辑表底部的「记录模板」，可把当前选中记录的字段保存为本机模板。先暂存表单或单元格输入，再打开模板；勾选需要复用的字段并命名保存，字段搜索不会取消已选项。所有字段默认不选，MySQL 自增列及两种驱动的生成列不提供捕获，SQLite 标识字段需自行省略。

选一个已保存模板并点击「预览模板」，核对后指定 1～100 条，点击「生成新增草稿」。每次生成是一条撤销操作，已有草稿保留；未选字段沿用数据库默认值。模板只属于原连接、数据库和表，保存了字段的真实记录值；连接配置或字段类型变化后须重新核对。可重命名、明确覆盖或删除本机模板，重启后仍可使用；生成草稿后仍须预览 SQL 并明确提交。详见[记录模板使用与验证](development/record-templates-20261104.md)及[五个原兼容基线的实库窗口结果](development/record-templates-live-20261104.md)。

查询页新增[语句导航](development/statement-navigation-20261103.md)：从“更多 → 脚本导航 → 语句导航”、编辑器右键或原生工具菜单打开；按完整正文搜索、分页、跳转与选中。支持MySQL／MariaDB的DELIMITER及SQLite触发器，不执行SQL；编辑后须明确刷新，选中复杂例程正文不会自动执行。

通过同一菜单的「上一条语句」和「下一条语句」，或按 Ctrl／⌘＋Alt／Option＋Page Up／Page Down，可直接移动光标。光标在语句间时会跳到指定方向最近的一条，到达首尾后保持原位。语句导航面板已打开时，搜索和分页会保留。

在 SQL 编辑器内按 Ctrl+E（macOS 为 ⌘+E），或从编辑器右键、原生「工具 → 查询」选择「选中当前语句」，可选中光标所在语句的正文。命令沿用原会话的分段规则，不执行 SQL。光标位于语句之间的空白时，选区保持原样。

在「查看 → 编辑器」启用「按 SQL 语句折叠」后，可用编辑器左侧箭头收起或展开多行语句，包括 MySQL／MariaDB 例程及 SQLite 触发器。折叠只影响显示，偏好随工作区保存。脚本边界不明确或超过本地扫描上限时，仍可使用普通缩进折叠。

同一菜单可分别切换「显示行号」和「高亮匹配括号」。两项默认开启，切换后立即应用到 SQL 编辑器及只读预览，并随工作区保存。

在查询编辑器中，从「编辑」或右键菜单选择「跳到匹配括号」或「选中括号范围」。可定位光标所在的配对括号，或选中该对括号及其中的内容。光标在括号内部时沿用编辑器的内层配对规则。操作只移动光标或改变选区。

MySQL／MariaDB 查询新增[本地语法检查](development/sql-syntax-check-20261103.md)：通过查询“更多”、编辑器右键或原生工具菜单检查当前脚本，点击问题跳转。支持 DELIMITER 例程及准确原文位置；编辑后旧标记立即失效。不执行 SQL，本地解析器提示与服务器实际执行结果分开，SQLite 方言后续接入。

SQL 查询新增[查看对象结构](development/object-definition-20261103.md)：在物理表或视图名称上右键选择该项，也可使用查询“更多”或原生工具菜单。显示当前查询原会话中的完整只读 DDL，SQLite 未限定名称优先识别 TEMP；不修改正文、执行查询或切换标签。不确定目标会显示原因，F12 仍定位本文声明。

SQLite 表／视图页的“更多 → 字段概况”可统计已应用筛选的全部匹配行，显示各存储类型的数量、不同值和极值。选字段后点击“开始统计”；不读取未应用条件、未提交草稿或当前查询事务，不刷新原页。类型与精度说明见[字段概况](development/sqlite-statistics-20261103.md)。

同一窗口的「只统计匹配行数」无需选择字段。它统计全部已应用筛选的匹配行，包括字段值为 NULL 的记录，结果不受每页条数限制。统计在独立只读快照中运行，可取消，不刷新当前页。

SQLite 表和视图也可从分页栏打开「统计匹配行数」，再点击「开始统计」。关闭窗口后，分页栏保留这次计数。刷新、翻页或重新应用筛选后，旧计数会清除。

MySQL／MariaDB 表和视图的分页栏可点击「统计匹配行数」，核对当前筛选后再点击「开始统计」。它统计服务器上所有匹配行，保留当前页未提交修改。关闭窗口后，分页栏仍显示这次计数。刷新、翻页或更改筛选排序会清除旧计数。

当前源码版在查询结果区提供“整理方案”：可把完整筛选、多列排序和冻结列边界命名保存，供同连接的其它查询标签及下次启动读取。选择后可预览、新建、覆盖、仅重命名或删除；点击“应用所选方案”才整理当前已返回行。筛选和排序可用结果整理撤销恢复，冻结范围在列管理中调整。完整字段和可见列须一致，连接配置改变后的旧方案需明确覆盖；失败后先刷新，系统不会自动重试写入。条件原值保存在本机，方案不包含 SQL 或结果行，细节及验收边界见[命名整理方案](development/query-result-presets-20261022.md)及[冻结列](development/frozen-columns-20261027.md)。暂不发布。

0.16 开发中的查询上下文规则：执行历史保存语句开始时的默认库，保存查询保存当前会话默认库。确认无默认库时，重新打开不会套用连接配置中的库；状态无法确认或断线后，先选择重连数据库，再自行执行所需语句。确认重连不会重放先前 SQL、恢复事务或临时表。发送前恢复信息保存失败时，本次 SQL 不会发送。该版本会将配置库升级至 schema5，升级前备份完整用户目录；当前公开安装包仍以版本发布页为准。

当前源码版可在保存查询列表点击“重命名查询”，填写新名称并确认；Enter 确认，Escape 先取消名称草稿。改名保留原 SQL、来源连接、默认库和分组，不执行 SQL。已打开编辑器保留当前内容，之后覆盖保存会重新核对来源；发生冲突时可重新打开或另存草稿。详见[重命名及验收边界](development/saved-query-rename-20261029.md)，暂不发布。

保存查询列表也支持跨页勾选后“删除所选查询”，最多100条。预览会完整列出所有选择的名称和编号；Escape取消预览，明确确认后整批提交。任一原记录变化都会整批拒绝，打开的草稿和磁盘SQL文件保留；旧来源已删除时可另存草稿。详见[批量删除及验收边界](development/saved-query-delete-selected-20261029.md)，暂不发布。

## 菜单与对象浏览

顶部原生菜单分为文件、编辑、查看、收藏夹、工具、窗口和帮助。模块栏依次提供连接、新建查询、表、视图、函数、其他、查询和工具；窗口变窄时，末端入口移入“更多”。只展示已接入功能，没有备份、模型等占位入口。

“表／视图／函数／其他”使用左侧选中的数据库，在中央打开对象列表；没有明确数据库时先选择连接并读取数据库。列表支持名称搜索、排序和右键管理，双击才打开表数据或对象定义。同一数据库的分类复用一个浏览标签，不覆盖原查询草稿。

查询执行、保存、筛选和事务始终属于当前标签，左侧选择其他库不会改变已有查询的会话。查询、结果和表格操作按用途放入“更多”；事务状态与表格修改的预览、提交仍保持可见。完整入口与开发验收边界见[导航重整说明](development/navigation-workbench-20261029.md)。

| 页面 | 常用入口 | 更多中的分组 |
| --- | --- | --- |
| 查询 | 执行方式、停止、格式化、保存 | 执行与分析、SQL 文件、查询与片段 |
| 查询结果 | 结果集、筛选、多列排序、列、导出 | 查看结果、结果整理、导出与写入、快照 |
| 表格 | 刷新、新增、删除记录、筛选、排序、导入、导出 | 设计与结构、生成查询、数据、显示与导航 |

查询的切换默认库、临时对象、采集警告与遇错继续集中在“会话与执行选项”。左树及对象列表右键同时选中节点并显示分组操作，不自动展开或打开标签；Shift+F10 也可打开，Escape 关闭。

## 安装和升级

Windows 使用 `DBArk-版本-win-x64-unsigned.exe` 安装。macOS 构建按 arm64（Apple Silicon）和 x64（Intel）区分，各版本的签名、公证及实际安装范围以对应发布说明为准。0.28 目前为源码开发候选，0.27 的本地 Windows 未签名候选也尚未安装验收；本版三平台原生、安装和实库验收继续。早期版本的三平台结果不能作为本版通过证明，公开下载仍以 0.21 发布页为准。

首版采用手动升级：退出 DBArk 后安装新版，配置库保留在当前用户的应用数据目录。升级、卸载或迁移前，退出应用并备份整个用户配置目录，包含 `dbark.sqlite` 及目录内其他文件；密码密文依赖原电脑的系统账户，迁移后通常需要重新输入密码。不要把配置库上传到公共仓库。

0.3.0 SQL 片段功能将 SQLite 配置格式从 schema 1 升级到 schema 2。升级保留已有连接、查询、历史和偏好设置；迁移或写盘失败时保留原配置文件，不提交失败的内存修改。旧 0.2.0 客户端不能读取 schema 2，不能通过删除新数据库、手动降低版本号或重置配置来回退。需要回退时先保留当前完整用户配置目录，再恢复升级前的完整目录备份；备份之后新增的片段等内容不会自动回到旧版本。

## 建立连接

### 左侧对象树与右键操作（开发版）

连接、数据库和对象使用固定 31px 单行，长名称省略，悬停可查看完整名称。原行内操作已迁入右键菜单；顶部“新建连接”和收藏面板入口保留。

右键会将节点设为左侧当前选中项，并更新后续操作使用的连接／数据库上下文；不会展开节点、建立连接、打开标签或改变当前编辑内容。左键仍沿用原来的展开或打开行为。连接、数据库、表、视图和例程各自提供对应操作，忙碌、权限限制及确认流程保持。

聚焦节点后可按菜单键或 `Shift+F10` 打开菜单，使用方向键、`Home`、`End` 选择，`Enter` 执行。按 `Escape`、点击外部、窗口失焦或滚动对象树会关闭菜单并保留节点选择；目录刷新、连接配置变化或节点消失后，旧菜单作废，需重新打开。

工具栏“整理连接”可先搜索并勾选多条连接，再分别启用分组或颜色修改。预览会列出全部已选目标，包括被搜索隐藏的选择；确认后一次保存，空分组与名为“未分组”的分组分别显示。此操作保留连接目标、凭据和当前工作区；列表变化或保存失败后先刷新重试。详见[连接批量整理](development/connection-organization-20261022.md)，当前为未发布源码功能。

新建连接可选择“从连接URI填入”，例如`mysql://dev:password@db.example:3306/app`。用户名、密码和数据库中的分隔字符需百分号编码；IPv6主机用方括号。填入后会清除URI输入，先核对普通表单，再明确测试或保存。默认不记住URI中的密码。查询参数和片段会被拒绝，SSH／TLS请在表单单独配置；操作及验收范围见[连接URI](development/connection-uri-20261021.md)。

点击“新建连接”，填写连接名称、主机、端口、用户名和密码。“连接分组”和“标识颜色”用于区分开发、测试等环境。先“测试连接”，再“保存连接”；测试操作不会保存配置。

在 PostgreSQL 查询结果中，点「列统计」可查看当前列的计数、极值、合计、平均值和常见值分布。可以切换可见列以及当前筛选后的全部行或勾选行。分布中的「按此值筛选」将原值填入草稿，确认后才应用。详见[PostgreSQL 查询结果列统计](development/postgres-query-result-statistics-20261105.md)。

SSH 模式填写 SSH 主机、端口、用户名和密码或私钥文件，并填写从可信渠道获得的 `SHA256:…` 主机指纹。数据库主机填写从 SSH 服务器可达的地址，例如数据库监听在隧道服务器上的 `127.0.0.1`。私钥口令与数据库密码分别保存。

TLS 默认验证服务端证书。私有 CA 或自签证书使用 CA 文件；服务端要求双向认证时再提供客户端证书和私钥。“安全保存密码”使用系统加密服务；服务不可用时密码只在本次应用会话存在。

启动时不会为了显示版本而主动检测系统凭据保护。偏好设置初始显示“尚未检测”，可点击“检测系统凭据保护”明确查看当前结果；检测失败会显示错误，不冒充可用或不可用。实际保存、读取凭据仍使用原系统保护器。

保存的密码不会显示在编辑表单中。留空保持原密码，使用“清除”明确改为空密码，再保存连接。

编辑已有连接时，只要该连接还有打开的查询或表数据标签，就不能保存主机、端口、用户名、默认数据库、数据库类型、密码或 SSH/TLS 配置的变更，避免旧会话和当前显示的服务器配置不一致。请先保存需要保留的查询、提交或放弃数据草稿、提交或回滚事务，再关闭此连接的全部标签后修改。拒绝保存不会关闭标签或清除草稿；名称、分组、标识颜色和“安全保存密码”偏好仍可修改，测试连接也仍可使用。

### 连接概要复制与迁移（0.7.0 开发中）

侧栏连接菜单的“复制概要”打开新连接表单，只复制主机、账号、分组、颜色及 SSH/TLS 设置；保存时生成新 ID。数据库密码、SSH 密码、私钥口令、已保存秘密标记和原连接表列偏好不复制，也不会自动测试或建立连接。

“连接导入导出”可选择所需连接，导出 DBArk 自主 JSON 概要格式。文件不包含密码、密文、私钥或证书内容，认证文件只写文件名提示。导入先显示目标、同 ID/同名/同目标候选及缺认证提示，逐项选择“新增”或“跳过”；新增始终生成新 ID，不替换既有连接。明确勾选仅暂存概要后最终确认，一批一次保存；失败不自动重试。首批不支持覆盖已有连接、秘密迁移或 Navicat 私有配置格式。

源文件在预览后变化不会改变已显示快照；本地连接配置在预览后变化会使确认失效，须重新预览。预览有效期十分钟，最终确认尝试一次后失效。单文件最多 500 条连接、2 MiB UTF-8 JSON，未知字段、秘密字段、绝对认证路径、重复来源 ID、非法版本或编码均拒绝。

复制或导入的私钥、CA、客户端证书和证书私钥须在编辑连接中通过本机选择器重新选择，保存后才可连接。文件名提示或手工输入同名路径不能完成重新选择；缺文件标记即使暂时关闭 SSH/TLS 也保留，以后开启仍阻止误连。严格证书验证及 SSH 指纹设置会保留，不因迁移而改用系统 CA 或密码方式。密码需自行补充，导入新增默认不持久保存密码。

开发版将用户配置升级至 schema 4，以保证旧版不会忽略缺认证文件标记后误连。0.6.0 及更早版本拒绝读取升级后配置；升级前退出应用并备份整个用户配置目录，回退恢复升级前完整备份，另行保留升级后目录，不能修改数据库版本号。上述功能尚待本批实际桌面、安装包及公开版本验收，结果见对应发布说明。

0.2.0 支持选择“满足全部条件”或“满足任一条件”，点击已有条件可修改，叉号移除条件。集合使用逐行输入，逗号和前后空格作为值保留；空行表示空字符串，也可勾选“包含空字符串”。区间上下限分别输入，NULL 使用专用空值条件，不能把文本 `NULL` 当空值。整数与精确小数筛选接受普通十进制字符串，不接受科学计数法或超出精确范围的值。

页码输入后点击“跳转”直接读取目标页；不会为获得总页数而自动扫描整表。超出实际数据的页可以为空，仍可跳回已有页。筛选、排序或页大小变化从第一页开始，取消放弃草稿确认时不会切页或更改已应用条件。

双击单元格或使用键盘进入编辑。“单元格”对话框提供文本/精确数值、JSON、十六进制二进制和 NULL 模式。BIGINT、DECIMAL 与日期时间以文本保留原精度。空字符串与 NULL 是不同值。

新增行尚未填写的字段显示“默认值”，表示提交时省略该字段，由服务器决定缺省行为；它与 NULL 和空文本不同。DBArk 内部复制保留该状态，粘贴到新增行可恢复字段缺省，粘贴到已有记录则明确拒绝整组修改，需显式填写值。跨应用的 TSV 无法表达数据库默认值，未填写字段输出空文本；从其它应用粘贴空文本不会被猜测为 NULL 或默认值。合法的 `__proto__`、`constructor` 等列名按真实单元格处理，不读取对象继承属性。

“新增”“删除”和粘贴只形成当前页草稿。点击“预览并提交”核对 SQL，随后“确认提交”。更新或删除会比较读取时的完整原值；发现其他会话修改时整批回滚，重新读取后再决定如何处理。

没有可靠唯一键、非事务存储引擎和视图以只读方式打开。任意 SQL 结果也只读；需要写入时执行明确的 SQL 或打开对应表数据标签。

### 记录表单（0.11）

在表数据标签选中一行，点击“记录表单”打开侧面板。默认沿用网格可见列及顺序，勾选“显示隐藏字段”仅改变表单展示。每字段先显示当前值、原值和默认值摘要，点击“编辑字段”再展开完整输入；只读记录仍可展开查看和复制。单字段超过 262144 个文本代码单元时保留原值摘要并明确只读，不截断后保存。

表页仍遵守原有整行 256 KiB 原始数据和每页 16 MiB 传输预算，服务器大行可能在打开表单前被拒绝；表单的文本展开上限不会绕过读取限制。需要完整大字段时使用文件导出，当前没有按字段延迟读取查看器。

编辑模式区分文本、JSON 原文、二进制 HEX、SQL NULL 和新增行 DEFAULT。空字符串、文字 `NULL`、SQL NULL、零字节二进制及未填写 DEFAULT 分别保留；已有记录不能设为省略 DEFAULT。点击“暂存本行”只将输入合并到网格草稿，仍需“预览并提交”核对 SQL 并最终确认。

“上一条”“下一条”仅在当前已加载页导航，不自动跨页查询。有未暂存输入时切行或关闭会提供暂存后继续、放弃后继续或留在当前编辑三种选择；非法 JSON/HEX 不能暂存，原输入保留。刷新、排序或翻页前也必须处理本页草稿。隐藏标签的输入仍受正常退出保护，强制结束进程不会恢复这些内存草稿。

表单内 Ctrl/Cmd+Enter 只暂存；单元格弹窗校验成功后暂存并关闭，失败保留输入。数据库并发冲突会回滚整批，同一预览不能再次提交；返回编辑后先核对服务器变化，再明确生成新预览。0.11发行版没有树及整行JSON视图，本批验证范围见[普通表单验收](../tests/integration/acceptance-d04-record-forms-20261014.md)。

### SQLite 记录切换

在可编辑 SQLite 表页选中已有记录并打开「编辑 SQLite 当前行」，可在表单底部切换当前页的上一条或下一条。切换会跳过待删除和本地新增记录。有未暂存输入时，按钮显示「暂存并查看」，输入校验通过才会切换。暂存只更新本地草稿，仍需集中预览并确认提交。

在只读 SQLite 表或视图中，选中一个单元格后，从「更多」的「显示与导航」分组打开「行详情」。侧栏展示整行字段，包括网格隐藏列，并在数据页提供类型时显示实际存储类型。可以按当前页行号跳转，排序、翻页或切换标签后需重新选择。展开长值也只使用当前页已加载的数据。

查询结果和 SQLite 只读表／视图的行详情都支持按字段名搜索。搜索不区分大小写，范围包含隐藏列。同名字段会分别列出，并保留原字段序号。侧栏内切换记录时会保留搜索词，关闭后重开会清空。

### 只读树与整行 JSON（0.12）

在记录表单内选择“记录树”（0.12版称“只读树”）或“整行JSON”。未暂存的字段输入需先暂存、放弃或留在表单；暂存仍只写本页草稿。两个新视图展示当前已加载行，切换、展开、查看和复制不会额外读取或提交数据库。刷新或翻页期间撤下旧投影，完成后重新选择当前页记录。

树按可见列顺序分组，每组最多32字段。普通文本需明确点击“按JSON查看此字符串”；实际JSON类型可直接展开。成员按客户端原文顺序编号，重复名称分别保留；“查看原始token与路径”显示未转换的数字/字符串及结构化路径。结构每段最多480条目，可翻段查看，非法或超限时不提供部分树。服务器存储前已丢失的格式或重复成员无法恢复。

整行JSON按元数据顺序包含隐藏字段，并明确区分字符串、实际数值、SQL NULL、未填写DEFAULT、待计算生成列及Base64二进制。全文转义后最多2MiB，超限不提供部分文档，原草稿不被截断。可以在原生只读文本框全选复制；该格式用于查看，没有导入、恢复或写回入口。0.13独立整行编辑及0.14节点值编辑见后续小节，0.15成员和数组结构操作见后续小节，版本范围见[投影验收](../tests/integration/acceptance-d04-record-projections-20261014.md)。

### 整行编辑（0.13）

在记录表单内点击“整行编辑”，逐字段缩进显示当前记录的输入。修改字段条目的`mode`和`text`，点击“暂存本行”或按Ctrl+Enter（macOS为Cmd+Enter）。网格和普通表单随后显示同一份本地修改；实际写入仍需“预览并提交”，核对SQL后明确确认。

`text`保留普通文字、大整数、金额和时间原文；`json`的text中填写完整JSON原文；`binary`填写偶数位HEX，可带`0x`；`null`表示SQL NULL，`default`仅用于新增记录且省略该字段。空文本、文字NULL、SQL NULL和DEFAULT是不同值。生成列及超出展开长度的大值保留`locked:true`，其完整原值留在当前页草稿中。

条目可以重排，但不能遗漏、重复或增加陌生字段。重复对象成员、错误模式、非法JSON/HEX和锁定项改写会整体拒绝，保留原输入。切行、切换模式和收起时可选择留下、放弃或暂存；刷新、排序、翻页使用整页丢弃确认。隐藏标签或取消退出后仍保留未暂存内容。

输入最多2MiB，包含JSON转义及缩进后的UTF-8字节；单字段沿用普通表单的长度限制。该入口使用独立本行输入格式，0.12“整行JSON”仍只读。数据冲突时整批回滚并保留草稿，旧预览不能重复提交。开发及实际发布范围见[整行编辑验收](../tests/integration/acceptance-d04-record-input-20261014.md)。

### JSON 树节点编辑（0.14）

切换到“记录树”，展开JSON结构；普通文本须先明确选择“按JSON查看此字符串”。在目标成员、数组元素或根值上点击“编辑此节点值”，填写完整JSON值，字符串需要双引号。点击“暂存本行”或按Ctrl+Enter（macOS为Cmd+Enter）后，只修改当前页草稿；真实写入仍需“预览并提交”。

重复成员按序号分别选择，精确数字、其它token及原空白保留，包含根值外的空白。JSON null与SQL NULL不同；后者使用字段编辑。展开“选中路径与输入限制”查看完整结构路径和预算。非法输入、合并后过深或超限会整体拒绝并保留原文；关闭、切行及模式切换继续提供留下、放弃和暂存三选。

0.14支持节点值替换，包含对象和数组；0.15成员与数组结构操作见下节。生成列、视图、无键和非事务表仍不能节点编辑。实际发布范围见[节点编辑验收](../tests/integration/acceptance-d04-record-node-input-20261014.md)。

### JSON 成员与数组结构操作（0.15）

在记录树的目标节点点击“结构操作”，再选择可用操作。对象成员可以改名、移除；对象容器可以追加成员；数组容器可以在指定下标插入或移动元素，数组元素可以移除。根值不能结构改名或移除，可使用“编辑此节点值”整体替换。0.15已提供这些入口，实际验证组合与边界见结构操作验收记录。

成员名称输入完整JSON字符串，必须带双引号；新值也是完整JSON，字符串值同样需要引号。数组下标从0开始，只接受完整十进制整数，插入可使用尾后一位，移动使用原数组中的位置。成员按原文序号识别，重名后仍保留独立条目，不自动合并；数组移动保留值token和原分隔符空白。

点击“暂存本行”或按Ctrl/Cmd+Enter只改本页草稿，数据库写入继续通过“预览并提交”。新增和移除操作打开后即视为待暂存意图，关闭或换行时需要暂存、放弃或留下。非法名称、值和下标保留在输入区，完整字段超预算时也不会部分暂存。生成列、视图、无可靠键、非事务表及失效记录仍只读。具体范围见[结构操作计划](plans/record-structure-input.md)。

## SQL 工作区

可在「编辑」菜单或编辑器右键菜单选择「切换行注释」，也可按 Ctrl／⌘＋`/`。有选区时切换所覆盖的行，光标未选中文本时切换当前行，每次可单独撤销。MySQL／MariaDB 的 `--8` 等双负号表达式会加上注释前缀，原表达式保持完整。

在「编辑 → 行操作」或编辑器右键菜单，可向下复制、上移、下移或删除当前行。选中多行时按整段操作。每次修改均可单独撤销。沿用 Monaco 的末行规则，选区末端到达文档最后一行时，向下移动会保持原位。

只想运行高亮的 SQL 时，选择一段正文，再从查询页的「执行方式」或原生「工具 → 查询执行与分析」选择「仅执行选区」。空选区、全空白和多个不连续选区都不会提交。原「执行查询」和 Ctrl／⌘＋Enter 仍是选区优先，无选区时执行整个脚本。

焦点在 SQL 编辑器内时，可按 Ctrl＋G 或选择「编辑 → 跳到行／行列」。编辑器右键菜单仍使用「跳到行列」。输入行号，或按 `行:列` 格式指定位置，例如 `12:8`，再按 Enter。Esc 取消；从「仅显示结果」调用会先恢复编辑区。

关闭有内容的查询时，可选择「关闭并保留草稿」。之后从「窗口」选择「重新打开上个保留查询」，或按 Ctrl／⌘＋Shift＋T。重开的标签是独立草稿，保留正文、数据库上下文和布局。选择「直接关闭」则放弃草稿。保留记录仅在本次运行中有效，最多 10 项，正文合计最多 20,000,000 个 UTF-16 单元。

在结果栏的「查询结果布局」中，可把结果放在 SQL 编辑器下方或右侧，也可临时只显示结果。位置按查询标签保存。工作区较窄时，右侧布局暂时回到下方，拉宽窗口后自动恢复。切换时可继续使用已有结果、筛选与排序；重启时会显示编辑器和已恢复的草稿。

结果在右侧时，可以左右拖动分隔条调整宽度。聚焦分隔条后，左右方向键每次调整 10 像素，按住 Shift 调整 50 像素，Home 恢复默认宽度。宽度按查询标签保存，窗口临时压缩时仍保留原偏好。

在查询编辑器选中文本后，可从「编辑」或编辑器右键菜单使用「选区转为大写」和「选区转为小写」。转换覆盖选区内的全部文本，包括名称、引号内的值及注释，可一次撤销。只想调整 SQL 关键字时，请使用格式化偏好。

一个脚本返回多组结果时，在对应语句开头写 `-- NAME: 月度汇总` 并换行，或写 `/*NAME: 月度汇总 */`，即可在查询完成后显示该名称。名称最多 80 个 UTF-16 单元，悬停可查看序号和完整名称。未命名结果沿用序号，修改草稿不会改动已返回结果的名称。

当前开发源码可在已连接查询的默认库旁点击“切换默认数据库”，从目录选择具体库并确认；取消不切库。操作沿用原会话，保留正文和已有结果，后续查询使用新默认库；切换确认可能更新服务器诊断区。无法确认时显示待确认并保留错误，不自动重试或重连。相关类型、单元及构建已通过，实库与正式窗口待专项授权后验收，暂不发布。详见[功能与验证边界](development/query-database-switch-20261029.md)。

标签较多时，点击主工具栏“查找已打开标签”，或按 Ctrl／⌘＋Shift＋A。输入标题、连接名称、数据库、表名或“查询／表”，多个词用空格分隔，所有条件同时匹配；仅搜索标签信息，不扫描 SQL 正文。上下箭头、Home／End 选择，Enter 或鼠标切换到原标签，Esc／取消保留当前标签。列表显示当前项、上下文和未提交／未保存提示，切换不新建或执行查询；原表页仍遵循既有刷新规则。详见[查找标签](development/open-tab-search-20261028.md)，当前为未发布源码功能。

源码版新增“遇错继续”，默认关闭。勾选后，普通或类型参数查询遇可继续的数据库语句错误时会记录失败并执行后续SQL，包括写操作；取消、断线、解析等异常及100条失败上限仍停止。摘要区可逐条定位原模板，查看完整成功结果；有错误的任务和历史仍记失败。继续前会读取原会话实际模式和默认库，影响会话诊断信息；不会自动重试、重连、提交或回滚，服务器错误仍可能回滚事务。详见[使用及验收边界](development/query-continue-on-error-20261027.md)，暂不发布。

源码版可点击查询工具栏“事务设置”，读取该标签原会话的隔离级别、默认只读、连接 ID、实际库及事务状态；修改后点击“应用到本会话”。这只改变 SESSION 默认值，当前事务及手写一次性事务覆盖可能不同。活动事务中须先明确提交或回滚，再重新读取并修改。

开发中源码另在同一弹窗提供“本会话自动提交”。关闭后，写入需要显式提交或回滚；关闭开关不会提交当前事务。原开关关闭且存在活动事务时，开启会提交这个会话尚未提交的写入，必须勾选确认并点击“开启自动提交并提交当前事务”。开关仅作用于当前查询会话，不保存为连接默认值；错误后按提示显式重新读取，不重复提交未知结果的操作。MySQL5.7／8.0／8.4、MariaDB10.11／11.4及严格TLS六组合Engine专项、Windows源码MySQL8.4正式窗口两例已验；安装版、macOS及真实取消／确认包丢失另验，详见[验收记录](../tests/integration/acceptance-query-autocommit-20261029.md)，暂不发布。

读取会改变会话诊断信息（例如 `ROW_COUNT()`、`FOUND_ROWS()` 和警告），保留已有可视查询结果和历史。失败后先显式重新读取，不能假设设置未改变；切换标签或来源变化后重新打开弹窗。设置不保存到连接配置，新标签沿服务器默认值初始化。详见[实现及验收边界](development/query-transaction-settings-20261027.md)，暂不发布。

当前源码版支持字段悬停：查看来源、类型、NULL、默认值目录文本及备注；不会执行SQL或改变正文。同名字段需用别名确认，计算表达式的类型未确认时不套用基础字段类型。临时表的完整属性须先在“会话临时对象”读取结构，未知时不会借同名永久表。平台和窗口验证范围见[开发记录](development/sql-field-hover-20261021.md)，暂不发布。

当前源码版支持整理已返回结果，详见[多列排序与条件筛选速查](query-results-guide.md)：先筛选，再设置列优先级、NULL位置和大小写选项；条件可单条或全部启停，显式应用后生效。源码、真实窗口与安装范围分别记录，暂不发布新安装包。

查询页可用“保存结果快照”保存当前已返回结果或固定结果，再用“打开结果快照”离线重开为一份固定结果，继续查看、整理、比较及查看源SQL。文件包含原始数据和源SQL，保存全部已返回列／行，不继承本地筛选排序；截断结果仍会明确提示。文件最多16MiB，固定结果仍受5份／累计16MiB限制。打开不改变编辑器正文或连接，也不执行SQL。该功能已验Windows源码窗口，安装包与macOS另验，详见[结果快照](development/query-result-snapshot-20261028.md)，暂不发布。

没有连接或查询标签时，直接点击主工具栏“查看结果快照”，再“选择结果快照”。可只读查看网格、查找、显示来源SQL或双击BLOB查看字节，也可“另存完整快照”；另存保留全部原始列、行、来源SQL和字节，不按勾选行裁剪。一次保留一份文件，取消或坏文件保留当前显示；文件操作未结束时请等待完成后再关闭。高级筛选排序与比较仍在查询页使用。Windows零连接／零标签、真实另存及新进程重开已验，见[全局入口验收](../tests/integration/acceptance-query-result-snapshot-global-20261028.md)；macOS／安装版另验，暂不发布。

0.28 开发候选的全局“SQL 格式化偏好”可选择保持原样（默认）、关键字大写或关键字小写。保存偏好不会改动已有 SQL；点击格式化或使用原格式化快捷键时，有选区只处理选区，否则处理全文。仅修改可确认的关键字，名称、字符串、注释和数值保持；无法证明安全的语句会拒绝修改。首次显式大小写格式化按需加载解析器，等待期间编辑、切换标签或打开其他模态窗口会撤销旧操作。

后续开发版可在命令栏打开“编辑器字号”，输入 8–32 的整数字号并保存；默认 13。恢复默认只修改弹窗草稿，保存才应用，取消保持当前值。“自动换行”可直接切换，按钮按下表示开启，偏好会在重启后恢复。这两项适用于 SQL 编辑器及只读 SQL 预览，字号不改变结果网格或窗口缩放；公开 0.20 尚不含该增量。

创建查询时选择连接和可选数据库。每个标签保持独立会话，因此临时表、会话变量和事务不会在标签间共享。Monaco 提供本地高亮、元数据补全和格式化。

0.16 开发版可在普通查询的 ORDER BY、GROUP BY、HAVING 中按 Ctrl + 空格补全 SELECT 输出别名，Enter 接受、Ctrl / Command + Z 撤销。比如 `SELECT SUM(amount) AS total FROM orders HAVING tot` 可补成引用后的 `total`。同 SELECT 列表和 WHERE 不使用该输出别名；GROUP BY 不推荐聚合别名，GROUP BY/HAVING 遇同名原字段时提供表限定字段。字符串形式的别名会转换为标识符引用，名称内的点号不拆分。UNION 的全局排序使用首分支输出名。无法确认冲突、模式或超出实际可引用长度时，可能省略建议并提示结果不完整；完整窗口、LATERAL 和例程局部名称仍在后续范围。

执行前选择 SQL 文本；没有选择时执行整个编辑器脚本。脚本解析支持注释、字符串及 MySQL `DELIMITER`。多语句返回多个结果集，总显示行数受偏好设置的上限约束；大结果还有内存限制，完整数据使用导出任务。

当前未发布源码支持“脚本失败后保留完整前序结果”：首错停止后仍可查看、固定、筛选、排序和导出此前完整成功语句的行结果。失败语句已传输的片段不作为完整结果，取消不产生此类回包；任务和历史仍记为失败。提示中的序号和完成数不代表失败语句未执行，此前已提交修改不会撤销，事务状态未知时须先核对或明确回滚，不自动继续或重放。详见[执行边界](development/query-partial-outcome-20261022.md)。

失败提示中的“定位未完成SQL”会在原编辑器选择已确认的整条语句，支持全文、选区、当前语句及类型参数模板。定位不会修改或执行SQL，也不猜测服务器错误的具体字符位置。范围未确认，或原正文、模型、连接已变化时禁用；编辑后即使Undo恢复原文也不复用旧定位。详见[源码定位边界](development/query-failure-source-20261022.md)。

“执行计划”仅接受一条可解释语句，不执行 `EXPLAIN ANALYZE`。事务可以开始、提交或回滚；DDL 通常隐式提交，执行前核对 SQL，不能依赖回滚撤销结构变更。

已返回的 JSON／文本执行计划可点“保存计划快照”。主工具栏“打开计划快照”提供离线只读查看、查找和另存，无需数据库连接，也不会执行 SQL；取消或坏文件保留已打开内容。文件为最多 1 MiB 的 UTF-8 JSON，保留服务器版本、原结果和截断提示，分享前请核对原计划中的表名、条件及常量。详见[计划快照说明](development/explain-snapshots-20261022.md)，当前为未发布源码功能。

“停止”按任务编号取消查询。连接中断后客户端不会重放写入语句，先核对服务器状态，再手动建立新会话。历史与保存的查询位于“历史与查询”。

当前未发布源码新增历史 SQL“插入当前查询选区”：先在活动查询中选中文本或放置光标，再打开历史面板并点击该记录的插入按钮。读取的是完整SQL，支持一次撤销；不会执行SQL、切换当前连接或默认库。历史卡片的连接选择只用于“在新标签打开”。原查询或选区变化、关闭面板后，需重新打开再选择；请核对SQL后自行执行。详见[开发与验收边界](development/history-insertion-20261028.md)。

0.2.0 支持“固定结果”：成功执行后保留已返回的只读快照，重新执行后可以从“固定快照”切回旧结果，或返回“本次结果”。“快照 SQL”显示原语句，查看窗口内的执行快捷键不会执行后台 SQL。失败或取消后的流式片段不能固定。每标签最多 5 组、合计 16 MiB，超限拒绝新快照，不截断已有快照；达到查询上限的快照同样只包含已返回数据。固定结果不写入配置库，关闭标签或退出后释放，不改变事务及数据库数据。

当前结果可在「更多结果操作」的「查看结果」分组点击「查看结果 SQL」。多结果查询先选要核对的结果，再打开查看器。查看器显示该结果附带的只读文本，长语句可能被截断，参数查询可能显示模板。查询编辑器中的后续修改不会改变这份文本。

0.3.0 起支持“打开 SQL 文件”和“另存 SQL 文件”。先打开查询标签，再从工具栏选择文件和 UTF-8、UTF-16LE 或 GB18030；UTF BOM 优先确定读取编码。打开总是新建同一连接、数据库下的查询标签，保留原 SQL 和事务；另存仅保存打开对话框时的全部 SQL 正文，不执行语句或提交事务，也不修改原标题。文件最多 20 MiB、2000 万字符，更大脚本使用 SQL 文件导入任务。无效编码、NUL、UTF-16BE 或无法无损保存的 Unicode 会拒绝；保存写完临时文件后替换目标，失败不先删除原文件。“保存查询”仍保存到本地查询库。

0.24开发分支增加SQL文件来源关联，尚未公开发行：

- 打开文件后，查询栏显示来源、编码、BOM、换行及修改状态。关联标签的Ctrl/Cmd+S及关闭时“保存”写回原文件；“另存SQL文件”选择新目标并切换关联。本地查询库保存入口仍单独提供，切换主来源不删除原查询库条目；复制标签成为未关联草稿。
- 原文件被修改、删除、替换或被其它标签保存时，先拒绝覆盖。可取消、明确另存，或“重读为新草稿”核对磁盘正文；重读只推进原标签的文件基线，原SQL在内存和本地配置中均保留，回包丢失也不先替换原文。
- 保存保留原编码、BOM和统一换行。混合换行未编辑时保持原字节；编辑后须在另存选项中明确选择LF、CRLF或CR。保存点击后继续编辑，写入的是点击快照，新输入仍保留为待保存内容。
- 任务显示阶段、字节进度与取消状态。替换提交点后不承诺可取消；已写入或结果不确定时先核对，不自动再次写入。启动和来源状态展示不自动读取或写入外部文件。

该开发实现限可证明身份的单链接普通文件；符号链接、硬链接及身份未知时拒绝原路径操作。Windows/macOS原生文件选择、安装、ACL/所有者/附加流等元数据仍需平台验收，见[当前证据与限制](../tests/integration/acceptance-sql-file-sources-20261018.md)。

0.26开发候选增加“最近 SQL 文件”：在查询标签工具栏或“文件”菜单打开最近列表，选择条目及编码，再点击“打开选中的 SQL 文件”，会在新查询中读取正文并保留原草稿。最多保留20个最近成功使用的文件，同一路径再次成功使用会置顶；列表展示和选择不会打开文件或执行SQL。

文件已移动或失效时，可从恢复窗口“重新选择 SQL 文件”，也可从最近列表移除该条目；移除历史不删除实际文件。最近列表无法读取时可点“重试读取最近列表”，也可关闭列表使用普通文件入口；坏历史记录保持，待本地配置恢复后再重试。可选历史维护失败不会回滚已经成功保存的文件来源。

开发候选增加“检查源文件外部变更”，各平台及安装验收仍未完成，未公开发行。在关联文件的查询标签中点击该按钮，核对当前草稿与磁盘文件的差异、编码和换行。取消保留当前草稿；明确勾选替换确认后，“确认重新加载当前草稿”才接纳外部全文，不执行SQL或写入源文件。检查期间原编辑器锁定，预览超过五分钟或文件再次变化，须重新检查。

重新加载保留原编辑器的撤销历史：换行变化时，先撤销正文，再撤销换行；换行未变时仅撤销正文。撤销后来源基线仍是已接纳的新文件，旧内容显示为未保存。若提示配置持久化结果不确定，请保留当前草稿并核对状态，不自动重放操作。当前验证与未验范围见[重载整合记录](development/query-file-reload-integration-20261020.md)。

0.3.0 起支持“导出已返回结果”：选择当前成功结果集或固定快照，在对话框核对行数、列名及最多 20 行预览，选择 CSV/JSON、编码及保存位置后开始。此操作不重新执行 SQL、不读取服务器上其余行，断线后的旧快照也可导出。截断结果明确只包含已返回部分；失败或取消查询的流式片段不可导出。重复和空列名会生成唯一标题/键，预览显示对应关系；CSV 沿用 `\N`、反斜线及 Base64 协议，JSON 保留精确字符串、NULL 和二进制对象。结果导出限定 100000 行、1024 列、2000000 单元格、单字段 256 KiB、单行 1 MiB、输入总预算 32 MiB。任务面板显示进度，取消或失败保留原文件；原子替换已经开始后不能撤销成功保存。

结果窗口也可选择INSERT SQL：明确填写目标库、表和全部列映射，核对实际SQL预览，选择文件并确认准确目标后导出。只保存已返回或勾选的可见快照，不猜测查询来源、不执行SQL。格式或映射变化会撤销旧预览和文件选择，详见[结果INSERT SQL说明](query-result-insert-sql.md)。

已返回结果和勾选结果的 CSV 可选择逗号（默认）、分号或制表符（Tab）。修改“CSV导出分隔符”后须重新选择保存文件，原快照、可见列和勾选范围保持；切换分隔符不会重新执行 SQL。NULL、空字符串、反斜线和二进制的表示保持原协议。

### 完整流式导出（0.5.0 开发版）

点击查询工具栏的“完整流式导出”。打开时固定当前选区，没有有效选区时固定全文；选择文件、编码或配置参数不会执行 SQL。最终“执行 SQL 并完整导出”会在当前查询标签会话进行一次新的执行，保留其临时表、变量与事务。它不续读旧结果，也不自动开始、提交或回滚事务。

JSON 保存全部异构结果集与状态结果，文件包含 `DBArk-query-results` 版本封装、列位置、原名和唯一输出名。该封装与表 JSON 导入的对象数组不同，当前不能直接作为表数据恢复。CSV 选择本次执行的第 N 个行结果集，从 1 开始；空行结果仍占序号，写入状态包不占行结果序号。其它结果和后续 SQL 仍完整执行一次，选中结果不存在会保留原文件，但不能撤销此前已提交的写入。

完整流式 CSV 和 CSV ZIP 的“CSV导出分隔符”均可选择逗号（默认）、分号或制表符（Tab）。ZIP 内所有行结果使用同一分隔符，清单记录实际选择；字段包含当前分隔符、双引号或换行时按 CSV 规则引用，NULL、空字符串、反斜线及二进制仍沿用原协议。修改分隔符会撤销原保存文件和执行确认，须重新选择文件并确认后才能执行；恢复原分隔符也不会恢复旧确认。选择文件、执行期间及完成后锁定该选项。JSON 和 SQL 没有此选项。

默认“文本严格模式”保持普通文本执行和诊断，不增加预处理。遇到 FLOAT/DOUBLE 会停止完整导出并保留原文件，因为服务器文本格式可能合并相邻浮点值；本条 SQL 可能已经执行。需要这些类型时明确选择“二进制模式”并确认其首次准备可能改变警告诊断。诊断和控制语句预先走文本，不在失败准备后自动回退执行；这部分文本路径遇浮点也会明确拒绝。

如需值参数，先点击“配置类型参数”，填写九种支持类型，再“应用参数”返回最终确认；此步骤不执行模板，参数只在本次操作内保留。历史保存 SQL 模板，失败任务概要不保存服务端展开错误或实际填写值。

完整文件不受工作台显示行数限制；工作台预览每结果最多 200 行、合计 16 MiB。当前完整任务最多 200 个含状态的结果、1024 列，原始及序列化字段分别限制 8 MiB、单行 16 MiB、文件 10 GiB；Base64、JSON 转义或编码可能使实际预算更早达到，超限明确失败，不截断文件后报告完整。进度使用已执行语句、已写行和字节，没有自动 COUNT 或百分比预扫描。

“取消任务”等待实际命令及文件清理结束；取消、断线和磁盘失败都不会重放 SQL。文件替换开始后的迟到取消不能撤销已保存的文件。失败后“再次执行”需要重新确认，是新的数据库操作，先核对已提交部分及事务；客户端不把它包装为单独重试文件写入。同一目标文件被其它保存或导出占用时明确拒绝并发操作。

### SQL 片段库（0.3.0 起）

查询工具栏的“SQL 片段库”保存可复用 SQL。新建时使用当前选区，没有选区时使用当前查询正文；填写名称、分组、说明和正文后保存。可以按分组筛选，并搜索名称、分组、说明或正文；同名、同组片段允许并存，编辑只修改所选记录。“复制为新片段”创建独立副本；删除需要确认，关闭或切换尚未保存的编辑时可取消或明确放弃。

在查询编辑器选中一段 SQL，可从右键菜单或「编辑」选择「将选区保存为片段」。新草稿只包含选中原文，填写名称后手动保存。查询正文保持原样。输入新语句时，可键入至少两个字符的片段名称前缀，在补全列表中选择片段。插入只替换名称前缀，保留片段缩进，可一次撤销。超过 65,536 个 UTF-16 单元的脚本可从片段库插入。

内置 MySQL/MariaDB 模板提供读取、分组统计和执行计划示例，可查看、插入或复制为用户片段；先根据实际数据库修改表名、列名和条件。片段不绑定具体连接，也不执行 SQL。“插入查询”替换打开片段库前的查询选区，或在当时光标位置写入；正文中的 `$`、JSON、注释和引号按原文保留，不作为编辑器插值。插入保留查询撤销栈，可以用撤销恢复，已有结果、事务和会话保持不变。预览窗口中的执行和保存快捷键不会作用于后台查询。

用户片段单独持久化，不占用保存查询或工作台设置字段。最多保存 500 条；名称、分组分别最多 100 字符，说明最多 2000 字符，单条正文最多 65536 字符，全部用户正文最多 4 MiB UTF-8 字节。内置模板不计入用户配额；达到条数上限仍可以编辑原片段。保存失败保留输入和原记录，可处理错误后重试。

### 类型参数查询（0.3.0 起）

在 SQL 中用独立的 `:name` 表示一个值，点击“参数执行”。当前选区优先，没有选区时使用全部 SQL；表单打开后本次模板固定，不跟随后台草稿变化。名称为 1～64 位 ASCII 字母、数字或下划线，首字符不能是数字；名称区分大小写，同一名称多次出现共用一个值。普通注释、字符串和引号包裹的标识符中的 `:name` 不绑定；可执行版本注释内部按 SQL 分析。

```sql
SELECT :id AS id, :keyword AS keyword, :id AS repeated_id;
```

例如为 `id` 选择“整数”并填入 `9007199254740993`，为 `keyword` 选择“文本”并填入查询文字，然后点击“执行参数 SQL”。参数只能代表 SQL 值，不能替换数据库、表、列名、排序方向、SQL 关键字或整个表达式；这些结构直接写在模板中。参数执行继续使用当前标签会话，因此现有事务、临时表和会话变量仍在同一会话内。

| 类型 | 输入约定 |
| --- | --- |
| 文本 | 普通文字；空字符串、引号、反斜线按实际值处理。 |
| 整数 | 普通十进制，可带正负号，最多 65 位有效数字；不经 JavaScript 数值转换，拒绝指数和 SQL 表达式。 |
| 小数 | 普通十进制，保留精度；最多 65 位有效数字，小数位上限依据服务器为 30 或 38。 |
| 布尔值 | `true` 或 `false`。 |
| 日期 | 有效 `YYYY-MM-DD`，年份 1000～9999，不接受零日期。 |
| 日期时间 | `YYYY-MM-DD HH:mm:ss[.微秒]`，最多 6 位微秒，不接受时区后缀或零日期。 |
| 时间 / 时长 | `[-]HH:mm:ss[.微秒]`，小时 00～838，最多 6 位微秒；端点是否接受非零微秒由服务器类型决定。 |
| 二进制（Hex） | 偶数位十六进制，例如 `00ff`，不带 `0x`；空值表示空二进制。 |
| NULL | 不填写值；与空文本、空二进制不同。 |

最多 200 个不同参数，每个值最多 64 KiB UTF-8 字节，所有值合计最多 1 MiB；单条语句的占位符最多 100000 处，模板及展开后 SQL 合计各有 20 MiB 上限。孤立 Unicode 代理项会被拒绝，不静默改写输入。识别失败可重试；手动重新识别按参数名保留已填写的值。表单预览过长时只显示前 65536 字符，执行仍使用完整模板。

当前开发源码新增[本标签参数暂存](development/query-parameter-reuse-20261029.md)，默认关闭。明确勾选后，仅完整成功且原会话、正文及默认库确认一致时在内存保留一组；下次打开仍须明确填入并执行。可单独忘记副本，来源变化或关闭标签会清除；参数不写入工作区、历史或文件。本批已通过相关CLI检查和Windows／MySQL 8.4只读窗口专项；安装包、macOS及其他参数类型的原生矩阵另验，暂不发布。

静态可分析脚本会在发送第一条用户 SQL 前核对完整模板的参数、缺参、多余参数及展开预算。明确的常量 `SET sql_mode` 可以预演词法模式；无法静态确定模式的 `SET`、程序调用或可执行版本注释会提示名称预览可能不完整，可手动添加后续语句需要的参数。动态脚本执行时按每条语句完成后的协议状态继续扫描、绑定。关闭会话变量跟踪或服务器错误可能使模式无法确定；此时只执行各候选模式下语句和参数边界均一致的 SQL，实际歧义会明确停止，不能猜测引号边界。后续缺参、模式或语法错误、累积预算超限和最终多余参数错误会停止脚本，**此前已提交的语句及 DDL 不会撤销，未提交事务也不会自动回滚或重放**。静态参数校验通过同样不保证服务器后续语句成功；执行写入前须核对整个脚本，失败后先检查事务和已提交数据。

服务器错误包不提供当前事务状态，界面会显示“事务状态需核对”，关闭时继续保护该标签。可以明确选择“提交”或“回滚”；后续成功查询也会按实际协议状态更新提示。客户端不通过内部 `SELECT` 或 `DO` 探测状态，以保留 `ROW_COUNT()`、`FOUND_ROWS()` 和警告诊断，也不会把上一次事务状态当作错误后的确定事实。

参数值不写入工作台、保存查询、历史或任务记录；这些位置保留 SQL 模板，任务和历史错误不会保存可能含值的服务器详情。模板中直接写入的字面量仍属于 SQL 正文，并不会被删除。查询结果、只读快照和用户导出的结果文件可能包含实际参数值；关闭标签只释放内存结果，不删除已导出的文件。已有会话的参数识别和语句间模式读取使用协议缓存，不插入额外诊断 `SELECT`，以保留 `ROW_COUNT()`、`FOUND_ROWS()` 和警告状态；连接已经失效时不自动重放语句。

## 页内查找替换与列布局（0.6.0 开发版）

在 MySQL／MariaDB 表格的「更多 → 数据传输」或 SQLite 可编辑表格上方，可选择「复制（含列名）」。勾选时按网格显示顺序复制可见列，无勾选时复制当前单元格。普通文本含表头，DBArk 内部粘贴只读取数据行并保留原类型。

选中任一数据格后，可在同一区域选择「复制当前列」。无勾选时复制当前页这一列的值，有勾选时只复制对应行。顺序跟随网格，跳过待删除行，使用当前草稿值。复制文本没有表头，DBArk 内部粘贴仍可读取原类型。

查询结果和 SQLite 只读表或视图也可「复制当前列」。先选中该列的数据格，按当前筛选、排序和勾选范围复制已显示的结果；虚拟滚动尚未渲染的行也包含在范围内。打开固定结果时同样适用。

表格和查询结果支持「跳到行」。焦点在网格内时，可按 Ctrl＋G 或选择「编辑 → 跳到行／行列」。输入从 1 开始的当前网格行号并按 Enter，焦点会移到对应行；按 Escape 可取消。行号按当前显示顺序计算，表格只定位当前页，查询结果只定位已载入的可见行。

表标签点击“当前页查找替换”，选择文字、SQL NULL 或未填写 DEFAULT，再选择可见列范围。文字支持大小写和整格匹配，读取完整原值而非截断的单元格预览；使用上一处、下一处跳转，未渲染行会继续通过虚拟滚动显示。范围仅是当前已加载页，包含未提交草稿、排除待删除行；其它页使用“打开服务器筛选”，不会因查找悄悄扫描全库。

网格活动时 Ctrl/Cmd+F 聚焦查找、Ctrl/Cmd+H 聚焦替换。单元格编辑器、其它输入框或模态内不会触发后台查找。文字 `NULL`、实际 SQL NULL、空串和 DEFAULT 分开；BIGINT/DECIMAL 不作数值转换，二进制不参与文字搜索。

填写“替换为文字”后先“预览当前页替换”，再“确认形成替换草稿”。首批只替换有可靠键的可写 InnoDB 表的非生成 CHAR、VARCHAR、TEXT 字符串列；JSON、数字、日期、ENUM、SET、NULL、DEFAULT、二进制不会被文字替换。确认只改本地草稿，仍需原“预览修改”和集中提交才能写数据库；其它连接改过旧值时整批提交回滚。页面、目标行或已加载结构变动会使替换预览失效。查找词最多 512 字符、替换词 4096 字符，扫描和计划有 16 MiB/50000 次匹配预算，超限明确拒绝，可缩小列范围后重新预览；首批不支持用户正则或单处替换。

“表列偏好”可显隐、前移/后移并设置 64～2000px 列宽；网格也可拖动列和调整宽度。布局立即用于当前页，点击“保存表列偏好”成功后才可重启恢复；未保存或保存失败会持续标明，关闭标签前按需保存。隐藏或重排不会刷新数据或丢草稿；勾选行复制与矩阵粘贴遵循当前可见列顺序，隐藏主键仍保留数据库提交定位。至少留一列；新增列自动追加、删除列忽略旧偏好，恢复默认只重置当前表布局。

源码版可在“表列偏好”选择“冻结到此列”，横向滚动时保留从首个可见列到所选列的位置；取消冻结或恢复默认可解除。范围随移动后的顺序变化，隐藏或删除边界列会解除，不改变原数据或提交定位。查询结果的“管理结果列”也支持此操作，重复别名按原列序号区分；冻结仅当前准确结果有效，可随整理方案保存。详见[冻结列使用与验收范围](development/frozen-columns-20261027.md)，暂不发布。

在表列偏好、SQLite 列布局或查询结果列管理中，输入宽度后可点击「统一可见列宽」，一次设置所有可见列。也可点击「按内容调整可见列宽」，根据列头和最多 64 条已载入记录的预览计算宽度，自动宽度限制在 64～640 像素。隐藏列的宽度保持原样。表格沿用本机布局保存流程，查询结果仍须点击「应用列布局」。

表列偏好和 SQLite 列布局可按列名搜索，搜索只过滤设置列表，移动列仍按完整列顺序。表格和查询结果的可见列旁都有「适应内容」，只调整所选列的宽度。结果中的同名列按原列序号区分。

在表列偏好、SQLite 列布局或查询结果列管理中，可选择紧凑（24 像素）、标准（32 像素）和宽松（56 像素）三档行高。宽松档最多显示三行预览。表格行高随对象布局保存，查询结果行高随当前结果生效。

查询结果支持拖动表头边缘调整宽度，也可在“管理结果列”按原列序号输入 64～2000 像素。留空或点击“恢复默认列宽”后应用，可恢复 170 像素；恢复宽度保留列顺序、显隐和冻结。宽度属于当前查询结果，新执行使用默认宽度。

0.6.0 将本地配置升级到 schema 3，布局按连接、数据库和表独立保存，不保存搜索值、筛选、行数据或凭据。0.3～0.5 不能读取 schema 3，升级前备份完整用户目录，回退按前文使用升级前备份；不要修改版本号或删除新库。当前为开发批次，实际验收状态见 D06 记录。

## 外键值选择与关联浏览（0.4.0 已发布）

在表标签选中一个外键单元格，点击“选择外键值”或“查看关联记录”。同一列参与多个外键时，在窗口明确选择约束。窗口显示来源与目标列的有序映射；跨库目标按真实外键定义读取，不根据连接默认数据库猜测目标。

候选默认每页 50 行，可筛选、排序、切换页大小或直接跳页。选择父行后点击“使用选中关联值”，客户端复核当前外键定义和父记录，并一次更新复合键的全部列。此时只形成原表的本地草稿，其它字段及已打开父表的草稿保留；通过原表“预览修改”和“确认提交”才写入数据库。提交仍使用可靠唯一键和完整旧值冲突检测，失败不覆盖其它连接的新数据。

“查看关联记录”只显示当前行的完整外键元组匹配结果，普通筛选的“任一”不会扩大到其它父记录。NULL 或尚未填写的默认值表示没有完整关联，不发送无条件父页查询。来源只读表仍可查看关联；无可靠非空唯一键的父表当前明确拒绝分页，需要使用 SQL 查看。

反过来查看引用当前父行的子记录时，选中已存在的记录并点击表工具栏“查看子记录”。选择当前账号可见的真实外键后，可在独立只读窗口中分页、筛选、编辑筛选分组和多列排序；不改变原表或已打开子表的条件。关联目录超过50项可翻页，空目录只表示本账号本次没有可见关系。没有可靠非空唯一键的子表仍可只读查看，但翻页期间可能重复或遗漏。

窗口使用打开时父行的当前值，包括已暂存的草稿，不会提交或丢弃父表草稿；这些草稿值可能尚未对应数据库中的真实关系。缺少关联字段会拒绝读取，包含NULL则显示没有关联。父行、页、草稿、连接或活动标签变化会使窗口失效，需要关闭重开；取消读取后要等原任务结束才能继续。

整组字段均可空且可写时，可点击“清空关联值”并确认，两列或多列一起暂存 NULL。父表 SELECT 权限不足不阻止合法清空，仍会复核最新源定义；其它父表读取错误显示实际错误，不返回替代候选。约束或源行草稿变化、父行删除时拒绝旧选择，保留原草稿，需重新读取。

读取期间可取消或关闭窗口。客户端等待本次独立服务器连接结束才允许原表继续操作；取消不提交或回滚查询标签里的事务。控制连接失败时明确说明不能确认服务端任务已结束，不伪报取消成功。

## 结构修改

新建表可点击“读取字段编码目录”，为普通CHAR、VARCHAR、TEXT、ENUM、SET字段选择实际字符集与排序规则，或保持“继承表默认”。例如表使用UTF8默认，某一文本字段单独选`utf8mb4_bin`，另一字段选`latin1_bin`。重排保留字段选择，类型不兼容时提示并保留原配对，可明确清除；确认时重新读取目录并显示逐列选择及完整SQL。目录变化须返回重读，预览不创建表。此能力用于新表，不转换已有数据；[实现与当前验收](development/table-create-column-encoding-20261022.md)另列，暂不发布。

当前开发源码的新建表字段区可选“VIRTUAL 虚拟生成列”或“STORED 存储生成列”，填写例如 `` `qty` * `price` `` 的算式。可配置多个生成列，只引用它之前的普通非自增整数／DECIMAL字段；生成列固定允许NULL、无默认值、自增和自动更新时间。重排或改名后先修正提示，再核对SQL和三项确认；普通字段的主键、索引与外键可保留，生成列自身键和生成链仍未开放。切回普通字段可恢复原草稿；六实例与Windows源码表单实测及未验边界见[新建表生成列](development/table-create-generated-20261022.md)，macOS及安装包另验，暂不发布。

0.27 开发候选的新建表字段区可设置“自动更新时间”。默认“未指定（保持原创建行为）”；选择 `CURRENT_TIMESTAMP` 时，字段须为受控 `DATETIME`／`TIMESTAMP`，字段、默认时间函数及自动更新时间的精度须一致（0 至 6）。默认值也可明确选择 SQL NULL，此时字段必须允许 NULL。先修正表单提示，再准备和核对真实 SQL；预览不会创建表，确认后只提交一次 CREATE。选择“明确不自动更新”表示该字段不带自动更新子句，选回“未指定”会取消本次明确选择。该片的版本及字段范围见[说明](development/table-create-on-update-20261018.md)；本版原生窗口和实库验收尚未完成。

新建或设计表时配置字段、主键、索引和外键，先生成 SQL 预览再执行。复杂已有结构（例如生成列、表达式默认值、部分特殊索引）通过 SQL 定义编辑，避免设计器丢失无法保留的属性。数据库创建和修改也先显示 DDL。

旧“设计表”流程（0.2.0）保留没有变化的索引与外键。同名外键的定义确需修改时，预览会先删除旧外键，再执行主体 ALTER 添加新约束；这两步不能保证原子完成。若第二步失败或被取消，需根据原定义恢复外键，执行期间应暂停相关写入。必须核对预览中的警告与全部语句。下述独立“外键差异”窗口采用新的受控计划，同名替换规则见对应章节。

### 字段差异编辑（0.8.0）

新增普通字段可选择JSON类别：MySQL使用原生JSON，MariaDB核对其LONGTEXT／utf8mb4_bin和JSON_VALID校验表示。当前JSON默认值只接受无默认值或可空时的SQL NULL；先审阅SQL再执行。新增、重新识别及实测边界见[JSON字段设计](development/table-column-json-20261021.md)。

从对象树数据表操作，或表标签工具栏打开“字段差异编辑”。先读取实际定义，选择已有字段并勾选确需修改的属性，或新增普通字段、标记删除。未勾选的属性保留原值；“应用本行草稿”只暂存修改，不发送 DDL。默认值分别选择无 DEFAULT、SQL NULL、文字量或受控 CURRENT_TIMESTAMP；空字符串、文本 NULL 与 SQL NULL 不同，精确数字使用原数字文本，二进制使用偶数位 HEX。

点击“生成字段差异预览”，逐项核对只读 SQL、删除或转换风险及维护窗口确认，再点击“确认执行本次字段差异”。本次令牌只能使用一次，外部结构或连接配置改变会拒绝旧计划，必须重新读取与生成预览。该操作使用独立短连接，查询标签的事务及临时表保持；目标表有未提交数据草稿或活动操作时先阻止入口，其它表的草稿保留。

当前开发源码新增数值生成字段：在“新增普通字段”的编辑区，将“新增字段类别”切换为“生成字段”，选择 VIRTUAL／STORED、整数或 DECIMAL 及生成表达式，例如 `` `qty` * `unit_price` ``。只接受本次快照明确列出的普通精确数值字段、十进制常量、加减乘、正负号和括号；单独追加至末尾，固定允许 NULL、无默认值。先应用草稿、核对预览及三项风险确认后执行，不能据未核验结果直接重试。目录或物理身份无法确认时此类别禁用，普通编辑仍可继续。[新增实现及验收边界](development/generated-column-add-20261022.md)另列，暂不发布。

已有可空数值生成列可选择该字段并勾选“修改生成表达式”，仅填写新算式，名称、类型、VIRTUAL／STORED、NULL、备注和位置保持。先应用草稿，再核对原表达式、新表达式、完整SQL和四项风险确认。修改明确复制表并重算已有行，可能等待锁、占用磁盘或因越界失败；MySQL虚拟列同时验证旧行，不能当作无锁修改。无实际差异不发送DDL；有本表索引／约束／表达式依赖或证据不足时显示只读原因。转换、生成链和完整表达式仍待开发，详见[修改范围与实测](development/generated-expression-edit-20261022.md)，暂不发布。

界面区分已执行并核验、已执行但未核验、尚未发送，以及结果未知。取消、断线或核验失败都不等于结构回滚；保留 SQL 和结果提示，独立核对数据库后再决定下一步，客户端不会自动重放。未核验或未知时目标表页过期，已有数据草稿保留，需手工刷新。

MariaDB 某些默认表达式即使只改旁列或原生改名，也可能改变后续默认值。因此存在风险默认值时整表字段 ALTER 受保护，只有能够可靠定位并完整覆盖全部风险默认值的单批显式替换/删除才可能开放；语法本身无法可靠解析时仍只读。MySQL 5.7/MariaDB 的部分二进制文字默认值在服务器定义和目录中已丢失原字节，客户端将原值标为不可可靠解析，禁止重述该列及自动结构导出；显式替换/删除默认值和旁列操作按能力开放，但不能证明结果时仍显示未核验。不要直接把不可靠的 SHOW CREATE 文本复制用于重建。

0.8首批暂未通过此窗口开放索引、外键、生成表达式、列字符集/排序规则、可见性、空间属性、分区及表选项；后续开发能力按本节新增说明及各专项边界使用。0.8当时的版本、平台和验收范围见 [0.8 版本记录](releases/v0.8.0.md) 与 [O01 验收](../tests/integration/acceptance-o01-columns-20261014.md)。

### 索引与主键差异（0.9.0）

从对象树数据表操作或表页工具栏打开“索引与主键差异”。已有索引可按实际能力编辑、改名或标记删除，也可新增普通、唯一或主键 BTREE。逐项选择字段并用上/下移调整顺序；前缀留空表示完整字段，字符列按字符、二进制列按字节。TEXT/BLOB 必须指定前缀。主键名称固定为 PRIMARY，只接受已经 NOT NULL 的普通完整字段；MySQL 5.7 不开放 DESC。

“应用索引草稿”只暂存本行。多项差异完成后生成只读 SQL 预览，核对字段顺序、约束影响及中文风险确认，再明确执行。单纯改名使用原生 RENAME INDEX；需要重建时 SQL 会明确展示 DROP/ADD。替代支持键等组合必须整批预览通过，能形成草稿不代表能够执行；界面保留单项依赖限制的原因。

独立短会话不借用查询标签。目标表有未提交数据草稿或活动操作时阻止入口，执行前再次检查；已核验后精确刷新目标表页并重新判断可靠键。取消、断线、真实重复值错误或核验失败不能当作回滚；一次性计划不能重试，应核对实际定义后重新读取。

首批仅开放已实证五个精确基线版本、InnoDB/DYNAMIC/16 KiB 页，其它能力显示只读；全文、空间、表达式、不可见/忽略、生成及陌生属性旧索引保留原片段只读。无权读取完整入向外键目录时会说明不完整，不能据此删除可能支撑依赖的旧键。Maria 风险默认值及旧版二进制默认保护继续适用。具体版本、当前验收与限制见 [0.9 说明](releases/v0.9.0.md)。

### 外键差异（0.10.0）

在左侧对象树的数据表操作区点击“外键差异”，或打开表数据标签后点击工具栏的同名按钮。窗口读取实际外键、子表字段及可读取的父表定义，保留每条约束的“原外键片段（只读）”和受限原因。子表有数据草稿或活动操作时先处理完再进入；执行前还会检查全部已加载父表的工作区，隐藏标签里的草稿也受保护。

新增或替换外键前，先显式准备并确认已存在的支持索引。子表需要完整字段、升序、可见且可识别的 BTREE 索引，外键字段按顺序位于该索引开头；父表必须有字段数量和顺序精确匹配的完整 PRIMARY 或 UNIQUE 键。前缀键、普通非唯一父键或无法确认属性的键不能充当本批支持键。字段类型、长度、精度、字符集及排序规则采用严格相容检查。缺索引时先通过“索引与主键差异”等明确操作创建，再重新读取外键；外键窗口不会自动建索引、改字段或修复现有数据。

1. 需要另一个父表时，在“候选父表数据库”和“候选父表名称”中分别填写真实名称，点击“加载候选父表并重读”。同库或跨库均需明确目标，名称保留大小写与空格，最多添加 16 个额外候选父表。已有外键的父表按实际定义读取。加载或移除候选会重读整个快照；有草稿或本行输入时，弹窗内先选择“保留当前编辑”或“确认继续”。新读取失败时旧草稿保留供核对，旧快照不能继续执行。
2. 点击“新增外键”，或对可编辑的已有外键点击“编辑外键差异”。填写“外键名称”，选择“父表”。新名称限 64 位以内 ASCII 字母、数字和下划线，首字符不能为数字。父表列表包含当前子表本身，可直接选择它建立自引用；自引用仍需符合相同的支持索引、类型和动作要求。
3. 在“有序父子字段映射”中逐行选择“子表字段”和“父表字段”，用“添加字段映射”、移除及上下移调整复合外键。每行两侧共同组成一对，移动同时改变两侧顺序；任一侧不能重复字段。父表显示的唯一键用于核对，最终是否符合精确顺序由预览裁决。切换父表后须重新核对映射，不能把另一父表的同名列当作原列。
4. 分别设置“父键更新时”和“父行删除时”，点击“应用外键草稿”暂存本行。删除已有约束使用“标记删除外键”，在窗口内确认后也只形成草稿；“撤销外键草稿”可撤销该项。以上步骤均不发送 DDL。
5. 点击“生成外键差异预览”，核对固定只读 SQL、目标和全部警告，再逐项勾选本次显示的风险确认。最后点击“确认执行本次外键差异”，本次计划只允许尝试一次。

| 引用动作 | 选择含义 |
| --- | --- |
| 限制（RESTRICT） | 对存在相关子行的父键更新或父行删除施加限制。 |
| 不操作（NO ACTION） | 明确使用服务器的 NO ACTION 动作，界面不自动改写为 RESTRICT。 |
| 级联（CASCADE） | 让服务器按所选更新或删除动作级联处理相关子行。 |
| 置空（SET NULL） | 将相关子字段置为 NULL；映射中的全部子字段必须已经允许 NULL。 |

窗口显示当前版本已经确认的省略动作默认值，新增草稿据此初始化；用户仍需核对两项动作。修改已有外键以同一条 ALTER 中的 DROP/ADD 表示，但首批**不支持同名替换**，必须由用户指定不同的新名称，仅改变字母大小写也不接受。同批“删除旧外键再同名新增”同样拒绝；客户端不自动起新名、不拆成两次执行，也不在失败后切换策略。

风险确认共四类，按计划显示并要求全部勾选：DDL 隐式提交、维护窗口与外部 DDL 并发、删除或替换旧约束、引用动作变化。前两项始终出现，删除增加第三项，替换包含全部四项。预览和执行前会再次核对父子定义、支持键及名称；名称目录不完整时会明确提示，空目录不能证明名称可用。能形成草稿或看到可编辑按钮不代表计划一定获准执行。快照过期、连接配置或实际结构变化后，需“重新读取实际外键”并重新预览。

执行使用独立结构连接，保留查询标签事务。点击“取消外键任务”后等待原请求和资源释放结束；DDL 可能已隐式提交，取消、断线或服务器报错都不能当作已回滚。界面分别报告未投递、已执行并核验、已执行但未完整核验及结果未知。后两种情况先独立核对实际定义，不能把旧计划当作未执行重新提交；客户端不会重放。已核验后更新目标子表页，未核验或未知时标记其需要核对刷新，父表数据页不会因此自动重载。

当前受控写入的版本门槛为 MySQL 5.7.44、8.0.46、8.4.11，以及 MariaDB 10.11.19、11.4.13，并要求已确认的 InnoDB、DYNAMIC、16 KiB 页与非临时表能力。新增或替换不开放分区或分区状态未知的父子表；其它版本和未证明能力只读。未知旧语法、未知属性或不符合受控命名规则的旧外键保留原始片段及原因，不能猜测后重建。MariaDB 风险默认值、不可证明的旧版二进制默认值及不完整目录仍可能阻止计划或使完成结果无法完整核验。实际版本、平台与操作验收范围见 [验证记录](validation.md)。

### 新建表 CHECK 约束（开发中）

在“新建表”窗口切换到“CHECK 约束”页签，新增命名表级约束，填写完整表达式和生效意图；可删除或调整顺序。字段改名不会自动改写表达式，提交前请核对引用。名称和表达式原文保留，删除最后一项后恢复原无 CHECK 的建表流程。

进入原建表确认阶段后，客户端读取实际服务器能力。不支持的版本或生效状态会阻止预览，不会静默忽略条件；MySQL 5.7 拒绝含 CHECK 的设计，MariaDB 不接受本流程的逐条 NOT ENFORCED。审阅完整 CREATE，填写准确目标，并确认 CHECK 语义风险后才尝试一次；有生成列时同时保留其风险确认。未知结果或完整核验失败时先核对实际新表，不要再次创建或自动删除补救。见[实现说明](development/table-create-checks-20261028.md)与[验收记录](../tests/integration/acceptance-table-create-checks-20261028.md)，暂不发布。

### 已有表 CHECK 约束（开发中）

在侧栏普通表的操作区或表数据页点击“管理 CHECK 约束”，再点击“读取检查约束”。窗口列出名称、完整表达式、表级／列级位置和生效状态；目录无法完整核对时明确只读，不能把未知当作没有约束。

一次选择新增、修改名称／表达式、删除，或 MySQL 支持时的启用／停用。先预览固定 SQL，再分别输入准确数据库名、表名并勾选全部风险确认，最后提交一次。返回编辑会废弃原预览；快照过期或结构改变后须重新读取。表达式是否适用、已有行是否符合条件，最终由服务器检验。

DDL 可能隐式提交、扫描已有行或等待锁。取消、断线及“已执行但未完整核验”都不能当作回滚，不要重复提交旧预览。功能使用独立结构连接，同目标表有未提交草稿或活动任务时拒绝提交。MySQL 5.7 等旧版本只读；MariaDB 不提供本窗口的逐条停用。当前源码、实库和平台验证边界见[实现说明](development/table-checks-20261028.md)及[验收记录](../tests/integration/acceptance-table-checks-20261028.md)，暂不发布。

## 数据库默认编码

在侧栏悬停或聚焦数据库行，点击“数据库默认编码”，查看当前字符集和排序规则。选择实际候选配对后先预览 SQL，输入完整数据库名并确认风险后执行；此操作只改后续新建对象的默认值，不转换已有表、字段或数据，也不提交其它查询标签的事务。结果不确定时请重新读取实际值，不要重试旧预览。详见[实现与验收边界](development/database-default-encoding-20261022.md)，当前为未发布源码功能。

## 导入导出

当前开发源码可在数据库节点点击“从文件导入新表”：选择CSV／JSON及编码，完整扫描后填写并核对表名，再进入正式表设计器。扫描列出整份文件的字段，样本最多20条；默认建议可空LONGTEXT，不推断主键或保证全文件类型，请明确核对字段类型、NULL、默认值和索引。

建表完成并关闭原确认页后，点击“继续配置导入”，核对映射并执行整文件预检，无问题才可明确导入。该流程固定原文件设置和指纹，采用整文件一次提交；源文件改变会阻止提交。建表与导入是两个独立阶段，导入失败不会自动删表或重建，结果未知须核对服务器。当前仅完成类型、分轮单元及构建验证，实库和正式窗口另验，详见[新表导入边界](development/import-new-table-20261029.md)。暂不发布。

从表标签打开“导入”或“导出”。通过本机文件选择器选择 CSV、JSON 或 SQL 文件，编码支持 UTF-8、UTF-16LE 和 GB18030。

CSV/JSON 导入先检查预览并建立字段映射；同一目标字段不能被多个源字段映射。JSON 顶层必须是对象数组，数字保留原始十进制文本以免丢失精度。CSV 默认第一行为列名，`\N` 表示 NULL，反斜线开头的文本用额外反斜线转义；二进制使用 `base64:` 表示。客户端先做无损类型检查，服务器约束和错误仍会终止当前批次。

CSV 导入的“CSV 分隔符”可选择逗号（默认）、分号或制表符（Tab），请按文件实际格式选择；程序不自动猜测。有标题时表头必须非空且不重复；无标题文件关闭首行字段名选项，按列位置映射，第一条数据仍会导入。双引号包围的字段可以包含分隔符和换行，字段内的双引号写成两个双引号；末尾空列保留为空字符串。修改文件解释选项后会重新读取预览并重建字段映射，必须等待当前预览就绪、再次确认映射后才能开始导入。预览仅显示前 20 条记录，实际导入继续流式读取完整文件。该选项不影响 CSV 导出、JSON 或 SQL 文件。

CSV/JSON 默认每 500 条源记录提交一批，也可选择“整文件一次提交”。失败或取消时尝试回滚当前事务，已确认提交的批次不会撤销。原 COMMIT 或回滚结果未知时必须核对服务器，不能自动重放；触发器对非事务表或外部系统的副作用不保证回滚。

“冲突处理”默认“只新增”。需要复用已有记录时，选择“跳过已有，仅新增”“新增或更新”或“仅更新已有（不匹配跳过）”，再明确选择完整主键或可靠唯一键，并映射其全部字段。可空、前缀、表达式、生成列等不能可靠定位的键不会用于匹配；目标结构变化后需重新读取目录。匹配遵循服务器排序规则，同文件重复键按源顺序处理。更新仅主动设置已映射的非匹配键列；触发器、生成列和 ON UPDATE 仍可能改变其它列或键。其它唯一键冲突、外键和服务器警告仍会失败，不会当作跳过。

冲突执行结果分别显示已确认处理与已确认提交的新增、匹配更新、跳过已有和跳过未匹配数量。“匹配更新命令（含未变化）”包含命中但值不变的 UPDATE，不代表实际修改行数。缺少有效原任务回执时显示未确认；样本预览不代表全文件匹配结果。冲突策略和匹配键不保存到导入配置，换文件、映射、目标或应用配置后重新选择；提交方式独立保留。SQL 和 Excel 暂无本次冲突策略。

SQL 文件按顺序执行，支持 `DELIMITER`。文件结束时若仍有未提交事务则回滚并报告；已经提交的语句与 DDL 不会撤销。

导出以流式任务读取完整表，不受工作台页大小或查询显示行数限制。SQL 导出可以独立选择表结构和数据。文件先写临时输出，完成后替换目标；失败或取消时清理临时文件。

表 CSV 导出的“CSV导出分隔符”可选逗号（默认）、分号或制表符（Tab），与导入选项分别设置。包含当前分隔符、双引号或换行的字段会按 CSV 规则加双引号；NULL 仍为 `\N`，空字符串仍为 `""`，二进制仍为 `base64:`。修改分隔符后须重新选择保存文件，已选字段与顺序保持，无须重新读取字段目录。省略该选项时保持原逗号输出。已返回/勾选结果导出、完整查询流式 CSV 和 CSV ZIP 也支持这三个选项，JSON/SQL 不携带此选项。

0.8 对已证无法保真重建的 MariaDB 默认表达式、旧版二进制文字默认及隐藏属性的兼容模式拒绝含结构 SQL 导出，保留原目标文件；可独立导出数据。视图的原定义与数据导出另有兼容检查。0.7 及更早文件没有本批保护，遇到这些表须独立核对建表默认值。

## 工作台恢复和退出

明暗主题、侧边栏宽度、查询文本和标签布局自动保存。退出时有待提交数据、活动事务或运行任务会提示；配置保存失败时可返回工作台处理，也可明确选择放弃未保存配置退出。

重启会恢复工作台布局，连接需重新建立。上次未完成的任务标记失败并要求核对数据库，客户端不会自动续跑写操作。

## 会话临时对象（0.16 开发中）

在查询标签创建临时表后，SQL 补全优先使用本标签的字段；其它标签各自保持独立会话。工具栏“会话临时对象”可选择已观察名称，或输入例程/动态 SQL 创建对象的库名与表名。点击“读取会话结构”获取真实字段，可按前缀查看；“刷新缓存列表”只刷新内存列表。

自动补全不在当前会话中附加 SQL。明确读取结构会更新诊断信息，请先查看需要保留的警告。LIKE、AS SELECT、复杂变更或“会话对象待核对”提示出现后，可从该入口读回所需结构；实际名称为永久表时会恢复该名称的普通目录。默认库未知仍需使用显式库名或执行 USE，读取对象结构不会替用户切库。重连后临时表不会恢复，已有查询正文和结果不会被结构读取覆盖。

“表或视图名称”也接受永久视图，读取只确认该名称的遮蔽状态。MySQL会话若隐藏数据库生成的主键，界面会说明字段列表尚未完整确认；读取保持会话设置，按提示自行恢复显示后可重新读回完整字段。

## 0.17 常用数据工具

### 全库搜索与本地查询

在工具栏打开“全库搜索”，明确选择连接、数据库和对象范围，再切换名称、定义正文或数据模式。数据模式须选择字段并确认分批结果；对象失败会列出明细。命中记录重新核验后按只读方式定位，不能把只读命中当成可编辑表。完整范围、身份及权限限制见[搜索说明](database-search.md)。

“历史与查询”按概要分页浏览保存查询和执行历史，完整SQL或错误在明确打开时读取。保存查询列表可按“全部来源”“未绑定连接”或指定连接筛选，并与分组、名称和 SQL 正文条件叠加。切换来源会清空已勾选项并从第一页开始。每批最多检查 25 条，本批无命中时可继续读取下一批。从查询标签的“查看本连接的执行历史”切换到保存查询时，初始来源为该标签的连接。

使用“搜索保存查询”可离线检索全文及可取消正则，打开为新标签并高亮SQL的多处命中，使用“上一处命中”“下一处命中”导航；超过200处会明确提示仍有未列出命中。编辑或换源后高亮失效，须重新搜索打开。来源失效须明确换源，不自动执行正文。

当前未发布源码的“保存的查询”支持层级分组。选择全部、未分组或某个分组，可切换是否包含子组，并结合原名称／完整SQL搜索。勾选查询或“选择当前页查询”后，可跨页选择最多100条再预览移动；改名、移动及解散分组也须预览确认。解散会把整棵子树成员退回未分组，不删除查询。整理不改SQL和来源摘要，已打开的查询仍可保存到原查询；出现并发变化时先刷新核对，不自动重试。详见[分组边界](development/saved-query-organization-20261022.md)。

执行历史可填写“最短耗时（毫秒）”和“最长耗时（毫秒）”后明确搜索，两个端点均包含，支持0、相等端点和单边限制；只接受非负安全整数，留空不限。该范围比较原本地记录的耗时，与时间、来源、结果及正文条件组合，不重发SQL。修改或清除耗时后须重新搜索，不能沿旧条件续页；非法输入保留当前页面。详见[耗时筛选](development/history-duration-filter-20261022.md)，当前为未发布源码功能。

在执行历史卡片点击「查看完整 SQL」，可原地只读查看本地历史正文。长文本分段展示，点击「上一段 SQL」或「下一段 SQL」继续查看。来源连接已删除时仍可使用。查看不会打开查询标签、建立连接或执行 SQL。

保存查询卡片也有「查看完整 SQL」。无绑定或来源已失效的查询同样可以原地查看。长正文按段展示，按 Esc 可收起正文并保留列表。

点击「另存为 SQL 文件」可把保存查询直接写成 UTF-8 文件，保留原换行。选择目标后会核对列表中的原记录，期间若查询被修改或删除，本次保存会停止。无绑定或来源已失效的查询也可另存。

在保存查询列表展开「导入 SQL 文件」，选择编码后可一次选择最多 25 个文件，合计最多 32 MiB，单文件最多 20 MiB。支持 UTF-8、UTF-16LE 和 GB18030，各文件的 UTF BOM 优先于所选编码。每个文件以文件名创建独立的未绑定、未分组查询，保留原换行。任一文件读取或解码失败时整批不入库。

在同一列表勾选查询后，点击「导出所选查询为 ZIP」。翻页或搜索隐藏的勾选项也会导出。每条查询保存为一个带序号的 UTF-8 SQL 文件，保留原文和换行。每批最多 100 条，单条最多 20 MiB，正文合计最多 32 MiB。若查询已修改、已删除或无法无损编码，整个 ZIP 不会保存。压缩包仅包含 SQL 正文。

从查询页的「更多查询操作」选择「查看本连接的执行历史」，会先列出当前查询标签所属连接的历史。可以更改「历史来源」后重新搜索。主工具栏的「执行历史」仍从「全部来源」打开。

### 保存来源与执行计划

已绑定的查询可保存到原查询或另存为新查询。原记录被其它标签修改或删除时，陈旧更新会拒绝；保留当前草稿后可明确另存。保存动作不执行SQL，也不替换已有物理会话、事务或临时表。

点击“执行计划”读取当前会话的JSON计划树，可查看节点及原文。展示的是服务器估算值，并非真实耗时；普通SQL错误不会自动换一种方式重发。真正的新查询替换旧计划，保存或另存期间保留当前选择和折叠状态。

源码版另有“实际执行分析”：选区优先，无选区使用完整正文。确认窗口会显示冻结的语句、连接和实际默认库；核对后勾选风险确认，再点击“确认并实际执行”。分析可能执行查询或写入并产生副作用，客户端不自动回滚；不同服务器版本对 DML 的分析行为不同，请先使用隔离数据。取消确认不执行，服务器报错也不自动重发。MySQL 需要 8.0.18 及以上，MariaDB 需要 10.1 及以上；当前验收版本见[实际执行分析记录](development/query-analyze-20261027.md)。

实测计划返回后点击“保存计划快照”，可保存 MySQL TREE 或 MariaDB JSON 的原始结果。通过工作台“打开计划快照”选择文件，即可离线查看并“另存计划快照”，不会重跑 SQL。原有 JSON／文本估算快照继续兼容；实测文件需要支持该新格式的 DBArk。文件不主动保存原 SQL 字段和凭据，但计划条件、表达式仍可能含敏感字面值，分享前请检查。详见[实际计划快照](development/analyze-snapshots-20261027.md)，当前为未发布源码功能。

节点详情现在显示服务器提供的候选索引、使用字段、过滤条件、排序和临时表等原始属性。查找框可按名称、中文标签或属性值查找收起分支，点击上一处／下一处会展开并聚焦；Enter／Shift+Enter 切换，Escape 清空。最多输入200字符，只搜索已展示内容；属性截断时请核对原始输出。查找不会重新执行SQL，缺失字段也不代表未使用该操作。详见[执行计划属性与查找](development/explain-properties-20261022.md)，当前为未发布源码功能。

查询分支和子查询列表现在按实际包装层显示“查询分支 · 第 1 项”等位置标题；这表示服务器JSON数组位置，不是执行次序。可以输入完整分支标题查找，详情保留该包装自身的依赖、缓存标志和子查询块，未知扩展仍明确提示。见[查询分支包装](development/explain-query-branches-20261022.md)。



### 页内查找与JSON成员移动

当前页支持逐处查找、仅替换一处及正则预览；替换先进入原页草稿，再通过集中预览提交。它不搜索或更新整表，替换文本中的`$1`、`$&`按字面处理。

记录树选择非空对象后，可打开“移动 JSON 对象成员”，填写原成员序号和移动后的最终序号。按原词法成员定位，重复名称仍按序号区分；操作先暂存到本页，再集中提交。原文保留针对本地缓冲，服务器最终存储表示以重新读取的值为准。跨对象移动、模板和持久恢复仍未实现。

### 二进制与SQL结果只读

表页“单元格”、记录表单字段及双击/Enter可打开字节查看器；任意SQL结果只提供只读查看，不推测所属表或写回定位。TEXT/LONGTEXT按真实表结构或实际值识别，不因协议报告BLOB就强行转为字节。

Hex每页4096字节；只有符合原表编辑资格且完整值在预算内时，才能暂存Hex输入。超限值可分页只读查看，不能将显示片段当完整值保存。NULL、零字节和文字空串有不同含义。图片仅支持受预算限制的PNG、JPEG、静态WebP查看，不加载外部URL或活动网页；格式及精确预算见[二进制说明](development/d07-binary-cell-viewer-20261015.md)和[Hex边界](development/d07-hex-budget-20261016.md)。

组合标志期间不会触发网格清空或预览；普通TEXT输入继续使用原编辑器。已验证浏览器报告的组合状态，尚未完成所有实体输入法候选提交场景。

### 收藏与结构比较

可将对象加入收藏、安排虚拟分组及开启专注模式；应用内复制的对象链接从“粘贴对象链接”打开。新源码正在接入系统 `dbark` 链接入口，开发启动不改系统关联；系统安装与原生验收边界见[系统对象链接](development/external-object-uris-20261027.md)，暂不发布。链接要求本机已有原连接，不执行其中的SQL。表/视图打开数据页，其它定义保持只读；新建查询会接管迟到导航，防止旧对象覆盖当前意图。

“结构比较”只读比较两张基本表，可选择受支持差异并保存SQL审查稿。它不能执行结构同步，不推断重命名，也不代表整库相同。存在不能保真的选中项时，整批审查SQL撤回；不要用其中的删除部分代替完整方案。

### 全文/空间索引与XLSX

“索引与主键差异”新增受控InnoDB FULLTEXT/SPATIAL。按界面真实候选选字段，先预览，再逐项确认DDL风险并执行；已有复杂特殊索引仍可能只读，不自动改列、坐标系或物理参数。单次令牌不能重放，失败及取消状态须先核对实际定义。

表页导入导出可选择XLSX工作表、表头及字段映射；不支持旧XLS，也不承诺公式重算。导入失败或警告会停止并回滚当前批次，此前已经提交的批次仍然存在。金额、大整数、微秒、NULL和字节保留既有精度策略。

### 多CSV完整归档

查询页打开“新执行并完整导出”，选择“CSV ZIP：全部行集与执行状态清单”，选定目标后确认新执行。在当前标签同一会话执行捕获SQL一次，行集按顺序各自保存为CSV，另含状态及位置映射清单；空行集保留标题，不为取得后续结果重执行SQL。

ZIP使用不压缩STORE格式，最终容器最多10GiB、含状态至多200个结果。文件失败或取消保留原目标，不能撤销已经发生的数据库操作；不自动重连、重放或强杀续跑。CSV ZIP格式及NULL/二进制约定见[归档说明](development/query-multi-csv-archive.md)。当前CSV/JSON实库百万行与超4GiB文件层已有独立记录，不能互相代替CSV ZIP的实库大规模验证。

0.17完整入口、已验平台和条件跳过见[版本说明](releases/v0.17.0.md)；本版仍是开发预览，完整Navicat清单未完成。

## 查询结果列统计

在查询结果网格选择一列后点击“列统计”；没有活动格时默认第一可见列。有勾选时默认统计打开窗口时选中的行，也可在窗口内切换“统计列”和“统计范围”。计数区分 NULL、空字符串与文字 NULL，数值列显示精确合计与平均值；循环平均值和浮点值分别提示近似原因。可取消正在进行的统计。

切到“值分布”查看次数最多的 10 个值及其占比；其他值合计显示，NULL 单独列出。范围沿用当前筛选或勾选，切换视图不会重新查询。详见[常见值分布](development/query-result-frequency-20261103.md)。

点击某个值旁的“按此值筛选”，可把它与已有条件一起放入筛选草稿。确认应用后，筛选作用于当前结果。勾选仅决定统计范围。SQLite 中归在同一组的等值整数和实数会一起匹配。

统计仅覆盖已经返回且当前筛选后的行。出现截断提示时，不能将这些指标当作全表统计；需要全库统计时另行执行适合的 SQL。字节／未知类型只显示计数，异常原值不会生成部分合计。切换结果、标签或连接后请重新打开窗口。详情见[实现与验收边界](development/query-result-statistics-20261022.md)。


## 对比两份固定查询结果

在同一查询标签执行并分别固定两份结果，点击“固定结果对比”。明确选择左右快照和 1～8 个匹配键，再点击“开始对比”。结果显示新增、移除、修改、未变化数量；可按类别分页，点击“查看差异”检查左右字段原值。修改来源会清除旧匹配键，停止后可手动重试。

匹配键不能为 NULL 或重复，也不支持浮点、字节及未知类型；两份结果必须有一致的完整列定义。对比只用固定时已返回的数据，截断时不能代表全表；非键按原值表示比较，NULL、空串及缺少整行不同。本功能只读，不执行同步 SQL。见[语义与验收边界](development/query-result-comparison-20261022.md)。

## 生成存储过程与函数调用

对象树的过程／函数行点击“生成例程调用”，再“读取参数并预览”。核对方向、完整类型与只读脚本后，“打开调用查询”会再次读取签名，确认一致才新建查询；不改原查询或自动执行。IN／INOUT在新查询中通过“参数执行”填写精确值；零输入参数可直接明确执行完整脚本。

OUT／INOUT脚本包含初始化、CALL、输出SELECT和末尾清值，需整份执行。失败或取消可能留下本会话变量值，SET NULL只清值、不删除变量。过程和函数均可能修改数据或隐式提交，请先审阅。当前仅Windows源码类型、170项相关单元和构建通过，实库／真实窗口需本轮隔离资源授权后另验，详见[开发及验收边界](development/routine-invocation-20261028.md)；暂不发布。
