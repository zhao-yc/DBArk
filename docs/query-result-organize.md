# 整理已返回的查询结果

以下为0.29独立开发线新增功能，尚未进入公开安装包，也不属于冻结的0.28候选。原生键盘、系统剪贴板与安装验收仍待完成。

## 列头排序

查询结束后，点击可排序的列头，或将焦点移到列头按Enter/空格，依次切换升序、降序、清除。也可用“恢复原返回顺序”清除排序。

排序只处理当前已经返回的行，不重新执行SQL。结果被截断时，未返回的记录不参与排序；要取得完整数据，应使用已有的完整导出流程并确认新执行。切换结果、重新查询或更改列布局后，应按当前顺序重新选择记录。

BIGINT和DECIMAL按原精确数值比较，日期时间保留已返回的字段和微秒。文本按UTF-16代码单元比较，与数据库排序规则可能不同。无法可靠比较的二进制或未知类型不开放排序，列头提示具体原因；排序预算不扩大原有浏览、选择和导出的预算。

## 复制含列名

- 勾选记录后点击“复制（含列名）”，复制这些记录的可见列。顺序与当前排序及列布局一致，隐藏列不参与。
- 没有勾选记录时，先选择一个单元格，再点击按钮，复制该列名和值。整行复制使用行勾选入口。
- 原Ctrl/Cmd+C继续复制数据正文，不自动添加列名。

通用文本使用制表符，必要时用引号保留Tab、换行和双引号；DBArk内部类型数据继续区分NULL、空串和二进制。BIGINT、DECIMAL保持原字符串，外部表格软件如何推断类型仍取决于该软件。

排序会清空旧勾选，避免原显示位置对应到另一条记录。列布局或字节查看器关闭后，可重新点击当前单元格领取新的复制位置；旧按钮或迟到回调不能复制之前的行。表头与正文共同受50,000单元格、10,000,000字符限制，不隐式改为复制全部结果或截断内容。

复制报告失败时，不自动重试，也不保证系统剪贴板保持原状；请先检查实际内容。成功事件的RAM验证不代表系统剪贴板已验收。

实现及准确验证范围见[排序说明](query-result-sort.md)和[复制整合记录](development/query-result-header-copy-20261019.md)。
